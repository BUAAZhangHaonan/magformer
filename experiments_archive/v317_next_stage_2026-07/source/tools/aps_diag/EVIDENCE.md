## 4. 检测误差分解 (diag_err/report.md, 全量3276图, 无抽样)

AP_s(measured)=0.2642 (gap 0.7358) 反事实链分解:

| 成因 | AP_s 损失 | 占比 |
|---|---|---|
| (a) 漏检: 全图无 mask IoU≥0.5 的检测 | 0.4356 | **59.2%** |
| (b) 已匹配但 mask 质量不足 (IoU>0.5 阈值全灭) | 0.2876 | **39.1%** |
| (c) 排序 + N=100 上限 | ≤0.0124 | ≤1.7% |
| (d) 小目标 FP 挤占 | 0.0002 | 0.02% |

- **排序/上限/FP 全部无罪** (合计≤1.7%): 小TP分数中位0.746 vs FP 0.094 双峰分明; 删除全部65350个小FP只+0.0002 → topk/NMS 手段对 AP_s 无意义
- 尺寸断崖 (segm ceiling@0.5 / 中位最优maskIoU): <64px²: 0.114/**0.004**(完全不可见) | 64-256px²: 0.348/0.282 | 256-1024px²: 0.695/0.652 (基本正常)
- 漏检形态: 28.9% 纯定位miss + 14.3% box命中但mask死; box≈mask@0.5 但 mask 在高阈值崩 (0.75: box 0.327 vs mask 0.238)
- 遮挡语境: 93.8% 被漏小目标位于 ≥2× 更大 GT 框 >50% 覆盖之下 (vs 命中的 79.5%); >50实例图 recall 0.513 vs ≤50实例图 0.836; 11.9% 被大目标吸收
- 找到的小目标 mask IoU 中位 0.669, 仅 33.5% 达 0.75 — 32px 目标 1px 边界误差就损 ~6% IoU

## 5. 架构机制 (audit, 详见 diag_arch/report.md)

1. **Matcher 对小 GT 信息量为零** (matcher.py:200-244): 12544 均匀点, 400px² GT 仅 ~4.8 前景点; dice 代价信噪分离 0.3-2.4 单位 vs 背景校准噪声 ±1.9; 小目标 Hungarian 分配由噪声决定 → query 从不稳定持有小目标 → 直接解释 ARs=0.277
2. **无 stride-4 注意力**: 可变形编码器仅 res3-5 (stride 8/16/32); 解码器 cross-attn 键同; mask_features = 未经细化的 FPN res2; masked-attn 0.5 阈值使小目标 query 退化为 attend-everywhere (multiscale_decoder.py:945-1022)
3. **排序饥饿**: 无 NMS (object_mask_threshold/overlap_threshold 是死配置键, 实际 topk=100 按分数); score=cls×mean_prob_in_mask 对 12-20px 理想 mask 上限 0.95-0.96 vs 大目标 0.99; 重复大目标 mask 占满 top-100
4. **stride-4 mask 网格天花板**: 理想 IoU: 8px→0.51, 12px→0.88, 20px→0.90-0.94 (待 oracle 实测)
5. **尺度增广碾压**: min_scale=0.1, P(scale<0.5)=21% → 20px 目标变 2px 不可学
6. loss 点采样背景质量主导 (被 uncertainty 采样部分缓解); matcher 是更坏的一半
7. DCCG/AGPE 全局统计门控对小目标中性偏负

已实现但 c0 关闭的机制: matcher.scale_balanced, mask_attn_topk_ratio(+min64), scale_adaptive_alpha, DN/DCQM/enc-query-sel, SAHI tiler, copy-paste prefer_small; small_object_sample_threshold 已退役(schema 拒绝非零)。
