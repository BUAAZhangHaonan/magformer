# P3/P4 细粒度斗兽场 · 提案输入简报（2026-09-21）

三路调研已完成（`docs/research_20260921/{mask_boundary,query_existence,score_maturation}.md`），本文档把它们与五路审阅证据（`reviews_20260920/`）固化为 7 场斗兽场的输入包。每场 5 个独立 SubAgent 提案，互不可见；裁决规则全场一致。

## 0. 全场统一规则（每份提案必须遵守）

**架构与现状**（所有提案的前提，不得改动塔与整体范式）：
- Swin-T RGB + MobileNetV3-L 深度塔 + DCCG 融合 + AGPE + MSDeformAttn 像素解码（stride 8/16/32 + stride-4 层）+ 8 层 Mask2Former 式解码器，200 queries，512² 掩码画布（stride-2）→ 双线性 ×2 → 阈值二值化；单类；1024² 输入。
- F1@128K 封存基线：segm mAP 0.8715 / AP_s 0.2675（trainer 口径，120K）；rescore 口径缺口分解：掩码内容 +27.1 / 渲染链 +4.0 / 检测存在性+分数 +16.5（0.768 天花板）。
- 已修复并验证的基线组件：AIM 匹配（已去 16-GT 帽，全覆盖）、copy-paste 深度通道（已可启用）、inference_topk/inference_mask_threshold 已 config 化。

**预算红线**：训练开销 ≤ +20% ms/it（当前 1.44-1.60 s/it 4 卡 DDP）；推理开销 ≤ +10ms（目标 ~100ms）；显存 ≤ 24GB/卡。**GPU 优先**：提案的计算必须给出 GPU 实现路径；仅当 CPU↔GPU 传输时延超过计算收益时才允许 CPU 侧。
**提案必备**：(a) 机制因果链（为什么攻击根因而非症状）；(b) 与二分匹配/set-prediction 的兼容性论证；(c) 理论收益上界与依据（引用调研数字需注明出处）；(d) 开销预算（训练 ms/it、推理 ms、显存 MB，给出估算算式）；(e) 正确性验证方案（单测/冻结基座探针/短训门）；(f) 与其它场胜出方案的叠加兼容性说明。
**判分**：理论收益 × 置信度 ÷ 开销；推理近零开销方案同分优先。纸面裁决取 1-2 名进实验室（冻结基座探针或 ≤16K 短训），实测门在裁决书里按场定义。

## 1. P3-a 掩码边界监督（主攻"12544 点采样对边界无约束"）

- 证据锚：CF1 反事实 +27.1pt；10px 目标边界每次迭代仅 ~4-47 个采样点且不落在边界上；±1px 膨缩都变差（抖动非偏移）；高 IoU 段崩塌（@0.75=0.247 / @0.9=0.018）。
- 调研输入：mask_boundary.md Top-5 —— 边界带过采样+不确定性采样（M2F 原生 importance sampling 不掉点；PointSup ~10 点/目标≈全监督 94-98%）、Kervadec 距离图边界损失（ISLES 小病灶 +14.8pt DSC）、Boundary DoU（尺度自适应带宽）、渲染链软标签（针对 27.1pt 缺口按构造定义）、DCT-Mask（第二阶段）。反面：RefineMask 收益集中大目标；固定 trimap 带宽对小目标失真；边界损失须 ramp 防塌缩。
- 场内问题：在 M2F 逐点 BCE+Dice 框架内，如何让小目标边界获得与大目标边界同量级的梯度密度？提案应覆盖点采样策略与损失形式两个子轴，可组合。
- 实测门候选：冻结 F1 基座 + 只换损失 8K 短训，看 matched IoU 中位（0.635→?）与 AP_s@0.75。

## 2. P3-b 小掩码表示与解码（<32px² 在 512 画布 2-3 cell）

- 证据锚：渲染链实测 4.0pt（CF2−CF1）；<32px² 链@0.5 仅 44% 可过 IoU≥0.5；逐目标 oracle 阈值链上限 0.842；stride-1 结构上限 1.000（+23.2pt 在本缺口之外）。
- 调研输入：DCT-Mask 频域头（AP@75 +2.1、近零推理开销）、软掩码导出/亚 cell 细化、面积自适应二值化阈值。反面：朴素加固定分辨率反而退化（34.7→32.5）。
- 场内问题：在推理预算 +10ms 内，如何提高 2-3 cell 目标的可表达掩码质量？（表示形式/解码分辨率/软输出/面积自适应阈值，任选组合。）
- 实测门候选：渲染链级离线模拟（R2 的 D 段方法）+ 阈值扫描已 config 化，短训验证表示类改动。

## 3. P3-c 边界稳定性（训练动力学）

- 证据锚：hires 组（stride-2 头+末层注意力）20× lr 峰值 2e-4、128K 时仍 1.21e-4（主组 6.1e-6），噪声球 20×；边界像素是最高方差预测；ce/mask/dice 自 24K 统计平坦；R4 退火尾段估值 +1.0~1.25pt。
- 调研输入：lr 分组退火、边界定向 EMA、层间一致性（×9 深监督）。
- 场内问题：如何在不动损失形式的前提下，把边界抖动里的"纯噪声"分量消掉？（lr 日程/参数分组/EMA 策略/一致性正则。）
- 实测门候选：128K 基座 + 分组退火 16K 对照（R4 的收尾臂即其最小版）。

## 4. P4-a 匹配稳定性残余（AIM 之后）

- 证据锚：AIM margin 0.13σ→2.43σ 已落地；但 o2o 匹配下小 GT 供给稀缺（每步 0.85 可见）；调研 B 反面：naive o2m 3300 query 从 32.6 崩到 8.4；去噪无隔离=作弊；稠密 query 不去重毒化 o2o。
- 调研输入：CDN-mask（去噪组正负样本天然捆绑覆盖×分数）、Group DETR 分组 o2m（Mask2Former 唯一公开数字 38.5→39.7，+18% 训练时间）、H-DETR。调研 C：o2m 增密必须与质量感知损失（DEIM-MAL）同 commit。
- 场内问题：在 AIM 之上，如何安全地把每个小 GT 的正样本供给 ×K 而不毒化 o2o 主匹配？（分组/隔离/辅助支路丢弃策略。）
- 实测门候选：小模型或 128K 基座 16K 短训双臂（±o2m 支路）。

## 5. P4-b 覆盖与 query 预算（38.1% 无检测）

- 证据锚：R2b 种子实验——probe 定位 76.3% 小 GT、64 种子 query 覆盖 92.1% IoU≥0.5，但 cls 0.22-0.29 导不出去（覆盖可解、分数必须捆绑）；P6 门控只被末层消费（前 7 层粗网格 attend-everywhere）；<32px 在 stride-4 仅 2-3 cell。
- 调研输入：DQ-DETR/Dome-DETR/HGSQ 热图预算家族（AI-TOD-v2 +3.3 AP）、CDN 去噪查询、门控多层化。反面：推理端热图头非零开销需训练期规避。
- 场内问题：如何让"会画小目标的 query"存在且被选中？（种子/预算/门控扩层/出生先验，必须与分数成型捆绑设计。）
- 实测门候选：冻结基座 + 种子注入 + MAL 分数绑定探针（R2b 协议复用，看分数能否脱离 0.29）。

## 6. P4-c 曝光与分数成型（0.85 可见/步；TP 分 0.29 vs 0.80）

- 证据锚：小目标像素份额 0.124%、损失点份额 0.1-0.4%；事后抬分全灭（重标定 -13.1 / score=IoU -11.9）；<64 det 池 hard-FP 80.5%；copy-paste 已修复可启用（文献 +2~5pt）；深度对比度 1.5σ 上限约束。
- 调研输入：DEIM-MAL（质量感知分类目标，~10 行，增密必配）、尺度分桶 EFL+Seesaw、RS Loss/Rank-DETR 排序目标、copy-paste 参数网格（尺度分层贴入、质量过滤入库、max_paste {4,12,20}）。反面：NorCal/FRACAL 类类先验方案不适用（尺度尾 hard-FP 与 TP 同类同分布）。
- 场内问题：训练期让小目标分数成型的最短路径？（损失目标/分桶 focal/排序项/贴入参数，可组合；与 P4-a 的 o2m 必须打包论证。）
- 实测门候选：10-15K 单因子开关看小桶 TP 分数中位位移 + 固定池 FP 率。

## 7. P4-d 导出与分数融合（topk 切割 × maskness 压分）

- 证据锚：topk-100 在 mask 融合前切掉存在性（c0 实测 topk200 +0.55pt，待 128K 校准确认）；score=cls×maskness 结构性压低小掩码（matched p50 0.613/0.723/0.821 随桶单调；理想小掩码 maskness 上限 0.95-0.96 vs 大目标 0.99）；CQTR 训练自由重打分 APs +1.95~3.81（9 检测器全升，零训练成本）。
- 调研输入：CQTR 轨迹重打分、maskness 解耦/尺度归一、尺度感知导出配额。反面：事后单调重标定不改 AP（排序不变性）——只允许改变排序或存在性的机制。
- 场内问题：在"不训练"与"近零开销"两个档位上，导出端还能收回多少？（重打分特征、融合公式、配额。）
- 实测门候选：封存权重离线即可验证（零训练）。

## 执行顺序（考虑依赖与卡位）

P4-d（零训练，封存权重直接验证）→ P3-a 与 P4-c（主攻双山，互不阻塞，先纸面后短训）→ P4-b/P4-a（依赖 P4-c 的分数绑定结论）→ P3-c（与收尾对照臂合并跑）→ P3-b（第二阶段）。校准指标（topk200/阈值/raw-EMA，今晨自动产出）先落入 P4-d 与 P3-b 的基线。
