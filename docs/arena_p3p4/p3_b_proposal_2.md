# P3-b 提案 #2：ACD——面积守恒亚 cell 解码栈（Area-Consistent sub-Cell Decoding）

提案人：#2（独立撰写，未读本场其它提案）· 日期：2026-09-21 · 场：P3-b 小掩码表示与解码（**第二阶段**）
基线：F1@128K EMA segm mAP 0.8744 / AP_s 0.2700（`docs/2026-09-21-f1-128k-calibrated.md`）

## 0. 一页摘要

**主张**：4.0pt 渲染链缺口的主要成分是"常数 0.5 面积多数决"对 coverage 语义场的**有偏求逆**，而非 cell 信息量不足的全部。P3-a BAS-CL+ 把 512 场的语义校准为 coverage（avg_pool 2×2 软标签，标签场求和=GT 面积），这使推理端可以做**无 oracle 的逐目标面积守恒求逆**——链模拟已给出该家族上界（逐目标 oracle 阈值 0.842 vs 现行 0.807）。ACD 用三个可独立杀线的组件回收这一段：

| 组件 | 机制 | 训练 | 推理 | 性质 |
|---|---|---|---|---|
| A1 AC-τ | 逐目标面积守恒阈值：\|M(τ*)\|=Σm 的 1-D 根找 | 0 | +≤1.0ms | 核心，零训练 |
| A2 CRSA | 逐 2×2 块覆盖守恒分配（亚cell 抖动：每块保 round(4c) 个子像素，按双线性场排序放置） | 0 | +1.5~2.5ms | A1 的构造性强化，消融臂 |
| A3 SSR | 离线一次性训练的 3 层卷积亚cell 精修器（GT coverage→GT 掩码对，主栈外训练） | 主栈 +0%（离线 ~30min 一次性） | +0.5~1.0ms | 可选，sim 门后接线 |

**中心收益主张**：链级（完美场）0.807→0.817~0.835（bucket-τ 线→逼近 oracle 0.842）；**生产兑现 +0.3~1.0pt AP_s**（上沿 +1.5 若 A3 过门），收益集中在 AP@0.75-0.95 与 <128px² 子桶。**全部组件先离线模拟判生死（零训练、零接线），接线有逐位 no-op 门。**推理合计 ≤4ms，叠 TREX+（≤2ms）后总 ≤6ms，红线 8ms 内。

六部分契约：§1=(a)，§2=(b)，§3=(c)，§4=(d)，§5=(e)，§6=(f)，§7 预注册杀线。

## 1. (a) 机制因果链

### 1.1 4.0pt 链缺口的构成分解

CF2−CF1 = 0.6033−0.5636 = **4.0pt**（检测集合/分数/其余掩码全冻结，只换已匹配小目标的掩码；R2 §D5）。分桶：<64 +2.2pt、64-256 +4.8pt、256-1k +3.9pt。机制上这 4.0pt 分三段：

| 段 | 机制 | 数字锚（链模拟，R2 §D3，GT 穿精确生产链） | 占比估计 |
|---|---|---|---|
| (i) 亚cell 信息丢失 | 512 画布每个 cell 是 2×2 块的 coverage 均值，块内位置信息被销毁；任何基于该场的重建只能做 Bayes 猜测 | 加权链级 0.807 → stride-1 = 1.000，总差 19.3 frac-pt；其中 oracle-τ 之外的 15.8 frac-pt 是本段 | 大头，但主体在远期（stride-1 结构上限 +23.2pt 在本缺口之外） |
| (ii) 常数 0.5 多数决偏置 | 阈值固定问"该 cell 是否多数被覆盖"，而非"重建该目标的面积"；coverage 0.3-0.5 的 cell 是目标的真实面积质量却被整块丢弃 | <32px²：@0.5 frac(IoU≥0.5) 仅 0.443（p50=0.400）；逐目标 oracle 阈值 0.807→**0.842（+3.5 frac-pt）**；分桶自适应仅 +1.0（0.817）→ 收益必须**逐目标** | 本提案主攻段，链级上界 +3.5 |
| (iii) 放置算子次优 | bilinear+常数阈值作为 coverage→二值的求逆算子，不利用块间 coverage 梯度做面积守恒的块内放置 | 未单独测量（本提案 §5 的 S1 模拟首次量化：CRSA/SSR vs AC-τ 的差即本段） | 待测，预计次级 |

**机制指纹（为何判定主因是 (ii) 而非别的）**：CF1 vs CF2 的损失**全部集中在高 IoU 阈值段**——AP@0.5 两者逐位相同（0.6035/0.6036），@0.75 起 CF1 才开始落后（0.6023→0.5267@0.9→0.3107@0.95 的坍缩曲线）。面积守恒缺失（小面积系统性低估）恰好在高 IoU 段定价，@0.5 不可见——与 (i)（形状信息丢失，会在所有阈值段均匀损失）的签名不同。另外 D3 显示 0.45 与 0.5 链级并列最优（0.808/0.807）而 0.4 反而 0.798：**全局平移阈值没有红利，红利只在逐目标自适应**——这直接解释了 128K 实测 0.45 +0.09/0.40 −0.13（噪声内）的负结果，并把它从"阈值机制已死"改写为"全局阈值已死，逐目标未试"。

### 1.2 为什么其它路线救不了这一段（因果排除）

- **训练侧（P3-a）救不了**：CF1 的构造就是"完美内容穿现行链"——即使 head 输出理想 coverage 场，0.5 求逆照样把 <32px² 目标 56% 打到 IoU<0.5。BAS-CL+ 改变的是场的**语义**（coverage 校准），不改变求逆算子；但它使 Σm 成为 GT 面积的无偏估计（coverage 标签场求和=GT 面积），**恰好是逐目标面积守恒求逆的使能条件**——这是本场声明为第二阶段的因果理由（§6）。
- **全局阈值已实测死**（见上）；**形态学后处理已实测死**（F 探针：<64 膨胀 0.652→0.476、侵蚀→0.256，边界误差是抖动不是偏置——但注意该探针在**未校准**生产掩码上做，且膨胀/侵蚀是全局算子；逐目标面积守恒是每掩码自适应的双向修正，不同机制，S2 探针直接判）。
- **朴素加分辨率反面锚**：Mask R-CNN 28²→112² 固定分辨率 34.7→32.5（调研 [14]）——ACD 不加画布、不加容量，只换求逆算子。
- **DCT-Mask 入主栈被否**：COCO AP_S 仅 +0.5（AP@75 +2.1）[12]，训练 +10% 级超本场 +5% 预算，且其收益证据集中在中大目标高 IoU。其"频域条件化解码"思想以 A3 的预算纯净形式保留（离线小网，主栈零成本）。

### 1.3 各组件回收哪段

- **A1（AC-τ）回收 (ii)**：把"常数多数决"换成"逐目标面积等式"。对紧致形状（单类工业零件的主流形态），IoU 最优阈值近似满足面积守恒（对称边界误差下最优水平集面积≈GT 面积；D3 中 <32/<128 子桶 oracle 方向即降阈值=补面积）。oracle-τ +3.5 是其上界，bucket-τ +1.0 是其下界。
- **A2（CRSA）回收 (ii)+(iii)**：面积守恒下沉到每 2×2 块（每块保 round(4c) 个 1024 子像素，按双线性场值排序放置）——总面积守恒按构造精确成立（免根找），且块内放置利用块间梯度，比全局 τ 的放置更优。对 <32px²（2-3 cell）目标，失效模式从"整块面积塌缩"变为"±1 子像素放置抖动"，后者 IoU 容忍度高得多。
- **A3（SSR）回收 (iii)+(i) 的可学切片**：以 GT coverage→GT 掩码对训练的 Bayes 重建器（块内位置的先验放置），是 +15.8 frac-pt 亚cell 缺口在"不动主干、不加画布"约束下唯一可碰的路线；因证据弱（DCT-Mask AP_S +0.5 反面锚）而设为可选臂，sim 门不过不接线。

### 1.4 与 P3-a 的会计不重叠

CF1 在现行解码器下测得；ACD 落地后 CF1 需以新解码器重渲染（CF1_ACD ≥ CF1 预期），CF2（精确 GT）不变——两场收益按 CF 构造天然分账：P3-a 吃 27.1pt（内容），ACD 吃 4.0pt 内的求逆段（≈1~3.5 frac-pt），无双重计费。

## 2. (b) 与渲染链 / 导出契约 / TREX+ 的兼容性

### 2.1 代码落点

改动全部位于二值化一步之内，上游（topk、gather、bilinear×2、sigmoid）与下游（bbox、打包、传输）逐位不动：

- 生产路径：`experiments_archive/v317_next_stage_2026-07/source/magformer/models/magformer/gpu_postprocess.py` `postprocess_tensors()` L204-216（interpolate→sigmoid→`mask_probs > mask_threshold`→maskness→融合）与 `arch.py` `_inference_raw` L1557-1572（eager 路径，逐位一致）。阈值已 config 化（`inference_mask_threshold`，arch.py L85/124/657）。
- 新增 config 键 `inference_mask_decoder: {legacy, ac_threshold, crsa, ssr}`，默认 legacy=现行链逐位一致；`inference_mask_threshold` 保留为 legacy/回退值与 A1 的 clamp 锚。
- A1 只替换 `mask_probs > τ` 的 τ 为逐掩码向量（直方图 CDF 根找，张量算子，无 host sync）；A2 在其后追加逐块 rank+select（固定 4 元排序网络，纯 elementwise）；A3 在小面积 ROI 缓冲上跑冻结小网（固定 (32,1,64,64) 缓冲，mask 填充）。

### 2.2 导出契约不变量（全部保持）

- 输出结构不变：uint8{0,1} (K,1024,1024) + scores float32 + category_ids + GPU bbox（`compute_bbox_xyxy_gpu` 消费二值掩码，语义不变）；空掩码→bbox_valid=False 跳过（ACD 下若守恒面积 <1px 仍输出空，契约一致）。
- 传输/打包路径（pinned ring、bit-pack、deferred export）零改动——它们消费的是最终 uint8 掩码。
- CUDA graph 兼容：现行 `mask_threshold` 是"baked into graph constants 的 python float"；A1/A2/A3 全部固定形状、无数据依赖分支（histogram 是固定 128 bin 的 atomicAdd；CDF 扫描是 7 步张量二分；排序网络无 divergent branch），可捕获性不降。

### 2.3 maskness 耦合与双掩码打分（关键交互守护）

现行 `final = cls × mean(mask_probs inside binary mask)`。A1/A2 会把低概率子像素（probs 0.25-0.5）纳入小掩码，直接压低小掩码 maskness → 加重已知的"小掩码分数结构性压低"（score p50 0.613 vs 0.821）。**守护：双掩码打分**——导出掩码用守恒版，maskness 在 `{probs>0.5} ∩ 导出掩码`（高置信核）上计算，为空则回退导出掩码均值。大掩码 τ*≈0.5 核≈掩码（分数几乎不动），小掩码分数不因求逆改善而被罚。此为默认；备选臂是交给 TREX+ 的桶中位锚定吸收（每桶 median(g)=1 数学上抵消桶内系统性平移），但双掩码自包含、不依赖他场存活。

### 2.4 TREX+ 预算分摊与次序

- 预算：TREX+ 核心 ≤0.5ms、含特征 ≤2ms；ACD ≤4ms（§4）；合计 ≤6ms ≤ 红线 8ms（总 10ms 框内）。
- 次序：ACD 改变掩码内容与（受守护的）maskness → **TREX+ 的常数（β 扫描、z5 内外掩码度）必须在 ACD 落地后重拟合**（其 Phase 1 特征转储 ~2h 重跑，零训练）。若 TREX+ 先落地，ACD 的 W1 门在 TREX+ 打分导出上复验。双掩码的"核 maskness"与 TREX+ z5（m_int/m_bnd）同源互补，重拟合后信息只增。
- 双方都以"关=逐位一致"为 Gate 0，叠加上可独立归因。

## 3. (c) 理论收益上界与依据（链模拟数字锚定）

### 3.1 完美场（D3 协议 = 后 BAS-CL+ 理想场）

D3 的输入是 GT 穿链的 coverage 场——**这正是 BAS-CL+ 校准后模型场的理想极限**（标签即 avg_pool 2×2 coverage）。锚点全取 R2 §D3：

| 解码器 | 加权链级估计 | <32px² frac≥0.5 | <128px² frac≥0.5 / ≥0.75 |
|---|---|---|---|
| 现行 0.5 | 0.807 | 0.443 | 0.755 / 0.508 |
| 全局 0.45 / 0.40 | 0.808 / 0.798 | 0.600(@0.4) | 0.846 / 0.587(@0.4) |
| 分桶自适应 τ | 0.817 | — | — |
| **逐目标 oracle τ** | **0.842** | — | — |
| stride-1（远期，场外） | 1.000 | 1.000 | 1.000 |

- **A1 上界 = oracle 0.842（+3.5）**，下界 = bucket 0.817（+1.0）——AC-τ 是 per-mask 自适应，构造上 ≥ per-bucket；对紧致形状近似 oracle（方向性证据：D3 中最小子桶 oracle 方向=降阈值补面积）。声明为假设，S1 模拟证伪。
- **A2 ≥ A1（期望）**：面积守恒按构造精确 + 放置更优；<128px² frac≥0.75 的合理落点 0.58-0.65（@0.4 的 0.587 是"全局平移+无守恒"已达线）。
- **A3**：无文献直接数字；最近的反面/正面锚 DCT-Mask AP_S +0.5、AP@75 +2.1 [12]、PatchDCT 再 +0.7-1.3 [13]。上界受 (i) 段可学切片约束，S1 直接测。
- <64 桶内证据：自适应（选 0.4）0.371→0.446（桶内 +7.5）。

### 3.2 生产兑现折损模型（算式）

```
实现收益 ≈ 链级收益(frac-pt) × 匹配检测覆盖系数 × 校准残差系数 × 分数阻尼系数
```

- 链级收益（A1+A2）：+1.0~2.8 frac-pt（S1 实测替换）。
- 匹配覆盖：现 38%（0.2925/0.768），栈全落地后 0.5-0.7 量级；小桶 rec@0.5=12.2%（<64）钳制最小桶兑现——**兑现主体在 32-256px²**（32-64 链 frac≥0.5 @0.5→@0.4 = 0.866→0.955，且 64-256 桶有 761 个 matched）。
- 校准残差：Σm vs GT 面积的偏差中位（S0 探针实测；BAS-CL+ 后预期 |Σm−A|/A 中位 ≤0.2-0.3）。
- 分数阻尼：双掩码打分后趋近 1（无阻尼），保守取 0.8-1.0。

**中心主张：+0.3~1.0pt AP_s**（生产、栈内、EMA）；上沿 +1.5（A3 过门）；机制指纹预测收益集中在 AP@0.75-0.95 与 <128px² 桶（S1/W1 逐段核验）。同时 <64/64-256 matched IoU p50（0.635/0.674）预期 +0.01~0.03。

### 3.3 不主张什么（诚实边界）

不碰 27.1pt 内容（P3-a）、不碰 16.5pt 检测集合（P4-b/c）、不碰 +23.2pt stride-1 结构上限（远期）；R2 对本块的总评级"5~7.5pt（缺口 11-16%，真实但二阶）"中，ACD 只认领求逆子段（≈4.0pt 缺口的 25-70% 兑现），DCT 类内容增益不计入本场主张。

## 4. (d) 开销预算

### 推理（每图，bs=1，topk=100，1024²，A100 级 1.5TB/s 带宽，内存_bound 估算）

| 组件 | 算式 | ms |
|---|---|---|
| A1 AC-τ | 512 网格 quantize+histogram：100×512²=2.62e7 元素 ×8B 流量 ≈210MB ÷1.5TB/s ≈0.14ms；+atomic 开销与 7 步 CDF 张量二分（100×128，可忽略）×3 安全系数 | **≤1.0** |
| A2 CRSA | 1024 网格：1.05e8 元素；4 元排序网络（5 对 min/max）+k 比较+选择 ≈6 遍 ×4B ≈2.5GB ÷1.5TB/s ≈1.7ms；融合核 ≤4 遍 | **+1.5~2.5** |
| A3 SSR | 固定 (32,1,64,64) ROI 批：32×64²×16ch×3 层×3²×2 ≈0.11 GFLOP（计算 0.01ms）+2 次 gather/scatter | **+0.5~1.0** |
| **合计（A1+A2，默认全开）** | | **≤3.5（声明 ≤4）** |

叠加 TREX+ ≤2ms → 总 ≤6ms，红线 8ms 内余 ≥2ms。随 topk 线性缩放；与现管线共池（mask_probs 张量已存在，无新增大分配）。

### 训练 / 显存

- A1/A2：**0 ms/it、0 显存增量**（纯推理算子）。栈已占 6-11%，本场不新增。
- A3：主栈训练图外冻结模块——**栈训练 +0%**；离线一次性训练：train split GT 目标裁块 ~5-10 万样本、4ch→16ch×3 conv，单卡 ~20-40min、<2GB 显存，一次性成本。
- 被否方案（诚实记录）：DCT-Mask 入主栈（+3FC/L1）估 +1~2% ms/it，证据弱（AP_S +0.5）且占栈预算，否。

## 5. (e) 正确性验证方案（全部先离线可判，零训练先行）

### U. 单测（CPU/GPU，接线前）

1. **no-op 逐位回归**：`inference_mask_decoder=legacy` 时输出 dets.json 与现行 md5 一致（沿用 TREX+ Gate 0 纪律）。
2. A2 守恒精确性：每掩码 Σ(binary)==4·Σm(512)（±4 舍入）；确定性（排序网络固定序，CUDA graph 重放两次一致）。
3. 空掩码/bbox_valid 契约；τ* clamp [0.30,0.70] 边界；双掩码打分空核回退路径。

### S1. 链级离线模拟（D3 协议扩展，先验判读，零 GPU 训练）

对 2000 个小桶 GT coverage 场跑解码器全家 {0.5, 0.45, 0.4, bucket-τ, **AC-τ, CRSA, SSR**, oracle-τ}，报逐子桶 frac≥0.5/≥0.75 与加权链级。**判读数字（预注册）**：
- AC-τ ≥ 0.817（bucket 线）且 <128px² frac≥0.5 ≥ 0.80（@0.4 的 0.846 为参照）——不过即杀 A1；
- CRSA ≥ AC-τ 且 <128px² frac≥0.75 ≥ 0.58——不过则 A2 降为 A1；
- SSR ≥ CRSA+1.0 frac-pt——不过则 A3 不接线（null 报告也是交付）。

### S0. 生产场校准探针（封存 128K EMA，零训练，dump 一次）

`include_raw_tensors=True`（arch.py L1584-1586 已有 mask_probs/mask_logits 出口）dump 全 val 的 512 概率场：测逐桶 |Σm−A_GT|/A 中位。**使能门：<128px² 中位 ≤0.30**——不过则本场保持 stage-2 等待 BAS-CL+ 落地后复测（这正是第二阶段时序的定量化）。

### S2. 解码器换装 rescore（R2 CF 机器复用，零训练）

对 matched 检测（R2 §D5 协议）把导出掩码换为各解码器版本，重算 rescore AP_s 与 matched IoU——**接线前拿到生产兑现的真实数字**。判读：A1+A2 换装 ≥ +0.2pt 才进入接线；< +0.2 → null 收场（发布负结果，关闭求逆分支，与 128K 阈值扫描同理但口径升级为逐目标）。

### W1. 接线与全 val 门

ΔAP_s ≥ +0.30（与 TREX+ Gate C 同标尺）且 AP_m/AP_l/mAP 回退 ≤0.1；分桶报告 <64/64-256 matched IoU p50 与 AP_s@0.75/@0.9（机制指纹应在此两处显形）；TREX+ 常数重拟合后复验。

## 6. (f) 与其它场叠加兼容性与时序（第二阶段声明）

| 场 | 关系 | 处理 |
|---|---|---|
| **P3-a BAS-CL+**（已裁决） | **使能依赖，非竞争**：coverage 软标签使 Σm 成为 GT 面积的无偏估计（标签场求和=GT 面积，语义与 A1/A2 的消费端逐位对齐）；CF 会计分账（§1.4）。ACD 反过来固化 BAS-CL+ 的收益出口（校准的场需要正确的求逆才兑现在二值掩码上） | **进场时点 = BAS-CL+ 16K 门通过后**（S0 探针可随时先跑，数值早银行化） |
| **P4-d TREX+**（已裁决） | 消费其上游内容；maskness 交互由双掩码打分守护；z5 与核 maskness 同源互补 | ACD 先落或后落均可，TREX+ 常数在 ACD 之后重拟合（~2h，零训练）；预算 ≤6ms/8ms |
| **P3-c HDA+**（已裁决） | 正交互利：画布键退火降场噪声 → Σm 校准更稳 → S0 通过率升 | ACD 在退火检查点上评估；HDA+ 的 byte-equal 断言不受影响（ACD 在推理侧） |
| **P4-a/b/c**（已裁决/训练侧） | 无共享表面（query/匹配/损失/分数流），构造性正交；P4-b 增大小检测供给只放大 ACD 的兑现面（topk=100 固定缓冲，无成本爆炸） | 无需协调；P4-c 落地后 W1 复验一次 |

## 7. 诚实风险清单（预注册杀线）

1. **校准依赖是软肋**：BAS-CL+ 若 16K 门未过，S0 不过，本场兑现带塌缩到 ~0——已用 stage-2 时序+双门显式声明，不藏。
2. **细长件面积守恒过冲**：极端长宽比零件的最优阈值偏离面积等式——τ* clamp [0.30,0.70]（常数取自 S1 sim 的 train 侧，不碰 val）+ A2 的逐块粒度天然缓解；S1 分形态报告。
3. **A2 边际可能小**：A1 已拿走多数 (ii) 段收益——故 A2 是消融臂自带杀线（S1 不达标降级 A1），栈不为其付维护成本。
4. **A3 先验风险**：学到的可能是数据集形状先验而非逐件放置——S1 在 val GT 上测泛化 + 训练加 coverage 噪声增广（噪声模型从生产场偏差拟合）；不过门不接线。
5. **收益集中高 IoU 段**意味着 AP_s 主值变动可能小于 AP@0.75/0.9 的变动——判读以分阈值曲线为准，防"主值平=无效"的误杀，也防只报好看段（全曲线归档）。
6. 本提案全部数字为链模拟/文献锚定的纸面推断，兑现以 S2/W1 实测为准；null 结果按 §5 预注册发布。
