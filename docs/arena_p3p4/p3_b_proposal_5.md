提案人 #5（独立，未读同场其它提案）。场：P3-b 小掩码表示与解码，**第二阶段**（BAS-CL+ 收敛后进场）。
一句话：**渲染链 4.0pt 缺口里 ≥87% 是"0.5 固定阈值对低峰覆盖场的系统性侵蚀"，不是插值/网格；P3-a 的 coverage 软标签恰好把 Σmask_prob 变成 GT 面积的无偏估计，使逐掩码面积守恒二值化（AMB）成为免-oracle 收割这 3.5pt 上限的规则——零训练、+2~3.5ms、可离线先验、开关关闭即逐位回到基线。**

## (a) 机制因果链：4.0pt 链缺口的构成分解与本方案回收的段落

### a.1 缺口分解（全部锚 R2 报告 `reviews_20260920/r2_maskiou/report.md` D3/D5 段）

CF2−CF1 = 4.0pt（0.6033−0.5636，完美内容下链代价）。用 D 段链模拟（GT→INTER_AREA→512 coverage→bilinear×2→阈值，2,000 小桶 GT）按人口加权得链级估计：

| 规则 | 链级 AP 估计 | 相对固定 0.5 |
|---|---|---|
| 固定 0.5 | 0.807 | — |
| 固定 0.45 / 0.40 | 0.808 / 0.798 | +0.1 / −0.9 |
| 分桶自适应阈值 | 0.817 | **+1.0** |
| **逐目标 oracle 阈值** | **0.842** | **+3.5** |

交叉验证到 CF 口径：CF1@0.5=0.5636，阈值行 +3.5pt → 0.5986 ≈ CF2=0.6033（差 ≤0.5pt）。**结论：4.0pt 缺口 = 阈值规则行 ~3.5pt（85~90%）+ 双线性/网格残余 ≤0.5pt（10~15%）。** 逐目标最优阈值几乎抹平整个链缺口——链的罪不在"画不出"，在"切不对"。

### a.2 侵蚀机制（为什么 0.5 专打 2-3 cell 目标）

<32px² 目标在 512 画布占 2-3 cell，coverage 全为分数（无整格）；bilinear 场处处低于 1、峰值 ~0.5-0.7。固定 0.5 切在峰值处 → 系统性侵蚀：D3 实测 <32px² p50 IoU@0.5 = **0.400**、frac(IoU≥0.5) 仅 **0.443**；降到 0.4 → 0.583 / 0.600。32-64px² 8-16 cell：0.866→0.955。这是**链对校准内容的构造性侵蚀**，与模型好坏无关。

### a.3 为什么全局阈值死了而逐掩码没死（已有负结果的统一解释）

固定阈值平移（0.45/0.40）在生产上 +0.09/−0.13（`docs/2026-09-21-f1-128k-calibrated.md`）——D3 说得很清楚：**小目标要降、大目标要保，聚合互相抵消，只有逐掩码规则能收割**。F 探针（±1px 膨缩全变差）说明当前权重下掩码无净面积偏置——但这恰恰是因为**当前 Σp 并不估计 GT 面积**（未校准），逐掩码 AM 无从发力。这些负结果不构成对本方案的证伪，反而是其前提的注脚。

### a.4 BAS-CL+ 打开的可兑现行（本场进场条件）

P3-a 裁决（`p3_a/VERDICT.md`）：coverage 软标签（512² avg_pool 软图）使 **0.5-等值线本身被校准、Σmask_prob 成为 GT 面积的无偏估计**。推理侧：canvas 概率场 p̂ 逐 cell 估计 coverage → **4·Σ_canvas p̂ ≈ A_GT（1024 像素面积）**。这是逐目标面积信息的免-oracle 来源——oracle 行（+3.5pt）从"需要 GT"变成"从校准场自读"。**本方案回收的就是阈值行 3.5pt 的主要部分；插值残余 ≤0.5pt 与 <32px² 结构上限 0.842→1.000（+23.2pt，链外）不在本方案主张内**（后者由可选第三段 DCT 支路试探，见 §8）。

### a.5 AMB 规则

对每个 top-k 掩码 k（概率场 f_k 已存在于链中，(K,1024,1024)）：

1. **质量目标**：A_k = 4·Σ_canvas p̂_k（canvas 侧求和，262K 元素，与 1024 场插值方式解耦）。
2. **面积匹配阈值**：τ_k = g⁻¹(A_k)，g(τ)=#{f_k>τ}（单调减），二分 6~8 次求根，纯张量操作。
3. **守卫**：τ_k ← clamp(τ_k, 0.40, 0.52)（落在 D3 已扫描的中性包络内）；A_k ≤ 4px 或 g(0.52)≥A_k≥g(0.40) 无解时回退 τ=0.5。
4. 二值化 f_k > τ_k，其后 maskness/bbox/导出全部沿用现有公式。

**性质**：(i) 大掩码场双峰、0.5 附近 g 平坦 → τ 落谷底、掩码逐位不变（鲁棒 by construction）；(ii) 小掩码低峰 → τ 自动下探，**二值面积按构造等于估计的 GT 面积**（质量守恒），恰好消除 a.2 的侵蚀；(iii) 全程无 GT、无桶边界、无拟合常数。这是分桶自适应（+1.0）的连续推广、oracle（+3.5）的免标签逼近。

## (b) 兼容性：渲染链 / 导出契约 / TREX+ / 匹配

1. **渲染链接线**：替换 `gpu_postprocess.py:213`（`postprocess_tensors`）与 `arch.py:1568`（`_inference_raw`）两处的 `mask_probs > mask_threshold` 为 `mask_probs > τ_k(B,K,1,1)`；其余算子序列（gather→interpolate→sigmoid→maskness 融合）不动。配置面新增 `inference_binarizer: {fixed, area_matched}`、`am_tau_clamp: [0.40,0.52]`、`am_min_area_px: 4`；`inference_mask_threshold` 保留为 fixed 模式与回退值。
2. **CUDA graph**：现有阈值是"baked 常数"，AMB 把它变成图内张量——二分固定迭代次数、形状静态、无 host 同步（不用 `.item()`），**可捕获性不变**；eager 与 graph 路径逐位一致性的单测照搬现有协议。
3. **导出契约**：输出仍是 uint8{0,1} (K,1024,1024) + GPU bbox + RLE，`coco_export`/`export_pipeline`/DeferredExportRing 零改动；下游消费者无感知。
4. **TREX+（P4-d）分摊与交互**：TREX+ 只重打分不动掩码，AMB 只动掩码不动轨迹——正交。两点显式声明：(i) maskness 在 AM 掩码内计算 → 小掩码 maskness 上移（τ 更低、纳入像素概率更高），final_scores=cls×maskness 小桶分布右移——这**与已知"maskness 结构性压低小掩码分数"（p50 0.613<0.821）方向一致**，属对齐的副作用，但必须实测不得假设；(ii) TREX+ 的拟合常数（z5 内外掩码度等）在 AMB-on 的 dets 上**重拟合一次**（5 折、零训练，Phase-1 协议复用），Gate A/Gate C 重跑——TREX+ 裁决书自己预登记了"P4-c 落地后 Gate 重跑"的同一模式。预算分摊：AMB +2~3.5ms + TREX+ 0.5~2ms ≤ 剩余 8ms，且二者串在一条导出链上无循环依赖（AMB 在 postprocess 内、TREX+ 在其后）。
5. **二分匹配 / set-prediction**：纯推理端解码规则，训练损失、matcher、o2o/AIM、query 集合一概不触——与 P4-a/b/c 训练侧方案零耦合。与 P3-a 训练构造也无冲突：BAS-CL+ 的软标签与验证恒等式（软图+bilinear×2+0.5=CF1 掩码）在训练侧；AMB 只改推理切分，不动那条恒等式（可选：探针恒等式加 AM 版对照读数）。

## (c) 理论收益上界（链模拟数字锚定）与可兑现实势

| 层级 | 上限 | 中心估计 | 下限 | 依据 |
|---|---|---|---|---|
| 链级（sim，完美内容） | +3.5（oracle 0.842） | **+1.8~2.8**（AM 介于分桶 1.0 与 oracle 3.5 之间；对无偏覆盖场 AM≈最优） | +1.0（不低于分桶规则） | D3 表 |
| CF-rescore（生产完美内容） | CF1+3.5pt≈CF2（+3.1pt AP_s 量级） | +1.5~2.5 | 0 | CF1 0.5636→~0.598 vs CF2 0.6033 |
| **生产 AP_s（BAS-CL+ 后）** | **+3.1** | **+0.8~1.6** | **0（开关关）** | 中心=oracle×40~55% 兑现率 |

兑现率折扣的来源（如实）：(i) 校准误差（Σp̂≠A_GT）——§e 的鲁棒性注入实验直接测捕获率随误差的衰减；(ii) 内容抖动残余（P3-a 主攻、回收中的 27.1pt）让 per-mask 最优 τ 与 AM τ 分叉；(iii) <64 桶受 rec@0.5=12.2% 检测钳制，链级收益的 AP 权重打折（P3-a 裁决同款诚实声明）。**收益结构集中在 <128px²**：<32 frac≥0.5 0.443→(0.6 级)、32-64 0.866→(0.95 级)、64-128 0.960→(0.99 级)——其中 <64 桶的抬升同时抬高 P4-b/c 检测集合工作的链上限（跨场复利，非重复计费：那些场兑现的是检测行，本方案兑现的是链行）。
反向护栏的数字理由：clamp [0.40,0.52] 把最坏行为封在 D3 已扫描的聚合中性包络内（0.40 全局才 −0.9pt，而 AM 只对亏损掩码下探）；F 探针警告（<64 膨胀 1px 0.652→0.476）针对的是"整圈加面积"，AM 是逐掩码精确补质量，机制不同——但该探针正是杀线的一部分（§e）。

## (d) 开销预算

**推理（核心，零训练）**：作用于已物化的 (B,K,1024,1024) mask_probs（B=1,K=100 → 104.86M 元素）。
- 质量求和：canvas 侧 262K 元素 ≈ 0.05ms。
- 二分 8 iter：每 iter = compare(读 419MB float32/写 105MB bool) + 归约(读 105MB) ≈ 630MB 流量；按 1.5TB/s 有效带宽 ≈ 0.42ms/iter → **≈3.4ms 最坏**；基准后择优：6 iter（分辨率 0.12/64≈2e-3，充足）≈2.5ms，或"子采样 4 粗 iter(26M 元素,~0.11ms×4)+全量 2 精 iter(0.84ms)"≈1.3ms。**承诺 ≤3.5ms 实测上界，目标 ~2ms**；与 TREX+ 合计仍在 8ms 窗内（余 ≥2.5ms）。备选 ROI 限制版（仅对 A_k≤1024px 的小掩码在小 bbox 邻域二分，(K,64,64) 缓冲 0.4M 元素 <0.1ms）作为超预算回退。
- 显存：两个 (K,1024²) bool 工作缓冲 ≈ 210MB 瞬时（allocator 复用），**持久 0**；≤24GB 无压力。
**训练（核心）**：**0 ms/it、0 新参数**（解码端）。
**训练（可选第三段 DCT 支路）**：每 query 3-FC(256→300) L1 头，仅末层 +2~3% ms/it（本场上限 +5% 内）；推理 iDCT 基阵 (300→64²) 每 mask ≈1.2M MAC，100 masks ≈0.25 GFLOP ≈ **+0.5~1ms**。

## (e) 正确性验证方案（四道门，前两道纯离线可先验）

**G1 离线链模拟（先验，CPU，复用 R2 D 段协议，纸面轮后即可跑）**：对 2,000 个 sim GT 施 AM 规则（A_k 用精确 coverage 质量以隔离"规则本身"），判读：
- 链级加权估计 ≥0.815（即至少打平分桶自适应 0.817 一线）——**<0.815 纸面杀**；
- <32px² frac≥0.5 ≥0.58（对照 0.443@0.5 / 0.600@0.4）、256-1024 frac≥0.75 回退 ≤0.005（0.945 基线）；
- 捕获率报告：(AM−0.807)/(0.842−0.807)；
- **鲁棒性注入**：A_k 乘 U[0.85,1.15] 噪声重跑——捕获率保持 ≥50% 方可进 G3（校准误差敏感性的直接测量）。
- 消融臂：full-AM vs small-only-AM（A_k≤1024px 才 AM）vs 桶查表（对照）vs τ-clamp {[0.38,0.55] 基线 [0.40,0.52]}；同框架顺带跑**插值序消融**（sigmoid∘bilinear vs bilinear∘sigmoid、bicubic 臂）——sim 赢 ≥+0.5pt 链级才考虑进生产（零成本换算子）。
**G2 no-op 逐位回归（CPU/GPU 各一，先验）**：`inference_binarizer: fixed` 下输出与现基线 bit-identical；AM 数值单测（构造双峰场 τ→谷底不动掩码；构造低峰场 τ=面积分位）。
**G3 启用条件探针（BAS-CL+ 收敛 ckpt 上，~30min GPU）**：matched-pair 上 median|4Σp̂−A_GT|/A_GT ≤ 0.15（>0.25 = 校准未落地 → **机制死，报告 null 收场**，不进 G4）。同时读带内错分率复用 P3-a 探针。
**G4 全 val 重推理（~1-2h GPU，evaluate.py 标准协议）**：主门 AP_s ≥ +0.2pt 且 AP_m/AP_l/mAP ≥ −0.1pt；分桶 matched IoU p50（D2 协议：<64 0.635→? 、32-64 子桶、64-256 0.674→?）；AP@0.75 不回退。杀线：AP_s<+0.1、或任一桶 matched IoU p50 下降 >0.01、或 256-1k 出现 F 探针式退化（膨胀签名）→ 关 AM 回 fixed，交付负结果。TREX+ Gate A/C 在 AMB-on dets 上重拟合重跑（P4-d 协议）。

## (f) 叠加兼容性与时序（第二阶段声明）

| 场 | 交互 | 结论 |
|---|---|---|
| P3-a BAS-CL+ | **硬依赖（单向）**：AMB 的面积来源=其校准场 | AMB 排在其 8K/16K 短训门与 128K 收敛 ckpt 之后；其验证恒等式不受影响 |

## 落选候选的处置与反面锚（裁决人参考）

- **朴素提分辨率**：死（Mask R-CNN 28²→112²：34.7→32.5，调研 A 反面 #2）；且本方案证明链内 ≥87% 是阈值行——提分辨率打错了行。
- **DCT-Mask 头作为核心**：降级为可选第三段。理由：COCO AP_S 仅 +0.5、AP@75 +2.1 的证据偏向大/中目标边界（RefineMask 小 +1.5 vs 大 +6.0 同族教训）；其真实价值在亚网格结构（0.842 之外的 +23.2pt 领地），风险高、需训练臂，不配当主注。但它是**预算内唯一能突破 0.842 链上限的表示形式**（iDCT 可在任意分辨率重建、绕开画布网格），故保留为门控支路而非删除。
- **分桶自适应阈值（预测面积→τ 查表）**：被 AM 严格支配（同机制、更粗、需桶边界），保留为 G1 对照臂（+1.0pt 锚）。
- **软掩码导出**：COCO 消费二值 RLE，无软消费者——只在"二值化前的场更准"意义上有效，收编为插值序消融（§e G1）。

## 风险与诚实备注

1. **全部收益条件于 BAS-CL+ 的校准落地**：校准不来，AMB=0（G3 判死）。这正是本场定位为第二阶段的根据，也解释了迄今一切推理侧负结果（全局阈值、topk200）。
2. 兑现率 40~55% 是外推（sim 完美内容 → 生产抖动内容），G1 鲁棒性注入给出衰减曲线、G4 给真值；oracle 3.5pt 不可全额计入。
3. maskness 分布右移对 final_scores 的影响是双刃（小桶 TP 抬升 vs 固定池 FP 抬升），G4 必须读 hard-FP 分数中位（P4-d 反搭车协议）。
4. strays/斑点风险（低概率孤立区域被低 τ 收编）：small-only-AM 臂与 0.30 硬地板消融在 G1 注册。
5. 本提案不触 GPU、不跑实验（纸面轮）；G1 脚本为 R2 `analyze2.py` D 段的加规则扩展，产物落 `reviews_20260920/r2_maskiou/` 同目录约定。

**判分要素自陈**：理论收益 +0.8~1.6pt（上限 3.1）× 置信度 0.5（条件于 P3-a、且 sim 可先验折算）÷ 开销（训练 0%、推理 ~2ms）——推理近零开销档、可先验、可无损回退。
