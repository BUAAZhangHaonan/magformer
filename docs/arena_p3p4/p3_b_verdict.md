## 二、裁决

**胜出（核心）：#5 AMB+ 的二分 τ_k + #4 的归约定理与水填充表述**——机制上四份核心等价（面积守恒求逆），取实现最直（二分/水填充，免 LUT 免拟合常数）与理论最干净（归约定理保证大目标零扰动，与已死的全局阈值/膨胀失效模式正交）之并集。

**合并采纳（最终形态 ACB 面积守恒二值化）**：
1. τ_k = 使二值面积 = 4·Σ_canvas p̂ 的逐掩码阈值（二分或水填充，等价），clamp **[0.40,0.52]**（#5 的紧界；#3 的 [0.30,0.55] 过宽留消融卡）；
2. **#5 的四道门**：离线 sim 先验（≥0.815 杀线 + **校准噪声注入鲁棒性检验**——独有且关键，防"完美 coverage"假设下的纸面收益）、no-op 逐位回归、BAS-CL+ 校准探针（|4Σp̂−A_GT|≤0.15 才进场）、全 val 重推理（ΔAP_s≥+0.4 与 TREX+ 同标尺）；
3. **#4 的大目标护栏**（|τ−0.5|<0.03）；
4. 亚 cell 臂（#1/#2/#3 的精修头/CRSA/条件重渲染）**全部登记为 ACB 实测后的第三段卡**——ACB 的链级上限 0.842 内先兑现，破 0.842 才开表示类改动（DCT 频域等）。

**亚军：#3 ICR+**（其 C2 条件重渲染是破 0.842 的最强候选，随第三段卡带优先权）。

**ACB 最终形态**：零学习参数、零训练、推理 +2~3.5ms（与 TREX+ 合计 ≤6ms < 8ms）、CUDA-graph 兼容、关=逐位回基线。中心收益 **+0.8~1.6pt AP_s**（链级上界 +3.1），严格第二阶段。
