# P4-a 提案 #4｜CDN-SQ：小目标定向、块隔离、质量目标的对比去噪供给

提案人：#4（独立，未读同场其它提案）｜2026-09-21｜纸面轮，未跑任何实验

**一句话**：把本树已存在但带隔离缺陷的 DN 路径改造为「只喂 AIM 资格线内最小 GT、K=3 分层噪声正样本 + 资格核查负样本、cls 目标挂 MAL-q、中间层头不计算 DN 行」的训练期专用供给臂——每个小 GT 的正样本供给 ×4（1 o2o + 3 DN），matcher 零增载、推理 0ms、零新参数，训练 +2~5% ms/it。

---

## 0. 设计概览

训练期查询流布局（推理期 DN 块整体消失，与基线逐位相同）：

```
[ learned 136 | SCB+ 种子槽 64 ]   [ DN+ ≤48 ]   [ DN− ≤16 ]
└────── regular 200（o2o+AIM 池）──┘  └─噪声正样本─┘ └─核查负样本─┘
         ↑                                   ↑              ↑
   自注意力三块块对角隔离（regular 看不见任何 DN 行；DN 行互相也不跨界）
   cross-attn：regular 行走语义门控（现状）；DN 行只走 padding 掩码（自由注意）
   中间 8 次预测头只算 regular 行；最终 1 次头算全 264 行（DN 损失只挂最终层）
```

三处对 P4-b 移交件（tiny-CDN / SDN）的吸收与增量：吸收 tiny-CDN 的「仅小 GT + K=3 + N 有界」与 SDN 的「块对角隔离」；**增量三件**：(i) DN 正样本 cls 目标挂 q-DN（DEIM 铁律合规——两份移交件的一行描述均无此项）；(ii) 单类场景负样本资格核查（新发现的单类陷阱，见 §2.4）；(iii) 中间层头不计算 DN 行的省钱结构（头部成本 +3.6% 而非 +32%）。

## (a) 机制因果链

### a.1 o2o 下小 GT 正样本稀缺如何限制学习

**供给算术**（数字出处：R3 report D1/D2、SYNTHESIS P10、P4-c VERDICT）：
- 每步可见 <64px GT 期望 **0.85 个**（batch=4；仅 16.2% 图含 <64 目标）；P4-c 分层贴入后升至 **3~10 个/步**。
- o2o 下每个 GT 每步**至多 1 个**正样本 query（还要先过匹配）。对照：中大目标 ~55.5 实例/图 ×4 ≈ **220 个正样本/步**。
- → <64px 桶的梯度份额 ≈ 0.85/220 ≈ **0.4%**（与实测损失点份额 0.1-0.4% 一致）。贴入后也仅 1.4~4.4%。

三条受限通道：
1. **梯度份额饥饿**：cls 头要用正样本分布才能校准分数（focal/q 目标本质上在学"分数=可达质量"的映射）；0.85 个样本/步喂不出这个映射——<64 桶 TP 分数中位 0.29 vs 大目标 0.80（P4-c 证据）就是症状。贴入把样本数抬到 3-10，但每个仍是单样本估计、方差大。
2. **收敛速度受限**：单 GT 的"定位→画掩码→打分"整链每步只被优化 1 次；DN-DETR 证明去噪供给可把同性能所需 epoch 砍半（R50 12ep 43.4，+1.9 over baseline）[调研B 表2.1]。我们的 AP_s 在 72K→112K 仍 +1.1pt 但减速（R3 结论 10）——斜率真实而慢，正是供给受限的形态。
3. **单估计方差**：o2o 给小 GT 的监督是每步单采样；K 个噪声锚点的重构等于对同一小目标函数做 K 次扰动采样，方差降低（Group DETR 的 K 组等效 o2m 即此机制，调研B 候选 2）。

### a.2 本方案为何安全（三条构造性证明）

- **P1 匹配不变**：criterion 在进 matcher 前已剥 DN 行（`criterion.py:209-216, 252-258`）；Hungarian/AIM 的输入分布与无 DN 时逐位相同。o2o 主匹配的语义、AIM 的 cost 构成、margin 统计（2.43σ）一概不动。
- **P2 信息隔离（反"作弊"）**：解码器中唯一的跨 query 算子是 self-attention（LN/FFN 逐 query，cross-attn 是 query→memory）。给 `tgt_mask` 设三块块对角（regular×DN+×DN− 互不可见）后，regular 200 行的输出是 (权重, memory, regular query) 的纯函数——**DN 的存在与否在数学上不可能改变 regular 输出**（单测 T1 以逐位相同验证）。这关闭了 DN-DETR 指出的"无 attn-mask 隔离=任务平凡化"缺陷；P4-b 裁决书认定的本树真缺陷（`multiscale_decoder.py:578-583` 与 `:600-605` 的 `tgt_mask=None`）由此修复并成为本设计的地基。
- **P3 推理恒等**：DN 生成带 `self.training` 守卫（`arch.py:1373`），推理路径 dn=None，图结构与基线相同 → **+0ms**；零新参数（DN 内容向量用 query_embed 均值，`arch.py:1432` 现状保留）→ EMA/DDP/seed-dropout 全不受影响。

**因果链闭环**：稀缺（a.1）→ 用不经过匹配、推理即丢弃的旁路查询把每个入选小 GT 的正样本 ×4 → 供给直达 cls/mask/定位三头（共享头权重，DN 梯度真实改进同一组参数）→ 而隔离证明（P1-P3）保证 o2o 主匹配与推理行为零污染。

## (b) 与二分匹配 / AIM / 种子槽（SCB+）的兼容性与隔离设计

### b.1 查询行分区与 SCB+

- regular 块 = 200 行（136 learned + 64 SCB+ 种子槽），与 SCB+ 裁决一致：种子槽是池内普通 slot，单池 o2o、AIM 零语义改动。DN 块 append 在 `num_regular_queries` 之后（现有拼接点 `multiscale_decoder.py:801-806`），不占 200 预算。
- 种子行的 probe-fg 注意力先验只作用于行 `[num_learned, num_regular_queries)`，树内 AUD-2 修复（`:847-853`）已显式排除 DN 行——无需改动即兼容。
- deformable 路径下 DN 参考点保持初始位（`:1011-1018` 现状，detach）——保留。

### b.2 R0 前置修复（任何 DN 臂的必修，本设计内含）

1. **块对角 tgt_mask**：`multiscale_decoder.py:578-583`（dense）与 `:600-605`（deformable）的 `tgt_mask=None` 改为三块布尔掩码（264²×B×heads bool ≈ 2.2MB，可忽略）；随参数传入 `cp.checkpoint`（use_reentrant=False 支持非张量/布尔参数）。
2. **DN 行 cross-attn 解除语义门控**：DN 行的语义掩码来自其自身早期垃圾掩码预测，会退化 attend-everywhere。DN 行本就携带噪声 GT 锚（这正是去噪任务的定义），设计为只受 padding 掩码约束（自由注意 memory）——同时省掉 DN 行的 topk/插值开销。regular 行的门控逻辑一字不动。
3. **重设计 `_generate_dn_queries`**（`arch.py:1348-1459`）：现状 dn_scalar=5 × 全部 GT，GT 均值 55.5/图 → 每图可膨胀 ~275 行，无界且不聚焦；重写为有界分层版本（§2.3-2.5）。
4. **重写 `_compute_dn_loss`**（`criterion.py:584-726`）：现状 12544 随机点 + one-hot CE；改为 AIM 窗口确定性网格 + q 目标（§2.6）。

### b.3 DN+ 正样本：分层噪声、只选最小

- **入选池**：0 < 画布面积 < 4096px²——与 AIM 资格线同一条（`matcher.py:292`），同一人群、同一度量家族；每图按面积**升序取最小 m=4 个**（<64px 桶现在 0.21-0.3/图、贴入后 0.75-2.5/图，升序排序保证它们**必然全入选**；池均值 12.7/图，p90=41，上限截断在 m）。
- **K=3 分层噪声**（每 GT 三份、噪声类型不同，非 iid）：
  - λ1 平移：中心偏移 U(0, 0.3)×盒尺寸（定位噪声）；
  - λ2 缩放：绕中心独立双轴缩放 ×U(0.7, 1.4)（尺度/边界膨胀-侵蚀代理——直接对冲 R2 发现"±1px 膨缩都变差（抖动非偏移）"的边界脆弱性）；
  - λ3 复合粗噪声：平移 U(0.5)× + 缩放 ×(0.5, 1.8)（CDN 式难度阶梯的"难档"）。
  - 单类无标签噪声可言（CE 目标唯一类 0），明示。
- 锚经现有 `_sinusoidal_box_pe` 编码；内容向量 = query_embed 均值 + 0.1 噪声（零参数，现状保留）。

### b.4 DN− 负样本：资格核查（单类陷阱，本提案新发现）

CDN 原生负样本 = 移位/滚动的 GT 框。**多类下这是"错误类别"监督，单类下滚动框经常落在另一只同种真件上——"此处无物"标签是假阴性监督**，工业零件高度重复，此风险不是边角。设计：每个入选 GT 产 1 个负锚（同图入选集内循环滚动），**资格核查**：负锚与该图全部 GT（含贴入 GT）的 max-IoU ≥ 0.1 则换方向重采样（≤3 次），仍失败则丢弃该负样本（正样本不受影响）。比 ≤4/图 → ≤16/步，pos:neg = 48:16 = 3:1（负样本主力仍是 regular 未匹配行的 focal 负项，DN− 只是定向纪律剂量）。

### b.5 AIM 一致性（"同源同度量"承 P4-c 裁决的评分理由）

- DN 入选线 = AIM 资格线；q-DN = AIM 同款窗口确定性网格 soft-Dice（`matcher.py:276-354` 的窗口构造可直接抽公共函数复用）；**匹配选的就是它（AIM cost）、分数学的就是它（MAL-q）、去噪重构的也是它（q-DN）**——一个度量贯穿到底，零漂移。

### b.6 与 MAL-CP+ 的损失级整合

- DN+ 的 cls 损失从 one-hot CE 改为与 MAL-CP+ 完全同形的质量目标：`target = q-DN`（detach，warmup 1000 iter，QFL β=2.0，负项逐位不动）——DN 正样本是"增密"的一种，按 DEIM 铁律必须与质量感知损失同 commit，不得单飞（P4-c VERDICT 裁决语、调研C 反面 3：DEIM 消融"无 MAL 的 dense 匹配退化"）。
- DN 掩码损失在 AIM 窗口网格上算 BCE+Dice（每行 ≤R²≤4096 点，R∈[8,64] 与 matcher 同 clamp）；DN− 只挂"无物"CE（权重 0.5，现状键）。DN 损失只挂最终层（现状接线即 final-only，`criterion.py:328-339`；aux-DN 列为 Phase-2 旋钮，默认关，省预算）。
- DN 损失权重沿用现状 2.0/5.0/5.0/0.5（ce/mask/dice/neg）。

## (d) 开销预算（算式）

**默认档 m=4, K=3, N_dn ≤ 64（48 DN+ + 16 DN−）；查询流 200→264（+32%）。**

| 项 | 算式 | 开销 |
|---|---|---|
| 解码器层（cross+self+FFN） | 解码器层占步时 ~6-10%（头部另计；1.44-1.60 s/it 基准）× +32% query 线性（self-attn 264²/200²=1.74 但占比 ~15%，综合 ×~1.36） | **+2.0~3.4% ms/it** |
| 预测头 einsum（bqc,bchw，掩码画布上大头） | 基线 9 次调用 ×200 行；本设计中间 8 次**只算 regular 行**、最终 1 次算 264 行 → 1800→1864 行 | **+3.6% 头部成本**（不做此优化将是 +32%——这是设计关键省钱点，因为 DN 损失只挂最终层、中间层根本不需要 DN 行的预测） |
| DN 损失 | ≤64 行 × R²≤4096 点（确定性窗口网格，替代现状 12544 随机点）= 0.26M 点样本 vs 主掩码损失 ~2.8M/层 | **<+0.2% ms/it** |
| matcher | DN 不进 matcher（criterion 已剥行） | **+0**（对比 Group/H-DETR 家族 matcher ×K——贴入已使 AIM 列 42M→100M 点/步 [P4-c VERDICT 开销裁决]，再乘 K 不可接受，这是对两条替代路线的一票否决项） |
| DN 生成 | ≤64 框 PE + 噪声 + 资格核查（几十次框 IoU） | <1ms |
| **训练合计** | | **+2~5% ms/it（中心 +3%）** |
| 推理 | dn=None（training 守卫），图恒等 | **+0ms** |
| 显存 | tgt_mask 264²×4×8 bool ≈2.2MB；最终头 DN 掩码 64×512²×4img×2B(bf16) ≈134MB 存活至 DN 损失反传；层内激活 ≤64×256×8层 微量 | **≤ +0.5GB/卡**（探针实测确认） |

**叠加总账**（红线 ≤+20%）：P4-c +3~6% + P4-b 核心 +~1% + 本案 +2~5% = **+6~12%，余量 8pt**。
**档位阶梯**（预注册）：降档 m=3/K=2（N_dn≤40）+1.5~3%；升档 m=6（N_dn≤96，即 tiny-CDN 信封）+3~6%。

## (e) 正确性验证方案（预注册，纸面轮不执行）

### e.1 单测（CPU，训练前）

- **T1 隔离逐位测试（反作弊门，一票否决）**：固定权重、train 模式、关 dropout，同批数据 ±DN 前向 → regular 200 行的 `pred_logits/pred_masks` **atol=0 相同**。不过则隔离实现有漏，方案否决。
- **T2 掩码结构**：tgt_mask 三块块对角、off-block 全 True；DN 行 cross-attn 掩码全 False（仅 padding）。
- **T3 生成有界性**：N_dn≤64；入选=每图升序面积最小 m 个且 <4096；λ1/λ2/λ3 噪声互异；**负样本资格核查**：构造重叠 GT 对的对抗用例，负锚必须重采样/丢弃。
- **T4 损失正确性**：matcher 输入 shape=200（剥行断言）；q-DN∈[0,1] 且与 `matcher._aim_small_gt_costs` 在玩具用例上同值；q-off 时 DN 损失逐位回归旧公式；权重键接线。
- **T5 零参数**：DN on/off 参数计数相同（EMA/DDP 安全）。

### e.2 冻结基座探针（不训_optimizer 关）

封存 F1 128K（或 SCB++MAL-CP+ 底座就绪后用之）+200 步前向：ms/it 增量 ≤+7%；显存增量 ≤+1GB；AIM 主匹配健康：matched-margin ≥2.0σ 且与无 DN 时分布相同（P1 的实测版）；q-DN 初始分布记录（预期低/噪声，无门）。

### e.3 ≤16K 短训双臂门（主验证）

两臂同底座（SCB+ + MAL-CP+ 常开，DEIM 铁律）：A=底座、B=A+CDN-SQ。判读 @16K：

| 类别 | 指标 | 门 |
|---|---|---|
| **主判** | AP_s（trainer 口径）净 Δ(B−A) | ≥+0.5pt 过（≥+1.0 强过） |
| 收敛速度 | AP_s@4K：B≥A−0.3pt | DN-DETR 早期爬坡效应应可见；B 落后 >0.3pt 即警示 |
| **S1 主匹配质量（防毒化）** | matched IoU 中位（0.635）/ AIM margin | ≥0.62 / ≥2.0σ |
| **S2 重复率（防毒化）** | dets/small-GT（基线 1.30）；≥2-det 份额（11.7%） | ≤1.45 / ≤14% |
| **S3 hard-FP（防毒化）** | <64 det 池 hard-FP 份额（80.5%）与中位分 | 份额 ≤82.5%；中位分 ≤A+0.02 |
| **S4 反搭车判别对** | <64 TP 分数中位 Δ(B−A) | ≥0 且 S3 同时成立（与已证伪事后路线的分水岭，同 P4-c G1/G2 对） |
| **S5 DN 内部** | q-DN 中位@4K 单调升 | @4K ≥0.5，否则早杀（DN 臂未学习，停） |
| 遥测 | ms/it 每 500 步 | 持续 >+7% → 自动降档 m=3/K=2 |

失败判读树：S1 违→隔离/损失接线复查（最可疑：q-DN 未 detach 或 tgt_mask 漏 head）；S3/S4 违→DN− 资格核查或 q-DN warmup 复查；主判未达但 S1-S5 全过→供给不足，升档 m=6 复跑而非否决机制。

## (f) 与其它场叠加兼容性

- **P4-c MAL-CP+（已裁决，同 commit 族）**：q 机器共享（同 QFL β=2.0、同窗口 Dice、同 warmup）；贴入扩大 DN 入选池而 m 上限保成本不变——升序排序使**贴入的 tiny 优先入选**：贴入把可见 tiny 数 ×3-10，CDN-SQ 把每个的正样本再 ×4，两机制乘法叠加、预算加法叠加。消融按 2×2（DN on/off × 贴入 on/off，MAL 恒开）归因。
- **P4-b SCB+（已裁决）**：行分区 [136|64|48|16] 互不侵占；种子先验行范围树内已排除 DN（AUD-2）；seed-dropout/α 坡道/零开销回退档全不触碰。分工不双计：SCB+ 认领覆盖（存在性 38.1%→≤20-25%），本案认领每 GT 梯度供给（质量/收敛）。
- **P3-a 边界监督（若胜出）**：正交——DN 供更多正样本、边界损失锐化每个样本的监督；λ2 缩放噪声与边界损失的鲁棒性目标同向。分臂归因。
- **P3-b / P4-d（推理侧）**：DN 推理缺席，零交互。
- **Group DETR / H-DETR 家族（若本场另选）**：与本案**互为同一预算槽的替代品而非可叠加项**——o2m 组各自跑 matcher（AIM 已是增长成本项）+ 组间注意力改造，叠加须整体重审计 20% 红线并防供给冗余。本案是族中最省形态（matcher 零增载、推理 0ms、零参数），若裁决要双臂对照，建议本案 vs Group-mini 而非两者叠加。

## 诚实备注与风险登记

1. 收益中心 +1.2pt 是三通道外推折信值；Mask2Former 无官方 mask-CDN 数字（Mask DINO 证可行），自实现噪声语义（框 PE 参数化，无 mask 输入通道）是残差来源——λ2 只能代理边界噪声，Phase-2 扩展卡：mask-noise 输入投影（Mask DINO 式，+256 参数，放弃零参数属性需重审 EMA/DDP）。
2. DN-cls 分布移位（DN 锚定 GT，任务比常规 query 容易）：由 q-DN 目标对冲（分数绑定实际重构质量，画不准就没有高分）+ S4 哨兵盯防。
3. 单类负样本假阴是通用 CDN 未面对的陷阱，资格核查（b.4）是本提案的独立发现与承重组件，T3 对抗用例必须先行。
4. 本案不重复计 R3 oracle 阶梯（+6.7/+37.5）——那是覆盖×变现的值，已被 P4-b/P4-c 认领。
5. 预算按诚实口径（含解码器层、头部、损失、生成全链）记账；ms/it 与显存以冻结探针实测为准，超门自动降档。
