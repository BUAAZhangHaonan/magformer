# P4-b 提案 #4｜SAGE-Q：种子出生 × 全层门控 × 小目标去噪供给 × 质量绑分

> 提案人 #4（独立，未见其它提案）。场：P4-b 覆盖与 query 预算。
> 一句话：把 R2b 已证"覆盖可解"的种子通道以生产级形态复活（出生先验），用配置级开关把 topk 门控推广到全部消费层（注意力持有），加一组**匹配外、带隔离、分数目标=AIM 同源 soft-Dice** 的小目标去噪查询（供给），三件全部骑在 P4-c MAL-CP+ 的分数流上（变现）。
> 攻击的缺口段：38.1% never-hit 的**召回补全段**（oracle 阶梯 +6.7 → +37.5pt 之间），不主张掩码内容 27.1pt（P3-a 的山）也不主张渲染链 4.0pt（P3-b 的山）。

### 0.1 T1｜种子出生（R2b 复活版，生产级）

源码树内已全部存在（`multiscale_decoder.py:767-854` 种子注入 + `arch.py:21-47,193-237` probe 头与损失，`seed_enabled/probe_enabled` config 打开即活）。本提案的生产级改造三点：

1. **probe_area_max=1024（画布 px²）对齐缺口人口**：never-hit 重灾区 <64px² 87.8%、64-256 59.3%、256-1024 24.9%（R3 D1），1024 阈值恰好覆盖三个桶；不追 AIM 的 4096（那会把 DN/种子预算摊到 256-4096px² 的低缺口人群）。种子数 64 ≥ 每图小 GT max 26（R3 D2），出生槽位充足。
2. **seed_prior_layers=4**（新增，~20 行）：现 `seed_attn_prior` 只约束 layer 0 的种子行注意力；扩到 layer 0-3（probe_fg 插值到当层 key 网格、OR 进种子行），layer 4 起释放——"获得在前 4 层、持有靠自预测"。全程 fallback 安全已有（`_combine_semantic_and_padding_mask` 的全掩码恢复路径）。
3. **seed_dropout_p=0.25**（新增，一个伯努利门）：warmup（500 步）后，25% 训练步强制 `seed_active=False`、末 64 槽回落到原 learned embedding。作用：(i) 训练网络在"无种子模式"下同样成立，**导出端可整体去掉 probe（0ms 档）**；(ii) 防 64 槽对 learned 人口的路径依赖。val 上两种模式都评，按 AP_s 取导出档——这就是"种子类推理开销的训练期专用规避方案"。

### 0.2 T2｜门控多层化 lite（P6 残余的便宜子集）

R3 D4 已核：topk 门控 mask（256²、min64/ratio2.0）只被第 8 层消费，前 7 层 key 是 stride 32/16/8 粗网格 + 硬 0.5 阈值——c0 的 attend-everywhere 病理保留 7/8，且"query 获得与持有小目标恰发生在无门控区"。本 tier：

- **`mask_attn_topk_only_stride4: false`**：现有 config 键（`multiscale_decoder.py:992` 的 `topk_gate` 分支已实现全部 level 的 top-K 路径），翻转后每层每个 level 的掩码构建都走自适应 top-K（K=max(64, 2×pred_area)）而非硬 0.5。**注意 K 规则不动**：per-query 无竞争、min-64 对极小目标是 7-16 倍窗口（R3 D4 几何），不饿死。
- 诚实定位（引 R3 D4）：门控是**稳定器不是发现器**——无信号 query 的 top-64 仍落在它误指的大目标上。所以 T2 必须与 T1 捆绑：种子负责"出生在正确位置"，全层门控负责"前 7 层不稀释"。单独 T2 不立项。
- 不做（预算否决）：把 stride-4 key 扩到 layer 0-6 的"全层 hires"——dense cross-attn 在 65536 key 上 ×7 层，解码器成本近 ×7，超红线。stride-4 消费仍只末层。

### 0.3 T3｜SDN：限定小目标的对比去噪查询（供给 ×3，匹配外）

现树内 DN 路径（`arch.py:1348-1459` DINO 式 CDN）**禁用中且带已知缺陷**：自注意力无隔离掩码（regular↔DN 互看，作弊风险，简报明示）。SDN 是它的替代实现，四处重构：

1. **对象**：每图面积 <1024 画布 px² 的 GT（n 均值 2.91 / p90 12 / max 26，R3 D2）。每 GT 正样本 2 份（质心抖动 σ=0.05/0.15 两档）+ 负样本 1 份（GT 序号 cyclic roll——出生在"别的小目标位置"），行数 padding 到静态 48（正≤32+负≤16），保 CUDA graph 形状静态。
2. **出生接地**（与 R2b 种子同一管线）：content = `seed_proj_content(gather(mask_features, GT 质心抖动 cell))`，pos = 质心正弦 PE + 抖动——不是原 DN 的"base_content+白噪"（位置信息只进 PE 不进内容）。
3. **隔离（前置正确性 commit）**：解码器自注意力加块对角 `tgt_mask`——regular 块 / SDN 正组 σ1 / 正组 σ2 / 负组四块互不可见，块内可见。DN-DETR 铁律：无隔离=任务平凡化。
4. **质量绑分（本提案自带的分数绑定件）**：SDN 正样本 cls 目标 = q̂ = soft-Dice(pred_mask_dN, GT)，在 **AIM 同一确定性窗口网格**上计算（与 matcher `_aim_small_gt_costs` 抽公共 util，单一事实源；matcher 侧 no_grad、损失侧带 grad），detach 后按 QFL β=2.0 映射——**与 P4-c C1 的 q 同度量同温度，零漂移**。负样本 cls 硬目标 eos（CDN 负样本纪律：在"似是而非的小目标位置"学输出低分——直接对 <64 det 池 hard-FP 80.5% 的人口）。mask 侧损失同样走窗口网格点采样（小 GT 上比 12544 均匀点 SNR 高且更省）。

供给语义：每个可见小 GT 每步从"1 个 matched query"（o2o，且 ×9 深监督逐层重掷）变为"1 matched + 2 匹配外正样本"，且后者的归属**由构造决定、零重掷**。<64 桶每步正样本期望 0.85 → ~2.6。

### 0.4 Q｜与 P4-c MAL-CP+ 的打包（推荐形态）

种子是 regular query，进同一 Hungarian o2o、吃同一 AIM 列——**matched 种子自动获得 MAL-CP+ 的 q 目标，C1 零改动**。R2b 的死因（覆盖 92.1% 但 cls 卡 0.22-0.29）正是"focal 硬目标 1 + 网络对小子掩码的低质量先验"：MAL 把目标换成实测 q（小子好掩码 q≈0.6-0.75），分数流才有出口。本提案不重复造分数件：**若 P4-c 已落地则直接复用；若未落地，SDN 的 q̂ 绑定（§0.3-4）自带等价设计**，种子行 fallback 到 SDN 同款 QFL——纯覆盖方案无资格的红线由此满足。

## (a) 机制因果链：三重成因各打一刀，顺序有据

缺口的人口结构（R3 D1）：never-hit 并非均匀——<64px² 87.8%（best-IoU 中位 0.006，**物理不可见**）、64-256 59.3%、256-1024 24.9%。三重成因与攻击：

1. **出生先验（主攻，因果证据最强）**：200 个 learned query 的初始分布不由数据放置，小目标无人"站上去"。这是唯一有**直接因果实验**支持的成因：R2b 把 64 个种子放到 probe 峰上，覆盖率 61.9%→92.1%（小模型）——出生位置换掉，覆盖即跳变。probe 定位率 76.3% 是生产外推的绑定因子（见 §1 上界折算）。→ T1。
2. **注意力覆盖（次攻，持有侧）**：query 获得与持有小目标发生在 layer 0-6（粗网格、硬阈值、attend-everywhere），只有末层享受 256² 门控（R3 D4 代码级核查）。出生正确的种子若在前 7 层被稀释，到第 8 层已无信号可门控。→ T2（便宜子集：同 K 规则全 level 化 + 种子行先验延层）。
3. **供给（第三刀）**：o2o 下每个小 GT 每步 ≤1 个正样本，<64 桶期望 0.85 可见/步；×9 深监督同列反复重掷归属（AIM 修好了列的 SNR，但每层仍重掷）。CDN 形态的匹配外供给绕开匹配的生死判决（DN-DETR +1.9 / DINO +6.0 / Mask DINO mask 版可行 54.5 AP；调研 B 候选 1）。naive o2m 3300 query 崩到 8.4 的反面教训由"匹配外+隔离"规避（正样本洪峰不进 o2o 主匹配）。→ T3。
4. **变现门（捆绑，不可单独成立）**：oracle 37.5 vs 现实 6.7 的差 = 分数流门控；R2b 无分数件时覆盖收益归零。→ Q（P4-c MAL-CP+）。

为什么不是其它子轴（读过证据后的否决）：
- **热图预算家族的"数量"半边（DQ-DETR 计数/动态 query 数）**：其前提"固定 query 数不敷使用"被 R3 D2 本地证伪——每图小 GT max 26 ≪ 200，稀疏图 AR_s 也仅 0.319，容量不 binding；动态形状还与批处理/CUDA graph 冲突。我取该家族的"**位置**预算"半边（HGSQ 把热图当预算而非可视化的用法）：probe 峰 = 位置预算，形状全静态。
- **密集 proposal（DDQ 式）**：稠密化不去重毒化 o2o（调研 B 反面 3），且 R3 D3 已证重复/摊薄 ~0pt（oracle 去重 −0.25）——花预算买已证伪的轴。

## (b) 与二分匹配 / set-prediction 的兼容性

- **种子 = regular query，语义零改动**：种子行参与同一 Hungarian o2o；AIM 对其 pred_mask 施加同款确定性窗口 dice 列（margin 2.43σ 实验室值的受益人群恰好是种子要画的小子掩码——AIM 与种子是同域互补：AIM 修"分得对"，种子修"有人可分"）。匹配输了 -> eos：种子间在同一小目标上的竞争被 probe 局部极大值 NMS（3×3、>0.25）限到每 GT 1-3 个，o2o 留最优，败者的掩码不吃监督但注意力先验维持其定位，长期由人群分工消化（R3 D3：现人口 1.30 det/GT 无坍缩迹象）。
- **SDN = 匹配外支路，o2o 主匹配不受污染**：criterion 已按 `dn_num_regular_queries` 切片（`criterion.py:210-265`），matcher 只见 regular 块——SDN 的正样本洪峰（每步 ≤32）从不进 cost 矩阵，这是与 Group/H-DETR 分组 o2m 的本质差别（后者仍在集合预测内扩供）。set-prediction 的输出语义不变：推理时 SDN 块不生成，200 槽导出协议原样。
- **与 AIM 的交互**：AIM 在 matcher（no_grad、cost）；SDN/MAL 的 q 在损失侧（带 grad）——同一窗口网格、同一 soft-Dice 公式抽公共函数，"匹配选的就是它，分数学的就是它"（与 P4-c 裁决书对 #3 的嘉许同构）。AIM 去帽（v317 源已无 `sel[:16]`）保证全小 GT 有 AIM 列，种子/learned 的竞争在同一把尺子下进行。
- **已知缺陷的修复承诺**：现 DN 路径自注意力无隔离掩码——SDN 的前置 commit 即补上块对角 `tgt_mask`（`SelfAttentionLayer.forward` 已有 `tgt_mask` 参数，纯接线）；若裁决只采 T1/T2，此修复单独合并以防他人启用旧 DN。

## (c) 理论收益上界与依据

攻打的阶梯段：**召回补全段**（R3 D6 表：注入 never-hit @0.45 → +6.7；@0.99 → +37.5）。折算链（每步注明出处）：

1. 覆盖上限：R2b 小模型覆盖率 92.1%；生产绑定因子 = probe 定位率 76.3%（R2b 实测）× 种子掩码成功率（~0.85，R2b 覆盖定义即 IoU≥0.5）→ 种子可恢复 never-hit 人群的 ~62-70%；learned 人口自留 61.9% 基础上与种子并集 → never-hit 38.1% → **~12-16%**（<64 桶 87.8% → ~55-65%，因该桶 probe 定位更难，保守取上界 65%）。
2. 变现率：+6.7 臂假设注入分 0.45；MAL-q 目标下小 TP 分数 0.29 → ≥0.40-0.50（P4-c 实验室门 G1，种子行同样适用），SDN 负样本同时压 hard-FP——恢复检测以 0.45-0.6 分数段进入 top-100，落在两臂之间 → **可变现段估 +8~16pt**（对 +6.7 与 +37.5 做分数-排序插值的保守带；AR_s@10=0.0 → 小 TP 进前 10 是该段的先行信号）。
3. 诚实折扣：(i) 生产 probe 在 1024²/深度塔上可能低于 76.3%（§4 前置门先否决）；(ii) 16K 短训只能移动先行指标，AP_s 全额需 32-48K。**短训可判读主张：AP_s 净 +1.5~3.5pt（对 arm A），全程潜力段 +8~16pt，置信度中**。不主张：掩码内容 27.1（P3-a）、渲染 4.0（P3-b）、容量 0.9（R3 已证非 binding）。

## (d) 开销预算（算式）

基线 1.44-1.60 s/it 取中 1.52s（4 卡 DDP）；解码器占步时 ~10-15%（调研 B §2.1 DN 行估算口径）。

| 项 | 算式 | ms/it |
|---|---|---|
| T1 probe 前向+反传 | FLOPs≈65536×(256×128+9×128+128×2)×2×3 ≈ 13 GFLOP ÷ ~50 TFLOP/s 有效 + 核开销 + union/focal 损失 | +3~5 |
| T1 种子注入/prior 延层 | gather+proj 64 行 ~0；probe_fg 插值到 4 个 level + OR 掩码 | +1~2 |

超限降档序：SDN 正本 2→1（−15~20ms）→ sdn_max_rows 48→24 → T3 整体摘除（T1+T2+Q 仍成立，+7~12ms）。

**推理**：T1 probe-on 档 = probe 前向 4.4 GFLOP（~0.5-1ms）+ maxpool/topk/gather（~0.5ms）+ prior 延层 sort（~0.3ms）≈ **+1.5~2ms ≤ +10ms**；**0ms 规避档** = seed_dropout 训练后导出 seed-off（§0.1-3），val 双档实测按 AP_s 取。T2 推理同构建路径仅 sort 换比较 +0.5ms。T3 推理零（不生成）。**显存**：probe 激活 ~50MB + SDN 行末层掩码 +26MB bool + MHA 权重瞬态 ~+100-300MB + 损失点采样 <50MB ≈ **峰值 +≤0.8GB/卡**（24GB 内；超限先降 sdn_max_rows）。

## (e) 正确性验证方案

**单测 6 项**（不占卡）：
1. SDN 隔离：固定种子下把 dn_query_feat 换随机噪声，regular 块输出逐位不变（隔离成立）；掩码块覆盖 pattern 正确（4 块对角）。
2. SDN q 目标：损失侧窗口网格 dice（带 grad 版）与 matcher `_aim_small_gt_costs` 同输入同输出（共享 util 的回归测试）；detach 语义（q 不回传梯度进掩码）。
3. 种子确定性：eval 两次逐位一致（tie-break 缓存）；seed_dropout 强制 on/off 两路径形状与槽位数 200 不变。
4. 全层门控：`only_stride4=false` 下每层每行 attended cell 数 ∈ [1, K]（含全掩码恢复路径触发用例）。
5. SDN padding 行零损失贡献；空小 GT 图（batch 内 0 个 <1024 GT）退化为纯 regular 前向。
6. CUDA graph 兼容：SDN 块 48 行静态形状下 capture 通过。

**冻结基座探针（F1 128K 封存权重，先于任何短训）**：
- P-A probe 质量：只训 probe 头（其余全冻）2-3K 步 → val 小 GT 定位率（峰在 GT 2 cell 内）≥70%（R2b 76.3% 折扣锚）。不过 → 方案源头否决，不进短训。
- P-B 种子覆盖：注入训好的 probe+种子，全冻跑 val → never-hit 38.1% → ≤32%（先行；R2b 92.1% 覆盖的生产折扣门）。
- P-C 分数绑定（简报指定的 R2b 协议复用）：冻基座 + 种子 + MAL/SDN q 目标只训 cls 头与 seed_proj 2K 步 → **种子 TP 分数中位 0.29 → ≥0.40**（脱离 R2b 死区即证绑分成流；这是"覆盖×分数捆绑"成立性的直接实验）。

**≤16K 短训门（封存 128K resume，三臂）**：A = P4-c MAL-CP+（参照臂，可由 P4-c 实验室代跑）；B = A+T1+T2；C = B+T3。
判读数字与门：never-hit（small）B ≤30% / C ≤26%；<64 桶 87.8% → ≤78% / ≤72%；AR_s@100 0.309 → ≥0.36 / ≥0.38；**AR_s@10 0.0 → >0.02**（变现先行）；种子/DN-TP 分数中位 ≥0.40 且 <64 det 池 hard-FP 中位不随之上移（P4-c G2 对齐 ≤0.10）；AP_s（rescore 口径）C 对 A 净 ≥+1.0pt。
失败判读树：覆盖升+分数卡 → 分数流主导，移交 P4-c Phase-2（排序 hinge）；覆盖平 → probe 生产失败，查 P-A 复测；AP 降+FP 升 → SDN 负样本纪律不足，负本 1→2 或降 sdn 权重 1.0→0.5；B 升 C 降 → 隔离/供给过载，摘 T3 保 T1+T2。

## (f) 与其它场叠加兼容性

- **P4-c MAL-CP+（已裁决，强绑定）**：本提案是其覆盖侧孪生——同 q 度量、同 β=2.0、同 warmup 1000；开销合计 +5.2~9.4%（§d）。分臂归因：C1/C2 归 P4-c，T1/T2/T3 归本场，2×2 扩展为 A/B/C 阶梯。
- **P4-a（o2m 分组）**：T3 与 Group-DETR/H-DETR 在"供给 ×K"轴上是**替代品**——预算冲突预登记（SDN +2~3% + Group +18% + P4-c 6% 破 20% 红线）。裁决规则：两场若同胜，供给轴取一（本场主张 SDN 更便宜且自带负样本纪律；Group 胜出则本场降档为 T1+T2+Q）。另：种子行"好掩码但匹配败"比率若 >20%（探针可测），是 P4-a 分组供给的预注册接口。
- **P3-a/P3-b**：正耦合零冲突——边界/渲染改进抬 q 上限，本方案的 q 目标与 SDN 窗口 dice 直接继承更高 q；不同 commit 分臂归因。
- **P4-d 导出**：种子抬小目标分数后 topk-100 切割伤害自减；CQTR 轨迹重打分的空间收敛度信号可直接用在种子槽（种子出生→收敛轨迹更短、更可分——留作 P4-d 的免费特征假设）。
- **P3-c 退火**：probe/seed_proj/SDN 无新大模块（SDN 复用 seed_proj），唯一新参数群 probe 头 + 两个 Linear——并入新模块 lr 组（hires 组先例），不与退火日程互斥。
- **P6 门控**：T2 即 P6 残余的便宜子集；若它场胜出更激进的全层方案，T2 被吸收，无冲突。

## 结论

R2b 已替本场付过一半学费：覆盖可解（92.1%）、无分数件必死（0.22-0.29）。本提案把它的种子基础设施以生产级形态复活（出生），一个 config 翻转修掉 7/8 层的 attend-everywhere（持有），一组带隔离、匹配外、q 绑定的小目标去噪查询补上供给，全部骑在 P4-c 的 MAL 分数流上（变现）。边际开销 +2.2~3.4%（叠加 P4-c 后 +5.2~9.4%，红线余量 2 倍+），推理 0~2ms 双档可选，显存 +≤0.8GB。理论上界主张召回补全段的 +8~16pt（对 6.7/37.5 阶梯的分数插值），16K 短训可判读净 +1.5~3.5pt，且每一步都有便宜的前置门能在训练开始前否决自己。
