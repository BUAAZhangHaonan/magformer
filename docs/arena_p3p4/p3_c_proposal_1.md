# P3-c 提案 #1：HDS —— hires 组差异化退火（Hires-Decoupled Schedule）

提案人 #1/5（独立撰写，未读场内其他提案）| 2026-09-21 | 纸面轮（未跑任何实验；证据全部引自既有实测）

## 0. 方案卡

**一句话**：在不动任何损失形式的前提下，把 hires 组（stride-2 掩码头 + 末层 cross-attn + probe/seed 模块）的 20× lr 乘数在 256K 日程的 25%~75% 段平滑衰减到 1×，让边界关键权重在训练最后 25%（64K 步 = 9.3 个 EMA 半衰期）进入与主组同级的低噪声静默区；主组日程逐位不动。

**两个形态**：
- **HDS-256K（协议形态）**：`m(s) = 1 + 19·0.5(1+cos(π·u))`，`u = clamp((s−t1)/(t2−t1),0,1)`，t1=25%（64K）、t2=75%（192K）；hires lr = base_lr × cos_mult(s) × m(s)。约 40 行 scheduler 代码（LambdaLR 单 lambda → 按参数组 tag 的 lambda 列表）。
- **HDS-close（收尾臂形态，零代码）**：从封存 128K checkpoint 续跑时把 `hires_lr_multiplier: 20 → 1`。这就是本场对照设计的 B 臂——**R4 的收尾对照臂（A 臂）本身就是本场的最小实现**，本提案的边际要价 = 1 条额外 32K 续跑臂。

**主张**：协议级（256K 全栈）中心 **+0.3~0.6 AP_s** vs 同栈均匀日程；上界 +1.0（R4 退火尾段中心）；机制置信度高（三个独立锚），幅度置信度中。**开销 ≈ 0**（纯日程：训练 +0.0% ms/it、推理 0ms、显存 +0MB）。附带交付全场共用对照线（A 臂把停训点外推不确定度 ±0.8pt 压到 ±0.15pt，R4 估值）——这部分交付比 HDS 分数本身更确定。

## (a) 机制因果链：边界噪声的优化器侧成因，HDS 消哪个分量

### a.1 边界抖动的分量分解（谁已经消了什么）

| 抖动分量 | 状态 | 归属 |
|---|---|---|
| 目标侧：0/1 硬标签不可达 → 预测在软边界两侧永久振荡 | **已消**（coverage 软标签） | P3-a BAS-CL+ |
| 分配侧：matcher 列掷硬币 → 梯度目标逐迭代漂移 | **已消**（margin 2.43σ） | AIM（已落地） |
| 数据侧：12544 均匀点对边界欠采样 → 边界梯度方差大 | **部分缓解**（带内 ≥200× 密度） | P3-a BAS-CL+ |
| **优化器侧：步长噪声球——边界关键权重常驻 20× lr 随机游走** | **残余，本场主攻** | P3-c（本提案） |

P3-a 消的是"梯度说什么"（目标可达性）；本场消的是"优化器以多大的零噪声幅度跟随任何梯度"。二者正交且乘法叠加在同一个可观测量（边界抖动）上。

### a.2 优化器侧成因四步链（每步带实测数字）

1. **更新机制**：AdamW + 全模型 clip_value=1.0，preclip gradnorm 中位 ~1200-1400 → 100% 步被裁 → 每步有效更新 ≈ lr_g × 归一化方向（R4 核验 trainer.py:1251-1253；Deformable-DETR 式）。Adam 的逐坐标二阶矩归一进一步使位移幅值 ~ lr_g 量级。⇒ **参数组 g 的每步位移 ∝ lr_g**。
2. **噪声球**：ce/mask/dice 自 24K 统计平坦（无权重 OLS，t=-0.2/-0.7/-0.2，8K 桶 88K 步）⇒ 系统性梯度分量 ≈ 0，更新以零均值噪声为主 ⇒ 权重围绕当前解随机游走，稳态噪声球半径 r 随 lr_g 单调增（恢复力模型线性则 r∝lr，二次型则 r∝√lr）。hires 组 20× ⇒ **r 为 4.5×~20×**，且恰是 stride-2 掩码头+末层 cross-attn——边界 logit 的直接生产者。实证旁证：hires 组桶均值 ce 在 0.25-0.45 振荡（残差 std 0.05）、112K 桶 ce 反弹 0.326→0.429（~2σ，R4 堵点3）。
3. **决策面放大**：边界像素 logit 位于 0.5 阈值邻域（sigmoid 拐点，翻转最敏感区）。权重抖动 δw → logit 抖动 δℓ → 掩码边沿在 δℓ/|∇ℓ| 像素内随机翻转。10px 目标周长 ~36px、面积 ~80px²，±1px 边带 ≈ 面积 25-30% ⇒ 单目标 IoU 摆动数个点 ⇒ 与实测的 **±1px 膨缩双向变差（零均值抖动而非偏移）** 与 **@0.75=0.247 / @0.9=0.018 崩塌**（高 IoU 阈值对边沿稳定性的指数敏感）逐项吻合。
4. **价格实测（下界锚）**：EMA（0.9999，窗口 ~10K 步）比 raw **+1.02 AP_s**（0.2700 vs 0.2598，同协议配对，docs/2026-09-21-f1-128k-calibrated.md）——输出侧平均化可回收 1.02pt，证明该纯噪声分量的价格 ≥1.02pt。且 R4 堵点4 证明 EMA 平均化**不完全**：残差 gap 1.02pt 本身就是没被平均掉的部分；128K 冻结的 EMA 还整合了 hires lr 1.02e-4 高噪声期权重。

### a.3 HDS 消掉哪个分量、为什么是唯一在源头起效的杠杆

HDS 直接压缩 a.2-第2步的 r：m→1 后边界组噪声球半径收缩 √20~20×。三个子分量同时受益：
- **raw 轨道**：瞬时权重色散立即收缩（部署安全、短训臂读数干净）；
- **EMA 残差**：平均化负担与滞后污染（10K 步均值核混入噪声期权重）同时减轻；
- **冻结点方差**：封存哪个噪声球实现的问题变小（单次冻结无法量化，机制论证 + EMA-raw gap 代位）。

**为什么不是 EMA/正则/梯度整形**（详见附录算术否决）：参数组 EMA 要把 4.5×~20× 半径的平均到主组残差需把窗口拉长 20~400 倍（半衰期 141K~3.5M 步，超过全预算）；一致性正则要加损失项（违本场"不动损失形式"约束，且与 P3-a 软标签机制重叠）；梯度整形在全模型方向归一化下与 lr 乘数冗余——lr 乘数是我们直接、透明、可配置控制的同一个量。**一个旋钮（lr），不是四个。**

### a.4 与二分匹配/set-prediction 的兼容性

纯日程改动：matcher 代价矩阵、损失、query 集合语义、DN 行、种子槽**一个都不碰**。唯一变化是这些组件的参数在什么 lr 下训练。AIM（1.72ms/次，推理 0ms）与 HDS 无共享代码路径。DDP：LambdaLR 确定性、各 rank 一致，无新增集合通信；参数组划分不变（协议形态只加 lambda，不动分组），不触发 bucket 重建。

## (c) 理论收益上界与依据

**三个锚**（均注明出处）：
1. **R4 退火尾段**：128K 停训放弃的中心 **+1.0~1.25pt**（区间 +0.1~1.9；幂律 +1.25 / 对数 +1.88 / 老家族形状锚 +0.83，r4_dynamics/report.md）。这是均匀退火的总包（主组退火 + hires 退火 + 更多步数）；HDS 的增量主张 = 其中 hires 份额。
2. **EMA>raw +1.02pt**（f1-128k-calibrated.md，同协议配对）：噪声分量的输出侧实测价格。源头收缩应在 raw 轨道收回其大部分、在 EMA 轨道收回"平均化不掉的残差"。
3. **老 128K 家族尾形**：末 1/4 +0.24pt / 后半程 +0.71~0.83pt（唯一实证过退火尾段的运行族）——退火收益真实但有限的形状锚。

**分解算式（协议级）**：
`ΔHDS = Δanneal_tail × share_hires`，其中 share_hires ∈ [0,1] 先验取 0.3-0.5（hires 是 20× lr 且边界关键，但 giou 定位流在主组且仍下降、主组退火也贡献）⇒ **中心 +0.3~0.6，上界 +1.0**（不许超过它所加速的尾段总量）。

**机制侧可回收量（预注册预测，非收益主张）**：raw 轨道应收回 1.02pt gap 中的 ≥0.5pt（若 hires 噪声占 gap 主份额）；EMA−raw gap 在退火后臂中 ≤0.5pt（见 (e)）。

**诚实边界**：
- R4 明言"增量衰减=协议内信号耗尽，新算法需作用于可得分条件本身"。HDS **不创造新可得分条件**——它是 27.1pt 山上的"刮噪声层"：让 BAS-CL+ 的新监督落在稳定权重上、让 MAL 的 q 目标不抖。定位为精化/巩固型 + ≤1pt 收益 + 全场对照线基建，不与 P3-a/P4-c 的 3-10pt 主张同台折算。
- 噪声球本身在中段承担了部分有用探索（R4：中段增量=噪声球内慢漂移+EMA 平均化）。HDS 用巩固换探索，净效应正是 (e) 中 B−A 臂要测的量，不预设为正。
- 冻结点方差（封存到好/坏噪声实现的概率）只有一次冻结样本，无法量化——以 EMA-raw gap 与 ce 桶振荡作代位证据。

## (e) 正确性验证方案（对照臂设计 = 核心：分离"方案收益"与"退火本身收益"）

### e.1 零训练前置（CPU 单测 + 离线基线，纸面轮后立即可做）

1. **闭式单测**：per-group lambda 在采样步 {2.5K, 64K, 96K, 128K, 160K, 192K, 224K, 256K} 与本提案表格逐位对账；`t1=t2=∞`（衰减关闭）时与现行调度器输出**逐位回归**（no-op 测试）。
2. **resume 语义单测**：改乘数续跑后第一步 scheduler.step 的各组 lr = 闭式值（捕获 load_state_dict 覆盖 lr 的顺序问题）；A/B 臂 config diff 仅 2 键（max_iter、hires_lr_multiplier）的等价性核查。
3. **离线基线（~15min GPU，封存权重）**：EMA−raw gap 基线已有实测 1.02pt（0.2700/0.2598）；补一个**边界带翻转率探针**：同一权重对相邻 200 步两个 raw checkpoint 在边界带（|GT 距离|<2px）内的像素翻转率——直接的抖动观测量，先在 128K 基线测得 J₀，供臂间对比（免受精度变化的混淆）。

### e.2 三收尾臂设计（从 f1_seal_128k 副本续跑，各 32K 步，eval_period 8K，共 4 个实测点；R4 规则：≥2 个 EMA 半衰期 14K，32K 充分）

| 臂 | 配置 diff（vs 封存 config） | resume 时 lr（主组 / hires） | 语义 |
|---|---|---|---|
| **A 均匀收尾** | `max_iter: 256K→160K` | 9.85e-7 / 1.97e-5 → 0/0 | **= R4 收尾对照臂**：均匀退火总收益（退火本身 + 续训步数）；同时是全场新算法臂的公共对照线 |
| **B 差异化收尾** | `max_iter: 160K` + `hires_lr_multiplier: 20→1` | 9.85e-7 / 9.85e-7 → 0/0 | 主组轨迹与 A 逐位相同；hires 提前 100× 静默。**B−A = HDS 的净贡献**（纯 config，零代码） |
| **C hires-only**（可选） | 主组 lambda 冻结在 0.508（5.08e-6 恒定）；hires 快速余弦到 0 | 5.08e-6 / 1.02e-4→0 | 隔离"hires 噪声移除"（C−基线）与"主组退火"（A−C）；需 e.1 的代码 PR |

**分离逻辑**：A−基线 = 退火本身（R4 预期 +0.5~1.3pt）；**B−A = 日程形状（本方案）**；两臂主组 lr 轨迹逐位一致、终点同为 0，唯一的差异变量是 hires 的退火时序——混淆被构造性消除。B 的"hires 更早到低 lr（更多静默步）"不是混淆，正是被测机制本身。EMA 滞后在 A/B 两臂对称存在（都余弦到 0），不偏置 B−A；另以 raw 轨道为共同主读数（raw 无滞后，对 lr 变化即时响应）。

### e.3 判读数字（预注册）

**主门**（AP_s，EMA 轨道 @160K，full val 3276 图）：
- `B−A ≥ +0.15pt`（≈2σ_eval，σ≈0.05-0.09pt/eval；以 160K 点 + 末两点均值双读）→ **采纳**：HDS 写入 256K 协议（t1=25%/t2=75%），协议级收益主张更新为 ≈ B−A 实测值。
- `B−A ∈ (−0.05, +0.15)` → 机制未证；协议保留均匀日程，HDS 存档为已验证无增益（负结果仍交付 A 对照线）。
- `B−A ≤ −0.05` → **杀**（128K 时 20× 仍在买真实适应）。唯一复活路径：t1 推后消融（35%→80%，一次）后复测 B'−A ∈ (−0.15, −0.05) 才允许，否则终杀。

**机制门**（解释力核查，预注册）：
- EMA−raw gap：基线 1.02pt → B 臂 @160K **≤0.5pt**（噪声球收缩的直接指纹）；若 B 的 gap ≥0.9 且 AP_s 仍升 → 收益来自别处（如纯续训步数），审计后再读。
- 边界带翻转率：J(B)/J₀ ≤ 0.7（抖动幅度直接读数）。
- AP@0.75：B−A ≥ +0.20pt（高 IoU 段对边沿稳定性的放大效应；@0.9 方向一致即可，不设阈值——基数 0.018 太小）。

**护栏**（任一破线 → 停读归因）：
- AP@0.5：B ≥ A − 0.10pt（破线 = 边界模块欠适应，与主门"杀"分支同读）。
- bbox_AP_s：|B−A| ≤ 0.05pt（box 流在主组、日程逐位相同——bbox 大动 = 意外耦合的哨兵，先审计再读 AP_s）。
- matched IoU p50(<64px)：B ≥ 0.635 − 0.005（基线 0.635）。
- 叠加栈哨兵：若 B 臂与 P3-a/P4-c 短训臂同期跑，各场指标按各自预注册门读，共享 A 对照线（R4 规则：新算法臂必须显著超 A 的 160K 终点才算算法效应）。

### e.4 协议形态（256K 从头）的残余风险与 t1/t2 依据

- t1=25% 依据：ce/mask/dice 平坦 onset 24K ≈ 10% 日程（旧弱监督下）；20× 的原论证是"读预训练没见过的特征层需要快速适应"——适应是暂态，64K 步 20× 是老家族全程步数的 2 倍，充分。t2=75% 依据：为 EMA 留 64K 步 = 9.3 个半衰期（均匀日程下 hires 直到 ~242K/94.6% 才降到 ≤1.5e-6，仅剩 13.7K 步 = 2.0 个半衰期——**均匀日程的 EMA 终值携带 ~25% 噪声期权重污染，HDS 形态 <0.2%**）。
- 衰减曲线斜率在 t1/t2 端点为 0（余弦），96K 处 m=17.2（几乎没动）、128K 处 m=10.5（hires lr 仍为均匀的 52%）——实际削减集中在 128-192K 段，等效于收尾臂 B 所测窗口。

## (f) 与其它场胜出方案的叠加兼容性

**叠加矩阵**（机制轴完全正交：P3-a=损失目标、P4-c=损失目标+数据、P4-b=query 结构、P4-a=监督供给、P3-c=优化日程）：
- **P3-a × HDS**：软标签（可达目标）× 噪声收缩（安静权重）——同一直接量（边界抖动）上的乘法复合；各自消掉抖动分解表中的一行，无双计（归因靠不同 commit + 不同臂）。
- **P4-c × HDS**：HDS 稳定掩码 ⇒ 稳定 q 目标（MAL 的监督目标方差下降）；贴入持续供小 GT，post-t2 窗口内 hires 模块以主组速度消化它们（不是冻结，是等速）。
- **P4-b × HDS**：seed 模块默认随组衰减 + `hires_decay_scope` 消融保险 + 64K 日程健康检查；seed-dropout/零开销回退档不受影响。
- **P4-a × HDS**：DN 梯度密度 ↑ 与噪声球 ↓ 同模块汇合（SNR² 复合）；其 on/off 双臂必须同日程（预登记）。
- **预算**：+0.0% 使叠加总账停留在 ≤+11.6%（红线 20%，余量 8pt+）；若 P4 系追加超支，降档责任不在本场（我们已为负）。
- **归因纪律**：全部新算法臂（含五场）统一以 A 臂 160K 终点为对照线（R4 判读规则）；HDS 自身的增量只从 B−A 读，不与退火收益混算——这正是本场对照设计的构造性质。
