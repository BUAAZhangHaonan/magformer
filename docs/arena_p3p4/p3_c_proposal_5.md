# P3-c 提案 #5：「HDA-E」hires 分化退火 + 组分化 EMA（Hires-Differentiated Annealing + group-wise EMA）

提案人：#5（独立，未读同场其它提案）| 日期：2026-09-21 | 纸面轮，未跑任何实验

**一句话**：边界抖动的"纯噪声"分量 = hires 组（stride-2 掩码头 + 末层 cross-attn + probe/seed 模块）在 20× lr 噪声球里的零均值震荡——本提案用**两条零成本改动**在源头上把它消掉：(C1) hires lr 倍率走独立余弦 20→1（β=0.55），让边界关键模块提前 ~100K 步进入主组噪声量级；(C2) EMA 按参数组分化 decay（hires 组 0.99995 vs 主组 0.9999），把时间平均窗口加长在噪声最大、信号已死的模块上。训练开销 ≈ +0.00%，推理 +0ms，显存 +0MB。

## 0. 方案构成（精确到公式与代码落点）

### C1（主项）：hires 倍率退火（差异化余弦）

现状（`output/aps_20260913/configs/f1_full_design_256k.yaml:174-189` + `tools/train.py:705-759` + `magformer/engine/cosine_scheduler.py`）：hires 组（`hires_dw / hires_proj / hires_shuffle / small_probe / seed_proj / seed_norm / cross_attention_layers.{last}`，substring 规则见 train.py:747-757）以 base_lr×20 建组，随后 LambdaLR 用**单一 cosine lambda** 乘所有组。即 hires lr = 1e-5 × 20 × main_mult(s)，main_mult(s)=0.5(1+cos(π(s−2500)/253500))。

改法：hires 组的 lambda 换成"倍率自身退火"：

```
mult_hires(s) = main_mult(s) · m(s)
m(s) = 1 + 19 · a(s)
a(s) = 0.5 · (1 + cos(π · min(1, (s−w)/(β·(S−w)))))      # w=2500, S=256000, β=0.55
```

组的 lambda = mult_hires(s)/20（组内 base lr 已是 20×）。性质：倍率从 20 平滑单调降到 1，此后 hires 组与主组同曲线一起退到 0——不提前冻结、末段仍保留全部可塑性。PyTorch LambdaLR 原生支持 per-group lambda 列表，`build_cosine_lr_scheduler` 加一个 lambda 工厂即可；`trainer.py:1283-1284` 的 `lr_scheduler.step()` 不动。

关键落点数值（1e-5 base）：

| step | 现行 hires lr | HDA-E hires lr | 倍率 m(s) | 噪声半径降幅 |
|---|---|---|---|---|
| 64K | 1.72e-4 | 1.06e-4 | 12.3 | 1.6× |
| 96K | 1.40e-4 | 3.96e-5 | 5.65 | 3.5× |
| **128K（封存点）** | **1.02e-4** | **7.4e-6** | 1.46 | **13.7×** |
| 150K | 7.5e-5 | 3.7e-6（=主组） | 1.0 | 20× |
| 256K | 0 | 0 | 1.0 | — |

主组曲线**一字不动**——giou 信号（唯一仍显著下降的分量，t=−3.2）主要走主组，不冒险。β 中心 0.55，敏感性 {0.45, 0.7}；两档变体：末层 cross-attn 单独 β_attn=0.65（它同时服务内容与定位流，晚一点归队），见 (e) 的护栏。

### C2（辅项）：组分化 EMA decay

现状（`model_ema.py:72-92`，`trainer.py:1289-1290, 1660-1699`）：单一 decay=0.9999 全模型共用，shadow 更新是对 state_dict 逐张量 `mul_(d).add_(p, 1−d)`。

改法：decay 变为 name→decay 的映射，hires 组张量 0.99995（半衰期 13863 步，均值滞后 19999 步），其余 0.9999（6931 / 9999，现状）。更新循环 kernel 数与字节数不变，只是把标量换成查表标量。config：`runtime.ema_decay_hires`。收尾对照臂里不用它（见 (e)，隔离变量）；正式 256K 跑默认开启。

### 明确不做的子轴（本轮否决，理由附后）：层间一致性损失、梯度噪声整形（per-group clip / SAM）。见附录 A。

## (a) 机制因果链：边界噪声的优化器侧成因，本方案消哪个分量

**因果链六步，每步有实测锚**：

1. **每步都是方向归一化更新**。preclip gradnorm 中位 1200-1400 vs clip_value=1.0（f1 config:184-186）→ 100% 步被裁剪；AdamW 对梯度的整体缩放近似不变（m/v 比值尺度不变，eps=1e-8 量级可忽略），于是参数更新的幅度由 lr 单独决定，权重稳态涨落（噪声球半径）∝ lr（R4 根因链原句："步长=lr×单位梯度，噪声球半径 ∝ lr"）。
2. **hires 组常驻 20× 噪声球**。峰值 2e-4，112K 实测 1.21e-4、128K 1.02e-4（主组 6.06e-6 / 5.08e-6，R4 lr 对账表）——恰是 stride-2 掩码头与末层细注意力，即**边界渲染的直接执行器**。其桶间 loss 均值振荡（最终层 ce 0.25-0.45，残差 std 0.05；总 loss 桶间 ±2.4；112K 桶 ce 反弹 0.326→0.429 ≈ 2σ）是该噪声的观测面。
3. **中后段注入 hires 模块的梯度几乎全是零均值噪声**。ce/mask/dice 自 24K 起 88K 步 OLS 统计平坦（t = −0.2 / −0.7 / −0.2），即可提取的定向信号在 24K 附近耗尽；此后没有方向分量的梯度 × 高 lr = 纯随机游走，权重围绕某个均值震荡。
4. **权重噪声 → logit 噪声 → 0.5 阈值等值线抖动**。512² 掩码画布上，小目标边界处的 logit 斜率有限，hires 权重噪声直接转成边界 logit 噪声，阈值穿越点左右游走。这正是症状签名：**±1px 膨胀/侵蚀都更差（抖动非偏移）**、边界像素是全模型最高方差预测、高 IoU 段崩塌（@0.75=0.247 / @0.9=0.018——小目标 <1px 容差下轮廓噪声即致命）。
5. **EMA 事后平均可回收其中 +1.02 AP_s**（docs/2026-09-21-f1-128k-calibrated.md：EMA 0.2700 vs raw 0.2598，同协议配对）——证明这部分边界误差是**零均值、可在权重空间平均掉的纯噪声**。但 EMA 是事后手段：它平均的是持续以速率 ∝ lr 注入的噪声，窗口受滞后约束（decay 再大 → 滞后 d/(1−d) 步 → val 读到陈旧权重），且封存点的 EMA 整合的是 hires lr ~1.0e-4 高噪声期的轨迹（R4 堵点 4）。
6. **本方案在源头消第 2 步**：C1 把封存点噪声半径压 13.7×、后半程压至 20×（与主组同量级），让"信号已死"的模块停止大步随机游走；C2 把平均窗口加倍在噪声最大、剩余信号斜率 ≈0（滞后代价 ≈0）的同一组模块上。二者叠加的净效应：边界轮廓噪声幅度近似按噪声半径比例收缩。

**本方案消的是 Var[边界误差] 里的零均值项，不消 E[·]（系统性模糊/偏移——那是 P3-a 监督几何与 P3-b 表示的领地），也不碰存在性/分数（P4-c/P4-d）**。分工声明：P3-a 修均值，本场修方差；二者可乘性叠加。

## (c) 理论收益上界与依据

**上界结构**：本场可回收的总收益 = 退火尾段收益（R4 已估）+ 分组差异化的增量。本提案的可裁决主张是**增量 Δ_diff**。

1. **下界锚（实测）**：EMA > raw = **+1.02 AP_s**（F1@128K 同协议配对，0.2700 vs 0.2598）。这是在 hires lr 仍 1.02e-4（未退火）条件下、仅靠事后权重平均回收到的纯噪声分量——**源噪声再降 13.7× 只会让可回收份额更大、EMA 更容易 settle**。故 +1.02 是本场目标量的实测下界锚，不是上界。
2. **上界锚（R4 外推）**：128K 停训放弃的尾段中心 **+1.0~1.25pt**（幂律 +1.25 / 对数 +1.88 / 老家族形状锚 +0.83 / 悲观 +0.10；区间 +0.1~+1.9）；其中"退火本身"份额 +0.5~1.3pt，老家族实证后半程 +0.71~0.83pt、末 1/4 仅 +0.24pt。**本场的增量主张不能超过该尾段总量**。
3. **增量 Δ_diff 的机制估值**：R4 堵点 3 的明确假设——"AP_s 增量在 104-112K 塌到 +0.04 可能部分是 hires 组噪声淹没信号，而非信号真尽"。若尾段剩余信号有 1/3~1/2 被 20× 噪声淹没，差异化退火将其重新暴露：
   - **Phase-1（32K 收尾窗）Δ_diff 中心 +0.1~0.3pt**（收尾窗只覆盖 32K 步，且两臂末段都退到 0，差异集中在前 16K 的噪声能量与 EMA settle 速度）；
   - **Phase-2（全程 256K）期望 +0.2~0.5pt**（整个后半程 138K 步处于低噪区）；
   - **全场合计（退火+差异化）+0.8~1.5pt**。
4. **置信度**：Δ_diff ≥ +0.15pt：中（0.5）；Δ_diff ≥ −0.05pt（无害）：高（0.8）——因为成本为零，即使中位情形也满足"免费采纳规则"。
5. **次级收益（不进判分、进判读）**：封存/对照点方差收缩（R4："128K 冻结点方差大"）——尾部 4 个 eval 点的 AP_s 散度是噪声的直接量测，预期 Arm B < Arm A；方差变小 = 未来检测 +0.3pt 级效应需要更少种子，折算为实验预算节省。
6. **不主张的**：不修系统性模糊（27.1pt 掩码内容缺口主体归 P3-a/P3-b）、不修 16.5pt 存在性缺口（P4-c/P4-d）、不修 giou 流（主组日程未动，bbox_APs 护栏反而保护它）。

## (e) 正确性验证方案（核心：把"我的方案收益"与"退火本身收益"分离）

### Phase 0：零 GPU（当天可完成）

1. **调度器单测**：per-group lambda 闭式对账，s ∈ {2500, 64K, 96K, 128K, 150K, 192K, 256K}，各组 lr 与上表公式相对误差 <1e-9；warmup 段两公式一致。
2. **组成员快照测试**：hires 组成员集合 == train.py:747-757 substring 规则的展开（SCB+ 的 seed_* 自动入组是回归点）。
3. **EMA 单测**：0.9999 半衰期 6931 / 0.99995 → 13863；warmup 线性 ramp；旧格式（单 decay shadow）checkpoint 加载时按默认填充、best.pt/last.pt 读写 round-trip 逐位一致；`state_dict()` 序列化兼容旧评估工具。
4. **基线锚已就位（免费）**：F1@128K raw=0.2598 / EMA=0.2700（校准报告），收尾臂的 Δ_anneal 基点 0.2698（trainer 口径 128K 终值）。

### Phase 1：GPU 分离实验（2 臂 × 32K 步 ≈ 15.4h/臂，挂封存 F1@128K 副本）

- **Arm A（均匀收尾，= R4 对照臂）**：max_iter 160K，双组同一快速余弦（128K 处主组跳 ~1.0e-6、hires 跳 ~2.0e-5，再退到 0），hires 全程保持 20× 比例，EMA 0.9999。
- **Arm B（差异化收尾）**：主组日程与 A **逐位相同**；hires 倍率在前 8K 步内 20→1（压缩余弦），此后贴主组曲线；EMA 同样 0.9999（**C2 不进 Phase-1，隔离变量**）。

**分离算式**：Δ_anneal = AP_s(A@160K) − 0.2698（退火本身的收益）；**Δ_diff = AP_s(B@160K) − AP_s(A@160K)**（本方案的净主张）。

**判读数字（共主 + 次级一致性规则，弥补单种子 ±0.05-0.15pt 噪声底的统计功效）**：
- **验证通过**：Δ_diff ≥ +0.15pt；**或** Δ_diff ≥ +0.08pt 且次级读数同向 ≥2/3；
- **免费采纳**：−0.05 ≤ Δ_diff < 阈值（成本为零，保 C1 进 256K 正式跑，但本场不作为独立胜者宣称）；
- **否决**：Δ_diff < −0.05pt（hires 尾段真的需要高 lr——有信息量的负结果，回退）。
- **次级读数（边界特异性）**：① AP@0.75 / @0.9（基线 0.247 / 0.018，轮廓噪声的首要受害段）；② 尾部 3 个 eval 点 AP_s 散度（std），要求 B < A（噪声直接量测）；③ matched IoU 中位（0.635→?）。
- **护栏（保护 giou 流）**：bbox_APs（B）− bbox_APs（A）≥ −0.05pt。若违反 → 末层 cross-attn 切 β_attn=0.65 两档变体重跑（该层同时服务定位流）；hires_dw/proj/shuffle 头部模块不受影响。
- **归因审计（分离"退火帮 EMA settle"与"噪声源被移除"）**：两臂 best.pt 各含 raw backup，各花 ~15min 重评一次——若 Arm B 的 (EMA−raw) 缺口 < Arm A 的，则证明源噪声确实收缩，而非 EMA 单方面受益于低 lr settle。
- **时序预期**：两臂差异应集中在前两个 eval（136K/144K）——B 的 hires 在 129K 起即低于 1e-5，EMA（半衰期 6.9K）在 160K 前有 ≥3 个半衰期 settle；若差异只在末点出现，机制解释存疑，降级处理。
- **EMA settle 下限**：两臂均 32K 步 ≥ 2×半衰期×2（R4 的 144K 版否决理由同样适用此处）。

### Phase 2：正式协议落地（用户已定从头 256K）

C1（β=0.55；若 Phase-1 Δ_diff ≥ +0.3 则加扫 0.45/0.7 的敏感性，否则单点）+ C2（hires 组 0.99995）烙进正式 256K 跑；对照 = 该协议自身的均匀余弦基线臂。**C2 的单独归因只能在全程跑里看中段 eval 稳定性**——诚实声明：其证据强度弱于 C1（机制清楚、成本为零、默认开、留消融开关 `runtime.ema_decay_hires`）。

**证伪条件**（Phase-1 任一成立即机制存疑）：(i) Arm B 的最终层 ce 桶间振荡带（现状 0.25-0.45）不收缩；(ii) 尾部 eval 散度 B ≥ A；(iii) bbox_APs 护栏破。

## (f) 与其它场叠加兼容性

- **执行顺序**（遵循 BRIEF 执行顺序节）：P4-d（零训练）→ P3-a / P4-c → P4-b / P4-a → **P3-c 与收尾对照臂合并跑**。本提案设计上把"收尾臂槽位"当作 Arm A 复用——五场已占 +6~11% 预算的格局下，本场的 GPU 边际只有 1 支 32K 臂。
- **与 P3-a 共训（最重要的叠加）**：BAS-CL+ 的边界带梯度密度提升 × HDA-E 的噪声底下降 = 信噪比双重改善；反向风险（边界信号晚段仍活跃 vs 提前退火）用 β=0.6 + bbox 护栏处理，已声明于 (b)。这是全场最应该打包的一对。
- **与 P4-b 叠加**：seed/probe 模块自动继承日程与 EMA 分组，零额外代码；SCB+ 若把先验扩到全层（更多 cross-attn 层高 lr），组规则需同步扩 substring——声明为合并时的一个 config 审查点。
- **与 P4-a 叠加**：mCDN+ 去噪臂默认主组；去噪组的梯度尖峰（文献共识风险）与本方案无交互，但若合并跑出现 AMP skip 上升，去噪臂是第一嫌疑（本方案无此通道，单测覆盖）。
- **与 P4-c 叠加**：贴入改变数据分布 → 收尾臂/正式跑的对照基线需与贴入参数同 commit 对齐；本方案不引入任何数据依赖，是最容易保持对照洁净的一场。
- **互斥情形**：无。若 P3-b（第二阶段表示改造）重写掩码头，C1/C2 的组成员名单需重审——substring 规则让这是 config 级维护而非代码手术。

## 附录 A：本轮否决的候选子轴（展示完备性，防止"没考虑过"的质疑）

1. **层间一致性正则（×9 深监督轨迹一致）**：需在 9 路输出间加一致性损失项——**违反本场"不动损失形式"的前提**；且其目标（轨迹连贯）已被 C1+C2 以零成本间接服务（噪声源收缩 → 轨迹自然连贯）；实现需逐层 boundary-band 采样对齐，估 +1-3% ms/it。若 C1+C2 落地后仍测得层间边界预测系统性分歧（用现有 9 路损失日志即可离线诊断），可作为超出本场的 Phase-3 候选，届时按 P3-a 的边界带定义做 EMA 教师蒸馏。
2. **梯度噪声整形之 per-group clip**：当前 100% 步已被 full-model clip 到方向归一化，再对 hires 组降 clip 上限只是整体缩放梯度——AdamW 的 m/v 比值对整体缩放不变（eps=1e-8 量级可忽略），**更新幅度不变，方案无效**。明确否决，避免虚耗实验臂。
3. **梯度噪声整形之 SAM 式扰动一致**：前向×2 反向×2 ≈ +80-100% 训练开销，破 20% 总红线，否决。
