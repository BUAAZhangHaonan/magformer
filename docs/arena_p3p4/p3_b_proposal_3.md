# P3-b 提案 #3：ICR+ —— 质量守恒等值线读出（C1）+ 小目标选择性 crop 重渲染（C2）

提案人 #3 / 5（独立，互不可见）。**第二阶段声明**：本方案在 P3-a BAS-CL+ 的 coverage 软标签收敛后进场，其全部中心收益主张以"画布输出已被 coverage 标签校准"为前提；进场前的即刻可跑项（C1 的离线链模拟 Gate 0 与封存权重中性探针 Gate 1）不占训练臂、不依赖 BAS-CL+。

## (a) 机制因果链：4.0pt 链缺口的构成分解与本方案回收的段

### a.1 缺口的三段分解（锚 r2_maskiou D3/D5/CF1/CF2）

CF2−CF1 = 4.0pt（0.6033−0.5636，5,897 matched 小 det 全冻结只换掩码）。按 CF 桶内分解（D5 表）：

| 段 | 机制 | 桶内证据（D3/D5） | 在 4.0pt 中的权重 | 归属 |
|---|---|---|---|---|
| **i. 面积多数决侵蚀** | 512 画布 2×2 coverage 经 bilinear×2 后，0.5 阈值=逐输出像素多数决；2-3 cell 目标的 coverage 多数 <0.5，整块被抹 | <32px² frac≥0.5@0.5=**0.443**、p50=0.400；@0.4→0.600（+15.7pt）——纯阈值机制即救回 1/3 以上 | AP 权重最小（<64 matched 仅 12.2%，CF 桶内 +2.2pt），**但是 <64 的存在性前置**与未来 P4-b/c 抬 recall 后的主战场 | **C1 回收** |

**关键读数（本场独有的因果主张）**：D3 同时给出——统一阈值 0.45≈0.5（链级 0.808/0.807）、分桶自适应 0.817（+1.0）、逐目标 oracle 0.842（+3.5）。这三个数字合成一条结论：**可回收空间是真实的、但只存在于逐实例粒度；任何标量常数（无论拟合得多好）在聚合上是零和**——0.4 在 <64 桶内 +7.5pt 的同时在大桶 frac≥0.5 上回吐。F 探针（±1px 膨缩均大幅变差）证明今日生产内容无偏置可修——**所以修的不是常数，是读出方式**。

### a.2 C1：质量守恒等值线读出（Iso-Contour Readout）

机制：对每个 top-k 实例，sigmoid 后的 1024² 概率图 p 下，取

- 质量锚 `m_i = round(Σ p)`（校准 coverage 场下 = GT 面积的极大似然估计）；
- 分位数阈值 `τ_i = Quantile_{m_i}(p)`，即取概率最高的前 m_i 个像素；
- 生效式 `τ_eff = 0.5 + g(m_i)·(clamp(τ_i, 0.30, 0.55) − 0.5)`，g 为面积门（<128px² 全效，1024px² 余弦淡出到 0）。

三个自保护性质（区别于已死的全局旋钮与 +1.0 的分桶查表）：
1. **大目标自中性**：校准内容的概率分布对 0.5 近似对称，τ_i 自动落回 ≈0.5——不需要学"何时不修"；
2. **零拟合常数**：无任何在 val dets 上拟合的参数（对照：分桶表 +1.0 需在 val 上拟合、TREX+ 需 5 折重拟合）；clamp 与门宽是先验安全界，不是调出来的——分布漂移下不失效；
3. **与 P3-a 的语义闭环**：BAS-CL+ 的 coverage 软标签把画布输出**按构造**校准为 cell 覆盖率，"期望面积读出"正是校准场的 Bayes 一致译码。P3-a 修标签使 0.5 等值线可校准，本方案提供与该校准配套的读出器——**两场是同一枚硬币的两面，这正是第二阶段时序的机制依据**（无 BAS-CL+ 时全局阈值实测死 = 内容未校准的直接证据，见 docs/2026-09-21-f1-128k-calibrated.md：0.45 +0.09 噪声内、0.40 −0.13）。

回收段：**段 i 全部 + 段 ii 的面积偏置分量**。锚 D3 oracle：逐目标阈值 +3.5pt 链级；τ_mass 是其无 GT 估计器——coverage 经 2×2 avg_pool 后取值量化于 {0, 0.25, 0.5, 0.75, 1}，≤3 cell 目标的分位数几乎由直方图唯一决定，估计噪声小；预期兑现 oracle 缺口的 60-80%（Gate 0 离线先验判定，见 (e)）。

### a.3 C2：小目标选择性 crop 重渲染（Selective Crop Re-render）

机制：对通过面积门（期望面积 <128px²@1024）的实例，在预测 bbox 外扩 ×1.5 的 ROI 内（取固定 32×32px@1024 = 8×8 cell@stride-4 的窗口，pad 对齐），跑一个 ~0.3M 参数的条件细化头：

```
输入 = [stride-4 mask_features ROI (256ch, 8×8) ‖ 粗 canvas 概率 ROI 双线性采到 8×8 (1ch)]
头    = Conv3×3(257→96) → Conv3×3(96→96) → Conv3×3(96→16, 零初始化) → PixelShuffle(×4) → 32×32@1024 stride-1 logits
条件  = query embedding 经 FiLM（Linear 256→96 ×2）逐通道调制
输出  = 仅替换 ROI 内的掩码概率；ROI 外强制背景（小目标 ROI 外本应为空）
```

- **stride-1 只在 ROI 内发生**：stride-4 网格 ×4 shuffle = 1024 原生分辨率，2-3 cell 目标获得 ~16× 的表达 cell 数；
- 训练：只在匹配真 query 的小 GT ROI 上加逐点 BCE+Dice（复用 BAS-CL+ 点包在 ROI 内采样）；DN 行（mCDN+）不进 C2 损失——隔离声明；
- 最后一层零初始化：开启瞬间 ROI 输出 = 常数 0.5 等值线 ≈ 旧链，**step-0 与旧链逐位近似相等**——复用 `hires_proj` replicate-init 的零回归先例（pixel_decoder_msdeformattn.py:383-400 的设计惯例）。

回收段：**段 ii 的结构性分量 + 段 i 的表达力上限**。锚：当前链 <32px² frac≥0.5 上限 0.443@0.5（oracle τ 也只到 0.842 链级），E3 stride-1 = 1.000。C2 不是全图 stride-1，只在 ≤128px² ROI 拿到 stride-1 的表达力——**显式声明只主张 23.2pt 链外缺口中 ≤2pt 的切片**，其余仍归远期。对照反面锚的差异化：(i) Mask R-CNN 28²→112² 固定分辨率退化（34.7→32.5，[14]）——C2 是逐实例条件触发 + ROI 限定，不是全局分辨率；(ii) RefineMask 收益集中大目标（小 +1.5 vs 大 +6.0，[11]）——C2 计算只花在小目标；(iii) DynaMask 证明"选择性分辨率"才是有效形态（AP_S +2.4，[14]），C2 是其预算内最小版；(iv) DCT-Mask AP_S 仅 +0.5（[12]）——故 DCT 频域头仅登记为 C4 替换臂、默认关（见 (f) 决策树）。

## (b) 兼容性：渲染链 / 导出契约 / TREX+ / CUDA graph

### b.1 渲染链与两处硬编码位点

现链（gpu_postprocess.py `postprocess_tensors` L200-226 = CUDA-graph 路径；arch.py `_inference_raw` L1557-1572 = eager 路径，逐位一致）：gather → bilinear×2(512→1024) → sigmoid → `> mask_threshold`（已 config 化 `inference_mask_threshold`）→ maskness 融合。

改动方式：两处函数签名各加一个可选参数 `per_instance_tau: Optional[Tensor]`（(B,K,1,1)），
- `None`（默认/开关关）→ **逐位回到现行为**（Gate 必测）；
- 给定时 `binary = mask_probs > per_instance_tau`（广播比较，静态形状）。
τ 的计算（质量锚 + 32-bin 直方图 + clamp + 面积门）全部为固定形状算子（bucketize+scatter_add），**无 `.item()`/无同步/无动态形状 → CUDA-graph 可捕获**；质量锚在 512² 画布网格上算（100×262K sigmoid+reduce ≈ 0.1-0.2ms），直方图同样在 512² 网格全实例向量化（≈0.3-0.5ms）——不做逐实例 ROI 裁剪，**消灭数据依赖分支**（graph 杀手）。τ 从 512 网格直方图取分位、在 1024 网格生效：bilinear 近似保分位结构，等价性由 Gate 0 离线验证。

C2 接线：在 `postprocess_tensors` 之前、`multiscale_decoder.py:982-998` 的 `is_final_iter` hires 消费点旁路——C2 只消费已有的 `mask_features`（stride-4）与最终层 query 输出，**不改解码器**；固定 32 槽位 pad-batch（静态形状，graph 安全），空槽输出被面积门乘 0。

### b.2 导出契约（不可破坏的下游）

- 输出仍是 `(B,K,1024,1024)` uint8 {0,1} 二值掩码 + scores/category_ids/bbox——`coco_export` RLE、`compute_bbox_xyxy_gpu`、`mask_transfer_payload`/`DeferredExportRing`/packbits **接口零改动**（消费的是产物，不是算子序列）；
- 软掩码导出轴**按 COCO 契约判死**（评测只收 RLE 二值），本方案将其重定向为"τ 读出"——软信息用于选等值线，不用于导出。

### b.3 与 TREX+（P4-d，已占 0.5-2ms）的分数解耦

风险：maskness = 二值掩码内平均概率，τ_i<0.5 使导出掩码变大 → m_bnd 下移 → 分数被进一步压（小目标理想 maskness 上限已只有 0.95-0.96）。设计决策：**maskness 一律在 0.5 参考集上计算，τ_i 只作用于导出二值化**——`final_scores` 与基线逐位相同：
- Phase 1/2 的 ΔAP 归因因此是纯掩码质量效应，无排序混淆；
- TREX+ 运行时逻辑与常数不动；唯一影响是 z5（m_int/m_bnd）特征在新生成的二值掩码上重算——**离线 5 折重拟合一次（零训练）**，时序上排在 P3-b 合并之后（见 (f)）；
- `object_mask_threshold` 死键不动（归 P4-d/分数侧）。

### b.4 与二分匹配/set-prediction

C1 纯推理端，matcher 零接触。C2 训练损失挂在 AIM 匹配 indices 之后的已匹配真 query 上（post-hoc），不改 cost、不加 query、不动 DN 行隔离——匹配语义不变。与 o2o 主匹配无任何毒化通道。

## (d) 开销预算（算式）

**推理（红线 ≤ +8ms，扣除 TREX+ 0.5-2ms 后余量）**：

| 项 | 算式 | ms |
|---|---|---|
| C1 质量锚 | 100 实例 × 262K px sigmoid+reduce，≈52M 元素级 OP，A100 级 >20T OP/s | ≈0.1-0.2 |
| C1 直方图+τ | bucketize+scatter_add 同规模 ×2 + clamp/门（逐元素） | ≈0.3-0.5 |
| C1 生效 | 广播比较替代标量比较，开销不变 | ≈0 |
| C2 头 | ≤32 槽 pad-batch：conv1 8·8·257·96·9≈14M + conv2/3 ≈1M FLOP/实例 ×32 ≈ 0.5 GFLOP + ~10 个 kernel launch | ≈0.8-1.5 |
| **合计** | | **≈1.2-2.2ms**（TREX+ 0.5-2 + 本场 ≤2.2 → 栈总 ≤4.2ms < 8ms） |

**训练（红线 ≤ +5%；栈已占 6-11%）**：
- C1：**0%**（纯推理译码改动，训练侧一行不动——coverage 标签由 P3-a 负责，训练/推理语义由校准闭环保一致）；
- C2：ROI gather（≤32×8×8×257ch）+ 头前向 + ROI 内逐点损失（≤512 点/ROI，复用现有点包）+ 反传：估算 +1.5~3% ms/it（1.44-1.60 s/it 基数上 ≈ +25-50ms，大头是 gather/bookkeeping 而非 FLOP）；
- 合计 **+1.5~3%**，叠加后栈总 ≤14%，红线内。

**显存（红线 ≤24GB/卡）**：C2 参数 ~0.3M（conv1 257×96×9≈0.22M + conv2 96×96×9≈0.08M + conv3 96×16×9≈14K + FiLM ~50K）≈1.2MB；激活 32×(96ch×8×8 + 16×32×32) ≈ 单位数 MB；C1 零参数。**总增量 <10MB**。

**GPU 优先合规**：C1/C2 全程 device 侧（直方图/scatter_add/卷积/pixelshuffle 均原生 CUDA），无新增 DtoH；τ 向量在 device 上生成并留在 device。

## (e) 正确性验证方案（三级门，前两级可先验、便宜）

**Gate 0（离线链模拟，CPU，零训练，先验判 C1）**：复用 R2 D 段协议（2,000 小桶 GT 穿精确生产链，analyze2.py `D` 级 + results_D.json 的 sim_raw），把固定 {0.4,0.45,0.5,0.55} 换成 τ_mass 读出（512 网格直方图 → 分位 → clamp → 面积门），另跑 512-直方图 vs 1024-直方图等价性对照。判读数字：
- 链级 AP 估计 **≥0.825 采纳 / 0.817-0.825 降级为分桶查表 fallback（保 +1.0 底）/ <0.817 杀 C1**；
- <32px² frac≥0.5 目标 **≥0.55**（0.443 基线、0.600 oracle@0.4）；512/1024 等价性 Δ<0.003。

**Gate 1（封存 EMA 128K 权重 + C1，~30min GPU，可立即跑、不依赖 BAS-CL+）**：全 val 推理。预期**中性 null**（全局 |ΔAP_s|≤0.2，64-256 桶 AP@0.75 或 +0.2-0.6）。判读：全局 ΔAP_s < −0.2 → 杀（自中性失效）；中性 + 桶内小升 = 机制证据（未校准内容下读出器不捣乱、校准后才有肉）。同时跑 `enabled=False` **逐位回归单测**（两处位点的 scores/masks 与基线 bit-identical）。

**Gate 2（第二阶段 16K 短训，双臂：BAS-CL+ 基线臂 vs +C1/C2 臂）**：
- 主门：**ΔAP_s ≥ +0.5**（C2 部分；<+0.3 杀 C2）；C1 单独 Δ ≥ +0.3 保留；
- 机制门：matched IoU p50(<64) 在 BAS-CL+ 臂 ≥0.70 基础上 **≥0.75**；生产输出穿链模拟 frac≥0.75(<128px²) **+5pt**；
- 护栏：AP@0.5 ≥ 基线−0.2；AP_m/AP_l/mAP 无损；空掩码率 ≤+1pt；maskness 分布漂移 <0.02（TREX+ 重拟合前置检查）；C2 头梯度范数 ≤ 末层 2×（承 P3-a/P3-c 同款守卫）；
- 归因纪律：C1（改一处常数级译码）与 C2（新模块短训）**不同 commit、不同臂**，承 P3-a/P4-c 的分臂归因惯例。

**杀线汇总**：Gate 0 <0.817 杀 C1；Gate 1 全局 <−0.2 杀 C1；Gate 2 ΔAP_s<+0.3 全场降级为"链级 +1.0 fallback 或关门"，并把"逐实例读出在真实内容上不可兑"作为负结果交付（对齐 P4-d 的 null 报告姿态）。

## (f) 与其它场叠加兼容性与时序（第二阶段声明）

**时序（进场条件与合并顺序）**：
1. **即刻可跑**（不占训练臂、不依赖谁）：Gate 0 离线模拟（CPU）+ Gate 1 封存权重探针（~30min GPU）——两者都是先验/中性验证，不违反第二阶段定位；
2. **进场条件**：P3-a BAS-CL+ 8K/16K 短训门通过（matched IoU p50<64 ≥0.70、coverage 标签收敛）→ 本场中心收益解锁；
3. **合并顺序**：P4-d TREX+（零训练）先行 → BAS-CL+ 短训定案 → 本场 Gate 2 双臂 → **TREX+ 常数在本场合并后离线重拟合**（z5 特征随掩码变化，5 折协议照旧，零训练成本）。

**逐场兼容**：
- **P3-a BAS-CL+**：直接依赖（正向耦合）。coverage 软标签使 τ_mass 成为校准场的 Bayes 一致读出；BAS-CL+ 的点包/带采样训练侧零冲突（C1 不动训练，C2 复用其点包在 ROI 内）。反向：C1/C2 不改损失、不改标签——不干扰 P3-a 的归因臂。
- **P4-d TREX+**：分数解耦保证运行时互不触碰；重拟合为一次性离线动作。τ_i 只改变导出掩码、不改排序 → TREX+ 的桶中位锚定语义在新掩码分布上依然成立。
- **P3-c HDA+**：C2 头新参数入**标准 lr 组**（不进 hires 20× 组），末层零初始化 + 触发式退火（HDA+ 的平台检测）不受影响；画布三件套双 EMA 键集合不变（C2 头单列一组标准窗）。
- **P4-c MAL-CP+ / P4-b SCB+**：正交（分数/query 侧）。正向耦合：C2 抬小目标掩码质量 → matcher dice 列与 q 目标（QFL）的信噪比上升——MAL-CP+ 的 q-IoU 前置门在本场落地后应重跑；分 commit 归因。
- **P4-a mCDN+**：DN 行的掩码损失仍在 512 画布上（C2 只训常规匹配行）——块对角隔离不破坏；mCDN+ 的 parity 单测不受 C1（推理侧）影响。
- **C4（DCT 频域头，默认关的替换臂）**：仅当 Gate 2 中 C2 探针显示"冻结 trunk 只训头"的 matched IoU 顶到链模拟上限仍不够（= 内容容量瓶颈而非译码瓶颈）时，才把 C2 预算换购 64²-DCT 回归分支（COCO 锚：AP@75 +2.1 但 AP_S 仅 +0.5，[12]；训练 +3-4%）——决策树写死，避免与 P3-a 的内容账本纠缠。

**最终形态 ICR+**：C1（质量守恒分位数 τ，512 网格直方图、clamp[0.30,0.55]、面积门、maskness 在 0.5 参考集解耦、开关关=逐位基线）+ C2（≤128px² 目标 32² ROI stride-1 条件重渲染，零初始化热启动，~0.3M 参数，固定槽 pad-batch graph 安全）→ 推理 +1.2-2.2ms、训练 +1.5-3%、显存 +<10MB → 条件中心收益 **+1.5~4.0pt AP_s**（BAS-CL+ 后），链级账本 4.0+3.5 内、链外切片显式封顶 2pt。
