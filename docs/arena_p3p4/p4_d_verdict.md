## 一、五路全收敛（本场最强信号）

五份提案互不可见却**全部**发现同一核心事实并围绕它设计：**解码器 9 组逐层预测（`multiscale_decoder.py` 的 `aux_outputs`：逐层 cls/mask/box）在推理时已算出、被 `_inference_raw` 直接丢弃**——轨迹信息零成本（CQTR 的免费版）。全部方案以此为原料构造 TP/FP 不对称的轨迹可靠性信号，全部规避了被证伪的单调重标定家族（-13.1/-11.9pt），全部锚定 R1 反事实上界（重排 ≤+1.33~1.61、去重 ≤+0.26、TP/FP 完全分离 ≤+0.52）。

## 二、裁决

**胜出（骨干）：#4 TREX**——理由：
1. **防搭车设计最干净**：桶中位锚定（每面积桶 median(g)=1）数学上保证不净抬任何桶，只做桶内重排——而桶内恰是活口（64-256 桶现有分数 AUC=0.490=零信息）。附带的洞察最有价值：COCO 面积档评估只消费**桶内**排序，把"maskness 解耦"从已证伪的跨桶抬分框架重定向到桶内框架；
2. **开销最低**（核心 ≤0.5ms，原料免费）且明确"额外前向 FLOPs=0"；
3. **预注册最严谨**：Gate 0 逐位回归（关掉=基线 bit-identical）、Gate A 特征 AUC 判死门（含"null 报告也是交付物"的诚实姿态）、5 折拟合 + 全 val 裁决；
4. 对配额臂的超集论证（topk200 封顶存在性轴）虽有漏洞（见下），但"出数封分支"的处理正确。

**合并采纳**：
1. **#2 的切割移位臂**（唯一正确攻击"成员更换"的方案）：topk200 实测 +0.09 是在**旧融合分**截断下的结果，不构成新分下成员更换的上界——采纳 #2 的 G0 oracle-200 门（B2−B1 < +0.2 则关臂）作为成员臂的前置门；其 Arm C 配额仅在门后存活；
2. **#2 的 m_int/m_bnd 内外分解**并入特征集（= #4 z5 的更细版本）；
3. **#1 的软沉降温度**作为 z4 ×ε 沉降的消融对照臂；
4. **#3 的多阈值剖面**登记为可选特征臂；
5. **#5 的紧界 [0.7,1.3]** 作为 g 的默认 clamp（比 #4 的 [0.5,1.25] 更保守，防分布漂移）。

**亚军：#2 TIF-C**（若 TREX 的桶内重排在 Gate A 折戟而 oracle-200 门显示成员更换有肉，回退 #2 为主干）。

**最终形态 TREX+**：桶中位锚定乘法重排（z1 语义持续 / z2 空间收敛 / z3 跨尺度一致 / z4 重复组结构 / z5 内外掩码度 / β 扫描）→ g clamp [0.7,1.3] → 常数 ≤10 个、训练拆分 5 折拟合、全 val 裁决 → 成员臂（切割移位 + 门控配额）仅过 oracle-200 门后启用。**零训练、≤2ms、EV +0.3~0.8pt。**

## 三、实验室验证（预注册，承 #4 Phase 0-2 + #2 G0）

1. Phase 0 重锚：128K 封存 dets 上复算 R1 反事实全套（消灭 112K↔128K 口径漂移）；
2. Phase 1 特征转储（~2h GPU）：`dump_trajectory` 开关对全 val 前向一次落盘；
3. Gate 0/裁决门：关=逐位一致；Gate A：融合 AUC 64-256 桶 ≥0.57、<64 ≥0.80（不过=null 收场）；Gate C：ΔAP_s ≥ +0.30 且 AP_m/l/mAP 无损；G0：oracle-200−oracle-100 ≥ +0.2 才开成员臂；反搭车证据：hard-FP 分数中位 ≤+0.05 而 TP ≥+0.05。

## 四、诚实备注

- 本场是零训练档的**存量变现**：全部通道 oracle 总和 ≤~2.1pt，不是两座大山的替代品；EV +0.15~0.35pt 为主流预期，Gate A 判死（约 50% 概率）同样是有价值的交付（用数字关闭导出端分支）。
- 五家估计（+0.2~1.0）均锚 R1 反事实的 20-60% 兑现率——CQTR 文献量级（+1.95~3.81）明确不可全额迁移（其最贵的尺度干预腿超预算）。
- 与 P4-c 的关系：MAL-CP+ 从训练期修分数流，TREX+ 在其落地前榨干存量；P4-c 落地后 Gate A 重跑、由数字决定去留。
