# P3-b 提案 #4：ACAR — 面积校准自适应读出（Area-Calibrated Adaptive Readout）

提案人 #4 / 5（独立撰写，未见同场其它提案）。定位：**第二阶段**（P3-a BAS-CL+ 的 coverage 软标签收敛后进场），纯推理/读出端，零新增训练参数为主干。

---

## 0. 一句话机制

BAS-CL+ 训练后，512 画布上每个 cell 的 sigmoid 输出被校准为该 cell 的 **coverage**（GT 覆盖率），从而 Σp 成为 GT 面积的无偏估计（P3-a 裁决书原文）。本提案把导出端的读出从「全局 0.5 多数决」换成**逐目标水填充阈值（waterfill τ）+ 可选亚 cell 粒度**：对每个 top-k 掩码，取 τ 使保留的 cell 数 = Σp（面积守恒），使**渲染面积成为 GT 面积的无偏估计**，替代 0.5 多数决对小目标的系统性面积侵蚀；在 1024 上采样图上做同一水填充即免费获得亚 cell（sub-pixel）表达。零学习参数、零训练（主干）、推理 ≤2.5ms。

**明确不做**：DCT-Mask 频域回归头、任何新增高分辨率解码分支（理由见 §7 反面论证：与本栈已裁决结论双重计费 + 文献小目标证据弱 + 第二阶段训练预算不划算）。

## (a) 机制因果链：4.0pt 链缺口的构成分解与本方案回收哪段

### a.1 缺口分解（全部锚 R2 实测，完美内容口径）

CF2−CF1 = **4.0pt**（0.6033−0.5636，检测集合/分数/其余掩码全部冻结，只换已匹配小目标的掩码为「GT 穿生产链」版）——这是链在**固定 0.5** 下对完美内容的全部税。按机制拆三段：

| 成分 | 机制 | 证据锚（R2 D3/F 段） | 可回收性 |
|---|---|---|---|
| **(i) 多数决面积侵蚀** | 0.5 切割把 coverage<0.5 的部分 cell **整块丢弃**；目标越小、边界 cell 占比越高，渲染面积期望越低于真面积 | <32px²：p50 IoU @0.5=0.400 → @0.4=0.583（阈值挪 0.05-0.1，p50 动 18.3pt——概率质量恰好压在切点上）；32-64 frac≥0.75 0.592→0.675；逐目标 oracle 阈值链 0.807→0.842（**+3.5pt**），分桶常数 0.807→0.817（+1.0pt） | **本方案主攻**。无 oracle、无分桶常数，逐目标连续自适应 |
| **(ii) cell 级形状量化** | 即使 τ 正确，保留 cell 渲染为 4px 方块；<32px² 目标 2-3 cell 只有 0/4/8px 几个面积档 | stride-1 结构上限 1.000 vs 链 @0.5 frac≥0.5=0.443（<32px²）；2-3 cell 目标的面积档数 = 细胞数+1，亚 cell 读出把它乘 ×5（每 cell 0-4 px） | 本方案次攻（AMT@1024 亚 cell 水填充）。stride-1 本身（+23.2pt）明确不在本场计费 |
| **iii) 双线性混叠** | ×2 双线性把质量摊给邻域，孤立刻画小目标时中心值被稀释 | 无独立实测；与 (i)(ii) 耦合 | 不单独攻击（预算内不可分离），如实声明 |

### a.2 因果链（为什么这是根因而非症状）

1. **症状**：<32px² 链 frac≥0.5 仅 44%、高 IoU 段坍缩。**根因**：0.5 是「cell 面积多数决」——它对 coverage∈(0,0.5) 的信息一视同仁地扔掉，而小目标的**全部** cell 恰好都在这个区间。这不是模型画不好（CF1 已把内容换成完美 GT），是**读出规则在信息论上丢弃了已正确表示的部分覆盖信息**。
2. **为什么此前全局阈值已死、本方案不同**：128K 校准实测 0.45=+0.09（噪声）、0.40=−0.13；R2 F 探针显示生产掩码膨/蚀都变差。原因：全局降阈值 = 给**所有**目标做轻度膨胀，而 128-1024px² 桶的 p50 在 0.4 下实测**变差**（0.888→0.871、0.948→0.921）——全局常数的收益（<64 桶内 +7.5）被中大目标的膨胀损失对冲到零。**水填充阈值对已解析目标自动退化为 ≈0.5**（见 a.3 归约定理），只在小目标处偏离——它是全局常数已死结论的正交解，不是它的重试。
3. **为什么必须第二阶段**：水填充的锚是 Σp=无偏面积估计。当前 128K 权重（硬 0/1 标签训练）的 Σp **未校准**——这正解释了全局阈值扫描 ≈0 的观测：在未校准场上任何阈值规则都没有可靠输入。BAS-CL+ 的 coverage 软标签（512² avg_pool 2×2、CF1 构造对齐）把场的语义换成 coverage，Σp→面积无偏——**P3-a 校准了场，本方案消费它**。这是训练侧/推理侧同一根因的两半，因果闭合。

### a.3 归约定理（为什么中大目标零风险，一句话版）

对边界近似平直的已解析目标，边界环 cell 的 coverage 近似均匀分布，#{p>0.5} ≈ Σ环内 coverage，故水填充 τ* ≈ 0.5（不动）；τ* 只在概率质量退化（全部 cell 中低 coverage）的小目标处系统性下移。D3 的分桶 p50 曲线正是该定理的实证形态：<32px² 对 τ 极敏感（0.400↔0.583），128-1024px² 对 0.4↔0.5 几乎不动或反向。附安全 clamp τ∈[0.35, 0.52]。

## (b) 与渲染链 / 导出契约 / TREX+ 的兼容性

### b.1 渲染链接线（改动面：一行比较 + 前置统计，两路径共享）

- 现状：`gpu_postprocess.py:156-226 postprocess_tensors()`（CUDA-graph 路径）与 `arch.py:1491-1593 _inference_raw`（eager 路径）逐位一致；二值化在 `mask_probs > mask_threshold`（gpu_postprocess.py:213 / arch.py:1568）；`inference_mask_threshold` 已 config 化（arch.py:85）。
- 改动：在 gather 之后、interpolate 之前对 (B,topk,512,512) 的 sigmoid 场做逐掩码统计：Σp（sum）+ 32 桶 int32 直方图（`torch.bucketize`+`scatter_add`）→ cumsum → `searchsorted` 得每掩码 τ（clamp [0.35,0.52]，空保护：Σp≥0.5cell 时 k 地板=1，否则与基线同样出空）。二值化行改为 `mask_probs > tau[:,None,None]`（逐掩码张量广播）。
- **CUDA-graph 兼容**：全部为静态形状张量算子（直方图/scatter_add/cumsum/searchsorted 均可捕获），τ 从 Python 常数变为张量不破坏捕获；int32 scatter_add 的和确定，replay 逐位可复现。eager/graph 共用同一函数，两路径位一致性契约保持。
- **亚 cell 档（AMT@1024）**：同一套统计改在已上采样的 1024 图上做（该图本来就算出，无额外前向）；水填充目标 k = 4·Σq（×2 双线性近似质量和守恒，因子在 V0 模拟中校准）。

### b.2 导出契约

- 输出结构零变化：binary uint8 {0,1} (K,1024,1024)、`compute_bbox_xyxy_gpu` 由二值掩码导出、pack_bits/DeferredExportRing/pinned 传输全部不动——只改掩码**值**，不改任何形状/dtype/布局。COCO RLE 下游零感知。
- config：新增 `binarize_mode ∈ {fixed, amt_cell, amt_subcell}`，默认 fixed → **关掉即基线**（Gate 0 逐位回归）。

### b.3 TREX+（已裁决，先落地）分摊与解耦

- **打分-几何解耦（关键设计）**：maskness 打分仍在 fixed-0.5 几何上计算。理由：若 maskness 在 AMT 掩码内均值，小目标 τ 下降 → 掩码内掺入低概率像素 → maskness 降 → cls×maskness 结构性压低小目标分数（R2 B 段 0.613/0.723/0.821 的既有病会被本方案放大）。解耦后导出分数语义与 TREX+ 拟合时完全一致。
- TREX+ 的 z5（内外掩码度）消费导出二值掩码 → 掩码几何变了分布要重拟合：5 折 logistic 离线重拟合（零训练、零 GPU 训练），联合门 V4 预注册。
- 预算：TREX+ 已占 ~0.5-2ms，本方案 ≤2.5ms，合计 ≤4.5ms < 8ms 余量，不冲突。

## (d) 开销预算

**推理（算式，B=1、topk=100）**：
- AMT-cell：统计在 (100,512,512)=26.2M 元素上：bucketize+scatter_add 直方图（26.2M 读，~160MB 流量）+ (100,33) cumsum + searchsorted。A100 级显存带宽下理论上 <0.2ms，计原子写冲突保守 **≤1.0ms**。
- AMT-subcell：同一统计在 (100,1024²)=105M 元素（~640MB 流量），保守 **≤2.5ms**。
- 两档互斥（mode 开关），非叠加。clamp/空保护 <0.05ms。**合计 ≤2.5ms ≪ 8ms 红线**（扣除 TREX+ 后余量）。
**训练**：主干 **0**（纯读出）。可选稳定臂（仅 V1 边缘时启用）：Σp-vs-GT 面积 L1 辅助损失（λ=0.05、2K ramp），场已在显存，一次归约 +2-3ms/it ≈ **+0.2%**（红线 +5% 的 1/25）。后验校准（ACAR-3）为 val 离线 numpy 拟合，零。
**显存**：512 概率场多保持一份 (100,512²) float32 ≈ 105MB + 直方图缓冲 ≈ KB 级；**峰值 <250MB**，远低于 24GB。

## (e) 正确性验证方案（预注册数字，先离线后上线，纸面轮未跑任何实验）

- **V0 链级离线模拟（可先验、纯 CPU、零训练、复用 R2 analyze2.py D 段协议）**：2,000 个 GT coverage 图穿 {fixed0.5, 分桶常数, AMT-cell, AMT-subcell, oracle-τ} 五臂，出分桶 p50/frac≥0.5/0.75 + 加权链级 AP 估计。**门：AMT ≥ +1.2pt vs 0.807 且无分桶劣化 >1pt**；亚 cell 档在 <32px² 子桶额外 ≥ +0.5pt 否则砍档。
- **V1 校准门（BAS-CL+ 冻结权重，一次 val 前向，零训练）**：matched 对上逐桶 OLS (4·Σp vs GT 面积)。**门：后验校准后 R² ≥ 0.90 通过；<0.80 杀**（ACAR-3 后验仿射 α,β/桶先拟合使 slope=1，再量残差）。
- **V2 契约回归**：mode=fixed 逐位等于基线（Gate 0 同款）；CUDA-graph replay == eager；DeferredExportRing 载荷等值。
- **V3 端到端（post-BAS-CL+ 权重离线 eval）**：**ΔAP_s ≥ +0.4pt 且 AP_m/l/mAP ≥ −0.1pt**；τ 审计：256-1k 桶 |τ−0.5| p50 < 0.03（生产中大目标零扰动，即 F 探针失败模式的护栏）、<64 桶 τ 中位 <0.45（机制确实起作用）。
- **V4 TREX+ 联合**：z5 重拟合后联合 ≥ TREX+ 单独 + 0.2pt，防双计。
- **V5 可选训练臂**：仅当 V1 边缘（R²∈[0.80,0.90)）时 16K 微调 Σp-L1 臂，复跑 V1/V3。
- 附带负结果协议：sealed-128K（BAS-CL+ 之前）权重上跑 V3 预期 ≈0——**有意为之的对照**，用于证明「收益来自校准×读出的乘积而非读出本身」，同时复核全局阈值已死结论。

## 附：反面锚的逐条处置

1. **全局降阈值已死（0.45=+0.09 / 0.40=−0.13）**：AMT 非全局常数——归约定理保证大目标 τ≈0.5 不动，且死因（Σp 未校准的场）由 BAS-CL+ 移除；V3 τ 审计门护栏。
2. **F 探针（膨/蚀都差 17.6/39.6pt）**：探针在**全体** matched 掩码上 ±1px——AMT 只对质量退化的小目标偏离 0.5，中大目标逐位不动；且探针跑在未校准权重上。
3. **Mask R-CNN 28²→112² 退化（34.7→32.5）**：本方案不加任何分辨率/头/参数，是同一表示场的更优读出，不触发「固定分辨率上采样伤小目标」家族。
4. **DCT-Mask AP_S 仅 +0.5（AP@75 +2.1）**：其收益本质是内容质量（P3-a 已裁决域），小目标证据弱、需训练臂占第二阶段预算——**明确不采用**，把推理预算留给读出。
5. **RefineMask 小目标仅 +1.5 & 推理 −27% FPS**：精修头家族全线超预算或收益偏大目标，不采用。
6. **事后重标定不变排序（-13.1/-11.9）**：本方案改**掩码几何**不改分数排序，rank-不变性批评不适用；分数侧解耦后与该禁区无交集。

## 诚实备注

- +0.5~1.5pt 是条件期望（V1 门通过为前提），无条件下限为 0 且杀线预注册——本场若死，产出是「用数字永久关闭读出分支 + 确认 BAS-CL+ 校准的导出端不可兑付」，与 R2 的关分支原则一致。
- 链级 0.807/0.817/0.842 为 frac 积分估计（R2 自述偏高 ~4pt），只用作**相对**锚；绝对收益以 V3 端到端为准。
- 亚 cell 档的 ×2 双线性质量守恒近似（Σq ≈ Σp，非严格）在 V0 中以模拟校准系数，不引入学习参数。
