# P3-a 提案 #4｜BASS：边界锚定分层监督（Boundary-Anchored Stratified Supervision）

提案人：独立提案人 #4（P3-a 场，2026-09-21）。主攻：12544 点采样对小目标边界无约束。
一句话：**不动预算、不动匹配、不动推理——把 12544 个点的"位置分配"按边界长度等密度化，把每个点的"标签几何"换成渲染链可兑现的覆盖场，把带内点的梯度权重抬高**。三个组件（S1 采样 / S2 权重 / S3 标签）覆盖场内两个子轴，可独立开关。

## 0. 设计总览

| 组件 | 子轴 | 机制 | 开关默认 |
|---|---|---|---|
| S1 尺度自适应边界带分层采样 | 点采样策略 | 随机点份额按 GT 周长分享 + 逐 GT 地板（≥32 点）从"边界带坐标库"抽取；topk 不确定性候选池并入带内候选 | ratio 0.5 |

## (a) 机制因果链：为什么攻击根因而非症状

**根因链条（每环都有本仓库数字）**：

1. M2F 点损失把一个**固定且与实例尺度无关**的均匀点预算（12544）铺在画布上。对一个面积 A 的 GT，落在其边界带（|DT|≤2px @1024，≈1 个 512 cell 宽）的期望点数 = 12544×带面积/1024² ≈ 0.012×带面积。A=64px²（周长 32px）→ 带面积约 141px² → **期望 ≈1.7 个点**；3× 过采样不改变期望（候选池仍是均匀的），topk 只能在"均匀采样恰好落在哪"里挑。实测（BRIEF §1 证据锚）：10px 目标每次迭代仅 ~4-47 个采样点且不专门落边界。
2. 边界误差估计的方差 ∝ σ²/n_带内点。n≈2-5 时，每次迭代的边界梯度是一个高方差噪声样本——与 R4 的观测同构：hires 组 20× lr 噪声球、边界像素是最高方差预测（SYNTHESIS P3/P7 行）。**信号从未被分配到误差所在的位置**。
3. 系统最优解因此退化为"内部填充 + 边界 ±1-2px 随机抖动"：R2 §D4 实测 ±1px 膨胀/侵蚀都大幅变差（<64: 0.652→0.476/0.256）——非系统性偏移，是欠约束抖动；高 IoU 段崩塌（AP@0.75=0.247、@0.90=0.018，R2 §D1）。ce/mask/dice 损失自 24K 统计平坦（SYNTHESIS P7）= 现有信号已被榨干。
4. 该内容缺口被反事实精确切出：CF1 +27.1pt（0.2925→0.5636，R2 §D5/§D7）——检测集合、分数、渲染链全部冻结，只换已检出目标的掩码内容。

**BASS 在链条上的干预点**：S1 把 n_带内点按**周长等密度**分配（地板 32 点/GT/损失调用 ×9 层 = 每迭代 ≥288 个带内点 vs 现 ~4-47）——直接抬升 n、压方差；S3 让每个带内点携带**亚 cell 定量信息**（覆盖 0.37 vs 0.63 区分边界在 cell 内的哪一侧，硬标签只说"1"）——抬升单点信息量；S2 抬升带内梯度幅值。三者共同把"边界位置估计"从欠约束变成过约束。

**为什么不是症状层面的修法**（排除法）：
- 后处理形态学/阈值：R2 §D4 已证生产掩码无免费形态学红利；SYNTHESIS 已证事后抬分全灭。
- 加分辨率：反面教训 2（Mask R-CNN 28²→112² 反而 34.7→32.5，调研 [14]）。
- 只改损失形式（Kervadec 纯加权，调研候选 2）：对 ~4 个带内点做 λ 倍放大是在放大一个 4 样本统计量——方差问题没有被解决。**我们的数字结构决定了采样重分配必须先行**：PointSup 证明 ~10 点/目标即达全监督 94-98%（位置>数量，[8]），M2F 自己的重要性采样证明采样分布改动不掉点（[9]）。S1 正是在**零预算增量**下做位置再分配。
- S3 的针对性（超出所引文献的论证）：27.1pt 缺口本来就是"GT 穿生产渲染链"定义的（CF1 构造）。覆盖场标签 = 训练侧的链代理（avg_pool2d(2×2) 即 INTER_AREA 1024→512 的精确等价，R2 §D0/D3 用的同一算子），教会模型的正是"过链后仍高 IoU"的 0.5-等值线形态。医学边界损失文献 [1][4] 没有 CF1/CF2 分解，只能优化 DSC 代理；我们的标签与验收量（穿链 IoU）**构造性对齐**，且顺带把链 4.0pt 项中的形状可学部分前移（诚实声明：S3 收益计入 27.1 内，不与 CF2−CF1 重复计算——覆盖场完美回归的极限就是 CF1 锚 0.5636）。

**反面教训合规清单**（调研 §4 逐条）：① 无分辨率放大；② 区域损失原样保留 + λ_b ramp（教训 3 防塌缩，[1]）；③ 带宽尺度自适应 r(s)=clamp(√A/8, 1.5, 6)px@1024（教训 5 固定 trimap 失真，[23][4]）；④ 无预测边界检测算子（ABL detach 风险不引入，教训 4，[2]）；⑤ 不加 focal 项（教训 9 单类极小目标塌陷风险，[30]）；⑥ 零推理开销（教训 6）。

## (b) 与二分匹配 / set-prediction 的兼容性论证

1. **匹配在前、损失在后，因果单向**。匈牙利匹配的代价矩阵构造（`matcher.py:381-421`）本提案一个字节不动：均匀 12544 点集、AIM 小 GT 精算列（`matcher.py:276`，实验室 margin 2.43σ）原样保留。不存在"损失改变 → 匹配漂移"的反馈回路——AIM 的稳定性收益不被稀释。
2. **逐对损失结构不变**。M2F 损失本就是"匹配对的独立逐点项之和"：现行 `get_uncertain_point_coords_with_randomness` 已经**每行独立**采样（`torch.rand(num_boxes, ...)`，`criterion.py:97`），不同匹配对的点集本来就不同。S1 只是改变每行的采样分布（从均匀改为该行 GT 的带内/均匀混合），不引入任何跨对可比性需求（那是 matcher 代价的事）。
3. **集合置换等变**。S1 的配额分配 q_i = max(floor, n_band·P_i/ΣP)：ΣP 与周长份额在 GT 置换下不变 → 损失对 (queries, GT) 联合置换严格不变。S2/S3 是逐点逐行函数，天然等变。单测将显式验证。
4. **与 DN/辅助路径的一致性**。DN 正 query 的掩码损失（`criterion.py:674-699`）仍走均匀点（阶段 2 可选扩到 DN 正样本，同一 targets 几何零新增设计，与 P4-a 的 CDN 方案同向）。
5. **o2o 主匹配不毒化**。我们不增密正样本、不加支路、不动 query 数——set-prediction 的 o2o 语义完全保持。

## (c) 理论收益上界与依据

**硬上界**：+27.1pt rescore AP_s（0.2925→0.5636，CF1 定义；R2 §D5/§D7、BRIEF §1）。逐桶（R2 §D5 表）：<64 +2.7（0.0298→0.0566）、64-256 +18.7（0.1461→0.3336）、256-1k +33.2（0.3697→0.7013）。**近期可兑现集中在 64-256 与 256-1k**（matched 对 n=761/5016，rec@0.5=40.7%/75.1%）；<64 的 CF1 上限只有 +2.7pt 且受 rec@0.5=12.2% 的检测空洞钳制——那是 P4-b/c 的山，本提案不去碰。

**签名指标的可动空间**：matched IoU p50 <64: 0.635、frac≥0.75: 0.242 vs 链可达 frac≥0.75=0.817（R2 §D2/§D7）；AP@0.75 0.247→CF1 曲线 0.6023、AP@0.90 0.018→0.5267（R2 §D1/§D5）。即：**把 matched IoU p50 从 0.635 推到 ~0.75 一档，就能兑现 @0.75 段的大部分差值**——这正是边界精度（而非存在性）的敏感区。

**文献依据（均注出处）**：
- [1] Kervadec 边界损失：ISLES 小病灶 GDL 0.511→0.659（+14.8pt DSC）、HD95 减半（密集监督、直接优化 DSC 的上界型证据；单独用塌缩、对纯 CE 无增益 → 我们保区域项 + ramp）。
- [21] 植物 M2F + boundary loss：小目标 PQ_weed 49.17→51.16（+2.0，纯损失项、零推理开销）——同框架（M2F）最贴近的保守锚。
- [8] PointSup：~10 点/目标 ≈ 全监督 94-98%——位置分配 > 数量，S1 的合法性。
- [9] M2F 原生重要性采样：点损失不掉点省 3× 显存——采样分布改动的安全性先例。
- [4][23] 尺度自适应带宽的必要性（固定 trimap 对小目标失真）→ r(s) 设计。

**估计**：机制回收缺口的 25-40% → 收敛后 **+7-11pt rescore AP_s**（置信度：中。25% 下界锚 [21] 的同框架单项 +2.0 与 [1] 的小结构 +14.8 的插值，加上我们额外有 S1 密度修复与 S3 构造对齐两个 [21] 不具备的分量）。16K 短训门按 **净值 ≥+2.0pt** 判（见 (e)）。AP@0.75 与 AP@0.90 是最先响应的观测量。

## (d) 开销预算（算式）

全部计算 GPU 侧；每迭代一次、缓存跨 9 层深监督复用（在 `SetCriterion.forward` 顶部算好传入）。N=matched GT 数（均值 ~16/图，p90=41）。

**训练 ms/it**（基线 1.44-1.60 s/it，红线 +20% = +288-320ms）：

| 项 | 算式 | 估计 |
|---|---|---|
| 带掩码（2× maxpool3 on (N,1,1024,1024) f32） | traffic≈2×2×N×4MB=256MB @1.5TB/s | ~0.3ms |
| 覆盖图 avg_pool2d(2) | 64MB→16MB | ~0.05ms |
| 一次 nonzero（含 8B D2H 尺寸同步） | 16.8M bool 扫描 + sync | 0.5-1.0ms |
| 候选池扩容 37632→42336 的 grid_sample（+12%） | 现点采样全程 <5ms 量级 ×0.12 | ~0.6ms |
| 逐点加权/软标签 elementwise | (16,12544) | <0.1ms |
| **合计** | | **+1.5-2.5ms/it ≈ +0.1-0.2%**（预算占用 <1%） |

**显存**（红线 24GB/卡）：带 bool (N,1024,1024)=16MB（p90 42MB）+ 覆盖 f32 (N,512,512)=16MB（p90 43MB）+ 扩容坐标 (16,42336,2)f32=5.4MB + 库坐标 ~0.5MB ≈ **峰值 +40-100MB（≤0.4%）**。

**推理**：**+0ms**。无新模块、无新头、无导出改动（`gpu_postprocess.py` 与 `arch.py:_inference_raw` 均不触碰）——满足"推理近零开销同分优先"。

**CPU↔GPU**：仅 nonzero 的 8B 尺寸同步；无 CPU 预计算、无 dataloader 改动（GT 在 GPU 上现成，`targets[b]["masks"]` @1024²）。

## (e) 正确性验证方案

**1. 单测（CPU 即可，`tests/test_boundary_stratified.py`）**
- 几何：8×8 方块 GT @1024 → 带内 cell 数 = 期望解析值（4s·2r − 角修正）±1；覆盖图 cell 中心 = 面积分数（边界 cell=0.5）。
- 配额：64px² GT 获得 ≥32 个带内点，全部距轮廓 ≤r+0.5px；空带/贴边 GT 回退均匀不崩。
- **等变性**：(queries, GT) 联合置换 → 损失逐位不变（set-prediction 契约）。
- **回归护栏**：S1/S2/S3 全关（ratio=0, λ_b=1, mode=hard）→ 与基线损失**逐位相等**（同种子 golden 值）。
- 软标签：BCE(float 目标) 有限、label=0.5 处梯度存在。

**2. 冻结基座探针（零训练，F1 封存权重 + 200 张 val）**
- 实测带内/内部 BCE 比：预测 ≥1.5-2×（依据：±1px 抖动与 @0.75 崩塌意味着误差质量集中在带内）。**若 <1.1 → 假设证伪，杀**（成本一次前向）。
- 审计实际带内点数/GT/迭代 ≥32（机制交付核查）。

**3. ≤16K 短训门（从封存 128K 起，只换损失，4 卡）**
- 主门：rescore AP_s **净 ≥+2.0pt**（对照 SYNTHESIS Phase B 退火臂 +1.0-1.25 的对照线；无对照臂不判）。
- 签名：AP_s@0.75 **0.247→≥0.28**；AP@0.90 **0.018→≥0.03**；matched IoU p50 **<64: 0.635→≥0.68**（stretch 0.72）、64-256: 0.674→≥0.70；frac≥0.75 <64: 0.242→≥0.30。
- 护栏：256-1k matched IoU p50 回退 <0.01（不牺牲大目标）；**空掩码率 <1%**（教训 3 的塌缩监测）；ms/it 实测 ≤+5%。
- 消融（算力允许时 4K 臂）：S1-only vs 全开——分离采样子轴与损失子轴的贡献，判据 AP@0.75/ms。
- 杀线：8K 时 AP@0.75 无移动（<+0.01）且 matched p50 <+0.01 → 杀；空掩码率 >1% → λ_b 减半重试一次，再犯杀。

## (f) 与其它场胜出方案的叠加兼容性

- **P3-b（小掩码表示/解码：DCT 头、软导出、面积自适应阈值）**：正交且**正向互补**。P3-b 动头与导出端，BASS 动监督端；若 DCT 辅助回归胜出，其 L1 项与 BCE 路径共存。特别地：R2 §D4/F 段证明生产掩码**无阈值红利**恰因抖动——覆盖场训练校准了 0.5-等值线后，P3-b 的阈值扫描才从"≈0"变为可兑现行（校准场上的扫描 ≠ 抖动场上的扫描）。
- **P3-c（lr 分组退火/边界 EMA）**：乘性叠加——P3-c 压噪声幅值，BASS 抬信号密度，同位置双改 SNR。无参数冲突（他们动 optimizer/EMA，我们动 loss）。已知交互风险：带内加权放大边界梯度 ×hires 组 20× lr 噪声 → 建议 λ_b ramp 2K 步起步，与 P3-c 的分组退火合并臂验证（BRIEF §3 的对照臂本身就是其最小版）。
- **P4-a（o2m/CDN 增密）**：不动匹配、不动 query 集 → 与任何分组/隔离方案无冲突；DN 正样本路径（`criterion.py:674`）可零成本获得同一分层采样（CDN 的 mask 项直接受益）。
- **P4-b（query 种子/热图预算）**：probe 辅助损失（`arch.py:203-237`）独立于 `_loss_masks`，零接触；种子 query 存在后画得更准（我们的收益作用于"会画的 query"全集）。
- **P4-d（导出重打分/maskness 解耦）**：推理端，零交互；且边界校准后小掩码 maskness p50 0.613→上移，直接减轻 P4-d 要解的结构性压分。
- 显存/时序预算：BASS 占用训练预算 <1%、推理 0、显存 ≤0.4%——与任何其它场方案叠加不触顶。
