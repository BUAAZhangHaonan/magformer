# P4-a 提案 #2：ECDN —— GT 回声对比去噪支路（Echo-Contrastive Denoising）

> 提案人：独立提案人 #2｜2026-09-21｜纸面轮，不跑实验
> 一句话：**在 200 主池之外附加一条"免匹配"的小 GT 回声支路**——每个小 GT 以 K=3 个噪声水平"回声"出生 3 次 + 1 个大偏移负样本，块对角自注意力隔离，q 目标（MAL-CP+ 同源）监督，推理整支路丢弃（0 ms）。正样本供给 ×4，主匹配零改动。

## 1. 现存 DN 路径缺陷清单（Phase-0 必修，任何 DN 臂的前置）

## 2. (a) 机制因果链

### 2.1 o2o 下小 GT 正样本稀缺如何限制学习

1. **供给侧**：o2o 二分匹配下每个 GT 每步恰好 1 个正 query。batch=4 时 <64px² GT 期望仅 **0.85 个/步**（SYNTHESIS P10；R5）——即整个 batch 每步平均只有 0.85 个 query 行在"画+打分一个极小目标"上收梯度。P4-c 贴入（C2）把它提到 ~3-10/步，仍是全部梯度质量中最细的一股。
2. **方差侧**：小目标的正样本行本身高方差——AIM 之前归属掷硬币（margin 0.13σ，R3-D5）；AIM 后归属稳定（2.43σ），但单行监督下，掩码头/注意力在"stride-4 上 2-3 cell 目标重构"这一技能上的有效梯度样本量 = 每步个位数，与中大目标（每步 ~50 行）差 **1-2 个数量级**。ce/mask/dice 自 24K 统计平坦（R4）说明现有信号已耗尽，缺的不是步数是**该子群的样本量**。
3. **技能侧**：SCB+ 让 64 个种子槽出生在 probe 峰上（覆盖 92.1%），但出生→持有→画出的通路（`seed_proj_*` 投影 + 8 层注意力持有）**没有任何 GT 锚定的梯度**——probe 峰只是间接监督。种子实验"覆盖 92% 但 cls 卡 0.22-0.29"正是这条通路欠训的症状。
4. **纪律侧**：<64 det 池 **80.5% 是 hard-FP**（P4-c 证据锚）——分数纪律（"似是而非处→无物"）在纯 o2o 下只有 199 个负 query 行/图 可学，没有针对小目标邻域的定向负样本。

### 2.2 ECDN 为何安全且对症

- **供给 ×K 不经匹配**：回声 query 由构造直接指定源 GT（无 Hungarian、无 cost 矩阵）——"每个 GT 多个正样本"发生在匹配**之外**，主匹配的 o2o 语义逐位不变。这正面绕开 naive o2m 崩溃（3300 query 不分组 32.6→8.4，Group DETR 表 7）与 DDQ 稠密不去重毒化：稠密重复行**从不进入**主池匹配、也从不进入导出。
- **训练的正是种子通路**：回声 query 与 SCB+ 种子槽同构——从 `mask_features`（stride-4, 256²）在出生 cell gather 特征、过**同一对** `seed_proj_content/seed_proj_pos`（`multiscale_decoder.py:320-327`）。DN 臂以 GT 锚定梯度（每个小 GT 每步 3 次）训练这条投影+持有+画出通路，主池种子槽免费继承。这是对 P4-b "覆盖可解、分数捆绑"架构的供给侧补全。
- **负样本对症 hard-FP**：每 GT 1 个大偏移（2.5×尺寸、落点不得在任一 GT 前景内）负行，cls 目标 no-object（sigmoid focal α=0.25，与主负样本同形式）——小目标邻域的定向"无物"监督，是 CDN 负组（DINO ICLR23："负样本管分数纪律"）在单类下的正确形态（修 D2）。
- **q 目标锁死分数语义**：DN 正行 cls 目标 = 该行对自己源 GT 的 σ-Dice（AIM 确定性网格、detach、warmup 1000、QFL β=2.0）——与主池 matched query 的 MAL-CP+ C1 目标**同一标量、同一度量、同一日程**。共享分类头在两条臂上收到一致的"分数=可达质量"信号，o2m 增密不配质量目标=分数通胀的 DEIM 消融风险（DEIM CVPR25）由构造排除。
- **推理零成本**：`_generate_dn_queries` 已有 `not self.training → None` 守卫（`arch.py:1373`），推理路径（`arch.py:1034-1066`）从不传 DN 参数；eval 时 Nq=200，自注意力 mask 不构建。结构性 0 ms，不靠"丢弃"靠"从未存在"。

## 3. (b) 与二分匹配 / AIM / 种子槽（SCB+）的兼容性与隔离设计

### 3.1 构造（替换 `_generate_dn_queries`）

```
资格：processed targets（贴入后）中 0 < area < 4096 画布 px²——与 AIM 资格线同一张量同一单位（matcher.py:292），零单位漂移
优先级：按面积升序，每图取前 n_cap=12 个（实际服务 <64-256px² 主体：资格线均值 12.7/图）
正样本：K=3 组，组 g 出生偏移半径 r_g ∈ {0.25, 0.5, 1.0} × d_GT（d_GT=GT bbox 长边），方向均匀采样；
        出生 cell = clamp(质心+偏移) → gather mask_features → seed_proj_content/pos（SCB+ 参数共享）
负样本：每 GT 1 行，r_neg = 2.5 × d_GT，落点在任一 GT 前景内则重采样（≤3 次，仍冲突则弃）
每图行数：N_dn = 4 × 12 = 48（批内 pad 到同长，含 src_gt_idx/group_id/valid 映射张量，替换
        criterion.py:624-636 脆弱的 nv×dn_scalar reshape 假设）
```

噪声模型说明：mask 语义下的"噪声"定义在**出生位置空间**（质心偏移课程 0.25→1.0×尺寸）而非框坐标抖动——因为 query 的信息入口是出生 cell 的特征，偏移课程等价于 CDN 的噪声梯度组（DINO 的正组小噪声/负组大噪声），且与种子槽的出生形式完全同构。

### 3.2 隔离设计（三层）

1. **自注意力块对角 mask**（修 D1）：`_forward_decoder_layer` / `_forward_decoder_layer_deformable` 传入 2D `tgt_mask (Q_total, Q_total)`：主池块全 False（不变）；每个 DN 组（同 GT 的 3 正行互相可见；负行各自只见自己）为对角块；跨块全 True。结构只依赖行号区间 → 与 batch/内容无关，一次构建全程复用；对角线恒 False（无全遮蔽行）。Q_total=248，mask 248² bool ≈ 61KB，构建 <0.1ms。
2. **交叉注意力行级独立**（现状已安全，需单测锁死）：每行的 topk/0.5 阈值 mask 来自该行自身预测（`multiscale_decoder.py:1086-1160`），行间无泄漏；probe-fg 种子先验仅施加于种子行块 `[num_learned, num_regular)`（`multiscale_decoder.py:847-853`，AUD-2 L1 已修）——DN 行在其后，保持自身遮蔽，二者正交（UT-8 验证）。
3. **匹配/损失层剥离**（现状已安全，需单测锁死）：criterion 在 matcher 与全部 aux 损失前把 DN 行剥到 `num_regular`（`criterion.py:210-220`, `:244-253`）——matcher 看到的恰是 200 行（136 学习 + 64 种子），AIM 列构造逐位不变，**ECDN 不产生任何额外 matcher 调用/ AIM 列开销**（对照 §3.4）。

梯度隔离的诚实说明：DN 损失梯度进入**共享权重**（这是机制本身——掩码头/注意力/出生投影获得额外小目标梯度），但主池 query 嵌入、匹配、导出不受任何单步内交互；UT-3 用"扰动 DN 目标 → 主池损失逐位不变"证明单步零交互。

### 3.3 DN 损失（替换 `_compute_dn_loss`）

| 项 | 形式 | 权重 |
|---|---|---|
| 正行 cls | QFL，目标 q = AIM 网格 σ-Dice(该行 mask, 源 GT)，detach，warmup 1000（同 C1） | 2.0 × λ_dn 0.5 |
| 正行 mask | BCE@12544 点（与主损失同点机制），balanced_ce 同 config | 5.0 × 0.5 |
| 正行 dice | 同主 `_dice_loss` | **20.0** × 0.5（修 D5 权重错位） |
| 负行 cls | sigmoid focal α=0.25，目标 no-object；无 mask 损失 | dn_contrastive_weight 0.5（现有键） |

仅末层计损（预算取舍，§5；DINO 的逐层 DN 留作上档臂）。q 计算：N_dn×源GT 对 ≤48 对 × R²≤4096 采样点 ≈ 0.2M 点/步，对照 AIM 列 42-100M 点/步，可忽略。

### 3.4 为什么否决匹配式 o2m（Group DETR / H-DETR / MS-DETR）

| 方案 | 训练开销（我们的口径） | matcher/AIM 开销 | 判决 |
|---|---|---|---|
| Group DETR（K=3 组×100q） | m=(200+200)/200=2.0 → +10-15% 步时；文献 +18%（M2F 23→28 min/ep，调研B） | **匹配 ×K**：AIM 列 point_sample 部分随 Q×K（P4-c 已把 AIM 列记账为 +40-80ms 主项 → 再 +80-160ms） | 合计 +15-25%，超本场 ~10% 余量 |
| H-DETR（300 辅助 q, K=4 重复 GT） | m=2.5 → +19-31% 步时 | 匹配 ×2 支路 | 同上更贵 |
| MS-DETR（o2m 加在主池上） | 最省 | 主池匹配被改动 | **主池污染通道由构造存在**，需解耦损失对冲（AIM 无先例），风险不可裁 |
| **ECDN（本提案）** | m=1.24 → **+2.4-3.6%** | **零额外 matcher 调用** | 通过 |

Group DETR 的 M2F 公开数字（38.5→39.7，+1.2 mask AP，12ep）保留为本提案 (c) 的收益锚——机制同族（每 GT 供给 ×K），本提案是其在我们预算下的可行压缩形态。

## 4. (c) 理论收益上界与依据

**主张：单臂 AP_s +1.0~2.5pt（16-48K，叠加 MAL-CP+ + SCB+ 基座）；上界 +3~4pt。**

依据链（每步注出处）：

1. **同族机制收益锚**：DN-DETR R50 12ep +1.9 AP（43.4，arXiv:2203.01305）；Group DETR 在 Mask2Former 上 +1.2 mask AP（38.5→39.7，12ep；50ep +0.3，arXiv:2207.13085）——供给 ×K 对"欠供子群"收敛的正收益有跨架构复现。H-DETR +1.7（47.0→48.7，arXiv:2207.13080）。注意这些是全尺寸 COCO 数字；我们的 ×4 供给集中在 <4096px² 子群（其正样本密度缺口比 COCO 均值大 1-2 个数量级，§2.1），方向有利但**无 AP_s 专属公开锚——这是本提案最大的诚实不确定项**。
2. **收敛速度锚**：DN-DETR 同性能只需 50% epoch——供给稀缺的子群在 16K 短训门里的可测位移主要来自这一项（欠训技能的快速补课），与我们 ce/mask/dice 自 24K 平坦（R4）的"信号耗尽"诊断互补。
3. **价值上界的诚实边界**：召回补全的物理值 +37.5pt 是 oracle 分数口径（R3-D6）；现实分数口径 +6.7pt。ECDN 不直接拥有这 37.5——覆盖归 SCB+、分数变现归 MAL-CP+。ECDN 的可归因份额是 SCB+ 裁决书三因子分解（oracle 段 × r(0.55) × f(0.25)）中 **r（出生通路技能：DN 训练 seed_proj+持有）与 f（分数纪律：定向负样本打 hard-FP）两个系数**：r 0.55→0.65、f 0.25→0.35 的保守抬升 ≈ 覆盖段价值 ×1.6。以 SCB+ 自报 16K 门 +1.0-1.5pt 为基，ECDN 在其上的增量 +0.8~1.5pt（=16K 门 G4），48K 外推 +1.0-2.5pt 与 Group DETR 的 +1.2 同量级。
4. **负样本臂独立小收益**：hard-FP 占 <64 det 池 80.5%（P4-c 锚）且事后抬分全灭（-13.1/-11.9）→ 唯一出路是训练期定向负样本；CDN 负组即此形态（DINO：负样本管分数纪律）。MAL-CP+ 的 G2 门（hard-FP 中位 ≤0.10 且不随 TP 上移）由 ECDN 负臂提供第二重保险。
5. **不含**：掩码内容质量 27.1pt（P3-a 领地）、渲染链 4.0（P3-b）、导出端 ≤2（P4-d）。与 P4-c 主张 +3~6、P4-b +4~9 分臂归因，不双计。

## 5. (d) 开销预算

**算式**（步时 T=1.44-1.60s；解码器+头部占步时份额 φ=0.10-0.15，出处：调研B 候选1"解码器算力 +30-50% 但只占总步时 ~10-15%（pixel decoder 主导）"）：

- 查询数乘子 m = (200+48)/200 = **1.24**（解码器自注意力/交叉注意力/FFN/9 次头部 einsum 均随 Q 线性；Q_total=248）
- 解码器+头部增量 = T × φ × (m−1) = 1.44×0.10×0.24 ~ 1.60×0.15×0.24 = **35~58 ms/it（+2.4~3.6%）**
- DN 损失（末层一次）：B×48 行 × 12544 点 ≈ 2.4M 采样 ≈ 主掩码损失（~222 行 ×9 层 ≈ 25M）的 ~10% → +5~8ms
- q 网格 + 块对角 mask 构建 + 负样本重采样：<5ms
- **合计 +2.7~4.2%（~40-65ms/it）**

**叠加账本**（红线 ≤+20%）：P4-c MAL-CP+ +3~6%（含 AIM 列 +40-80ms 主项）+ P4-b SCB+ 核心 +~1% + **ECDN +2.7~4.2%** = **+6.7~11.2%**，余量 8.8pt 给 P3-a（损失侧，~+0.1-0.3%）。ECDN 对 P4-c 已记账的 AIM 列开销乘数为 **1.0**（零额外 matcher 调用，§3.2-3）——这是对 P4-c 裁决"开销记账诚实"条款的遵守。

**推理**：0.00 ms（训练期专用构造；eval Nq=200 与 F1 逐位一致，UT-1 锁死）。显存：DN 行激活份额 ≈ (m−1) × 头部激活，AMP fp16 下头部 einsum（256²×9 次 + 512²×1 次）主导，估 **+0.3~0.6 GB**；门：实测 ≤1.0 GB（对照 Group DETR 文献 +1.2-1.7GB/3300q@更低分辨率）。

**档位阶梯**：降档 K=2/ cap8（N_dn=24，m=1.12）→ +1.4-2.2%；上档 K=3/ cap16 + 逐层 DN 损失（0.2 权）→ +3.9-5.8% + ~1%。默认中档。

## 6. (e) 正确性验证方案

### 6.1 Phase-0 单测（训练前，隔离修复独立 commit）

| UT | 内容 | 判据 |
|---|---|---|
| UT-1 | **逐位回归**：dn off（含 SCB+ 开/关）前后向输出、损失、matcher indices | bitwise 相等 |
| UT-2 | 块对角结构：主池块全 False；DN 组对角块；跨块全 True；对角线恒 False；2D 形状 (248,248) | 断言通过 |
| UT-3 | **防作弊梯度测试**：单次前向，扰动 DN 源 GT mask → 主池各项损失 | 逐位不变（单步零交互的机器证明） |
| UT-4 | 构造：资格/面积升序截断/批 pad/偏移界（正 ≤1.0×d_GT、负 ≥2.5×d_GT 且不在任何 GT 前景）/映射张量与损失行对齐 | 断言通过 |
| UT-5 | q：∈[0,1]、detach（梯度不回流 mask）、warmup 日程、空 tiny 批（N_dn=0 → 损失为 0 无除零） | 断言通过 |
| UT-6 | 负样本语义：任何负行出生 cell 的 GT 前景占用率 = 0 | 断言通过 |
| UT-7 | 权重/形式：DN 三项权重 = 主损失 ×0.5；负行 focal α=0.25；无 softmax-CE | 断言通过 |
| UT-8 | 种子先验 ∩ DN：probe-fg 行级 mask 只落种子行块（`multiscale_decoder.py:847-853` 语义保持） | 断言通过 |

### 6.2 P0 冻结探针（前置门，封存 F1 权重离线前向，~1h GPU）

- **P0a 通路存在性**：val 子集（≥1000 个 <64px² GT）注入 oracle 出生行（零偏移 GT 质心 + gather 特征，隔离注意力），读末层 σ-Dice。**过门：p50 ≥ 0.4 且 ≥60% 的 tiny GT 达 σ-Dice ≥ 0.3**（对照主池 87.8% never-hit，R3-D1）→ 通路存在，DN 训练可固化；**不过：解码器机械对 tiny 目标本征失效 → 源头否决，移交 P6 持有侧**（预注册止损）。
- **P0b 负臂空间**：oracle 行 cls 分 vs hard-FP 位置 cls 分的分离度（AUC）——现状应接近随机（TP 0.29 vs hard-FP 同分布），为 16K 对照基线。

### 6.3 16K 短训门（预注册；基座 = MAL-CP+ + SCB+ 单 commit 栈，单因子 ±ECDN）

四臂：A（栈）、B（栈+ECDN）、C（栈+ECDN，q-off one-hot——**DEIM 必要性的在位证明，预期 C 翻车**，对应 P4-b "MAL-off 臂必须复现 0.29 卡死"）、D（降档 K=2）。

**收益门**：
- G1 供给转导：<64px² never-hit 87.8% → B 比 A **再降 ≥10pt**（A 自身目标 ~65%；B ~55%）；AR_s@100 ≥ A+0.02
- G2 分数纪律：hard-FP（<64 池）分数中位 ≤0.10 且份额 ≤80.5% 基线（**不随 TP 上移**——与已证伪事后路线的分水岭）；tiny TP 分中位 ≥0.40（不劣于 A）且 ≥0.45 为强信号
- G3 排序：AUC 0.75→≥0.82（与 P4-c G3 同口径，B 需 ≥A）
- G4 净值：AP_s（rescore）B−A ≥ **+0.8pt**（强 ≥1.5）→ 过门进 32-48K（判据：净超 R4 退火对照线 ≥+1.5pt）

**防毒化哨兵（任一越线 = 臂失败，预注册）**：
- S1 主匹配质量：主池 matched-IoU p50 ≥ 0.635（R2 基线），B ≥ A
- S2 主匹配稳定：相邻 aux 层匹配翻转率（新仪表，A 臂首测基线）B ≤ A×1.1
- S3 重复率：dets/small GT ≤1.6（基线 1.30，R3-D3；>2.0 硬停——稠密毒化哨兵）
- S4 大目标无回归：non-small mAP 波动 ±0.2pt 内（共享头污染哨兵）
- S5 梯度占比：‖g_DN‖/‖g_total‖ ≤0.5 持续（每 500 步记录）
- S6 **作弊哨兵**：DN 重构损失 <1K 步内塌到近零 → 立即停臂审计隔离（UT 之外的运行时保险）

### 6.4 失败判读树（预注册）

- 覆盖不动（G1 fail）但 S1-S4 干净 → 供给未转导主池：先升 cap 至 16/资格扩到 <256px²，再考虑 K=4；二连败 → 通路假设错，回 P0a 复诊
- S3 越线（重复暴涨）→ 负正比 1:3 → 1:2，或 λ_dn 0.5→0.35
- S4 越线（大目标回归）→ 资格线收紧到 <1024px²（只喂 starving 桶）
- C 臂（q-off）若不翻车而 B 无增益 → 本场机制无效，MAL 已吸干收益 → 明确放弃，不追加大算力

## 8. 结论

ECDN 是本场主题（AIM 之上安全 ×K 供给）在剩余预算内**唯一同时满足全部硬约束的机制形态**：免匹配（绕开 o2m 崩溃/毒化两条反面教训的构造性根源）、块对角隔离（修 D1 真缺陷）、q 目标捆绑（DEIM 铁律由构造满足）、推理 0ms、+2.7~4.2% 训练开销、且与两个已裁决捆绑件（MAL-CP+ / SCB+）形成供给×质量×覆盖的乘法闭环而非竞争预算。独立主张 AP_s +1.0~2.5pt，16K 预注册门 +0.8pt，六个防毒化哨兵 + 冻结探针 P0 前置否决权，失败判读树预注册。
