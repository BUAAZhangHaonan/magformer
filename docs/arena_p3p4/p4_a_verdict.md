## 二、裁决

**胜出（骨干）：#1 mCDN**——缺陷审计最全（7 项）、安全架构最完整（关 DN 时常规行输出**逐位相等**的 parity 单测 + 匹配 indices 逐位不变单测双锁定）、负样本设计唯一无假阴性风险（GT-free 环带验证负，规避单类陷阱）、供给分解最诚实（×11-35 与贴入乘法协同）。

**合并采纳（最终形态 mCDN+）**：
1. **#4 的最小 4 GT 保底**（<64 桶必全入选——与供给公平性对齐）与**中间层头只算常规行**的省钱结构（+3.6% vs +32%，决定性工程优化）；其"单类滚动负样本"陷阱分析并入 #1 的环带负设计论证；
2. **#3 的 3 档噪声表**（0.05/0.15/0.30×box，12px 目标位移 0.6/1.8/3.6px——对小目标的物理量标定）与 AIM 确定性窗口网格作为 DN 掩码损失（与匹配同度量）；
3. **#5 的双噪声级正样本 + K 自适应 4-8 + G0 冻结探针前置门**（噪声分级锚定 AIM 30% 窗口边界，训练前可否决）与错位/尺度失配两族负样本（直击 80.5% hard-FP 池）作为环带负的补充臂；
4. **#2 的出生投影共享**（DN 与 SCB+ 种子共用投影层——工程去重）。

**亚军：#5 QDN-tiny**（诚实账最全；若 mCDN+ 的环带负在实现中受阻，回退其两族负样本设计）。

**mCDN+ 最终形态**：每图最小 4 GT 保底 + AIM 资格线截 M≤8，K=3（0.05/0.15/0.30×box）+ GT-free 环带验证负（补错位/尺度失配族）；DN 行进 matcher 前剥除、块对角隔离、中间层头仅常规行；正样本 cls 目标 = q（AIM 同窗口 σ-Dice，承 MAL-CP+）、掩码损失 = AIM 确定性窗口网格；推理 0ms。训练 +2~4%，叠加 P4-c/b 后总 +6~11% ≤ 20%。

## 三、实验室验证（预注册）

1. 前置：树内 DN 缺陷修复清单（~10 项）逐项单测；G0 冻结探针（噪声分级落点核查，d₀≥0.25 否决线承 #1）。
2. 安全不变量：关 DN parity 逐位相等；匹配 indices 不变；推理 dets 与无 DN 逐位一致。
3. 16K 双臂（DN on/off，均含 MAL+种子）：主门净 +0.5~0.8pt；哨兵：主匹配 matched-IoU 不降、每 GT det 数 ≤1.45×、hard-FP 不随 TP 上移、TP 分中位 ≥0.40（与 P4-c 门共享）。
4. 失败判读树预注册（承 #1/#5）。
