## (a) 机制因果链

### a.1 边界抖动的噪声分解

边界预测 = 偏置项 + 噪声项。**偏置 ≈ 0**：±1px 膨胀/侵蚀对称变差证明抖动是零均值振荡而非系统性偏移（场简报 §1 证据锚）。因此本场的可作用对象是**方差**，分解为三个噪声分量：

- **N1 轨迹噪声（权重噪声球）**——主导分量；
- **N2 分配/目标噪声**——匹配掷硬币已被 AIM 削（margin 2.43σ），"目标不可实现"型噪声将由 P3-a BAS-CL+ 消（已裁决，本场不碰）；
- **N3 EMA 窗口失配残差**——评测权重的残余噪声。

### a.2 N1 的优化器侧成因（每一步都有代码/日志证据）

1. **更新幅值 = lr × O(1)**：preclip gradnorm 中位 1200-1400，clip_value=1.0 全程生效 → 100% 步被裁剪，有效更新 = lr × 单位方向向量（R4 §详细分析(2)，Deformable-DETR 式；trainer.py:1067-1093 张量系数裁剪核验）。
2. **平稳噪声球半径 ∝ lr**（OU 型平稳分布：加性噪声 σ∝lr，恢复力由曲率定 → 稳态 std ∝ lr）。hires 组（hires_dw/hires_proj/hires_shuffle + small_probe/seed_proj/seed_norm + 末层 cross-attn，train.py:747-759）20× lr → **边界关键模块的权重噪声 std 是主组 20×（方差 400×）**：峰值 2e-4，128K 时仍 1.02e-4 vs 主组 5.08e-6（R4 lr 表，与 logged 值逐点对账 <2%）。
3. **边界像素恰是这些模块的最高方差输出**：512² 掩码画布由 stride-2 头（hires 三件套）写出，边界像素位于 logit≈0.5 判决面，权重噪声直接翻转 ±1px 二值化结果。R4 堵点 3 的桶间 ce 振荡（0.25-0.45，残差 std 0.05）与 112K 桶 ce 反弹 ~2σ 与此一致。
4. **信号/噪声时序错位**：ce/mask/dice 自 24K 统计平坦（OLS t=-0.2~-0.7），即画布头模块的可达信号在 24K 附近探索完毕；此后 100K+ 步该组维持 1.0-1.4e-4 的 lr 只是在**制造噪声球**，不再产生方向性收益。EMA（10K 有效窗）在此条件下回收了 +1.02 AP_s（docs/2026-09-21-f1-128k-calibrated.md 表二：EMA 0.2700 vs raw 0.2598 同协议配对）——这是 N1 可回收份额的**实测下界锚**。
5. **N3 的成因**：单一 decay=0.9999（半衰期 6.9K）对所有参数一视同仁。对相关时间 τ 的游走噪声，EMA 残差 ∝ τ/W（W 为有效窗）。hires 键噪声 20× → 同窗口下残差 20×；反之，仍活跃的 giou 流（-0.0020±0.0006/8K，t=-3.2，唯一存活的信号）流经末层 cross-attn，被 10K 窗滞后（均值滞后 9999 步，R4 堵点 4）。**一刀切窗口对最噪的键欠平均、对最活的键过滞后**——这是纯架构性失配，不涉任何损失形式。

### a.3 本方案消哪个分量、怎么消

| 分量 | 手段 | 机制 |
|---|---|---|
| N1（画布头份额） | **BTA**：hires 画布三件套（hires_dw/proj/shuffle）改用压缩余弦 T_h=192K + floor 5e-6 | 该组信号已证明 24K 耗尽（mask/dice 平坦）→ 提前 64K 步进入 ≤2e-5 低噪区，噪声球提前收缩；主组日程逐点不变 |
| N3 | **2E**：画布三件套键 decay=0.99995（半衰期 13.9K，有效窗 20K），其余（含末层 cross-attn、box/cls 头）维持 0.9999 | 最噪的键拿到 2× 窗口（残差减半量级）；仍携带 giou 活信号的键保持短窗不受额外滞后。256K 生产运行内以**双 shadow 并存**（旧窗+新窗，final eval 双评取优）实现零风险 A/B |
| N1 的"掩蔽份额" | BTA 的中段效应（附带检验） | R4 堵点 3(ii)：104-112K 增量塌到 +0.04 可能是 hires 噪声淹没信号而非信号真尽；中段退火直接检验此假设 |

**不声称**：不创造新信号（27.1pt 掩码内容山归 P3-a）；不改损失形式、不改匹配、不改采样；只把方差兑换成精度，上界受噪声池约束（见 c）。

**分组路由的证据**（为什么只对画布三件套动刀）：
- mask/dice（画布头直接产出）自 24K 平坦 → 固定 T_h=192K 安全；
- giou（经末层 cross-attn + box 头）仍在降 → 末层 cross-attn 留在主日程、标准窗口；
- probe/seed（P4-b 领地）→ 留主日程，由共享 helper 决定归组（见 f）。

## (c) 理论收益上界与依据

**噪声总池（上界锚）**：EMA−raw = **+1.02 AP_s** @128K 同协议配对（docs/2026-09-21-f1-128k-calibrated.md 表二）。这是"10K 窗平均在恒定 lr 下可回收的轨迹噪声"，更长窗+退火可回收更多，故 1.02 是噪声池的**下界**、本方案全部收益的**上界**（生产中不可能超过 +1.0）。

**退火尾段估值（R4，对照臂将转实测）**：128K 停训放弃 +1.0~1.25pt（区间 +0.1~+1.9；幂律 +1.25/对数 +1.88/老家族锚 +0.83）。注意：**这部分属于 vanilla 256K 余弦本身就会拿到的**，不得计入本方案增量——这正是 (e) 对照设计的核心。

**本方案在生产 256K（vanilla 余弦之上）的三个增量通道**：

1. **中段解掩蔽**：vanilla 下 hires 在 96-224K 维持 1.4e-4→7.8e-6（R4 lr 表），画布头 100K+ 步泡在噪声球里；R4 堵点 3(ii) 明示增量塌到 +0.04/8K 可能是噪声掩蔽。BTA 让该组 152K 起即 ≤2.2e-5。若掩蔽假设成立，中段恢复部分增量率：老家族尾段份额校准（末 1/4 +0.24 / 后半 +0.71~0.83 ≈ 30%），保守按 130K 步 × 0.1pt/8K × 30% 复原 → **中心 +0.15~0.3，区间 [0, +0.8]**。
2. **EMA 残差回收（2E）**：最噪键窗口 ×2 → 残差约减半。该残差从未被测过（F1 只存 best/last，无权重轨迹），先验中心 **+0.1~0.2，区间 [−0.1, +0.4]**（负尾=滞后代价，已用键路由压到平坦信号键上）。
3. **冻结点方差收敛**：非均值收益。128K 封存实证了"EMA 整合高 lr 期权重"的风险（R4 堵点 4）；settle 窗 ≥4.6 半衰期后终评权重的重复方差收窄 ±0.1~0.2pt 量级，不计入中心估计。

**合计：中心 +0.25~0.5 AP_s，区间 [0, +1.0]**（0 = "平台真耗尽"情形，此时方案退化为零成本保险）。所有数字出处：R4 report §结论摘要/堵点表；calibrated 报告表二；mask_boundary.md §1（±1px 对称性）；老家族数字取 R4 §详细分析(4)。

## (d) 开销预算（算式）

**训练（生产 256K）**
- BTA：`build_cosine_lr_scheduler` 改为 per-group lambda 列表（torch LambdaLR 原生支持），每步开销 O(#groups) CPU ≈ 微秒级 → **+0.00%**。
- 2E 双 shadow：对画布三件套键（约 50-100 个张量，<1M 参数）每次 optimizer step 多一组 mul_+add_ ≈ +100 次 kernel launch ≈ **+1~2ms/it**；当前 1.44-1.60 s/it → **+0.07~0.14%**。
- 合计 **≤+0.5%**（含余量），500-it bench（ddp_bench 协议）实测门：增幅 <8ms/it。
- 对照五场已占 +6~11%：总账 **≤11.5% < 20% 红线**，本方案几乎不占预算。

**推理**：架构零改动、部署权重=EMA shadow（现状不变，张量数不变）→ **+0.00ms**（满足"推理近零开销同分优先"条款）。

**显存**：第二 shadow 仅画布三件套键，<1M 参数 × 4B ≈ **≤4MB**（按 5M 参数上界算 ≤20MB），<0.1% of 24GB。无激活值变化。

**验证成本（单列，非生产开销）**：Arm U（R4 收尾臂，已批/已列支）32K 步 ≈15.4h；Arm D（本场新增差分臂）同 15.4h；离线窗宽探针 2 次 full-val 重评 ≈30min；CPU 单测分钟级。

## (e) 正确性验证方案（对照臂设计=核心）

### e.0 CPU 单测（纸面轮后、GPU 前）
1. **lr 契约表测**：步 {2.5K, 48K, 96K, 128K, 152K, 160K, 192K, 224K, 256K} 上，主组/骨干/mgm 组 lr 与 vanilla 构建逐位一致；λ_hires 单调、192K 后=floor 5e-6±10%、152K ≤2.2e-5。
2. **主组路径不变性**：1000 步干跑 schedule 循环，断言非 BTA 组 optimizer lr 序列与 vanilla byte-equal——**这是把臂间差分归因于 hires 日程的许可证**。
3. **分组 EMA 回环**：2 张量玩具模型 + 合成噪声，断言各键按各自 decay 收敛；apply_shadow/restore 位精确；旧版单 decay checkpoint 可载入（向后兼容，默认 decay 路由）。
4. **平台触发器**：平坦/斜率合成序列的触发与滞回正确。

### e.1 收益分离设计（"我的方案收益" vs "退火本身收益"）

混淆源：任何退火日程的收益都混着 (i) 通用退火（噪声球收缩）与 (ii) 本方案定向差分。分离手段=**共享对照 + 单因子差分**：

- **Arm U（对照=R4 收尾臂，不新增成本）**：128K 封存副本续跑，max_iter=160K，两组同用 160K 余弦（128K 处 mult≈0.099：主组 9.9e-7、hires 1.99e-5，R4 §续跑设计）。产出 **A_u = AP_s(160K,U) − 0.2698** = 退火+续训总收益（R4 池 +0.5~1.3 的实测化）。
- **Arm D（差分臂）**：种子/config/eval 节奏与 U 完全一致；**唯一差异** = 画布三件套 λ 压缩（128K 的 1.02e-4 余弦降到 floor 2e-6 @144K 后平坦），主组 lambda 与 Arm U 数值逐点一致（单测 e.0-2 断言）。产出 **A_d**；**A_d − A_u = 纯定向日程效应**，通用退火分量被设计抵消。
- **离线窗宽探针（替代 Arm E 训练臂，省 15.4h）**：Arm U 按现有 checkpoint_period=8000 **落盘滚动 ckpt**（F1 只留 best/last，此为臂的配置要求），对画布三件套键做最后 m∈{2,4} 个 ckpt 的等权平均（=更长窗 EMA 的离线仿真），贴入 160K EMA 权重后按校准协议重评。产出 **A_w − A_u = 纯 2E 机制效应**（日程零差异）。注：F1 封存无权重轨迹，此探针只能在臂上做；若滚动 ckpt 缺失，回退为 256K 生产内的双 shadow A/B（见 e.3）。

### e.2 判读数字（写死，含杀死路径）

| 读数 | 判定 |
|---|---|
| A_u − 0.2698 | 退火总收益实测（对照线不确定度 ±0.8→~±0.15，R4 判读规则全盘继承） |
| **A_d − A_u ≥ +0.15**（且 152K 点 ≥0） | BTA 固定 T_h=192K 入选 256K 栈（阈 = 配对差 ~1.5σ，R4 窗噪声 ±0.09） |
| 0 < A_d − A_u < +0.15 | 只入平台触发版（零风险形态） |
| **A_d − A_u ≤ 0**（或 <−0.1） | 拒 BTA；同时产出"平台=真耗尽"证据（对 R4 堵点 2/3 的裁决性输入） |
| 144-160K 窗口增量率 Arm D > Arm U | 掩蔽假设成立（中段解掩蔽通道兑现） |
| 探针 A_w − A_u ≥ +0.15 | 2E 入选（双 shadow 生产形态） |
| 探针 ∈ [−0.1, +0.15) | 2E 以双 shadow 随行（final eval 双评、报两组数、val 取优并声明选择） |
| 探针 < −0.1 | 拒 2E（滞后代价>噪声收益，键路由失败的证据） |

**边界遥测**（每臂 final eval 一次，走现有校准链）：AP@0.75 小桶（基线 0.247，对边界质量最敏感）、matched IoU 中位（0.635）、EMA−raw 边界翻转率（matched 小 GT 边界带内二值化翻转像素占比——噪声最直接的观测量，须一次 raw 权重重推理 ≈15min）。预期：方案成立则翻转率显著下降且 AP@0.75 上移；AP_s 不动但翻转率降 → 收益被 mAP 吸收，如实记录。

## (f) 与其它场叠加兼容性

**预算**：五场 +6~11% + 本场 ≤0.5% = **≤11.5% < 20%**；推理本方案 0ms（不挤占 P3-b 的 +10ms）；显存 +≤20MB。
**代码面**：scheduler（per-group lambda）、model_ema（per-key decay 映射+可选第二 shadow）、train.py build_optimizer（组打 schedule 标签 + 抽出 `is_boundary_module` helper 供 P4-b 复用）。**零接触** matcher/损失/采样器 → 与 P3-a/P4-a/P4-c 的改动面无冲突。
**叠加时的形态切换**：任何含 BAS-CL+/CP+/mCDN+ 的栈内运行，BTA 一律用平台触发版（trailing 40K 桶均值 OLS t≥-1.0 触发，最早 128K，兜底固定 208K）——若相邻场复活了边界信号，退火自动推迟，不会切活信号；2E 的双 shadow A/B 与所有场无接触。逐场交互已在 (b) 表声明。

**已考虑并拒绝的子轴**（覆盖场简报候选清单，避免裁决方疑问）：
1. **层间一致性正则（×9 深监督）**：需加损失项，违反本场"不动损失形式"前提，且监督面越界进 P3-a 领地；其目标（共享头的轨迹不一致方差）由 BTA+2E 以零损失成本部分达成（画布头 settle 后 9 个监督点看到的是同一个稳定头）。推迟而非放弃。
2. **梯度噪声整形（分组累积平均）**：在 clip-to-unit 更新 + 固定 optimizer 步预算下，K 步梯度平均 ≡ 噪声侧 lr/K 但步数也 /K——总账等价于降 lr，不另立项。
3. **分组 clip 值**：等效于缩放有效 lr，被日程包含，且与 Adam v̂ 矩阵交互不可控。
4. **一次性 20×→10× 降倍**（R4 备选）：是 BTA 的分段常数退化形式，丢失平滑尾段与早期峰值保持——保留为 scheduler 重构受阻时的 1 行兜底。
