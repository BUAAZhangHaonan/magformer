# P4-a 提案 #1：mCDN — 小目标专用掩码对比去噪（掩码版 CDN，含隔离修复与 DEIM 打包）

提案人：独立提案人 #1（P4-a 场，2026-09-21）｜判分要素预览：收益主张 16K 门 +0.5~1.5 AP_s、组合上限 +2~4；训练开销 +2.0~3.4% ms/it；推理 +0ms；显存 ≤+0.4GB；置信度 0.5~0.65。

**一句话**：把 P4-b 移交的 tiny-CDN 骨架（小 GT 专用、K=3）与 SDN 的块对角隔离，重建为一条 DDP 安全、单类负样本语义正确、q 目标打包（DEIM 铁律）、AIM 网格监督的掩码版 CDN——每个小 GT 每步获得 K=3 个**绕过匹配、位置保证在 GT 上**的正样本，推理整臂丢弃 0ms。Group-DETR 式双组 o2m 作为预算门控的 Phase-2 卡（§8），不进基础 commit。

## 1.（a）机制因果链

### 1.1 o2o 下小 GT 正样本稀缺如何限制学习

o2o 二分匹配给每个 GT **恰好 1 个**正样本 query。当前数据（R3/R5/SYNTHESIS_20260920）：

- 有效 batch=4 每步可见 <64px GT 期望 **0.85 个** → 每步 tiny 正样本实例 ≈ 0.85；
- 对照：每图全部 GT 均值 55.5 → 每步总正样本 ≈ 222。tiny 正样本占比 **≈0.38%**，损失点份额 0.1-0.4%（P4-c 简报锚）；
- 即 128K 步全程，tiny 正样本实例总数仅 ~1.1×10⁵ 次，且其中 87.8% 的 <64px GT 连一次 IoU≥0.5 检测都没有（R3-D1）——正样本供给不是"少"，是**对多数 tiny GT 为零的期望**。

供给稀缺沿三条因果链限制学习：

1. **表示链（画不精）**：共享解码器/掩码头每步只在 ~1 个 tiny 实例上练习小掩码合成。掩码内容缺口 +27.1pt（CF1 反事实，SYNTHESIS §一）中，"练习频率"是可由供给乘子撬动的分量——每个 DN 正样本都是一次端到端 tiny 掩码重构训练（含 ×1 终层 + 9 次头调用的全链路梯度，若开逐层 DN 则更多）。
2. **分数链（分不成型）**：MAL-CP+ 的 q 目标 = matched query 的 soft-Dice。q 高的前提是匹配 query 的掩码画得好；tiny 供给 0.85/步 → q 中位长期贴地 → TP 分数卡 0.29（R2b 证据 0.22-0.29）。**q 目标（P4-c）与供给（P4-a）是乘法关系，不是加法**——没有供给，q 没有上升空间；没有 q，供给会通胀成 hard-FP（DEIM 消融）。两场必须捆绑，各自独立归因。
3. **覆盖-持有链（站不稳）**：SCB+ 种子解决"出生"，前 8 层先验解决"持有"；但持有层的特征质量取决于解码器权重是否"认识" tiny 目标——这又回到表示链。种子出生的 query 若解码器从未学过画 tiny 目标，AIM 匹配列的 Dice 起点低，归属仍弱。

### 1.2 为什么本方案（DN 正样本）安全

DN 正样本的四个安全属性，逐条对应本场硬先例：

| 硬先例 | 本方案的应对 |
|--------|-------------|
| naive o2m 崩溃（3300 query 不分组 32.6→8.4，GroupDETR 表7） | DN **不进匹配**：正样本由构造指定（加噪 GT 直接成为 query），不存在"正样本洪峰冲击二分匹配"的问题；匹配矩阵仍只含 200 常规行（criterion 已剥离，单测 U6 验证逐位不变） |
| 去噪无 attn-mask 隔离=作弊 | D1 修复：块对角自注意力（§2.2），并以"隔离开启时常规行输出与无 DN 时逐位相等"的强 parity 单测（U2）作机器可检证明——常规行**数学上不可能**被 DN 行影响 |
| 稠密 query 不去重毒化 o2o | DN 行推理期整臂不存在（`arch.py:1373` 训练态门控），导出/topk/融合链零改动；训练期 DN 行不进匹配、不进对比损失（`multiscale_decoder.py:1022-1024` 只取常规行） |
| o2m 必须与质量感知损失打包（DEIM 铁律） | DN 正样本 cls 目标 = q（soft-Dice，AIM 同源网格计算），QFL β=2.0、warmup 1000——直接继承 P4-c MAL-CP+ 的 C1 形态并扩展到 DN 行（§2.4）；DN 负样本保持硬 no-object（负样本是分数纪律侧，P4-c 已裁决"负样本逐位不动"） |

补充一条本提案引入的单类专属安全设计：**负样本 GT-free 验证**（§2.3）修复 D3——负样本只放在与全部 GT IoU<0.05 的环带位置，"此处无物"的监督语义在单类场景下为真。

## 2. 方案：mCDN 机制规格

### 2.0 总形态

训练期每图选取 **M=8** 个小 GT（AIM 同一资格线：画布面积 <4096px²，与 matcher `small_gt_area` 同一常数——度量与资格完全同轨），生成：

- **K=3 组正样本**（每组 M 槽）：同一 GT 的三份加噪副本，噪声水平递增 σ_c ∈ {0.10, 0.25, 0.40}（以目标尺度 s=√area 为单位）；
- **1 组负样本**（M 槽）：GT-free 验证的环带位置（§2.3）。

**N_dn = M×(K+1) = 32 行，静态常量**（DDP 安全，修复 D4）。行布局：`[0,136) 可学习 | [136,200) SCB+ 种子槽 | [200,232) DN`。

### 2.1 正样本构造（修复 D6：内容注入 + 尺度相对噪声 + AIM 窗口约束）

- **位置嵌入**：加噪框的 sinusoidal PE（复用 `_sinusoidal_box_pe`）。噪声：中心偏移 δ ~ U(−σ_c, σ_c)·s，尺度抖动 δ_s ~ U(−0.15, 0.15)·s；**约束：加噪中心必须落在该 GT 的 AIM 30% 膨胀窗口内**（与 `_aim_small_gt_costs` 的 marg 同源），越界则重采样——噪声永远指向"同一个目标"，在密集相邻零件场景下不会把 DN query 推到邻物上。
- **内容嵌入**：在 mask_features 上以加噪中心做 3×3 双线性 ROI 池化 → 一个 256→256 线性投影（新增参数 65K，EMA 覆盖无感）。给 DN query 真实的 tiny 目标外观信号（Mask DINO 混合选择的 DN 侧对应物，2206.02777）。
- **deformable 参考点**：保持冻结 detach（D7 的安全属性，代码已在）。

### 2.2 块对角自注意力隔离（修复 D1，任何 DN 臂的前置必修）

构造 `tgt_mask ∈ {0,1}^{(B·H)×Nq×Nq}`，Nq=232：

```
块划分: [ 常规200 | DN-pos-g1 (8) | DN-pos-g2 (8) | DN-pos-g3 (8) | DN-neg (8) ]
规则:   对角块内可见；所有跨块 = masked（含 常规×DN 全部双向、DN 组间全部双向、
        pos组×neg组）
```

dense 路径直接传给 `nn.MultiheadAttention(attn_mask=...)`；deformable 路径同理注入 `_forward_decoder_layer_deformable`。显存/开销账：bool 张量 32×232×232 ≈ 1.7MB，构建一次每层复用；注意力 FLOPs 不变（mask 只改 softmax 掩蔽）。种子先验逻辑（`multiscale_decoder.py:837-854`）已注释明确只写种子行块，DN 行块保持自己的掩蔽——不动。

### 2.3 负样本 GT-free 验证（修复 D3，单类专属）

对每个被选小 GT：在距其中心 2-4×s 的环带上均匀采样候选中心（复用其框宽高），取第一个与**全部** GT 框 IoU<0.05 的候选（≤5 次重采样，仍失败则弃该负槽）。box 级 IoU 判定向量化，开销 <1ms。语义：负样本 = "看起来像零件的邻域背景/深度边缘处"——正是 <64 det 池 80.5% hard-FP 的人群画像（P4-c 证据锚），负组因此成为 hard-FP 纪律的定向训练器。

### 2.4 损失（修复 D2/D5，DEIM 打包）

- **DN 正样本掩码损失**：废弃 `torch.rand` 均匀采样（D2），改用 **AIM 确定性 R×R 窗口网格**（复用 `_aim_small_gt_costs` 的网格构造代码：30% 膨胀 bbox、R≤64 clamp）做 BCE + Dice。tiny 目标前景点密度从 ~0.04% 提升到与目标尺度无关的满窗密度。
- **DN 正样本 cls 损失**：目标 = q = soft-Dice(DN 重构掩码, GT)（同网格计算，detach，QFL β=2.0、warmup 1000 与 MAL-CP+ C1 完全同参同节奏）。DEIM 铁律本地化：DN 是增密通道，q 是其强制配套。
- **DN 负样本 cls 损失**：硬 no-object，focal 形态与主损失一致（负样本逐位不动，P4-c 裁决口径）。
- **仅终层 DN 损失**（现状即如此，`criterion.py:328-331` 只在最终输出上算 DN）：省 8/9 开销；逐层 DN 作为后续可调拨盘（DINO 有先例，非首期）。
- **权重**：loss_dn_{ce,mask,dice,neg_ce} 各 1.0 起步（现 weight_dict 已有槽位）。

### 2.5 与匹配/AIM/种子槽的接口（契约 b 的核心）

- **匹配零改动**：matcher 输入 = 剥离 DN 后的 200 行（代码已做）；AIM 网格、资格线、margin 2.43σ、去帽分块全部不动。单测 U6 断言：固定批上开/关 DN，`indices` 张量逐位相等。
- **AIM 复用三处**：资格线同常数（选 GT）、噪声窗口同 30% 膨胀（约束）、损失网格同构造（监督）——"匹配选的就是它，分数学的就是它，DN 练的就是它"，三处同一把尺。
- **SCB+ 行分区**：种子占 [136,200)，DN 追加在 [200,232)。seed-dropout（P4-b 合并件）只作用于种子行；DN 行不参与 dropout（其价值恰在每步稳定供给）。种子先验注意力写种子行块，与 DN 块互不干扰。
- **EMA/导出**：新增参数仅 ROI 投影 65K；推理路径 `dn_query_embed=None` → 解码器与封存基座逐位同构。

## 3.（c）理论收益上界与依据

**供给算术**（本提案直接改变的主变量）：

| 阶段 | tiny(<64px) 正样本/步 | 相对现状 |
|---|---|---|
| 现状（o2o，batch=4） | 0.85 | 1× |
| +P4-c 贴入（3~10 可见/步，MAL-CP+ 裁决书） | 3~10 | 3.5~12× |
| +P4-c + mCDN（K=3，每可见 tiny GT 保底 3 正） | **9~30** | **11~35×** |

关键差别：贴入提升的是"有多少 tiny GT 可见"，mCDN 保证的是"每个可见 tiny GT 无条件获得 K 个正样本且位置钉在 GT 上"——后者不依赖任何 query 恰好站过去（o2m/分组方案的正样本仍要靠匹配发生，Group 组的 query 同样面临发现难题）。

**文献锚**（均注明出处）：

- DN-DETR（CVPR22, 2203.01305）：R50 12ep 43.4 AP（+1.9 over baseline），同性能只需 50% epoch——去噪供给的收敛加速效应最直接证据；
- DINO/CDN（ICLR23, 2203.03605）：49.4 AP，其中 CDN 正负组捆绑覆盖×分数；
- Mask DINO（CVPR23, 2206.02777）：mask 版 CDN 在 COCO IS 54.5 AP 可行性；
- Group DETR（ICCV23, 2207.13085）：**Mask2Former 唯一公开数字 38.5→39.7（12ep +1.2），50ep +0.3**——同族供给类方案在 M2F 上的量级与"长程衰减"双重锚（我们是 128K 封存基座 finetune，属"长程"侧，预期向 +0.3~1.2 区间下中部靠）；
- DEIM（CVPR25, 2412.04234）：增密无 MAL 退化消融——本提案 q 打包的依据。

**上界分解（诚实口径）**：

- 本场供给乘子撬动的是三座山中"掩码内容 +27.1（CF1）"的**练习频率分量**与"检测存在性 +16.5（E3）"中经由 q/特征侧的间接分量。练习频率分量 ≤ CF1 缺口的 1/3 是乐观界，但 finetune 短程只能回收其中一小部分；
- **独立主张**：16K 门（叠加在 SCB+/MAL-CP+ 控制臂之上）净 +0.5~1.5 AP_s（置信 0.5~0.65）；其中 ≥一半路径依赖与 MAL-CP+ 的乘法耦合（q 有空间上升）；
- **组合上限**：+2~4 AP_s（与 P4-c 的 +3~6 **有乘法重叠，不得加总**；2×2 消融归因是唯一诚实口径）；
- **不主张**：覆盖缺口本体（38.1% 无检测的物理存在，归 SCB+）、损失几何（边界监督，归 P3-a）、渲染链（4.0pt，归 P3-b）。

## 4.（d）开销预算（算式）

基线：1.44-1.60 s/it（4 卡 DDP），取 1.52s 中值；解码器占步时 10-15%（调研B：解码器算力 +30-50% 时总额只占 10-15%，pixel decoder 主导），取 12.5%。

- **查询数**：200→232（+16%）。解码器成本对 Nq 近似线性（交叉注意力 QK/AV 与 9 次掩码头 einsum 主导，均 O(Nq)；自注意力 O(Nq²) 份额 <5%，其 1.35× 增量折算解码器 +1.7%）。
- **训练增量**：Δms ≈ 1520 × 12.5% × (16% + 1.7%) ≈ **+34ms**；加 DN 损失与 q 计算（32 行 × R²≤4096 网格 ≈ 13 万采样点，<5ms）、负样本验证（<1ms）、块对角 mask 构建（<3ms）→ **合计 +38~52ms = +2.5~3.4% ms/it**（f_dec 取 10% 时 +2.0%，取 15% 时 +3.4%）。
- **叠加审计**：P4-c +3~6% + P4-b 核心 +~1% + 本案 +2.0~3.4% = **总 +6.0~10.4% ≤ +20% 红线**，余量约 2×。降档阶梯：K=3→2（N_dn=24，省 1/3）、M=8→6。
- **显存**：新增主要项为 DN 行的 pred_masks 激活（9 次头调用中 ≤2 次在 256²）：Δ ≈ 4×32×65536×4B×2 ≈ 67MB，加注意力 mask 与中间量 → **≤ +0.4GB / 卡**（24GB 红线内；对照 GroupDETR 文献 +1.2-1.7GB，本案小一个量级）。
- **推理**：**+0ms**（严格零——`_generate_dn_queries` 训练态门控早退，解码器/导出/topk/融合链零改动）；封存基座推理图逐位不变。
- **新增参数**：ROI 投影 1×256×256+偏置 ≈ 65.9K（总参数 <0.1%）。

## 5.（e）正确性验证方案

### 5.1 单测（训练前，8 项）

- **U1 隔离正确性**：块对角 mask 张量按 §2.2 规则逐块断言；hook 自注意力权重，验证常规行对 DN 列注意力权重 = 0、DN 组间 = 0。
- **U2 parity（最强证明）**：隔离开启时，相同输入下"开 DN 的常规 200 行输出"与"关 DN 的 200 行输出"**逐位相等**（交叉注意力逐行独立、自注意力被 mask、FFN 逐行）——任何不等 = 泄漏 = 否决。
- **U3 静态形状**：N_dn=32 恒定，跨批 GT 数变化（0/1/8/50 个小 GT）形状不变、validity 掩码正确（DDP 安全，修复 D4 验证）。
- **U4 噪声约束**：全部加噪中心 ∈ AIM 30% 膨胀窗；三组噪声水平序 σ1<σ2<σ3 成立。
- **U5 负样本验证**：全部负样本框与所有 GT IoU<0.05；重采样失败路径弃槽不越界。
- **U6 匹配逐位不变**：固定批上 ±DN，matcher `indices` 张量完全相等。
- **U7 q 目标回归**：DN 正样本 q ∈ [0,1]、与 AIM 网格 soft-Dice 数值一致（和 matcher `_aim_small_gt_costs` 同输入差 <1e-5）；warmup 段目标行为正确。
- **U8 mal-off 回退**：q 目标关闭时 DN 损失逐位退化为"硬目标 + AIM 网格"版本（参数回归）。

### 5.2 冻结探针（训练前，不训练）

封存 128K 基座，训练态前向（只前向无反传），val 子集 500 图：测量 **DN 零样本重构底线**——冻结权重下 DN 正样本在 <64px GT 上的 soft-Dice 中位 d₀。
- **预注册判据**：d₀ ≥ 0.25 → 通过（解码器容量在，训练将放大）；d₀ < 0.25 → 内容注入升级（ROI 3×3→5×5 + 两层 MLP）后复测；复测仍 <0.15 → 方案源头降级（K 维持但预期收益下修 50%）。
- 该探针同时给 5.3 的 G3 提供基线数。

### 5.3 ≤16K 短训门（双臂，冻结基座起步）

臂设计：控制臂 = SCB+ + MAL-CP+（已裁决捆绑件，**复用 P4-b/c 门的现成运行**，不重跑）；实验臂 = 同捆绑 + mCDN。seed 固定，EMA 口径，4K/8K/12K/16K 四点 eval。

| 门 | 指标 | 通过线 | 强信号 |
|---|---|---|---|
| G1 主收益 | AP_s 净增（vs 控制臂，16K） | ≥ +0.5pt | ≥ +1.0pt |
| G2a 主匹配质量（防毒化哨兵） | 全 GT matched-IoU 中位 | Δ ≥ −0.01 | Δ ≥ +0.02 |
| G2b 重复率（防毒化哨兵） | 每 small GT det 数（基线 1.30） | ≤ 1.45 | ≤ 1.35 |
| G2c hard-FP（防毒化哨兵） | <64 det 池 hard-FP 分数中位（基线池 80.5% hard-FP） | ≤ 0.10 且**不随 TP 上移** | 中位下移 ≥0.05（DN 负组起效的直接证据） |
| G2d 常规行损失 | ce/mask/dice（常规行）在控制臂噪声带内 | 是 | — |
| G3 机制确认 | DN 正样本 Dice(<64px) 相对 d₀ | ≥ +0.10 | ≥ +0.15 |
| G4 供给落地 | 每步 DN 正样本有效数（日志） | ≈ M×K×含 tiny 图率 | — |

**失败判读树（预注册）**：
- G1 未达 + 哨兵全绿 + G3 达标 → 供给不是当前约束 → 移交 P3-a（损失几何）优先，mCDN 冻结待 P3-a 落地后复用（其 AIM 网格点采样与 P3-a 边界方案天然共享管线）；
- G2c 翻车（hard-FP 随 TP 抬升）→ q 目标未覆盖 DN 行或 warmup 失效 → 查 U7 路径；仍翻车则 K=3→2 并 DN 权重 ×0.5；
- G2b 翻车（重复率升）→ 隔离不完整 → U1/U2 定位（理论上 parity 保证下不可能，翻车即实现 bug）；
- G2a 翻车（主匹配退化）→ 与设计矛盾（匹配零接触），按实现 bug 处理回滚；
- G1 达标 → 32-48K 组合臂（判据：净超 R4 退火对照线 ≥ +1.5pt，与 P4-b/c 门同口径）。

## 7. 与备选方案的对比（为何不选它们做基础 commit）

- **Group DETR 双组 o2m**：唯一 M2F 公开数字（+1.2/12ep）但 +18% 训练时间超本案预算余量；且组内正样本仍需匹配发生——组的 query 面对"谁站上 tiny 目标"难题，而该难题在本树由 SCB+ 单池解决，复制到第二组要么双计要么失配。降为 **Phase-2 卡**（§8）。
- **H-DETR 辅助 o2m 支路**（~+7%）：1500 辅助 query 的成本/收益比劣于定向 DN；辅助支路的 o2m 匹配对 tiny GT 的发现依赖同上。
- **MS-DETR 主 query 混合 o2m**：o2m 直接加在主解码 query 上需解耦去重——正撞"稠密 query 不去重毒化 o2o"硬先例（DDQ 教训），风险不可承保。

## 8. Phase-2 卡（预注册，不进基础 commit）

**双组 o2m 镜像组**：预算门（P4-c 实测 ≤ +4%）+ mCDN 16K 门通过后，评估追加 1 个辅助组（200 query 组内 o2o、块对角隔离、推理丢弃），预算 +10~12% ms/it，总叠加上限仍受 20% 红线约束——若超线则永不开。依据：GroupDETR M2F 数字 + 与 DN 正交（DN=匹配外保底供给，组=匹配内竞争供给），文献明确兼容（DINO=DN+CDN，GroupDETR 可叠加）。

## 9. 风险登记

1. **finetune 制 regime 风险**：DN 收益文献多为 from-scratch 加速（GroupDETR 50ep 仅 +0.3）——本案以 16K 门 +0.5 为底线主张，上限主张已按此折减；
2. **tiny 噪声设计无直接先例**（Mask2Former 无官方 mask-CDN，调研B 明示）：σ_c 三档与 AIM 窗口约束是自定设计，冻结探针 d₀（§5.2）是训练前否决阀；
3. **单类负样本语义**为本提案自研修复（无文献直接锚），G2c 哨兵专测其方向性；
4. 概率化主张：独立过 G1 门概率估 ~0.55-0.65；哨兵全绿概率 ~0.9（parity 单测把毒化风险压到实现 bug 级）。
