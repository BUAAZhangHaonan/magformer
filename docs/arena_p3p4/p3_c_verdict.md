## 二、裁决

**胜出（骨干）：#5 HDA-E 的 C1 + #2 的窗口设计**——乘子独立余弦 20→1、窗口 [24K,128K] 退到 1×（非 0，保 SCB+ 种子/probe 与 giou 流）、主组日程逐字节不动、β=0.55（128K 噪声半径降 13.7×）。

**合并采纳（最终形态 HDA+）**：
1. **#4 的触发式日程**（关键交互守护）：BAS-CL+ 会复活 mask/dice 信号，"自 24K 平坦"的退火依据在合并栈内不再成立——退火起点由平台检测触发（损失分量斜率 <阈值连续 N 窗）而非固定步数，防切新信号；
2. **#4/#3/#5 的画布键双 EMA 0.99995**（残余方差 ×0.5，可行域内）——**仅画布三件套键**（dw/proj/shuffle），末层 cross-attn（giou 活信号）留标准窗（#4 的细分）；
3. **#1 的零代码 B 臂**（`hires_lr_multiplier=1` 直接改 config 即为最简差分臂）与杀线（B−A ≥ +0.15 采纳 / B<A−0.05 杀"适应未完"）；
4. 主组轨迹逐位相同断言（byte-equal 单测）。

**亚军：#4 BTA·2E**（细分最精；若触发式日程实现复杂度超预期，回退其固定 T_h=192K+floor 版）。

- 臂设计：A=R4 收尾臂（128K→160K 均匀余弦，全场公用对照线）+ B=同日程仅动 hires 日程（15.4h）；2E 不占训练臂——用臂上滚动 checkpoint 的离线窗宽平均探针判定（#4）。
