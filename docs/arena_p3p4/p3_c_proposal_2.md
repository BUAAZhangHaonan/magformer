# P3-c 提案 2/5 · HFA-D：hires 组乘子退火（20×→1×）+ 主组保形的对照分离

提案人 #2（独立，未见其他 4 份提案）| 2026-09-20 | 纸面轮，未跑任何实验，仅引用已封存证据与代码核验。

**方案一句话**：把 hires 组（stride-2 掩码头 + 末层 cross-attn + probe/seed，`tools/train.py:747-758` 的 20× lr 组）的 20× 乘子做成随日程退火的量（cosine 20→1，在 256K 协议默认 [24K, 128K] 完成），主组日程逐字节不变；验证设计以 R4 已裁定的 128K→160K 收尾对照臂（A0）为公共对照，本方案只加一臂差异化收尾（A1），用"主组日程完全相同、仅 hires 组 lr 轨迹不同"把**方案收益与退火本身收益**干净分离。推理零开销、训练近零开销、不动损失形式、不动匹配。

## (a) 机制因果链：边界噪声的优化器侧成因，以及本方案消掉的分量

### a.1 成因链（每环都有实证或代码锚）

1. **更新规则是"步长=lr 的方向归一化随机游走"**。preclip gradnorm 中位 ~1200-1400 vs clip=1.0，100% 步被裁剪（R4 堵点 2），有效更新 = lr × 单位方向向量（`trainer.py:1250-1267`）。因此每个参数每步位移的上界由其组 lr 唯一决定：噪声球**半径 ∝ lr**（线性，不是 √lr——这是裁剪体制特有的）。
2. **hires 组半径 20×**。峰值 2e-4（base 1e-5 × 20），112K 处 1.21e-4、128K 封存点 1.02e-4，而主组同点 6.1e-6 / 5.08e-6（R4 lr 逐点对账表）。即封存时 hires 组从未进过低 lr 区，其噪声球半径是主组的 **20 倍（方差 400 倍）**。
3. **边界像素是这组参数的一阶敏感面**。掩码 logits = einsum(query, mask_features)，mask_features 直接由 stride-2 头（hires_dw/proj/shuffle，`pixel_decoder_msdeformattn.py:386+`）与末层 cross-attn（读 stride-4 层，`multiscale_decoder.py:309-312`）产生。内部像素离 0.5 判决线远，±σ 权重扰动很少翻转；轮廓像素恰在判决边界上，翻转概率 ∝ σ/|∇logit| 最大——所以"边界像素是全模型最高方差预测"（简报 §3 证据锚）是 hires 噪声球的**几何必然**，不是巧合。
4. **抖动是纯方差不是偏移**。±1px 膨胀/侵蚀都变差 ⇒ 期望损失最优点就在抖动带内部，不存在待纠正的系统偏置 ⇒ **去噪本身即是净收益，不需要新信号**。
5. **实测脚印**：EMA 0.9999 比 raw 好 +0.67 mAP / **+1.02 AP_s**（F1@128K 校准报告表二）——这是"对噪声球做带滞后的权重平均"这种**部分去噪**就已收回的量，即噪声分量的成本下界锚。
6. **20× 的存在理由已过期**。`train.py:702-704` 注释明说 20× 是为"short finetune 内完成适配"而设（hires_dw 零初始化，`nn.init.zeros_`，需要高 lr 起步）；但训练损失 ce/mask/dice 自 **24K** 起统计平坦（OLS t=-0.2~-0.7，R4 堵点 2）= 适配期 ~24K 步就结束了。最终协议改为 ImageNet 预训练 + **256K 从头**后，"短微调加速器"的理由消失，而 20× 又持续注入 128K+ 步的纯噪声。**乘子只应在适配窗口内存在**——这正是退火（fade）的形态：早期保 20×，适配完成后收回。

### a.2 边界抖动的噪声分解与本方案的作用面

| 分量 | 定义 | 证据 | 本方案 |
|---|---|---|---|
| **N1** hires 驻留噪声球 | 20× lr 的方向归一化游走，半径 20× | lr 表（R4）；ce 桶间 0.25-0.45 振荡 | **源头消除（乘子退火 20→1）** |
| N2 EMA 窗失配/滞后 | 单一 decay 0.9999（半衰期 6.9K，均值滞后 9999 步）覆盖 827 个 lr 相差 20× 的张量 | R4 堵点 4；`model_ema.py:88-92` | 间接缓解：N1 消掉后全模型噪声半径一致，0.9999 的窗口对每个张量都变得合适；另加免费的 EMA/raw 双评遥测（见 e） |

### a.3 为什么不是另外三个子轴（本提案的立场）

- **参数组 EMA（边界关键层单独 decay）——数学上限不足，否决**。指数平均的驻留残差 std ≈ σ·sqrt((1−d)/(1+d)) ≈ σ/sqrt(2W)（W=有效窗长）。要把 hires 残差砍 20× 需窗长 ×400：decay 0.9999→0.99999975、半衰期 6.9K→**277 万步**，远超 256K 全程；现实可行的窗 ×4 只换 std ÷2，却让均值滞后 ×4（≈4 万步）。**20× 的问题在源头上，平均术在算术上追不上**；lr 侧消 N1 零滞后成本拿到 20×。附带工程理由：改 decay 结构要动 `ModelEMA.state_dict` 的 checkpoint 契约（best.pt = EMA + raw backup），破坏全部续训/下游消费方。
- **梯度噪声整形（分组/自适应裁剪）——无证据锚，否决**。现状已是全模型整范数归一化（100% 步裁剪），分组裁剪改的是步内分配比例，超参面最大、最易伤 N4，且其可达的驻留协方差收缩用 lr 乘子更透明地就能拿到。
- **层间一致性正则——出局而非否决**。它加损失项，违反本场前提；其目标（层间目标不一致）与 P3-a 的软标签高度重叠；×9 深监督的层间多样性本身有正价值，一致性项与之对冲。留作 P3-a 叠加后的残余选项，不进本提案预算。

## (c) 理论收益上界与依据

先把账分清——三个数，归属不同：

1. **退火尾段收益（不属于本方案，属于 A0/协议本身）**：R4 中心估值 128K→256K 终点 +1.0~1.25pt（区间 +0.1~1.9；幂律 +1.25 / 对数 +1.88 / 老家族锚 +0.83）；32K 收尾臂捕获其中 +0.5~1.3pt。锚：老 128K 家族后半程 +0.71~0.83pt、末 1/4 +0.24pt；F1 末窗噪声底 +0.21±0.09pt/8K。
2. **噪声轴总上界（本场的理论天花板，任何去噪方案合计不可超过）**：≈ **1.0~1.3pt**。锚：EMA−raw = **+1.02 AP_s**（对噪声球做带 10K 步滞后的部分平均即收回此量，故为下界锚）；上界再补 EMA 收不回的部分（权重平均只在低损失盆线性连通内有效、且滞后 9999 步），估计残量 ≤0.3pt。超出此范围的任何增益属于其他场（表征/分数/数据），不在本场认领。
3. **本方案独占增量（A1−A0，裁决标的）**：
   - **阶段 1（32K 收尾分离实验）**：中心 **+0.2pt**，区间 0~+0.4。推导：A0 的全局余弦尾在 [128K,144K] 已把 hires 从 1.98e-5 压到 6.2e-6，两组臂的真正差异集中在 [128K,144K] 的噪声半径（A0 均值 ~1.1e-5 vs A1 ~0.4e-5）与 **EMA 冲洗净噪声的时间**（A0 的 160K EMA 仍积分 [128K,142K] 高噪声期权重；R4 自己论证 EMA 需 ≥2 个半衰期 14K 才 settle——A1 在 144K 完成 fade，留足 16K = 2.3 个半衰期的干净 settle）。收益通道 = 提前 1~2 个窗口的"无噪声下降"（老家族末段率 +0.22~0.26pt/8K 的分数）+ 更早的 EMA 收敛。
   - **阶段 2（256K 从头协议内嵌 fade [24K,128K]）投影**：中心 **+0.4pt**，区间 +0.2~+0.8。基线在 256K 协议下直到 ~200K hires lr 仍 ≥1e-5（192K 时 2.2e-5，是主组峰值的 2.2 倍）——fade 把整个后半程 12.8 万步从"噪声球内漂移"换成真下降，且消除 R4 点名的"128K 类冻结点方差大"（每个下游对照的方差收益，未计分）。
   - **置信度**：机制链全环有代码/数据锚（lr 表逐点对账、裁剪 100%、EMA>raw 实测、零初始化注释、24K 平坦 onset）；主要不确定度 = "均匀退火是否已把噪声收益全部拿走"（Δ_scheme≈0 的可能）——这正是 A0 vs A1 实验设计要消除的，而不是要假设的。

**判分口径**：收益取阶段 2 中心 0.4pt × 置信 0.6 ÷ 成本（≈0，骑乘臂）。

## (e) 正确性验证方案（对照臂设计是核心）

### e.1 纸面轮已完成（本轮，无 GPU）

- 代码核验：分组名单与 20× 匹配（`train.py:705-759`，含末层 cross-attn 的子串匹配 `cross_attention_layers.{L-1}.`）；调度器当前是**单 λ 广播到所有组**（`cosine_scheduler.py:58-62`）——逐组 λ 是 PyTorch LambdaLR 原生能力，改动 ≈15 行；EMA 单 decay 全张量（`model_ema.py:88-92`）；eval 100% 走 EMA（`trainer.py:1677-1719`）；×9 深监督逐点独立匹配（`criterion.py:250-259`）。
- 公式核验：A0 重分 horizon 后 128K 处 mult=0.099（主组 9.9e-7、hires 1.98e-5）与 R4 逐点复算一致；fade 公式连续性检查（resume 瞬间 lr 与封存点逐位相同，无 shock）。

### e.2 阶段 1 双臂设计（分离"方案收益"与"退火收益"的机制）

从同一份 128K 封存 checkpoint 副本（`f1_seal_128k/`）续跑，数据顺序/RNG 状态一致（resume 链恢复采样器状态；不一致则两臂同种子同序，共模噪声在配对差分中抵消）：

- **A0（公共对照，R4 原案）**：max_iter=160K，两组统一重分余弦（主 5.08e-6→9.9e-7→0；hires 1.02e-4→1.98e-5→0）。
- **A1（本方案）**：主组日程与 A0 **逐字节相同**（同一 λ、同一 horizon）；hires 组 = 主组 λ × m_h(s)，m_h 从 20 余弦退到 1，窗口 [128K, 144K]，此后恒 1（即 144K 起 hires lr = 主组 lr，160K 同归 0）。
- 两臂各 32K 步、eval_period 8K、每 eval 存 last.pt(raw)+best.pt(EMA)。A1 的 fade 终点 144K 特意让最后 16K（2.3 个 EMA 半衰期）在无 hires 噪声下 settle——把 R4 反对 144K 短臂的论证按子组尺度重用。

**归因逻辑**：Δ_anneal = A0 − 封存（退火+多步数的合并效应）；Δ_scheme = A1 − A0（两臂唯一差异 = hires 组 lr 轨迹）。主组字节相同 ⇒ Δ_scheme 对 hires 噪声因果封闭。

### e.3 判读数字（预注册）

| 读数 | 通过门 | 含义 |
|---|---|---|
| Δ_anneal（AP_s, EMA, 160K vs 封存 0.2698） | 预期 +0.5~1.3（R4） | 退火本身；若 ≥+0.5 则全部旧对照需重锚（R4 判读规则继承） |
| **Δ_scheme（AP_s, EMA, 160K）** | **≥ +0.15pt 且 152K、160K 两点同号**（单 eval 噪声 σ≈±0.09-0.1pt，R4 窗噪声；两点同号 ≈2σ） | 本场核心门：hires 噪声独占增益确认 |
| 抖动指数 J = ½[AP_s(膨胀1px)+AP_s(侵蚀1px)] − AP_s(原) | A1 的 J 比 A0 更接近 0 | 机制确认读数（边界方差下降），诊断用不替代门 |
| AP@0.75（0.247）与 小 GT matched IoU 中位（0.635） | A1−A0 ≥ +0.5pt(@0.75) 为强确认 | 噪声落在边界的机制特异性读数 |
| 各组 EMA−raw 参数 L2（遥测） | A1 的 hires 项自 136K 起显著小于 A0 | 噪声球收缩的直接物理证据 |
| bbox_APs（N4 安全监视） | A1 与 A0 差 ≤0.05pt | 若违例 → 切 F1 缩窗（seed/probe/末层 cross-attn 保留 20×），预注册无需新裁决 |

**失败分支预注册**（负结果也产出协议决策）：Δ_scheme < −0.1 ⇒ 20× 驻留实为净正（适配价值比损失平坦更持久）⇒ 256K 协议保留 20× 只走全局余弦；−0.1 ≤ Δ_scheme < +0.15 ⇒ 噪声收益被均匀退火全覆盖 ⇒ 采纳 A0 式收尾，本方案降级为 256K 协议内早期 fade 的可选项（β 网格 {0.25,0.5}，另议）。

### e.4 阶段 2（256K 从头协议内嵌）

## (f) 与其它场胜出方案的叠加兼容性

- **全兼容结构**：本方案只动优化器参数组乘子的时间曲线 + 评估遥测，与损失形式（P3-a/P4-c）、匹配（AIM/mCDN+）、query 结构（SCB+）、导出（P4-d）在机制层无共享自由度；唯一结构性交叠（P4-b 的 seed/probe 模块同在 hires 组）已用"退到 1× 而非 0"+F1 缩窗开关双保险覆盖（见 b）。
- **叠加后的预算账**：五场 +6~11% + 本场 ≤0.2% = +6.2~11.2% < 20% 红线；推理 0ms；显存 0。判分规则"推理近零开销同分优先"下本方案是全场极端点（0/0/0）。
- **执行顺序契合**：斗兽场排序本就把 P3-c 与收尾对照臂合并跑——本提案即该合并的具体形态：A0 先跑（已裁定必跑），A1 跟随，两臂 31h 内给出本场裁决 + 顺带把 R4 的 ±0.8pt 对照线不确定度压到 ±0.15。
- **不兼容声明**：无结构性不兼容。唯一的时序要求：A0/A1 必须在任何 256K 从头协议启动前出数（fade 参数 β 与 F1/F2 由它定型），与既定执行顺序一致。
