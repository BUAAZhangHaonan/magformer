## 二、裁决

**胜出（骨干）：#2 SCB「种子-回廊」**——持有侧最完整（种子行 probe-fg 先验贯穿全部 8 层，直接钉穿 P6 残余）、α 接生坡道保 DDP/cls 头稳定、**零开销回退档**（seed_active=False，80% 覆盖保持率判读——工程可退性全场唯一）、全量捆绑 MAL-CP+、收益分解最诚实（oracle 段 × r(0.55) × f(0.25)）。

**合并采纳（最终形态 SCB+）**：
1. **#1 的池内槽位语义**（64 种子 = 200 池内普通 slot，单池 o2o + AIM 零语义改动）与最省开销算术；
2. **#4 的 seed-dropout**（训练期随机关断种子 → 导出可零开销关断，与 #2 回退档互补）；
3. **#5 的 stride 感知 min-K**（门控扩层时各 stride 层的候选下限按分辨率设，防粗网格层候选爆炸）；#4 指出 `only_stride4=false` 本就是一位 config 开关——**先翻开关做零代码探针**，不行再上 #2 的行级先验；
4. **DN 供给组件（#3 tiny-CDN / #4 SDN）移交 P4-a 场裁决**（与该场主题重叠，避免双计；隔离修复作为该场前置必修），P4-b 核心不含 DN。

**亚军：#1 SeedQ-64**（若池内槽位在实现中与 DDP/EMA 冲突，回退其设计；其 16K 种子边际 ≥+1.0pt 的预注册门最严格）。

**SCB+ 最终形态**：200 池内 64 种子槽（probe 峰值出生，α 坡道）→ 种子行注意力先验全 8 层 + 门控扩层（先翻 config 开关）→ seed-dropout 训练 → 全量 MAL-CP+ 捆绑（q 目标 + 分层贴入）。训练 +~1%、推理 ≤2ms（含零开销档）。

## 三、实验室验证（预注册）

1. 前置门（训练前）：冻结基座 probe 定位探针（<60-70% 召回 → 源头否决，多份提案共识）；`only_stride4=false` 零代码探针（显存/速度/AP 三读数）。
2. 单测：step-0 parity、种子槽匹配语义、α 坡道、seed-dropout 分布。
3. 16K 2×2 短训（种子 on/off × MAL on/off）：**MAL-off 臂必须复现 R2b 的 0.29 卡死**（捆绑必要性的在位证明）；判读：覆盖率 61.9→≥88%、38.1% 缺口→≤20-25%、AR_s@100 0.309→≥0.42、TP 分中位 ≥0.40、净 +1.0~1.5pt。
4. 失败判读树承 #3/#5（预注册）。
