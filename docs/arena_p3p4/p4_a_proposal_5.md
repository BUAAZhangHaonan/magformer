## (a) 机制因果链

**病灶链条（o2o 下小 GT 正样本稀缺如何限制学习）**：

1. **事件稀缺**：o2o 二分匹配下每个 GT 每步至多产生 1 个正样本 query。有效 batch=4 每步可见 <64px GT 仅 0.85 个（BRIEF §4；R5/P10），P4-c 分层贴入后 ~3-10 个/步——但**每个 GT 的正样本事件数仍是 1**：贴入增加的是"GT 个数"，不是"每 GT 供给"。对照中大目标 ~55 事件/步（R3 D2：全 GT mean 55.5/图），tiny 桶的正样本梯度事件密度低 1.5~2 个数量级。
2. **表征欠拟合的落点**：解码器层、掩码头、cls 头是正/负样本共享权重的。tiny 目标的"从锚点到掩码重建"流形（亚 cell 定位 → 2-3 cell 掩码 → 高分）只被每步 ≤1 次的正事件打磨：R3 D1 的 <64 桶 87.8% never-hit、best-IoU 中位 0.006、AR_s@100=0.309 是其输出侧症状；R4 的 ce/mask/dice 自 24K 统计平坦说明在当前供给下训练信号已耗尽。
3. **AIM 修的是"哪个 query 拿到事件"，不是"事件有多少"**：AIM（margin 0.13σ→2.43σ）稳定了归属，但归属稳定 ≠ 供给充足。供给稀缺是 AIM 之上的独立残余——正是本场主题。

**为什么 DN（去噪查询）是安全的 ×K 供给**：

4. **按构造保证供给**：DN 正查询由加噪 GT 直接构造、直接监督，**不经过匹配抽签**——每个入选 tiny GT 每步获得 K 个正事件（K 自适应 4~8，见 §b），难度由噪声分级控制。这是对"匹配稳定性"最彻底的解法：不改善抽签，而是绕开抽签做供给（DN-DETR 的立论，CVPR22，+1.9 AP / 同性能 50% epoch）。
5. **权重共享传导、而非内容泄漏传导**：DN 查询对共享层产生 tiny 目标梯度；它与主通道的唯一交互面是**权重**。只要自注意力块对角隔离（§b），主通道 query 序列在数值上与无 DN 时完全一致——毒化主匹配的通路被物理切断，而非被正则化缓解。
6. **负样本免费打击 hard-FP**：<64 det 池 80.5% 是 hard-FP（P4-c 证据锚）。CDN 式负组（错位/尺度失配锚点 → "无物"目标）在"似是而非处"直接训练 cls 头输出低分——这是分数纪律的免费赠品，也是本方案对 hard-FP 结构的唯一训练期攻击点。
7. **q 目标防分数通胀（DEIM 铁律延伸）**：若 DN 正样本 cls 目标是 one-hot 1.0（本树现存缺陷，`criterion.py:624-647`），重噪下重建出的平庸掩码也被教成高分——这正是 hard-FP 的生成机制。本方案 DN 正样本 cls 目标 = q = soft-Dice(重建掩码, GT)（AIM 同度量，detach，QFL β=2.0，与 MAL-CP+ C1 同参数）——增密与质量感知在同一臂内打包，不单飞。

**对三条反面先验的正面回答**：

- *naive o2m 崩溃（3300 query 不分组 32.6→8.4，Group DETR 表 7）*：本方案**从不扩大被匹配的 query 池**——主池恒 200（含 SCB+ 的 64 种子槽），DN 行对 Hungarian 不可见（`criterion.py:209-218` 现成剥离路径），Arm-B 的 o2m 也被限制在 64 行的隔离块内。
- *去噪无 attn-mask 隔离 = 作弊（DN-DETR）*：块对角基座是本提案第一交付物（§b.1），任何 DN 臂前置必修——与 P4-b 裁决书移交说明一致。
- *稠密 query 不去重毒化 o2o（DDQ）*：DN 行推理期不存在、不产出检测；主池大小与导出协议零改动；重复率哨兵（§e）预注册兜底。

## (b) 与二分匹配 / AIM / 种子槽（SCB+）的兼容性与隔离设计

### b.1 前置必修：块对角自注意力隔离基座

**现存缺陷（本树实测读码）**：`multiscale_decoder.py` 的 `_forward_decoder_layer`（L578-583）与 `_forward_decoder_layer_deformable`（L600-605）自注意力一律 `tgt_mask=None`；DN 行在 L801-806 直接 `torch.cat` 进 query 流——正/主查询完全互通，GT 锚定内容可被主查询直接看到（作弊）且 DN 组间互相泄漏。

**修复设计**：decoder.forward 在 DN/aux 激活时构造一次布尔自注意力 mask，形状 (B·heads, Nq_total, Nq_total)，块结构：

```
            [ regular 200 ] [ DN-easy ≤32 ] [ DN-hard ≤32 ] [ DN-neg ≤32 ]
[ regular  ]      ✓              ✗               ✗               ✗
[ DN-easy  ]      ✗              ✓               ✗               ✗
[ DN-hard  ]      ✗              ✗               ✓               ✗
[ DN-neg   ]      ✗              ✗               ✗               ✓
```

- 组内可见（CDN 标准：同一噪声级的正样本互相可见，构成一个去噪集）；组间与主池互斥。Arm-B 启用时 aux 块同构替换 DN 三块。
- 传入两个层函数的 `tgt_mask` 参数（接口现成，只是从未被喂过值）；gradient checkpointing 下作为输入张量透传，无额外处理。
- 开销：4·8·296² ≈ 2.8MB 布尔（构造一次、8 层复用）；自注意力本体从 200²→296² 的增量在解码器内是次要项（见 §d）。
- 正则块 [0:200,0:200] 全允许——数学上与今天的 `None` 等价，**step-0 位同等价单测**（§e T1）保证不引入主通道扰动。
- 交叉注意力无泄漏：`forward_prediction_heads` 的 cross-attn mask 是**逐行**的（(B·h, Q, S)，每行只遮自己的 key），DN 行只受自身预测掩码约束，不构成行间信道；种子先验块已被 AUD-2 修复限定在 `[num_learned, num_regular)` 行（L847-853），DN 行天然豁免——这两点是"隔离只需自注意力"的依据。

### b.2 QDN-tiny 构造（Arm-A 主体，替换 `arch.py:1355-1459` 现路径）

- **资格集合 E**：`0 < area < 4096` 画布 px²——与 AIM 资格线同阈值（`matcher.py:292`），保证 DN 供给的正是 matcher 特殊照顾的那群 GT；按面积升序取前 min(|E|,16) 个（最小的优先，防止中大头挤占预算）。
- **正样本（≤64 行，2 个噪声级 = 2 个隔离组）**：
  - easy λ₁：锚框中心抖动 ≤0.1×extent、尺度 ×[0.9,1.1]；
  - hard λ₂：中心抖动 0.1~0.3×extent、尺度 ×[0.75,1.25]——**0.3 上限与 AIM 自身的 bbox+30% 窗口边界对齐**（`matcher.py:306`）：hard 噪声仍落在 AIM 可匹配盆内，教会模型"AIM 能接住的偏移都要拉回来"；
  - 每 GT 每级 ⌈K/2⌉ 份，K = clamp(⌈32/|E_sel|⌉, 4, 8)；全局正样本帽 64，超帽按 GT 轮转削减（保底每 GT 每级 1 份）。供给量：|E_sel|∈[4,16] → 每 GT 4~8 份/步。
- **负样本（≤32 行，1 个隔离组，两族对准 hard-FP 形态）**：
  - 错位族：锚点位移 0.5~1.0×extent（**跨出 AIM 30% 盆**——"此锚点不对应此 GT"的显式负例）；cls 目标 no-object。
  - 尺度失配族：tiny GT 中心上方 2~3× 过大锚框（"大掩码盖 tiny 物"型 FP 的训练期反例）；cls 目标 no-object。
- **内容初始化**：弃用现存 `mean(query_embed)+N(0,0.1)`（`arch.py:1432-1438`，无 GT 信息）；改为在加噪锚点中心 gather mask_features（复用种子路径的 gather 机制，`multiscale_decoder.py:792-797` 同型），过**专属** 2 层 MLP（Linear(C,C)+LN，≈0.26M 参数，不与 `seed_proj` 共享、避免污染 SCB+ 种子语义）；位置编码复用 `_sinusoidal_box_pe`（加噪锚框）。
- **掩码重建目标**：原始 GT 掩码（非加噪掩码）——去噪任务定义即"从带噪锚恢复真形"。

### b.3 DN 损失三处重写（替换 `criterion.py:584-726`）

1. **AIM 窗口网格替代 12544 均匀采样**：现存 DN 掩码损失用均匀点采样（L680-682）——400px² GT 前景点期望 ≈4.8 个，AIM 为匹配修掉的 SNR 病被原样带进 DN 损失。修复：把 `matcher.py:296-320` 的确定性 R×R bbox+30% 窗口网格构造抽成共享 helper `build_aim_window_grid(tgt_mask)`，DN 掩码 BCE+Dice 在该网格上计算。效果：前景点占比从 ~0.04% 提到 ~30-50%；且**DN 学的度量与 AIM 匹配度量为同一统计量**（"匹配选的就是它，DN 练的就是它"）。
2. **q 目标（QFL）**：DN 正样本 cls 目标 = q = soft-Dice(pred_dn, GT)（同一窗口网格上、detach、β=2.0、warmup 1000、负项逐位不动）——与 MAL-CP+ C1 完全同参数、同一开关（C1 off → DN 也回落 one-hot，回归单测 T5 锁定）。贴入 GT 的深度融合边缘伪影由 q 天然吸收（低质重建 → 低目标，不强推 1.0）。
3. **深监督 ×9 + 权重坡道**：DN 损失挂全部 9 个头输出；总权 0.5→1.0 线性爬升 2K 步（DN 臂早期失稳的文献通病）。`dn_scalar=5 / 全 GT 无差别 / box noise 0.4` 旧路径整体退役。

### b.4 Arm-B（对照臂，同基座零新增基建）

64 个可学习辅助查询（隔离块内独立自注意力），匹配目标 = E_sel 内 tiny GT 重复 ×K 后的目标表，**在该块内单独跑一次 Hungarian（AIM cost 原样复用）**——每个 tiny GT 获得 ~⌈64/|E_sel|⌉ 个"匹配选出"的正样本；cls 目标 q 与主通道同语义（MAL 语义在匹配分布内）；推理丢弃。定位：DN 供给"按构造"、Arm-B 供给"按匹配"——16K 门决定哪条通道进 32-48K 组合臂（两条不叠加，预算见 §d）。

### b.5 主匹配零改动清单

- matcher 输入在 `criterion.py:209-218`（主）与 L250-258（aux ×9）剥离至 num_regular=200——现成路径，单测 T1/T3 锁定；
- AIM cost、margin、种子槽语义、DDP/EMA 全部不动；DN 行数每 rank 局部决定（B=1/卡），无跨 rank 同步需求。

## (c) 理论收益上界与依据

**文献锚（均注出处）**：

| 锚 | 数字 | 出处 |
|---|---|---|
| Group DETR（唯一 M2F 公开数字） | mask AP 12ep 38.5→39.7（+1.2）、50ep +0.3；+5min/ep（≈+18%）、内存 +1.2-1.7GB | ICCV23，ar5iv 全文（调研B §2.1） |
| DN-DETR | R50 12ep +1.9；同性能 50% epoch（收敛供给锚） | CVPR22（调研B §2.1） |
| DINO/CDN | 较 DN-DETR +6.0（与 query 选择复合）；Mask DINO 证明 mask 版 CDN 可行（54.5 AP IS） | ICLR23 / CVPR23（调研B §2.1/2.3） |
| H-DETR（Arm-B 同族） | R50 12ep +1.7，训练 ~+7% | CVPR23（调研B §2.1） |
| DEIM 铁律 | 增密无质量感知损失 → 退化；有 MAL → 53.2 AP 且训练 -50% | CVPR25（调研C §2 #14、§4.3） |
| Semi-DETR | "o2m 先、o2o 后"的课程有效性（我们为 128K 基座微调，此先例仅作方向支持） | CVPR23（调研B §2.1） |

**我们的证据锚**：tiny 桶 87.8% never-hit、best-IoU p50 0.006、AR_s@100=0.309（R3 D1）；召回补全 oracle +37.5（oracle 分）/ +6.7（现实分）（R3 D6）；hard-FP 占 <64 det 池 80.5%（P4-c 简报）；全 GT 55.5/图 vs <64 GT 0.85/步的供给落差（R3 D2/R5）。

**上界推算（显式折扣，防双计）**：

1. 本场可主张的仅是"**供给份额**"：覆盖已由 P4-b（SCB+ 61.9%→≥88% 预期）主张、分数目标已由 P4-c（0.29→≥0.40 门）主张，两场的 +4~12 与 +3~6 不在本提案账上。供给机制作用于"已覆盖/将覆盖的 tiny 目标的表征质量与收敛速度"，其值 ≤ 现实变现带 6.7pt 的一部分。
2. 折扣算式：DN-DETR 全配置 +1.9（全尺寸目标、从零训练）→ tiny 专用缩版 ×0.3~0.5（作用人群 4.94% 实例、<64 桶检测池）→ **+0.6~1.0pt**；负组对 hard-FP 池的独立贡献无直接文献数字（CDN 负组是捆绑组件），保守 +0~0.5pt、上限假设下（若 hard-FP 分数中位被压低、固定精度 recall 抬升）再 +1~2pt——此项置信度低，只入上限不入中心。
3. **中心主张：16K 门净 +0.5~1.5pt AP_s（相对 MAL-CP++SCB+ 叠加基线臂）；全程中心 +1~3pt、上限 +3~4pt**。收敛侧另有无形收益（DN-DETR 50%-epoch 等效），在 16K 短门里表现为"更陡的早期斜率"，单独记录不强算分。

## (d) 开销预算（算式）

**基准**：1.44-1.60 s/it（4 卡 DDP）；解码器占步时 10-15%（像素解码主导；调研B 候选1 备注）。已占：P4-c +3~6%、P4-b +~1%。本臂预算 ≤10%，叠加后 ≤20% 红线。

**Arm-A（QDN-tiny，Nq 200→296，+48%）**：

- 交叉注意力 + 头部前向（随 Nq 线性）：×1.48；自注意力 200²→296² ×2.19（但绝对值小，见下）；→ 解码器整体 ≈ ×1.45。步时增量 = 0.145 × (10~15%) ≈ **+65~110ms/it（+4.5~7%）**。
- DN 损失侧：窗口网格点采样 ≤64 行 × R²(≤4096) ≈ 0.26M 点 ×9 层 ≈ 2.4M 点/步，与主掩码损失同量级（~220 mask × 12544 × 9）；point_sample 是插值核，估 **+15~30ms**。
- 匹配侧：**零**（matcher 输入被剥离，行数不变；与 P4-c 裁决书点名的"贴入致匹配列增长"不同源，无 42M→100M 类增量）。
- **合计 Arm-A：+80~140ms/it = +5~8%**。总账：3~6%（P4-c）+ 1%（P4-b）+ 5~8% = **+9~15% ≤ 20%**。
- 降档阶梯（预注册）：K=8→4（N_dn 96→48）→ +2.5~4.5%；或正帽 64→48。最坏账 3+1+2.5 = 6.5%。
- 显存：DN 行激活 ≈ 解码器激活份额（估 2-3GB）× 0.48 ≈ **+1.0~1.5GB** 上界口径，保守报 +0.6~1.2GB（自注意力 mask 布尔 2.8MB、MLP 参数 0.26M 忽略）；16K 门附显存读数，超 24GB 即触发降档。
- 推理：`arch.py:1373` `not self.training → return None`，0 行、0ms、导出图位同等价；T1 单测锁定。

**Arm-B（aux-64，Nq 200→264，+32%）**：解码器 ×1.3 → +3~4.5%；匹配多一次 (64 × K·|E_sel|≤128) Hungarian ≈ <1ms。**合计 +3~5%**。A+B 同开（Nq 360）≈ +8~12%——**禁止同开**，16K 门二选一，胜者进组合臂。

## (e) 正确性验证方案

### e.1 单测（训练前，全部 CPU 可跑）

- **T1 隔离位同等价**：同一 checkpoint eval 前向，DN config on/off → 主通道 200 行 logits/masks allclose（1e-6）；并断言训练态下 DN 行的梯度不流入主通道任何激活（autograd.grad 抽查 1 层）。
- **T2 块对角 mask 正确性**：给定块结构断言跨块全遮、块内全通、无全遮行；Arm-B 结构同测。
- **T3 剥离与记账**：dn_num_regular_queries 在主/aux 全 10 处生效；|E_sel| ∈ {0,1,4,16,50} 的构造/帽/轮转正确；|E_sel|=0 → DN 路径整体关闭、损失字典不含 dn 键。
- **T4 AIM 网格共享**：`build_aim_window_grid` 对合成 tiny 掩码与 matcher 内联版逐点一致（golden test）；R∈[8,64] 边界。
- **T5 q 开关回归**：C1 off → DN 正样本目标逐位 1.0、负样本逐位 0；detach 生效；空 batch 无 NaN。
- **T6 种子槽不干扰**：seeded+DN 同开，种子先验仅落 `[num_learned, num_regular)` 行（AUD-2 不变量扩展）；seed_active=False 回退档与 DN 开关正交。
- **T7 权重坡道**：0/1K/2K/3K 步的 DN 损失权 0.5/0.75/1.0/1.0。
- **T8 EMA/导出**：EMA 副本含新参数；export_pipeline 不见 DN 行。

### e.2 前置门 G0（冻结 128K 基座，无训练，一卡前向即可）

- **噪声标定探针**：200 张 val 图离线构造 DN 锚点，量 Dice(锚点蕴含掩码, GT) 分布——判据：easy p50∈[0.7,0.9]、hard p50∈[0.45,0.7]、错位族 <0.35（低于匹配盆）。不过 → 调 λ 重测，仍不过 → 方案源头否决（噪声设计失败）。
- **重建可行性**：冻结基座上 DN 正行的 E[q_dn] ≥0.3（easy 级）——若基座在受锚条件下连 easy 重建都不可为，说明"知识不存在"，本方案（及一切供给方案）提前止损（与 CQTR 的"存在但欠激活"判据互补：前者测存在，本门测可激发）。
- **DN 预算直方图**：每步正/负行数分布落在 [24,64]/[16,32]。

### e.3 16K 短训门（封存 128K 基座，叠加 MAL-CP+ + SCB+ 配置，双臂）

臂 1 = 叠加基线（MAL-CP++SCB+，无增密）；臂 2 = 臂 1 + QDN-tiny。（预算允许时臂 3 = 臂 1 + Arm-B。）

| 门 | 判读数字 | 通过线 |
|---|---|---|
| 主判据 | AP_s 净增量（rescore 口径）vs 臂 1 | ≥ +0.5pt（强 ≥ +1.0） |
| 哨兵 S1 主匹配质量 | 主通道 small-GT matched-IoU p50（实验室锚 0.4134）/全量 matched p50 0.635 | 下降 ≤0.01 |
| 哨兵 S2 重复率 | dets/small-GT 均值（基线 1.30，R3 D3） | ≤1.45（naive-o2m 会爆此线） |
| 哨兵 S3 hard-FP | 固定池 <64 det 池 hard-FP 份额 80.5%、分数中位 | >0.5 分 FP 计数不升；中位理想下降 ≥0.02 |
| 哨兵 S4 TP 分数 | <64 桶 TP 分数中位（臂 1 已含 MAL 目标 0.40） | ≥ 臂 1（不因 DN 增密回落） |
| 稳定性 | loss_dn_* 单调性、无 lr/loss 尖峰 | 坡道窗口内无爆 |

**失败判读树（预注册）**：AP_s 平 + 哨兵全清 → 供给在本规模非 binding，止损记录（防 sunk cost）；S2 爆 → 隔离泄漏，回查 T1/T2 与 cross-attn 行遮蔽；S3 爆 → q 温度过弱或负组太易，收紧 λ_neg 位移/加尺度失配族占比；S1 降 → DN 权过高，坡道延至 4K 或权 0.5 固定；训练不稳 → K 降 4。过门 → 胜出臂进 32-48K 组合臂，判据沿用全场（净超 R4 退火对照线 ≥+1.5pt）。

## (f) 与其它场叠加兼容性

- **P4-c（MAL-CP+，已裁决）**：**硬依赖、同 commit**——DN 臂内的 q 目标与 C1 共用实现与开关；C2 贴入直接喂养 DN 供给（贴入 tiny GT 进入 E_sel，正帽 64 由"面积升序+轮转"公平分配）；贴入边缘伪影由 q 目标吸收。预算冲突已按 P4-c 裁决书预登记口径合并（§d 总账）。
- **P4-b（SCB+，已裁决）**：正交且互益——DN 行追加于 200 池之后，种子槽语义/先验/seed-dropout/零开销回退档全部不动（T6）；DN 的内容 gather 与种子 gather 同型不同参，不污染 `seed_proj`；DN 梯度强化共享层后，种子槽"站上 tiny 目标后的持有与成型"直接受益（这正是 P4-b 覆盖收益的变现放大器）。
- **P3-a（掩码边界，并行场）**：正向耦合——边界损失作用于同一掩码损失路径时自动覆盖 DN 正样本（窗口网格点上），需分臂归因。
- **P3-b / P4-d（推理端）**：零交互——DN 推理期不存在，导出/topk/重打分协议无感知。
- **P3-c（退火对照）**：正交；DN 权重坡道与 lr 分组退火可同臂。
- **降档总预案**：若叠加审计触碰 20% 红线，按 P4-c 裁决书预案 max_paste 12→8 与本方案 K→4 双降，最坏总账 ~11%。
