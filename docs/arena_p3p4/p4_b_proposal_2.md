# P4-b 提案 #2：「种子-回廊」SCB（Seed–Corridor–Budget）+ MAL-CP+ 捆绑

> 提案人：独立提案人 #2（互不可见）｜日期：2026-09-21｜场：P4-b 覆盖与 query 预算
> 一句话：**用已有的 stride-4 probe 头让 64 个种子 query 出生在小目标位置（出生），用 probe-前景注意力回廊把这一出生钉穿全部 8 层（持有），用已裁决的 MAL-CP+ 把 matched 种子的 cls 目标绑到同一根 AIM soft-Dice 标量上（变现）**——三件事共用一个 probe 前向，训练 +1~1.5%、推理 ≤+2ms（有零开销回退档）、显存 +≤0.3GB。

## 1. (a) 机制因果链

### 1.1 三重成因与攻击点

存在性缺口的因果链按 R3 证据可拆为三段，本提案**三段全打，但重心在"出生"与"持有"**：

**成因 1：出生先验缺失（主攻）。** 200 个可学习 query 的内容/位置嵌入是 128K 训练固化出的"通用槽位"，其初始注意力分布被大目标主导（Salience-DETR/PanSR 点名的 query 选点尺度偏置；我们侧的镜像证据：probe 头定位 76.3% 小 GT，而 learned 槽对小 GT 的 IoU≥0.5 覆盖在生产模型上只有 61.9%）。一个 query 若在第 0 层就不在小目标附近，后续层没有任何信号把它拉过去——**它从不出生，就永不持有**。
→ **B1（出生）**：复用 R2b 的 probe-种子机制（代码已在：`multiscale_decoder.py` 的 `seed_queries/seed_attn_prior` 路径 + `arch.py` 的 `SmallObjectProbe`）：最后 64 个槽不使用 learned 嵌入，改为在 probe 峰值处从 mask_features 采样内容/位置嵌入出生。

**成因 2：注意力覆盖断裂（P6 残余，次主攻）。** R3 D4 代码核查：topk 门控（min64/ratio2.0，256² 网格）只被第 8 层 cross-attn 消费一次；layer 0-6 的 key 是 stride 32/16/8 循环 + 硬 0.5 阈值，且 layer 6（末层前一层的获得窗口）key 恰在 stride-32。query 对小目标的"获得与持有"发生在无门控区——出生在峰值上的种子，若无持续锚定，会在 7 层粗网格 attend-everywhere 中漂移溶解。R2b 只给了 layer-0 一次 probe-fg 先验（`seed_attn_prior` 只作用于初始 head call 的 mask，仅 layer 0 消费）——**出生后没有走廊，是 R2b 覆盖只有 92.1% 而非更高、且种子槽分数（0.219）低于 learned 槽（0.294）的机制候选**。
→ **B2（回廊）**：把 probe-前景先验从"仅 layer 0"扩到**全部 8 个 mask 消费点**（初始 call + layer 1-7 的消费 mask），每层把 probe_fg 双线性下采到该层 key 网格后 OR 进种子行的注意力掩码（阈值 0.25，沿用 R2b；种子行 = [136,200)，learned 行与 DN 行逐位不动）。种子从此每一层都只能在"probe 认为有前景"的 cell 上取特征——出生被钉穿全网络。这是 QueryDet"低分辨率找、高分辨率稀疏算"的注意力版，也是 HGSQ 把热图当计算预算的用法，但**只在训练期+1ms 内实现，不动 learned 查询的 c0 语义**。

**成因 3：正样本供给稀缺（借力 P4-c C2）。** 每步每小 GT 仅 0.85 可见正样本；never-hit GT 的 200 列 cost 全是噪声（<64px best-IoU 中位 0.006），Hungarian 归属是掷硬币 ×9 重掷。种子机制把"掷硬币"变成"必然"：出生在峰值的种子初始 soft-Dice 即 ~0.5+，AIM 列上以大 margin 稳定胜出（AIM 截断已修，全覆盖）。供给倍增由捆绑件 C2 分层贴入承担（tiny 抽样权重 0.60、max_paste 12 → 每步小 GT 可见数 0.85→~2-3，同时给 probe 更密的正监督）。

### 1.2 为什么不是别的子轴（证据否决）

| 备选子轴 | 否决依据 |
|---|---|
| query 扩容（200→300+） | R3 D2：容量不 binding——small GT/图 p50=1/max=26，稀疏图（查询远超需求）AR_s 仍只 0.319；maxDets 200 历史仅 +0.55pt |
| 门控多层化（learned 查询也吃 topk 门控） | (i) R3 D4：门控是稳定器不是发现器——无信号 query 的 top-64 落在它误指向处；(ii) 最便宜的可行变体（layer 6 key 换 stride-8 + 128² 门控）fwd +3.2 GMACs ≈ 训练 +4~6%，与 P4-c 叠加后挤占预算；(iii) stride-32/16 key 对 2-3 cell 目标物理亚 cell，门控无物可门 |
| 动态 query 数量（DQ-DETR 计数式） | 可变长 query 与固定 shape 批处理/CUDA graph 冲突（调研 B 明示）；且 DQ 谱系后续（Dome/D³R）仍需密度引导初始化——数量不解决选点。固定 k=64 shape-static 是硬选择 |
| 密集 proposal（DDQ 式全铺） | 不去重的稠密 query 毒化 o2o（DDQ 反面）；naive o2m 3300 query 从 32.6 崩到 8.4（Group DETR 表 7）；预算也超 |

## 2. (b) 与二分匹配 / set-prediction 的兼容性

1. **种子 = 槽位，不是特殊匹配类。** 种子占据槽 [136,200)，与 learned 槽进入**同一个全局二分匹配**，matcher 零改动。set-prediction 的损失对槽位置换不变：种子改变的是槽的**输入侧初始条件**（嵌入来源 + 注意力先验），不是损失侧语义——这是与 DN/Group（需要 attn-mask 隔离/分组）的根本区别，也是改动面最小的形态。
2. **与 AIM 的交互是同一根标量的闭环。** AIM 小 GT 列（确定性窗口 soft-Dice，截断已修）天然偏爱"已站在目标上"的种子：初始 mask 重叠 → dice 列低 → 大 margin 胜出（这正是 R2b 种子覆盖 92.1% > learned 87.0% 的匹配侧解释）。MAL-CP+ 的 C1 又把 matched 种子的 cls 目标设为**同一 matcher dice 列的 q 值**——"匹配选的就是它，分数学的就是它"，出生、胜出、得分三段共用一个度量，无漂移。
3. **无监督泄漏。** 回廊与出生用的是 probe 的**网络前向输出**（自监督于 GT 并集），不含 GT 信息；DN 查询（若 P4-a 胜出启用）需要的 attn-mask 隔离逻辑与种子行正交（AUD-2 修复已保证 DN 行掩码独立，本提案的回廊 OR 只写 [136,200) 行，单测覆盖）。
4. **训练动力学接坡（DDP 正确性）。** R2b 的 warmup=300 硬切换在 warmup 期使 `seed_proj_*` 无梯度，需依赖 find_unused_parameters=True（本身有同步开销）。生产版改为**α 接生坡道**：`content = (1-α)·learned_slot + α·seed_content`，α 在 2K 步内 0→1 线性——seed_proj 参数逐步皆有梯度（DDP 无需 find_unused）、cls 头无出生冲击、CUDA graph shape 全程静态。warmup 后 α=1，与 R2b 语义一致。
5. **导出语义不变。** 种子槽与 learned 槽在同一 top-100 分数导出流里竞争（inference_topk 已 config 化）；无配额、无特权。

## 3. (c) 理论收益上界与依据

**阶梯定位。** R3 D6 oracle：3634 个 never-hit 小 GT 注入自身 mask，score 0.99 → **+37.5pt**、score 0.45 → **+6.7pt**。本提案攻击的正是第一行的人群（never-hit），变现分数由捆绑的 MAL-CP+ 决定——即收益落在 **6.7→37.5 的区间内，由 r（可恢复比例）× f(s)（变现率）两个折扣决定**：

```
ΔAP_s ≈ r × [6.7 + (37.5 − 6.7) × f(s)]
```

- **r（覆盖恢复率）**：上界锚 probe 定位率 76.3%（R2b：76.3% 小 GT bbox 内有峰；种子覆盖 92.1% 对应缺口收敛到 7.9%）。生产外推三重折扣：(i) <64px 桶 87.8% never-hit 是最难人群、probe 在其中最弱；(ii) 深度弱对比（内外差 p50≈1.5σ）侵蚀 probe 输入；(iii) 128K learned 群体 entrenched。取 **r ∈ [0.40, 0.70]，中枢 0.55**（R2b 缺口收敛 38.1%→7.9% 的生产折半）。
- **f(s)（分数变现率）**：P4-c 门 G1 承诺 TP 分数中位 0.29→≥0.40（强 ≥0.50）；取成熟种子 s≈0.5-0.65，在 0.45（+6.7）与 0.99（+37.5）锚点间保守内插 **f ≈ 0.15-0.30**（0.45→6.7 与 0.99→37.5 之间的变现非线性，且单类 PR 曲线上小目标 det 仍排在大目标 0.80 分之下）。
- **中枢**：0.55 × (6.7 + 30.8 × 0.25) ≈ **+7.9pt**；区间 **+4~+9pt**；全变现上界（r=0.763, f=0.5）≈ +12pt。
- **归因拆分（2×2 预注册）**：种子-only 臂（无 MAL）在 0.29 分数水平下 ≈ +1.5~3pt（R2b 结局的定量版——这正是"纯覆盖没有资格"的原因）；MAL-only 臂是 P4-c 自己的 +3~6（已检出人群的分数）；捆绑臂 = 覆盖人群 × 分数机制的乘积项，非两者相加。
- **交叉核**：CQTR 在 9 个冻结检测器上 APs +1.95~3.81 仅靠重打分（零覆盖增量）——侧面校准分数半边量级；Dome-DETR 密度引导 query 初始化 AI-TOD-v2 +3.3 AP、QueryDet COCO AP-small +2.0 校准覆盖半边量级。捆绑中枢 +6~7 处于两半乘积的合理带。

## 4. (d) 开销预算（算式）

### 4.1 训练（现 1.44-1.60 s/it，4 卡 DDP）

| 项 | 算式 | ms/it |
|---|---|---|
| probe 头 fwd+bwd | conv1 256→128@1×1: 128·65536·256 = 2.15 GMACs；dw 3×3: 0.076；conv3 128→2: 0.017 → fwd 2.24 GMACs ≈ 4.5 GFLOPs，×3（bwd）≈ 13.4 GFLOPs ≈ 步总量（~200-250 GFLOPs 训练当量）的 +2%；管线非算力饱和，按带宽/launch 折算 | +8~15 |
| probe 目标构造 | GT 并集（<1024px²）max-pool 至 256² + focal/dice on 2×65536 | +2~4 |
| 种子出生（gather+2×Linear+LN） | 64·256·256·2·2 ≈ 16.8 MFLOPs + gather(64 of 65536) | <1 |
| 回廊（8 个消费点） | 8 × bilinear(256²→{32²,64²,128²,256²}) + bool OR on (B,8,64,S) 切片 ≈ 0.7M·B 元素级 ×2 | <1 |
| **合计** | | **+12~22（+0.9~1.5%）** |

**叠加审计**：P4-c MAL-CP+ 已裁 +3~6%（其主项 AIM 列随贴入增长 42M→100M 点/步，+40~80ms，**不在本账单内重复计**）→ 组合 +4~7.5%，红线 20% 的 1/3 以下，余量 2.7×。若 P4-a 后续也胜出（其 +10-18% 与本场叠加会触线），预登记降档：P4-a 取 K=3 组（其降档方案 +6~10%）→ 三场合计 11~17.5% 仍过线。

### 4.2 推理（目标 ~100ms，红线 +10ms）

- 主档：probe 头 fwd 4.5 GFLOPs fp16（~25 TFLOPS 有效）≈ 0.18ms + 峰值检测（maxpool3×3 + 比较 + topk-64 on 65536 cell）≈ 0.2ms + gather/投影 <0.1ms + 回廊插值 ≈ 0.2ms → **合计 0.6~1.0ms；非 CUDA-graph 悲观（~10 个 kernel launch）≤2ms**。全部为现有 CUDA 算子（maxpool/topk/gather/interpolate/bool OR），无 CPU↔GPU 往返、无 host 同步（固定 k=64 保 shape-static，兼容仓库 CUDA graph 路径）。
- **训练期专用规避档（红线要求的兜底）**：推理 `seed_active=False`（现有 flag）→ probe 与回廊整路不跑，**0ms**；learned 群体经由训练期共享权重获得迁移。判读规则：若回退档保住 ≥80% 覆盖增量（never-hit 率增幅的 80%），部署用零开销档，否则用主档（仍有 5× 预算余量）。
- 实现注意：`forward_inference_exported` 导出路径需把 probe/种子/回廊从 `return_features` 路径同样接通（脚手架已在，见 arch.py:1036-1057）。

### 4.3 显存（≤24GB/卡）

probe 参数 35K（0.14MB）；训练激活（B=2, fp32, ~4 个 128ch@256² 中间张量）≈ 67MB×4 ≈ **+0.27GB**；GT 并集目标 +掩码切片 <50MB。回廊零新增分配（在既有 attn_mask 切片上原地 OR）。**合计 +≤0.3GB/卡**。

## 5. (e) 正确性验证方案

### 5.1 单测（训练前，全部 CPU 可跑）

1. **形状/断点兼容**：seed_queries=64 时 query_feat/query_embed 仍 200 行（旧 checkpoint strict 加载）；α 坡道 0 与 1 两端输出与"纯 learned/纯种子"逐位一致。
2. **回廊行隔离**：OR 只写 [136,200) 行；DN 行（dn_enabled 时）与 learned 行逐位不变（AUD-2 回归）；OR 后无全掩行（复用 `_combine_semantic_and_padding_mask` 的恢复语义：fg 空图回退 attend-everywhere 而非 NaN）。
3. **确定性**：tie-break 缓存（seed 20260914）在同 grid 下 eval 双跑一致；α 坡道计数走 buffer 不走 wall-clock。
4. **probe 监督无泄漏**：probe 目标只来自 <1024px² GT 并集的 max-pool；推理路径 probe 输出与任何 GT 无关（代码审阅断言）。
5. **DDP**：α∈(0,1) 全程 seed_proj 有梯度（find_unused=False 下无 DDP 报错，单进程模拟梯度存在性）。
6. **导出等价**：seed_active=False 时导出比特位与封存基线一致（零开销档的回归保证）。

### 5.2 冻结基座探针（Stage-0，≤2K 步，R2b 协议复用——本场预注册实测门）

128K 封存权重冻结骨干（或 0.1×lr），只训 probe+种子+回廊，MAL 开/关双臂：
- **覆盖率先行指标**（主判读）：200-query 任意分数 IoU≥0.5 覆盖 61.9% → **≥70%**（强 ≥75%）；<64px 桶 12.2% → ≥20%；38.1% 缺口 → ≤30%；种子槽 matched 率与小 GT peak-in-bbox 率（生产分布上重测 R2b 的 76.3%）。
- **分数捆绑必要性复验**：MAL-off 臂的种子槽 matched cls 应复现 R2b 的 0.22-0.29（证"纯覆盖无资格"）；MAL-on 臂 ≥0.40（P4-c G1 同门）。
- **AR_s**：@100 0.309 → ≥0.35；@10 仍预期 ≈0（排序属 P4-c/P4-d 域，不作本场门）。

### 5.3 ≤16K 短训门（Stage-1，封存基座，2×2：种子{on,off} × MAL{on,off}）

| 门 | 弱过 | 强过 |
|---|---|---|
| AP_s（捆绑臂净增） | ≥+1.0 | ≥+2.0 |
| 覆盖率（先行，不等人） | ≥+8pt 绝对 | ≥+15pt |
| 38.1% 缺口 | ≤30% | ≤22% |
| AR_s@100 | 0.309→≥0.36 | ≥0.42 |
| 纪律（承 P4-c G2） | hard-FP 中位 ≤0.10 且不随 TP 上移 | 同左 |

**失败判读树（预注册）**：
- 覆盖↑ 分数卡 ≤0.35 → 移交 P4-c Phase-2（图内排序 hinge）与 P4-d（CQTR 重打分），本场机制保留；
- 覆盖不动 → probe 生产分布定位审计（peak-in-bbox <60% → probe 输入加深度边缘通道，或先跑 C2 贴入增密 probe 正样本再重试；**不硬推**）；
- 总 AP 掉 >0.5pt → 种子数 64→48 或回廊阈值 0.25→0.15 降档重试一次，仍败则止损。

## 7. 诚实备注

1. **收益主张不含 P4-c 的 +3~6**（那是已检出人群的分数收益）；本场主张的是 never-hit 人群 × 分数机制的乘积项 +4~9。两场上限物理和 ~+40（oracle 37.5 的覆盖段 + 排序段）不会同时全变现。
