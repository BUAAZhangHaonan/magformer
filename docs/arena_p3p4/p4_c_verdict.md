## 三、裁决

**胜出：#3 MAL-CP**——机制最完备（q 与匹配 cost 同源同度量、"匹配选的就是它，分数学的就是它"）、供给设计最完整（三桶权重+SNR 过滤+crop 上限+prefill 修复）、验证门最严谨（q-IQR 前置门在训练前就能否决方案）、开销记账最诚实，且自带 Phase-2 扩展卡（C3 EFL 分桶 focal）与 P3 移交规则（cls 贴地=pooling 上限→止损）。

**合并采纳**：
1. **#4 的 scale_weights 接线**（作为第二单因子臂：现成代码一行的接线，独立归因）；
2. **#2 的图内排序 hinge** 进 Phase-2 卡（与 C3 同级：MAL 落定后单因子试，风险隔离）；
3. **#1 的冻结 E[q] 探针**并入前置门（与 #3 的 IQR 门互补：一个测均值水平一个测方差）。

**亚军：#4 QST**（若 #3 的三桶抽样在贴入边缘 FP 计数上翻车，回退 #4 的固定配额形态）。

**MAL-CP+ 最终形态**：C1 q 目标（matcher dice 列免费搭车 + 大 GT 2048 点补算，QFL β=2.0，warmup 1000，负样本逐位不动）+ C2 贴入（bank 2000 / max_paste 12 / tiny(<64px²) 抽样权重 0.60 / 入库深度 SNR>1.0σ 过滤 / bank_max_crop_edge 192 / prefill 800 图[断点已修]）——单 commit；消融按 2×2（C1/C2 各 on/off）归因。
