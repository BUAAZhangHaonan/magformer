# P4-b 提案 #3：SCQ —— 种子出生 × 微型 CDN 直供 × MAL 分数捆绑

> 提案人：独立提案人 #3（2026-09-21，纸面轮）。判分口径同全场：理论收益 × 置信度 ÷ 开销。
> 一句话：**不加 query 数（R3 D2 已证容量不 binding），改 query 的"出生位置"与"正样本供给"，并把分数成型（P4-c 胜出件 MAL-CP+）直接焊进出生与供给两条通路**——覆盖与分数在同一个 commit 里成型，不存在"纯覆盖"形态。

## (a) 机制因果链：三重成因，我攻击哪一个、为什么

### 缺口的三重成因分解

38.1%（3634/9531）small GT 在全部 200 query 输出中无任何 IoU≥0.5 掩码（R3 D1）。成因按获得链路拆为三段：

1. **注意力覆盖（获得/持有）**：8 层解码器中前 7 层 key 是 stride 32/16/8 粗网格 + 硬 0.5 阈值掩码；<32px 目标在 stride-8 是 1 cell、stride-16/32 亚 cell；topk 门控（ratio 2.0/min 64）只被最终第 8 层消费（`multiscale_decoder.py:982-992` 的层调度：head_level==3 仅在 i≥6，且 i=7 的 mask 被 `build_attn_mask=not is_final_iter` 跳过——真正被消费的 256² 门控 mask 只有一个，进 layer 7）。小目标 query 的**获得**发生在无门控的粗网格层（R3 D4："query 获得与持有小目标的层恰恰在无门控区"）。
2. **出生先验（初始站位）**：200 个可学习 query 是图像无关的自由 content/pos 参数；小目标像素份额 0.124%，梯度探索需要从 AIM 修复后的匹配里反复中标才能"站上"小目标——每步 0.85 可见（P4-c 证据），冷启动站位全靠碰。R2b 证明**出生位置可以直接解决站位**：probe 头定位 76.3% 小 GT（bbox 内有峰），64 个种子 query 出生在峰值 cell → 种子槽以 92.1% IoU≥0.5 覆盖率持有小目标（学习槽 87.0%）（EVIDENCE.md L95，09-14 raw 权重、169 小 GT 读数）。
3. **供给（正样本事件率）**：o2o 匹配下每个小 GT 每步至多 1 个正样本；且匹配失败步零供给。分类头对小目标的 focal 事件率被 0.85 可见/步 × 1 槽位双重掐死——这正是 R2b"覆盖 92.1% 但 cls 停 0.22-0.29"的另一半解释：**即使覆盖了，事件率也不够把分数炼出来**。

### 本提案的攻击选择与因果论证

- **主攻出生（C1）**：R2b 已给出存在性证明——同样的 200 槽、同样的匹配器，只把 64 个槽的出生地从自由参数换成 probe 峰值，覆盖率 92.1%。出生先验是三重成因中唯一有直接实验证据"单独可解"的一环。probe 基建（`SmallObjectProbe`、种子注入、layer-0 注意先验、确定性 tie-break）全部在主干（arch.py:21-47, 167-201, 600-604；multiscale_decoder.py:767-799, 834-854），F1 封存配置只是没开（f1_full_design_256k.yaml 无 probe/seed 键）——**这是复活不是新建**。
- **主攻供给（C2）**：R2b 的负结果精确锁定了"分数成型"是卡点，而分数成型需要事件率。tiny-CDN 让每个小 GT 每步有 K 个"出生在目标上、不经匹配、直接重构 GT"的正样本 query——供给 ×K 且与匹配解耦；负组（大偏移出生）在"似是而非处"训练 cls=0，是分数纪律的免费赠品（调研 B 候选 1 的论证：正负两组天然捆绑覆盖×分数）。
- **捆绑分数（C0）**：R2b 的种子 query 分数停 0.294/0.219，离线抬分扫描（×1.5~×5）单调变差——低分是 focal 目标=1 下"诚实的坏校准"，事后无解（EVIDENCE.md L96）。MAL-CP+ 把匹配 query 的 cls 目标换成 AIM 同源 soft-Dice 质量 q——本提案把同一 q 目标**扩展到 DN 正样本**（q = soft-Dice(DN 预测 mask, 干净 GT)，AIM 确定性网格，与匹配同度量零漂移），使新出生的每一条覆盖通路（种子槽、DN 槽）一出生就在质量标量监督下。
- **辅攻注意力覆盖（C3，单开关副臂）**：门控多层化是**已实现的一个 config 位**（`mask_attn_topk_only_stride4: false` 即门控进全部 head call，multiscale_decoder.py:992 的分支）。R3 给的机理是"稳定器不是发现器"：门控防的是低置信 query 退化为 attend-everywhere，不创造分辨率。因此它排在出生/供给之后作单因子臂，采纳与否由消融决定，不入主包收益。

**明确不做**（防搭车）：动态 query 数量（R3 D2：容量不 binding，max 26 small GT/图 ≪ 200；DQ-DETR 的可变长还与固定 shape 批处理冲突）；密集 proposal（DDQ 反面：不去重的稠密 query 毒化 o2o）；推理端热图预算预测器（HGSQ 式"实时算预算"与近零开销冲突，本提案的 probe 只做出生路由且给脱离方案）。

## (b) 与二分匹配 / set-prediction 的兼容性

**C1 种子 query：语义上是常规 query，完全不触碰匹配器。** 种子占据 200 槽中的固定 64 槽（136-199），与学习槽一起进同一个 Hungarian o2o、同一个 AIM cost、同一套 ×9 深监督；输出仍是 200 元素集合，排列不变性由匹配器吸收。与自由 query 的唯一差别是初始化变成图像条件化（从 mask_features 峰值 cell gather）——这是 DINO 混合 query 选择/编码器选点的严格弱化版（主干本就有 `encoder_query_selection` 全量图像条件化路径，multiscale_decoder.py:734-754），不引入新的匹配语义。与 AIM 的交互是正向的：种子初始 mask 偏向小目标 → AIM 的确定性 soft-Dice 列恰好给这些槽在小 GT 列上高信噪比（margin 2.43σ 的既有收益直接作用于出生在目标上的 query）。**风险与对冲**：固定槽位特化可能造成"种子槽只认小目标"的隐性先验——这是特性不是缺陷（分区供给），且 R2b 读数显示学习槽在种子在场时覆盖率反而更高（87.0% vs 生产 61.9% 的事实差异说明种子没有挤占学习槽生态）；消融臂 G-seed（§e）单测。

**C2 tiny-CDN：匹配器外的辅路，隔离是硬前提——本提案发现现存 DN 路径没有隔离。** 现状核查：DN query 直接 concat 进自注意力，`tgt_mask=None`（multiscale_decoder.py:578-583 与 deformable 路径 600-605 均无自注意力隔离掩码）。这正是调研 B 反面教训 2"去噪无隔离=作弊"的形态：DN query 可从常规 query 抄答案、常规 query 可瞥见 GT 噪声解，监督任务被平凡化。**本提案的 C2 必修项**：块对角自注意力掩码（常规 200 | DN 正组 | DN 负组三块互不可见，~30 行，用已有的 `dn_num_regular_queries` 元数据构 mask，DN-DETR 标准做法）；配套单测见 §e。其次，C2 把现有 DN 改造为小 GT 专用：现实现是**全量 GT、box-PE、dn_scalar=5**（num_dn = 6×max_valid，全图 GT 均值 55.5、max 100 → 最坏 600 query，既贵又不对准）；改造为 canvas 面积 <4096px²（与 AIM 资格线同刻度）的小 GT、**mask 空间噪声**（中心平移 ±30% bbox + 尺度 0.7-1.3，在 256² 网格上 grid_sample 渲染——mask 任务的噪声语义），K=3，N_dn 上限 96。匹配语义：DN 正样本不进 matcher，直接指定源 GT 重构；DN 负样本（偏移 ≥1 bbox 出生）目标"无物体"。推理期 `_generate_dn_queries` 返回 None（arch.py:1373），辅路整体消失，零推理语义残留。

**C0 与 MAL-CP+ 的接口**：匹配 query 的 q 目标按 P4-c 裁决原样落地（不重造）；本提案新增的只有"DN 正样本 cls 目标 = q_DN"（QFL 同形，负组逐位不动）。q_DN 用与 matcher 同一 `_aim_small_gt_costs` 的确定性网格 dice 机制对干净 GT 计算——**匹配选的就是它、分数学的就是它、DN 重构的也是它**，三处同度量零漂移（承 P4-c #5 的"AIM 确定性网格"设计并推广到 DN 支路）。

## (c) 理论收益上界与依据

**阶梯锚（R3 D6，rescore 口径）**：给 3634 个 never-hit 小 GT 注入自身 mask，score 0.99 → +37.5pt；score 0.45（现实小目标分数水平）→ +6.7pt。即：**每个 never-hit 小 GT 在顶部排序下值 37.5/3634 ≈ 0.0103pt，在 0.45 分数水平下值 6.7/3634 ≈ 0.0018pt**。变现率被分数流门控在 18%~78%（SYNTHESIS L20）。

**覆盖侧外推**（本提案负责的那一段）：
- 可恢复质量 f：R2b probe 定位 76.3% 是发现上限；种子槽覆盖 92.1%（含学习槽协同）是持有能力。生产模型现状 61.9% 命中。保守外推种子+CDN 把 never-hit 质量回收 f ∈ [0.5, 0.75]（留出小模型→128K 生产、169 GT 子集→全 val 的两类转移折损；<32px 桶 92.0% never-hit 是最难段，probe 深度对比度 1.5σ 上限约束也在这里）。
- 变现系数 m：MAL-CP+ 的 G1 门（小 TP 分数中位 0.29→≥0.40）若兑现，新覆盖 det 的分数落 0.40-0.55 带，介于 0.45 锚与 oracle 锚之间，取 m ∈ [0.25, 0.55]（oracle 值的折算）。
- **ΔAP_s(P4-b 覆盖贡献) = 37.5 × f × m ∈ [+4.7, +15.5]，主张区间收敛报 +4~+12，中枢 +7**。若 MAL-CP+ 失效（分数停在 0.29），下界退到 6.7 × f ≈ +3.4——这正是捆绑设计的动机：C0 使该下界分支在机制上不应该发生，若发生则整案止损（§e 判读树）。
- C3 门控多层化：R3 D4 保守 +1~3pt（无消融依据），单开关臂单独归因，不入中枢。
- **不重复计入**：已覆盖半的分数抬升归 P4-c（其自主张 +3~6）；供给增密对已覆盖半的稳定收益与本场主张的交集部分，只在 G4 探针里作机制读数、不进收益主张。

**置信度标注**：92.1%/76.3% 出自 09-14 小模型 finetune（169 GT raw 读数），非 128K 生产直接证据——转移风险是本提案最大不确定性，已折入 f 的下界；4K 步微调协议移动不了 AP_s（P2"微调赛道闭合"±0.006 噪声带）→ 收益表达需要 ≥32-48K（与 P4-c 组合臂同刻度），12-16K 短训门只验机制不验终值。

## (d) 开销预算（算式）

基线 1.44-1.60 s/it（取中 1.52s，4 卡 DDP，B=1/卡）。红线 +20% ≈ +304ms；P4-c 已占 +3~6%（≈+45~90ms），本场上限 ≈ +214~259ms。

**训练（C1+C2，主包）目标 +2.5~5%（+38~76ms）**：
- C1 probe 头：fwd MACs ≈ 65536×(256×128 + 128×9 + 128×2) ≈ 2.24 G ≈ 4.5 GFLOPs；fwd+bwd ≈ 13.5 GFLOPs，小卷积+GroupNorm 实效带宽 ~10-20 TFLOPs → **~1-2 ms**。probe 损失（focal+dice on 256² 并集）~1ms。种子 gather/投影（64×256×256×2 MACs ≈ 8.4M）可忽略。**小计 ~3-4 ms（+0.25%）**。
- C2 tiny-CDN（N_dn = min(4×n_small, 96)，P4-c 贴入后 n_small 典型 6-10、最坏 38 → N_dn 典型 24-40、封顶 96）：
  - 解码器份额按调研 B 口径取步时 12%。Q: 200→224-296。自注意力 Q² 项：(296/200)²=2.19×，自注意力约占解码器 15% → 解码器 +18% → **步时 +2.2%（最坏）**；
  - mask head einsum（bqc,bchw，9 次调用）线性于 Q：+20% × 既有 ~30 G MACs → +6 G MACs ≈ **+1-2 ms**；
  - DN 辅助损失：96 mask × 12544 点 point_sample ≈ 1.2M 点 fwd+bwd ≈ **+5-8 ms**；噪声渲染 grid_sample ≤96×65536 ≈ **+1-2 ms**；
  - **小计典型 +8-12 ms（+0.6~0.8%），最坏（96 封顶）+35-45 ms（+2.5~3%）**。封顶 96 与 K=3 是预算的构造性保证。
- 合计主包：**典型 +11~16 ms（+0.8~1.1%），最坏 +40~50 ms（+3%）**——报 +2.5~5% 留裕量。
- C3 副臂（独立开关）：每 head call 追加 sort（B·Q, S）：粗层 S≤16384，200 行 → ~0.2ms × 5 calls ≈ **+1-2 ms（+0.1%）**，布尔掩码张量尺寸不变（topk 替换 0.5 阈值，同形状复用）。
- **叠加 P4-c 后合计 +6~11%（最坏 +9~14%），红线余量 ≥1.4×**。与 P4-a 若同时胜出的降档阶梯见 §f。

**推理（红线 +10ms）**：probe 头 fwd ~4.5 GFLOPs → **+0.5-1.0 ms**；种子 gather/topk（maxpool+topk on 65536）<0.3ms；C3 若采纳 +1-2 ms。**合计 +2~3 ms**。训练期专用规避（红线被 P3-b 挤占时启用）：**领养脱离（adoption off-ramp）**——主训结束后 4-8K 适配段关闭 `seed_enabled`（64 槽回到学习参数，其余权重热启动），probe 头与种子通路从导出图删除，推理增量降至 +1-2 ms（仅 C3）；脱离门：覆盖增益保留 ≥80%（never-hit 回升 ≤20%），不达标则保留 probe（1ms 仍合法）。DN 支路推理恒零（训练期专用，合规形态）。

**显存（红线 24GB/卡）**：probe 参数 0.24M + 激活 ~2MB；DN 查询全链激活 ≈ 96×256×~30 张量 < 10MB；einsum 增量 ≈ +75MB（9 调用 × 40MB/调用 的 20%）；自注意力矩阵 (8 头×296×296×4B)≈2.8MB；隔离掩码 3 块 ≈ 296² bool ≈ 0.1MB。**峰值 < +0.5 GB**。

## (e) 正确性验证方案

### 1. 单测（训练前，全部 CPU 可跑）

1. **DN 隔离（必修项的验收）**：构造 3 组 query（常规/正/负），验证自注意力 mask 块对角；反例测试——故意漏掩码时用梯度差分检测（常规 query 对 DN 输入扰动的梯度必须为 0）。
2. **eval 等价性**：同权重下 dn_enabled on/off 的 eval 前向逐位一致（辅路零推理残留）。
3. **种子确定性**：`_seed_tiebreak` 缓存 + 全零 probe 图 topk 分散性（既有测试扩展）；eval 两次前向逐位一致。
4. **DN 噪声语义**：500 次采样的 noised-GT vs GT IoU 分布落 [0.25, 0.85]，无 >0.95（任务平凡化）与 <0.1（噪声无效）质量；负组偏移 ≥1 bbox 断言。
5. **q_DN 目标**：负组目标逐位等于基线 focal 负目标（bit-equal）；正组目标 ∈[0,1] 且与 matcher dice 列同源（同一 GT 同一预测下相等）。
6. **预算封顶**：n_small=38（P4-c 贴入最坏）时 N_dn=96 断言、显存增量实测 <0.5GB。
7. **种子 warmup**：`_probe_step < probe_seed_warmup` 时种子通路关闭（既有行为回归）。

### 2. 冻结基座探针（训练前/廉价，判 MAL-捆绑可行性）

- **R2b checkpoint 离线读 q 分布**（R2b 协议复用，零训练）：在 09-14 种子 checkpoint 的种子槽上算 q = soft-Dice(种子 mask, 小 GT)（AIM 网格）：判 **q IQR ≥ 0.15 且 p50 ∈ [0.5, 0.8]、种子持有者 q − 重复者 q ≥ 0.10**（P4-c 前置门同刻度）。不过 → 种子槽的 mask 质量撑不起质量目标，方案源头否决，只保 C2。
- **probe 转移预检**：128K 冻结基座上挂零初始化 probe 只训 probe 头 300 步（其余冻结）→ 小 GT bbox 峰值定位率 ≥65%（R2b 76.3% 折损带）。不过 → C1 出生先验在生产塔上失效，降级为 C2-only 臂。

### 3. ≤16K 短训门（封存 128K 基座 finetune，单 commit = C1+C2+C0；对照臂 = 基座 + MAL-CP+ only）

预注册判读（rescore 口径）：
- **G1 覆盖先行指标（主判据）**：never-hit@0.5 small GT 38.1% → **≤25%（强 ≤18%）**；种子槽小 GT 覆盖 ≥85%（R2b 92.1% 的折损带）。
