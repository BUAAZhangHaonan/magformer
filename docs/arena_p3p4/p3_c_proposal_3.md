# P3-c 提案 #3：GDA-dEMA —— 分组差异化退火 + 边界组双速 EMA

提案人：独立提案人 #3（互不可见）| 日期：2026-09-21 | 场：P3-c 边界稳定性（训练动力学）
一句话主张：**hires 组（stride-2 头 + 末层 cross-attn，20× lr）的噪声球是边界抖动的优化器侧成因；用"分组差异化余弦退火（GDA）+ 边界组加深 EMA（dEMA）"两个零开销、不动损失形式的组件把它消掉——R4 收尾对照臂是本方案的公共对照 C0，C1−C0 即本方案净增量，预注册主门 +0.25~0.6pt AP_s@160K（对照臂自身 +1.0~1.25pt 归退火，不重复计价）。**

| 项 | 值 |

## (a) 机制因果链

### a.1 优化器侧成因的五步因果链（全部有代码或实测锚）

1. **更新量纲事实**（R4 堵点 3，代码核验）：preclip gradnorm 中位 ~1200-1400，`clip_value=1.0` full-model（`trainer.py:1067-1093`）→ 100% 步被裁剪 → 每步更新 = **lr × 单位方向向量**（Deformable-DETR 式）。参数组之间唯一稳定的量纲差就是 lr。hires 组（`hires_dw/hires_proj/hires_shuffle + small_probe/seed_proj/seed_norm + 末层 cross_attention_layers.{7}`，`experiments_archive/v317_next_stage_2026-07/source/tools/train.py` build_optimizer 的 hires_lr_multiplier 分组）峰值 2e-4、128K 时仍 1.21e-4，主组 6.1e-6。
2. **噪声球**：梯度方向噪声主导时（R4：ce 桶均值 0.25-0.45 振荡、残差相关来自数据顺序，非结构化信号），权重围绕解的稳态涨落幅度 **∝ lr**。hires 组噪声球半径 ≈ 主组 20×。`train.py` 注释自证 20× 的原始动机是"短微调内适应未见过 stride-2 特征层"——最终协议是 ImageNet 从头 256K，该动机只在早期成立，其代价（末程仍 20× 的噪声球）却被全程支付：128K 处 hires lr 1.02e-4，日程 49.5%，该组从未经历过低 lr 区。
3. **为什么恰好打在边界像素上**：512² stride-2 掩码画布的 logits 正由 hires 组参数产生。内部像素 logit 饱和（|logit|≫0，局部梯度≈0，对权重噪声免疫）；**边界像素 logit≈0 处于线性区，权重噪声 1:1 映射为 logit 抖动 → 0.5 阈值附近掩码翻转**。一次解释三个实测：边界像素是全模型最高方差预测；±1px 膨缩对称变差（零均值噪声，非偏置——若是偏置，膨胀或侵蚀该有一侧变好）；高 IoU 段崩塌（@0.75=0.247 / @0.9=0.018，亚像素边界移动直接击穿高阈值）。
4. **时间维度证据**：ce/mask/dice 自 24K 统计平坦（OLS t=-0.2~-0.7，R4 堵点 2）= segm/cls 信号在噪声球内耗尽；唯一仍降的 giou（-0.0020/8K，t=-3.2）在**主组**参数（bbox/cls 头不在 hires 子串匹配内）——低 lr 低噪声处学习仍在继续，与 lr 分区完全对齐。
5. **平均化实测**：EMA 0.9999（窗口 ~10K 步）比 raw 好 **+1.02 AP_s**（calibrated 报告配对复测，评估链协议闭环）——对噪声球做纯时间平均、零日程改动就白拿 1pt，直接证明残余缺口中"纯噪声"分量的存在与量级。

### a.2 噪声分解与本方案消掉的分量

边界抖动 = 标签侧噪声（0/1 目标在软边界上不可达 → **P3-a BAS-CL+ 已消**）+ 采样侧跨层抖动（8 层独立重掷采样点 → **BAS-CL+ 跨层坐标复用已消**）+ **优化器侧噪声（本方案）**。优化器侧再分三个子分量：

| 子分量 | 处置 | 组件 |
|---|---|---|
| (i) 噪声幅度 ∝ hires lr | 压缩：乘子日程 20→1 余弦合流 | A. GDA |
| (ii) 压缩后的残余涨落 | 加深平均：边界组 EMA 窗口 10K→20K，残余方差 ×0.5 | B. dEMA |
| (iii) 组间方向耦合（full-model clip 的共享单位向量被大梯度组带偏） | **只做免费遥测，不改动**（Phase-2 卡） | — |

不动损失形式、不动匹配、不动网络结构、不动主组日程。

### a.3 组件 A：GDA（分组差异化余弦）

主日程不动（`cosine_scheduler.py`：mult(s)=0.5(1+cos(π(s−2500)/253500))，256K 协议）。hires 乘子日程：

```
m(s) = 20                          s ≤ 40K（hold：适应期，保 20× 原始动机）
m(s) = 10.5 + 9.5·cos(π·(s−40K)/128K)   40K < s ≤ 168K（余弦合流）
m(s) = 1                           s > 168K（与主组同速，随主余弦到 0）
```

关键步点的算术（主组 lr = 1e-5×mult；hires = 主组×m）：

| step | 主组 lr | 本方案 hires lr | 基线（20× 常驻）hires lr | 噪声压缩比 |
|---|---|---|---|---|
| 40K | 9.47e-6 | 1.89e-4（m=20） | 1.89e-4 | 1×（hold） |
| 104K | 6.54e-6 | 6.87e-5（m=10.5） | 1.31e-4 | 1.9× |
| 128K | 5.08e-6 | 2.65e-5（m=5.2） | 1.02e-4 | **3.9×** |
| 168K | 2.69e-6 | 2.69e-6（m=1） | 5.38e-5 | **20×** |
| 256K | 0 | 0 | 0 | —（终点相同，路径不同） |

hold 段 40K（日程 15.6%）的理由：覆盖 ImageNet 从头协议的早期适应 + BAS-CL+ 的 2K λ_b ramp ×20 余量 + mCDN+ 噪声课程早期 + SCB+ 种子出生期；合流终点 168K（日程 65.6%）为可重校准锚点（见 e Stage 2）。**乘子→1 而非提前归零**：边界参数最后 1/3 仍以主组速度学习（P3-a 注入的新边界信号需要），只是不再付 20× 噪声税。

### a.4 组件 B：dEMA（边界组双速 EMA）

`model_ema.py` 现状：单一 decay 0.9999 全模型（半衰期 6.9K，均值滞后 9999 步）。改为**逐张量 decay 映射**：hires 组张量名 → 0.99995（半衰期 13.9K，窗口 10K→20K，平均估计的残余方差 ×0.5），其余不变。

依据：giou 仍在降（t=-3.2）→ **主组 EMA 不能加深**（会滞后真实学习）；而 hires 组 ce/mask/dice 自 24K 平坦 → 均值近平稳时纯噪声过程**加深平均零滞后代价**。global 0.9999 是两组需求的折中——本组件把它解开。EMA−raw=+1.02 证明该窗口量级的平均有效；窗口翻倍对"平稳+噪声"参数 strictly 更优。

## (c) 理论收益上界与依据

**锚 1（硬下界，实测）**：EMA−raw = **+1.02 AP_s** @128K（docs/2026-09-21-f1-128k-calibrated.md；raw=last.pt，EMA=best.pt，827 张量 diff=0 逐位证实口径）。零日程改动、纯平均即得 1pt——这是"优化器噪声分量"存在性的直接测量，也是平均/退火类方案收益的量纲锚。

**锚 2（对照臂自身期望，非本方案增量）**：R4 退火尾段估值 +1.0~1.25pt（三模型外推中位 +1.25 / 老家族锚 +0.83，区间 +0.1~1.9）。C0 吃掉这一份。

**门臂增量（C1−C0 @160K）：+0.25~0.6pt（中心 +0.4）**。分解算式：
- C0 尾段（128K→160K，160K horizon 重算）hires lr 从 2.0e-5 余弦到 0，尾段均值 ~1e-5（仍 ≥10× 主组 ~1e-6），且 EMA 半衰期 6.9K → 尾段 32K 仅 4.6 个半衰期、R4 明言"EMA 整合的是高 lr 时期权重、需 ≥2 个半衰期重新 settle"→ **C0 收下噪声租金的大头但不满额**；
- C1 把 hires 在 128K 处即刻合流到 ~1e-6（20× 静默）+ 边界组窗口翻倍（残余方差 ×0.5）。按 C0 已收份额 50-75% 估残余 0.25-0.5 × 1.02 ≈ **0.26-0.51pt**，加上 dEMA 对残余份额的减半效应取上沿 0.6。
- 硬上界诚实声明：纯噪声分量的可回收上限以 **+1.02 为锚**——本方案主张（0.25~0.6）+ C0 自身（1.0~1.25）合计落在"退火+平均"总租金区间（~1.0-1.9pt）之内；超出 +1.02 的任何部分只能经耦合（P4-c 的 q 稳定、P4-b 种子行稳定）产生，**本提案不为此计价**。

**最终 256K 协议（vs 均匀 20× 基线）：+0.5~1.0pt（中心 +0.7）**。依据：(i) 基线 hires lr 在 104K-200K 仍有 1.3e-4→3e-5 的噪声税区间，GDA 从 168K 起让边界参数与主组同速静默（噪声积分差，路径效应）；(ii) 下游协同——MAL q 目标与种子行在整个后半程读到稳定的边界特征生产者（二阶效应，方向为正）；(iii) 老 128K 家族实证：末 1/4（全组 lr≈0）尚有 +0.24pt——低噪声区不是零收益区，其长度的边际收益有实证形状。两项合计取 0.5~1.0。

**本方案不解决的**：标签侧噪声（P3-a 领地）、表示上限（P3-b：oracle 0.455 vs 0.264）、匹配分配方差（AIM 已收）。本方案只动"可得分条件已在但被噪声盖住/未被平均足额"的那一份。

## (d) 开销预算（算式）

**训练稳态**：
- GDA：每 optimizer step 一次标量 m(s) 计算（闭合公式）+ 对 hires 参数组 lr 的乘法循环。参数组数 = 可训练张量数（state_dict 827 张量口径，可训练 ~600-800，现 build_optimizer 本就一参数一组）；一次 CPU 循环 ≈ 0.05-0.1 ms。
- dEMA：现状每 step 已遍历 827 张量做 `mul_/add_`（`model_ema.py:87-92`）；双速版仅增一次 decay 字典查找 ≈ 0.02-0.05 ms。
- 合计 Δms/it ≈ **0.1-0.15 ms / 1440-1600 ms ≈ +0.01%**（报 +0.1% 为上限裕量）。红线 +5%，已占用的 +6~11% 不受影响。

**显存**：**+0 MB**。无新张量（shadow 已存在；decay 映射为 CPU 侧 name→float 字典 ~50 KB）。

**推理**：**0 ms**（日程与 EMA 均为训练期对象；eval 仍是 apply_shadow 单次换入，机制不变；红线 +10 ms）。

**门臂 GPU 时（实验室阶段一次性，非协议稳态开销）**：C0 = R4 收尾臂 15.4h（4 卡，全场公共对照线，沉没/共摊）；C1 = 15.4h；C2（可选归因臂）= 15.4h。可选 raw 双评 3 检查点 ×15 min ≈ +45 min/臂（wall clock +4.9%，仅门臂）。

**GPU 实现路径**：全部改动在优化器/EMA 更新循环（CPU 侧标量与既有 GPU 张量原地操作），无新 kernel、无 CPU↔GPU 传输——满足"GPU 优先"判据（改动本身不引入 GPU 工作）。

## (e) 正确性验证方案（对照臂设计是核心）

### Stage 0：CPU 单测（纸面可写，训练前）

1. **no-op 逐位回归**：三种退化配置（hires_lr_multiplier=1 / m≡20 / decay 映射全 0.9999）下，逐 step lr 与现行 `cosine_scheduler.py` 逐位一致；shadow 更新与现行 `ModelEMA` 在随机张量 AR 参照下逐位一致。承 P3-a #1 的 no-op 纪律。
2. m(s) 锚点与单调性：m(40K)=20、m(168K)=1、区间余弦单调；warmup 2500 段不受影响；EMA warmup 对两组同样生效。
3. 断点 round-trip：decay 映射随 shadow 一同存取；resume 后 lr/EMA 状态连续。

### Stage 0.5：冻结基座探针（~15 min GPU，训练前否决机制）

- **P0 噪声租金的 IoU 段定位**：sealed 128K 的 raw vs EMA 配对重评（评估链协议已有），按阈值分解 Δ@{0.5, 0.75, 0.9}。**预注册**：+1.02 租金的 ≥50% 集中在 @0.75/@0.9 段 → 边界噪声机制成立；若各阈值平坦 → 机制否决，**零训练成本止损**（本场降级，不跑训练臂）。
- **P1 权重空间噪声计**：hires 组 vs 主组 ‖shadow−raw‖₂/‖raw‖₂（纯张量统计，零推理）。**预注册**：hires 组归一化距离 ≥3× 主组（20× 噪声球的方向性证据；若否 → 机制重审）。

### Stage 1：核心归因臂（32K，两必跑 + 一可选）

| 臂 | 配置 | 唯一差异 |
|---|---|---|
| C0（对照） | sealed 128K → max_iter 160K，均匀余弦重算 horizon（128K 处主组 ~1e-6、hires ~2e-5→0），hires 保持 20×，EMA 0.9999 | = R4 收尾臂，与全场其它门共用 |
| C1（本方案） | 同 C0 主日程；hires 128K 处即刻合流 m: 20→1；边界组 dEMA 0.99995 | **hires lr 路径 + 边界组 EMA 视界，仅此两项** |
| C2（可选） | C1 减 dEMA | 隔离纯 GDA 贡献 |

**判读数字（预注册）**：
- 主门：AP_s(EMA@160K)：**C1−C0 ≥ +0.25pt 过**（机制确认）；≥ +0.50 强过；**< 0 杀**（退火租金归均匀日程，本场记负结果关闭）；[0, 0.25) 弱过——组件保留进最终协议但降优先级。
- 次级门（方差机制必须动，即便主门平）：(i) 噪声计：C1 的 hires 组 ‖shadow−raw‖₂@160K **≤ 0.5×C0**；(ii) eval 间 AP_s 抖动（末 3 个 eval 的 std）：C1 < C0；(iii) 边界翻转率（固定 200 图子集，末 16K 两 checkpoint 间边界带像素预测翻转率）：**C1 ≤ 0.7×C0**。
- **dEMA 已知偏置（预注册声明）**：32K 臂只覆盖 0.99995 的 2.3 个半衰期，读数系统性低估 dEMA；若 C2 可用且 C1−C0 ≈ C2−C0 → 门内 dEMA 无可测贡献，**dEMA 去留由最终协议的噪声计遥测决定**（不在门内处刑）。R4 关于 144K 臂太短的警告同理适用，故门臂取 32K。
- **归因逻辑**：C0 吃掉全部"退火+更多步数"效应（R4 +1.0~1.25）；C1−C0 隔离"hires 噪声专属份额"——主日程/数据/步数/随机性其余全部相同。其它场的短训臂一律以 C0 为公共对照，杜绝"退火收益搭车"（与 P4-c 反搭车判读树同构；反向亦然：本场不把 BAS-CL+ 等的收益记在自己账上）。

### Stage 2：最终协议集成（ImageNet 从头 256K）

- 落地形态：m(s)=20 (s≤40K) → 余弦 20→1 over [40K, 168K] → 1；边界组 dEMA 0.99995；warmup/主日程/其余不动。
- **锚点重校准**：BAS-CL+ 门数据落地后，用免费遥测（每 log_period 记录各组 preclip 范数份额与逐层 mask 损失散度）复核 hold 段：规则 = hold ≥ 新损失 ramp 结束 + 32K；T_m 相应平移。
- 最终验收：256K 终点 AP_s + 240K-256K 噪声计轨迹，对照 = 同协议均匀 20× 臂（若预算不允许全程双臂，退而用 C0/C1 门臂 + 噪声计轨迹外推，并在判读规则写入 ±0.8pt 不确定度承 R4）。

### 失败判读树（预注册）

1. C1 < C0 − 0.15：提前合流有害 → 回退锚点（hold 64K / T_m 200K）重跑一次；仍负 → 场关闭。
2. C1−C0 ∈ [0, 0.25) 且噪声计动：机制对但量小 → 仅 GDA 进最终协议，dEMA 挂遥测。
3. P0 各阈值平坦：机制否决，止损于零训练成本。
4. P1 hires 组距离 < 3× 主组：噪声球假设动摇 → 重审 (a) 链第 2 步后再决定是否跑臂。

### Phase-2 卡与明确拒绝

- 卡 1：分组梯度裁剪（解 full-model clip 的组间方向耦合）——先积累免费遥测证据（各组 preclip 范数份额），有数字再议。
- 卡 2：dEMA 深度扫描 {0.99995, 0.99998}——只在最终协议（避免门臂半衰期偏置）。
- **明确拒绝：层间一致性正则**。(i) 加正则项 = 改动损失形式，越本场章程；(ii) R4 实证 7 个 aux 层损失为**相关噪声**（数据顺序效应）——一致性项把 9 个监督点的噪声耦合进同一梯度，是放大不是消除；(iii) 唯一已证实的层间抖动源（逐层独立重掷采样点）已被 BAS-CL+ 的跨层坐标复用免费消除；(iv) 新风险类（ABL 去 detach 失稳 −4.5 mIoU 的教训）。零成本替代：逐层 mask 损失散度入遥测。
- **明确拒绝：EMA-as-teacher 自蒸馏**（改损失形式；与 P3-a 软标签功能重叠）。

## (f) 与其它场叠加兼容性

1. **正交性**：本方案只动优化器日程与平均器，与全部损失/数据/结构/导出侧场次（P3-a/b、P4-a/b/c/d）无共享代码路径。任何组合臂中 GDA-dEMA 作为一个独立开关位；全场共用 C0 锚，各场增量在各自臂上读，结构上不可能双计。
2. **预算**：BAS-CL+ 0.2-0.6% + MAL-CP+ 3-6% + SCB+ ~1% + mCDN+ 2-4% + 本场 ~0.01% = **6.3-11.7% < 20%**。本方案是"免费叠加层"，不挤压任何降档讨论（P4-c/P4-a 预登记的降档阶梯不受影响）。
3. **耦合方向清单**（全部为正或零）：q 目标方差↓（P4-c）、种子行输出稳定↑（P4-b）、DN 边界噪声注入↓（P4-a）、重打分特征噪声↓（P4-d，不计价）、BAS-CL+ 新边界信号的静默巩固区↑（P3-a）。唯一需管理的依赖：hold/T_m 锚点随 BAS-CL+ 门数据重校准（已入 Stage 2 规则）。
4. **P3-b（二阶段表示类）前瞻**：DCT/频域头若胜出，新增参数默认落主组（命名无 hires 前缀）；若实现选择挂 stride-2 头下，需一行 config 重新声明分组归属——预登记，防静默错组。
5. **与最终协议**：ImageNet 从头 256K 使 20× 的"短微调适应"原始理由进一步弱化为纯早期动机——hold 段设计正是对该理由的显式保留与显式退役；从头定义日程无续训断点问题。
