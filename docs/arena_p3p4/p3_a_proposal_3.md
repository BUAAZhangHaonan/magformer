# P3-a 提案 #3：双锚点边界监督（GT 边界带采样 + 距离加权 BCE + 窗口确定性 Dice）

提案人 #3（独立，未见其他提案）｜日期 2026-09-21｜场：P3-a 掩码边界监督

**一句话**：把 M2F 逐点损失里"锚在预测边界上的不确定性采样"扩成"预测锚（精修）+ GT 边界带锚（搬移）"的双锚点采样，并给 BCE 加 GT 距离衰减权重、给小目标加 bbox 窗口上的确定性软 Dice——全部纯 loss 侧，推理 +0ms。

---

## 0. 诊断：为什么现有采样对边界"无约束"（代码级根因）

真实实现核查（`source/magformer/models/common/criterion.py`）：

- `_loss_masks`（criterion.py:423-502）对每个 matched mask 独立采样 12544 点：`get_uncertain_point_coords_with_randomness`（criterion.py:89-112）先均匀撒 12544×3=37632 点，按**预测 logits** 的 `-|logit|` 不确定性 top-k 出 9408 点（75%），再补 3136 纯均匀点（25%）；GT 标签由 `point_sample(target_masks, coords)`（criterion.py:77-82）从**1024² 输入分辨率的二值 GT** 双线性取得。
- 旧的小目标重采样钩子 `small_object_sample_threshold`（criterion.py:455-462 + `_resample_small_object_points` criterion.py:504-582）是**逐目标 Python 循环 + `mask.nonzero()`**，已退役（BRIEF §6-P10"键已退役未重建"）；它采的是掩码内部+bbox 点，也从不落在边界上。

由此，边界无约束是三个机制的叠加，每一个都能从我们的数字里读出来：

1. **密度**：10px 目标（1024 尺度）在 512 画布上 ≈5px 直径、边界带（r=1px）≈30px²，占画布 30/262144≈1.1e-4。均匀分（含 75% 不确定性份额的候选池也是均匀撒的）期望落带 ≈12544×1.1e-4≈1.4 点；实测每次迭代 4-47 点且不专门在边界（BRIEF §1、SYNTHESIS P3）。更致命的是**软标签点数**：GT 双线性过渡带仅 ~1px@1024，落在 0.1<label<0.9 的点期望 <1 个/迭代——BCE 从未见过"边界在哪"的连续标签，只见过错位位置上的硬 0/1。
2. **锚点错位**：重要性采样锚在**预测**边界。它能在边界大致正确时精修，不能把边界**搬**到 GT 上——而我们的失败签名恰是搬移类：±1px 膨胀/侵蚀双双大幅变差（<64: 0.652→0.476/0.256，r2_maskiou §D4），segm−bbox 差 @0.5 +2.8 → @0.85 −11.6pt 反转（r2 §D1），即"外接框对、边界抖动错位"。预测锚还受 hires 组 20× lr 噪声（BRIEF §3）污染——不确定性采样在追一个抖动的靶。
3. **估计量方差**：per-mask Dice 的分母是采样到的 GT 前景点数（小 mask 只有 4-47 个），单点翻转 = 相对损失 1/20 量级的跳变；边界位置的梯度信噪比被采样噪声封顶。高 IoU 段崩塌（AP@0.75=0.2465 / @0.9=0.0181，r2 §D1；链可达 frac≥0.75=0.817，r2 §D7）正是"永远学不到亚 cell 边界放置"的结果。

**为什么这是根因而非症状**：CF1 反事实（把 matched 掩码换成 GT 穿链版本，AP_s 0.2925→0.5636，r2 §D5）证明检测集合、分数、渲染链全部无辜，缺口在 head 画的内容；F 段形态学探针证明后处理不可救。唯一还没被检验的环节就是监督几何本身。

## (a) 机制因果链

三件新事，各自对准一个根因，乘性互补：

**A1. GT 边界带采样（子轴：点采样策略）**
把每个 matched mask 的 12544 点预算重组为：**75% 预测不确定性点（不变）+ 12.5% GT 边界带点（新）+ 12.5% 均匀点（塌缩保险）**。边界带定义在 GT 上：`band = dilate(GT, r) \ erode(GT, r)`，r 尺度自适应 `r = max(1, round(s/16))`（s 为该目标在对应网格上的短边；防 Boundary IoU 固定带宽失真教训 [23][4]）。实现走 **bbox+30% margin 窗口 + 窗口内 maxpool 膨胀/侵蚀 + Gumbel top-k 采样**——直接把匹配器 AIM 胜出方案已验证的向量化窗口机制（matcher.py:276-354 `_aim_small_gt_costs`，margin 30%/min 3px/R∈[8,64]/chunk 16 全部现成）搬进损失端。
因果：监督质量从"锚在抖动预测上的 1.4 个期望带点"变成"每 mask 1568 个锚在 GT 边界上的确定带点"（10px 目标带密度提升 **30-300×**；调研候选 1 的保守口径是 5-10×）。带内点经 1024 GT 双线性取标签，其中落在 ~1px 过渡带的分数显著非零——**这是 BCE 唯一能学到边界连续位置信息的通道**。

**A2. 距离加权 BCE（子轴：损失形式）**
逐点权重 `w = 1 + λ·exp(-DT/τ)`（DT 为到 GT 边界的 chamfer 距离，窗口内 3-4 次 maxpool 迭代近似，GPU 侧；w 逐 mask 归一到均值 1，保持总损失尺度）。Kervadec 边界损失的点采样化 [1]：梯度幅值 ∝ 到边界距离。
因果：采样把梯度**质量**搬进带，权重决定带内的**形状**——两者正交；单独用任一个都被反面教训覆盖（Kervadec 单独用塌成空掩码、必须配区域项+α ramp [1]；纯采样不加权则带内梯度仍是平的）。

**A3. 小目标窗口确定性 Dice（子轴：损失形式，新增项 `loss_bdice`）**
对 area<4096px²@1024 的 matched mask（覆盖 COCO-small 全部三个子桶：<64、64-256、256-1k），在 bbox+30% 窗口的 R×R 确定性网格上算带梯度的软 Dice，权重 `bdice_weight`。这把 AIM 在**匹配代价**里已被验证的"确定性、尺度无关、零方差"统计（margin 0.13σ→2.43σ，matcher.py:193-199 注释）搬进**损失**，对准根因 3：Dice 梯度不再被 4-47 个前景点的采样方差污染。
因果：Dice 是把掩码整体对齐的力（分母归一目标大小），窗口化后它对小目标的边界位置变得敏感且稳定——正好补 BCE 软标签学到的"局部正确"之外的"整体对齐"。

**合成因果链**：带采样（把监督搬到真边界）→ 距离权重（带内梯度成形）→ 窗口 Dice（方差封顶解除）→ matched IoU 分布右移（p50 0.635/0.674/0.737 → 向链可达 0.817+ 靠）→ 高 IoU 段坍缩恢复（AP@0.75 0.2465→、AP@0.9 0.0181→）→ CF1 缺口兑现。全程不动匹配器、不动架构、不动推理。

**超出所引文献的针对性论证**（为什么在我们的数字结构下更好）：

1. **重要性采样已在跑且仍不够**——多数 M2F 部署（含调研 [1][4][21] 的医学/植物场景）没有"不确定性采样锚在预测上"这一层，我们证明了即便 M2F 原生 importance sampling 开着（config `importance_sample_ratio: 0.75`），预测锚的系统性偏差仍使边界监督缺位。文献没有"pred-锚 vs GT-锚"的分析，这是我们从 ±1px 探针 + segm/bbox 交叉曲线推出的本仓库特有诊断。
2. **M2F 的 per-mask 采样预算使带采样近乎免费**——每个 matched mask 独立享有全画布 12544 点，小 mask 的均匀点 99.6% 落在无关背景上；把它们换成带点，全局覆盖率零损失。医学文献的全局损失没有这个结构可用。
3. **缺口的质量分布决定收益分布**：CF1 桶内增益是 <64 +2.7 / 64-256 +18.7 / 256-1k +33.2（r2 §D5），相对坍缩度 64-256（61.7%）≈<64（62.0%）（r2 §D1）——边界监督的收益主体在中小学桶而不只是极小桶。尺度自适应 r(s)+AIM 窗口天然覆盖整个 <1024px² 区间，一套机制吃全段；RefineMask/DCT-Mask 类"收益偏大目标、小目标 +0.5-1.5"的头侧方案（调研反面教训 1 [11][12]）结构上做不到。
4. **确定性窗口 Dice 是我们自己的实验室数字背书的**，不是文献移植：同一统计在匹配代价里已把小 GT 列的 margin 从 0.13σ 提到 2.43σ。
5. **balanced_ce 交互的先行修复**：现有 `balanced_ce` 的 fg_ratio 从采样标签估计（criterion.py:65-74），带采样会让小 mask 的 fg_ratio 从 ~0.004 升到 ~0.3，fg 上权从 99× 塌到 ~2×。本提案改为**从 GT 面积直接计算** fg_ratio = area/(H·W)（确定性、与采样器解耦）——这本身是对现状的一处正确性修复，逐点权重方案不依赖它也能跑。

## (b) 与二分匹配 / set-prediction 的兼容性

- **匹配器零改动**：HungarianMatcher 的代价（均匀 12544 点 BCE+Dice + AIM 小 GT 列，matcher.py:356-453）一行不动；AIM 保持原样。损失项在 `indices` 计算之后作用于 matched 对，set-to-set 结构、o2o 语义、DN 隔离全部不变。
- **损失-代价一致性**：M2F 范式本就允许损失项多于代价项（上游 CE 只进损失、MaskDINO 的 L1/GIoU 可只进损失）。新增 `loss_bdice` 与逐点权重遵循同一惯例：每个监督层的 matcher 独立匹配（criterion.py:259），随后 per-pair 计算。
- **无循环性风险**：带/权重/窗口全部只依赖 GT（`torch.no_grad()` 块内构建，与现状同，criterion.py:445），不依赖预测——不存在"损失改变匹配、匹配改变损失"的新回路；唯一的反馈是良性的（更好的掩码 → 下一步匹配的 mask 代价列更可信），且 AIM 的 2.43σ margin 已提供归属稳定性余量。
- **逐层一致**：`_loss_masks` 被 8 个监督层（7 aux@256² + final@512²）复用（criterion.py:250-270 循环）；带/DT/窗口坐标只依赖 GT，**每次迭代构建一次、8 层共享**，归一化坐标在任意 pred 网格上语义一致（`point_sample` 用 [-1,1] 网格，arch.py `_prepare_targets`:1461-1481 证实 GT 掩码保持输入分辨率、无下采样路径）。
- **DN 支路**：`_compute_dn_loss`（criterion.py:584-726）v1 保持纯均匀采样不变（去噪 query 是辅助监督，先不引入新自由度）；v2 可选扩展。

## (c) 理论收益上界与依据

**机制天花板**：CF1 = +27.1pt（AP_s 0.2925→0.5636，r2 §D5）。其中本机制不可及的部分：链量化 4.0pt（CF2−CF1，P3-b 域）与 <64 检测集合（16.5pt 是 E3−CF2，含未检出目标，P4 域）。边界监督的可及域 = matched 掩码的内容质量。

**边界项在 27.1 中的占比论证**：AP@0.5 在 CF1 下几乎不动（0.6036→0.6035）→ 缺口全部住在高 IoU 段；高 IoU 段的签名（±1px 双向变差、segm/bbox @0.65 反转）是边界抖动/错位而非内部空洞 → **机制可及上界取 27.1pt 的主体（≈20-25pt）**。

**兑现率锚**（均注出处）：
- Kervadec 距离图边界损失，ISLES 小病灶 DSC 0.511→0.659（+14.8pt）、HD95 减半 [调研A-1]；
- 植物 M2F 仅加一个边界加权损失，小目标 PQ_weed 49.17→51.16（+2.0pt，推理零开销）[调研A-21]——机制弱于本提案（只有加权、无采样搬移、无确定性 Dice）；
- PointSup ~10 点/目标 ≈ 全监督 94-98% [调研A-8]——点的**位置**而非数量是瓶颈，与本诊断同向；
- 本提案独有的第 4 锚：AIM 窗口统计在匹配端的 2.43σ（自有实验室）。

**申报值**：matched IoU p50 若右移 +0.05-0.08（<64: 0.635→0.69-0.72，向链 0.817 靠），按 CF1 敏感度（全缺口↔IoU p50 差 ~0.15-0.18）线性折算 ≈ **+6-10pt AP_s（rescore 口径）为乐观上界，可交付预期 +4-8pt**；短训门（16K）底线 **净 +1.5pt vs 同步长对照臂**（SYNTHESIS Phase D 判据），并要求 AP_s@0.75 0.2465→≥0.28、AP_s@0.9 0.0181→≥0.05。附带正效应：掩码变实 → maskness 上升 → matched 分数结构改善（score p50 0.613/0.723/0.821，r2 §D2），与 P4-c/P4-d 正耦合（判读时用 rescore 固定检测集合剥离该效应）。

**明确不申报**：<64 检测集合空洞（16.5pt）、渲染链量化（4.0pt）、<32px² 信息论不可画段（23.2pt，P3-b/远期）。

## (d) 开销预算（估算算式）

规模参数（出处：SYNTHESIS/r2）：per-GPU batch=1；matched mask N≤200，其中 area<4096px² 窗口目标 N_w≈12.7/图（train 均值，p90=41）；窗口 R≤64（matcher.py:311 clamp）。

**训练 ms/it**（现 1.44-1.60s，红线 +20% ≈ +288-320ms）：
- 带构造+chamfer DT（每迭代一次，8 层共享）：N_w×R²≤41×4096≈168K px ×（2 次 maxpool × 3 迭代 + gather）≈ 2-5ms；
- Gumbel top-k 带采样：在 N×窗口候选 (~200×平均500) ≈ 10⁵ 元素上 sort → 1-3ms；
- 窗口 Dice 逐层 grid_sample：8 层 × N_w×R² = 8×168K ≈ 1.3M 点 ≈ 1-2ms；
- 逐点权重乘法融入现有 BCE（同 tensor 形状）：<1ms；
- kernel launch 与 Python 胶水 ~40-60 个小核 ×10-20μs ≈ 1ms。
- **合计 ≈ +5-12ms 计算，墙钟目标 ≤ +30-50ms ≈ +2-3.5%**，红线裕度 >6×。逐点采样总量不变（12544 重组而非追加），现有 point_sample 开销零增量。

**显存 MB/卡**（红线 24GB）：
新增持久张量 = 窗口坐标/带/DT（N_w×R²×4B×3 ≈ 2MB）+ 逐层 bdice 激活（8×N_w×R²×4B×2 ≈ 4MB）+ 采样坐标尺寸不变。
公式：`8·N_w·R²·4B·k, k≈5 → 8×41×4096×20B ≈ 27MB`。**合计 ≤ +50-100MB**。

**推理 ms**：**+0.000**。损失侧改动不进任何导出路径（`_inference_raw` arch.py:1483-1580、`gpu_postprocess.py`、CUDA graph 均不触碰）；架构、query 数、渲染链不变。判分规则"推理近零开销同分优先"下这是本提案的结构性优势。

**GPU 侧实现承诺**：带/DT/采样/窗口 Dice 全部 GPU 张量算子（maxpool、sort、grid_sample、gather），无 scipy EDT、无 per-object Python 循环——旧 `_resample_small_object_points` 的退役原因（CPU nonzero 循环 + 跨设备同步）被显式规避。

## (e) 正确性验证方案

**E1. 单测（CPU，无 GPU）**：
- 带掩码 vs scipy 距离变换参考（合成圆/矩形 r=3/5/10px@1024），r(s) 尺度自适应表；
- Gumbel top-k 采样分布 vs 带面积（卡方）；
- 逐点权重均值归一（E[w]=1/mask）与总损失尺度不变性（新旧采样器下大 mask 损失差 <1e-4）；
- fg_ratio 改 GT 面积计算后与旧口径在纯均匀采样下等价（回归测试）；
- 边界带坐标归一化在 256/512 网格上一致（aux vs final）。

**E2. 冻结基座探针（CPU，复用 r2 的 dets.json + val GT）**：
对 val 的 matched 对统计：现行采样器 vs 提案采样器的 (i) 落带点数（<64 桶 p50：~4-47 → ≥1500），(ii) 软标签点占比（0.1<label<0.9：~0.1% → ≥5%），(iii) 窗口 Dice 与全分辨率 Dice 的偏差（<0.01）。纯推算，不改训练。

**E3. ≤16K 短训门（4 卡，从封存 F1 128K resume）**，双臂：
- 臂 A（对照）：损失不变 16K 余弦收尾 = R4 Phase B 对照线（一卡两用，省一次对照）；
- 臂 B：A1+A2+A3 全开，λ/bdice_weight 走 2K 线性 ramp（Kervadec 塌缩教训 [调研A-4.3]）。
判读数字（预注册）：

| 指标 | 基线 | 门（16K 净 vs 臂 A） |
|---|---|---|
| matched IoU p50 <64 / 64-256 | 0.635 / 0.674 | ≥0.68 / ≥0.71（r2 §D2 口径） |
| AP_s@0.75（segm small） | 0.2465 | ≥0.28 |
| AP_s@0.9 | 0.0181 | ≥0.05 |
| AP_s [.5:.95] rescore | 0.2925 | **净 ≥+1.5pt**（Phase D 线） |
| 塌缩哨兵 | — | AP@0.5 降幅 <0.5pt；空掩码率 ±0.2% |
| 开销哨兵 | 1.44-1.60 s/it | Δms/it <+8%；显存 Δ<0.5GB |

子轴归因（预算允许时加 8K 诊断臂）：B1=仅 A1（采样）、B2=仅 A2+A3（损失形式）——三 config 开关独立（见 §接入点），直接回答场简报"两个子轴可组合"的要求。
