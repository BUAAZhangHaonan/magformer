## 1. (a) 机制因果链

### 1.1 缺口的三重成因分解（38.1% never-hit）

| 成因 | 证据 | 对缺口的贡献判断 |
|---|---|---|
| **出生先验**（无 query 生在小目标处） | R2b（09-14 小模型）：仅改变出生机制——probe 定位 76.3% 小 GT + 64 种子 query 出生在峰值处——覆盖率 61.9%→92.1%（IoU≥0.5 拥有小 GT），其余全部不动 | **主导**。单一变量 causal 隔离，覆盖摆幅 +30.2pt |
| **注意力覆盖/持有**（获得后丢失） | R3 D4：topk 门控只被第 8 层消费；前 7 层 key 是 stride 32/16/8 粗网格 + 硬 0.5 阈值；<32px 目标在 stride-8 = 1 cell、stride-16/32 亚 cell；门控是稳定器不是发现器 | **次要**。决定种子能否"持有"到末层并抬 q 上限；P6 估值 +1~3pt（低置信） |
| **供给**（每步正样本稀缺） | R5/P4-c：有效 batch=4 每步可见 <64 GT 期望 0.85 个；小目标损失点份额 0.1-0.4% | **第三**。由 P4-c C2（分层贴入）覆盖，已裁决，本提案不重讼 |

### 1.2 本提案攻击什么、为什么

**攻击出生先验（主）+ 持有（次），供给与分数走捆绑件。**

排序依据：
1. **出生是唯一有因果隔离实验的成因**。R2b 在小模型上只动出生就拿到 92.1% 覆盖——这是全场唯一被实验证明"可解"的杠杆。反面证据同样指向出生：R3 D4 证明门控无法把无信号 query 引向小目标（top-64 落在它误指向的大目标上）——**先有指向，门控才有意义**；Semi-DETR 的"o2m 先、o2o 后"与 PanSR/Salience-DETR 对"query 选点偏大→小目标漏检"的点名（调研 B §4-5）同序。
2. **R2b 的失败不是覆盖失败，是分数失败**（cls 卡 0.22-0.29）——这正是纯覆盖方案没有资格的原因。失败机理三条：(i) matched query 的 focal 目标=1 而实际掩码质量 q≈0.6，模型学会对冲（MAL-CP+ C1 直击）；(ii) 正样本事件稀少（0.85/步，C2 贴入直击）；(iii) ×9 深监督逐层重掷归属（种子的槽位恒定性本身即缓解——同一 slot 逐层持有同一目标，见 §2.3）。三缺一分数都不成型，故本提案把 C1 列为**同 commit 硬依赖**而非可选。
3. **持有的最小修复不是全层门控**。全层 topk 门控改 200 query × 7 层的注意力统计，置信度低（R3 保守 +1~3、纯代码推算）；本提案只对 64 个种子行施加 probe-fg 先验（它们本就该只看小目标前景），是外科手术式的持有修复，成本近零。全层门控留作 Phase-2 卡（§5.4）。

### 1.3 因果链全文

```
probe 头（stride-4，focal+dice 直接监督小 GT 并集）
   └─> 峰值 topk（3×3 局部极大值 = 空间去重 + 确定性 tie-break）
         └─> 64 个种子 slot 的 content/pos 从 mask_features 峰值 cell 投影出生
               ├─ 出生：query 生在小目标上 → 掩码证据从第 0 层就聚焦（R2b: 61.9→92.1）
               ├─ 持有：种子行 0-5 层 cross-attn 被 probe-fg 先验约束（不再 attend-everywhere 稀释）
               │    └─ 末层照常享受 256² topk 门控（现状不动）
               ├─ 供给：C2 贴入使每步小 GT 可见数 ↑（P4-c 件，同 commit）
               └─ 分数：C1 使 matched 种子的 cls 目标 = AIM 同源 soft-Dice q
                    └─ 分数脱离 0.22-0.29 → AR_s@10 脱离 0.0 → 覆盖变现
```

每一环都有独立仪表（§5），任何一环断掉有对应的失败判读与止损（§5.5）。

## 2. (b) 与二分匹配 / set-prediction 的兼容性

### 2.1 种子的匹配语义：普通 query，无特殊身份

- 种子占据 200 个 slot 的**后 64 行（136-199）**，与 136 个可学习 query 一起进入**同一个 o2o 匈牙利匹配**。没有任何第二匹配器、辅助分配或分组——这是与 CDN/Group DETR（需要隔离结构）的本质区别：**种子只需要出生机制，不需要匹配语义改动**。
- 全程无 GT 身份注入：种子消费的是 probe **输出**（模型自身的前向），不是 GT 本身；GT 只进 probe 的辅助损失（与深监督同类，属常规辅助监督）。这保证了：(i) set prediction 的置换等价性不变——输出仍是一个 200 元素可交换集合，query 内容输入条件化有 DINO/Mask DINO 的 mixed query selection 先例；(ii) 推理端零泄漏。
- **与 CDN 的关键对比**：CDN 去噪 query 携带 GT、推理即丢弃——它的存在性收益**不随导出存活**（训练期供给，推理期消失）；种子在推理端持续出生（probe 推理期运行，§4.2），存在性收益直接落在导出检测集上。这是 38.1% 缺口（推理端指标）选择出生机制而非去噪机制的裁决性理由。

### 2.2 与 AIM 的交互：正反馈，非竞争

- AIM 的确定性 soft-Dice 列要产生 2.43σ 分离，前提是**存在掩码落进小 GT 窗口的 query**；可学习 query 出生偏远时列间无差异（近似均匀），AIM 花钱修的区分度无处兑现。种子恰好提供高区分度列——**AIM 的 lab margin 是在随机 query 上测的，种子抬它的可实现上限**。
- 匹配结果与 C1 的 q 同源同度量：matcher 用 AIM dice 列选中某 (query, GT) 对，C1 用同一列的值做该 matched query 的 cls 目标——"匹配选的就是它，分数学的就是它"（P4-c VERDICT 对 #3 的裁决语言）。种子不引入第二度量，零漂移。
- 未匹配种子与所有未匹配 query 同待遇（eos_coef 0.1），不设特殊通道——不给分数通胀留后门（P4-c 反搭车判读树 G2 直接复用）。

### 2.3 与 ×9 深监督的交互

每次预测头独立匹配。种子 slot 恒定（同一行从第 0 层到第 7 层持有同一空间先验），其逐层匹配的稳定性高于"内容漂移的可学习 query"——对 R3 D5 指出的"归属反复重掷"是结构性缓解，尤其配合已落地的 AIM 去 16 帽（BRIEFS §0：全覆盖已修复验证）。

### 2.4 去重/毒化检查（DDQ 反面教训）

- 64 种子来自 3×3 局部极大值峰值 = stride-4 网格上的空间 NMS（输入尺度 ≥12px 间隔）；过度密集风险受控。
- R3 D3 已证当前重复不构成稀释（每小 GT 1.30 det、oracle 去重 −0.25pt）；种子增密后以同一仪表复测（§5.3 G2-dup），不引入去重机制除非数字翻案。

## 3. (c) 理论收益上界与依据

### 3.1 占据 oracle 阶梯的哪一段

R3 D6 阶梯：召回段 +6.7（现实分数 0.45）~ +37.5（oracle 分数 0.99）；掩码内容段（+27.1）与排序段（≤2）不属本场。**本提案攻击召回段的存在性子集，其变现由捆绑的 C1 解锁。**

### 3.2 按 R2b 覆盖率外推

- 覆盖缺口闭合率（小模型实测）：(92.1−61.9)/(100−61.9) = **79.3%**。
- 外推到 F1 的 3634 never-hit 小 GT：物理上界 ≈ 37.5 × 0.793 ≈ **+29.7pt**（oracle 分数下）；现实分数（0.45）下 ≈ 6.7 × 0.793 ≈ **+5.3pt**。
- **诚实折扣**：R2b 是小模型数字，F1 尺度须过 Gate A/B 再确认（§5）；probe 召回 76.3% 是出生天花板（余下 23.7% 靠可学习 query 与 probe 改进 knob，§5.5）。

### 3.3 与 MAL-CP+ 捆绑后的联合落带

- 变现率结构：现状 6.7/37.5 = 17.9%（分数流门控，AR_s@10=0）。C1 的预注册门是小桶 TP 分数中位 0.29→≥0.40（强 ≥0.50）——按 R3 的 PR 形状（小桶 precision≥0.9 保持到 recall 0.62 后跳水），分数到位后注入检测可进图内前列，变现率向 37.5 端移动。
- 联合主张（32-48K 激活臂，对 R4 退火对照线）：**+6~12pt AP_s**（存在性 79.3% 闭合 × 分数成熟度 30-50% 变现的区间积分）；其中**本提案（种子+先验）的边际**在 16K 门预注册 **≥+1.0pt（强 ≥+2.0pt）**，由 2×2+1 消融归因（§5.3），不与 P4-c 的 +3~6 重复记账。

依据出处：oracle 阶梯与 AR/覆盖率 = R3 report D1/D6（112K rescore 口径）；79.3% 闭合率 = R2b（09-14 小模型，场简报 §5）；文献同构锚 = Dome-DETR 密度引导 query 初始化 AI-TOD-v2 +3.3 AP、QueryDet +2.0 AP-small（调研 B §2.2/§2.3）；HGSQ 96 FPS 证热图头轻量（单作者新作，仅作旁证不进算式——调研 B §4-8 证据分层）。

## 4. (d) 开销预算（给算式）

### 4.1 训练 ms/it（基线 1.44-1.60s，红线 +20% = +288-320ms）

| 项 | 算式 | 值 |
|---|---|---|
| probe 前向+反向 | MACs ≈ 256²×(256×128 + 128×9 + 128×2) ≈ 2.24 G-MACs/图 ≈ 4.5 GFLOP；×B4 ×3（fwd+bwd）≈ 54 GFLOP/it；TF32 有效 40 TFLOP/s | ≈ 1.4 ms |
| probe 辅助损失 | 逐图 GT 并集 any+maxpool ≈ 100M bool ops（B4） | ≤1 ms（若 C2 贴入使 GT 数上涨超 2ms 则向量化，预登记 §7-5） |
| 峰值检测+topk+gather+2×Linear | maxpool 3×3 on 4×65536；topk 64/65536；gather 64×256；Linear 256×256 ×2 on 4×64 tokens | <0.5 ms |
| 种子先验扩层（0-5 层） | 3 个 level 各一次 (B,1,256,256)→(32²/64²/128²) 双线性 + OR 进 64 行 bool 掩码：32×64×16384 ≈ 33M bool/层 ×6 | <1 ms |
| C1 q 目标 | 搭 matcher AIM dice 列便车（matched 对的列值已算出），大 GT 2048 点补算属 P4-c 账单 | **0（本场侧）** |
| 解码器本体 | Q 总数 200 不变（种子替换而非增补），self/cross-attn、mask heads 逐位不变 | 0 |
| **合计** | | **+3~5 ms/it（+0.2~0.35%）** |

**叠加审计**：P4-c +3~6%（+43~96ms，VERDICT 采 #3 诚实口径）+ 本场 +0.2~0.35% ⇒ **+3.3~6.5% ≤ 20%**，余量 >3 倍。若 P4-a（o2m +10~18%）也胜出：预登记降档（K=3、max_paste 8 → o2m ~+8-12%）⇒ 三场合计 ~+12-18.5%，仍在线内。

### 4.2 推理 ms（红线 +10ms）

- probe 前向（无反向）：4.5 GFLOP ≈ 0.2-0.5ms（骨干 ~200+ GFLOP @1024² 的 ~2%）+ 峰值/topk/gather/投影 ≈ 0.3ms ⇒ **+0.5~2 ms**，串行依赖（种子在解码前出生，必须等 probe）。
- 其余全部零：slot 数、掩码头、topk 导出、CUDA graph 形状均不变。
- **训练期专用规避方案**（红线要求的预案）：本方案的 probe 推理端必须保留（存在性收益的载体），故给三级降档而非规避：(i) probe conv 走 fp16（减半）；(ii) probe 输入降到 stride-8 128²（FLOPs ÷4，Gate A 复测召回 ≥70% 才可启用）；(iii) 1×1 首卷积与像素解码器 stride-4 投影融合。实测门：probe+种子块墙钟 ≤3ms（单测 U9），超则逐级降档。

### 4.3 显存（红线 ≤24GB/卡）

- 参数：probe ≈ 35K（~0.14MB）+ 种子投影 2×256×256 ≈ 131K——可忽略。
- 激活：probe 中间量 65536 cell×128ch×4B ≈ 33.5MB/张/图 × ~4 张 × B4 ≈ 537MB 前向，含反向状态 ≈ 0.8-1.2GB；先验 bool 掩码 3 level × 33MB 瞬态。**合计 +0.7~1.2GB**；若基座逼近 24GB，probe 可 hidden 128→96 或分段 checkpoint（改动一行）。

## 5. (e) 正确性验证方案

### 5.1 单测（训练前，9 项）

1. **种子确定性**：同输入两次前向 → 种子索引逐位相同（tie-break 缓存，`_seed_tiebreak`）；eval 确定性保持。
2. **形状静态**：种子块恒 64 行、可学习块 136 行；DDP 静态图与 CUDA graph 捕获兼容。
3. **先验作用域**：probe-fg OR 只落在行 [136,200)；fixture 上可学习行 attn mask 逐位不变。
4. **无 GT 泄漏**：种子路径只消费 probe logits（静态审查 + 置零 targets 不改前向输出只改损失的动态测试）。
5. **matcher 中立**：种子开/关，同一 (pred,GT) 对的 AIM 列逐位相同（matcher 只见输出）。
6. **mal-off 回归**：C1 关闭时输出与基线 config 逐位一致（继承 P4-c 单测，防集成漂移）。
7. **CUDA graph**：probe 路径推理图可捕获——tie-break 缓冲在 init 物化（当前懒创建靠 warmup 兜底，改为显式，§7-4）；eval 分支无 `.item()`/host sync（已核：`_probe_outputs` 的 `.item()` 仅在 training 分支）。
8. **warmup 跨 resume**：`_probe_step` 是持久 buffer，resume 后种子日程不重热。
9. **预算实测**：1×1024² probe+种子块墙钟 ≤3ms（超则 §4.2 降档链触发）。

### 5.2 Gate A：冻结基座 probe 探针（训练前否决权，~4K 步仅训 probe，骨干/解码器冻结，约 2h）

- 小 GT 定位率（stride-4 峰值命中）：≥70%（R2b 76.3%）；**<55% ⇒ 方案源头否决**（出生杠杆在 F1 尺度失效，让位 P4-a CDN 路线）。
- fg 通道 cell 召回 ≥85%、精度 ≥30%（先验不过宽）。
- probe 前向 ≤3ms（U9 同源）。

### 5.3 Gate B：≤16K 短训门（封存 F1 128K resume，双臂 {MAL-CP+} vs {MAL-CP+ + SeedQ-64}，边际即本场主张）

| 仪表 | 基线 | 过门 | 强信号 |
|---|---|---|---|
| 覆盖率（任意分数 IoU≥0.5 拥有小 GT）**先行指标** | 61.9% | ≥78% | ≥86% |
| never-hit（38.1% 缺口本体） | 38.1% | ≤22% | ≤14% |
| AR_s@100（rescore） | 0.309 | ≥0.42 | ≥0.52 |
| AR_s@10 | 0.0 | >0 | ≥0.05 |
| **种子边际 AP_s**（B 臂 − A 臂） | — | **≥+1.0pt** | ≥+2.0pt |
| AP_m / AP_l（slot 重分配回归看守） | — | ≥−0.3pt | — |
| hard-FP 纪律（<64 det 池，继承 P4-c G2） | 中位 ~0.29 TP/80.5% hard-FP | 中位 ≤0.10、>0.5 分计数 ≤150 | — |
| 重复率（DDQ 毒化看守） | 1.30 det/GT | ≤1.6 | ≤1.4 |

判读顺序契约：**覆盖率必须先于 AP_s 移动**（分数无关指标先行）——覆盖率动而 AR/AP 不动 ⇒ 分数仍门控 ⇒ 升级 τ/移交 P4-d，**不加种子**。

### 5.4 Phase-2 卡（过门后单因子，风险隔离）

- 全层 topk 门控（P6 全量版，显存/算力先单独审计）；
- probe 召回改进 knob（阈值 0.25→0.15、峰值核 3→5+两尺度、probe 训练延长）；
- 264 增补式种子（若 AP_m/l 看守触发但覆盖率收益大，改为 136+64→200+64 增补，重审计 +3-5%）。

### 5.5 失败判读树

- Gate A 挂 ⇒ 出生杠杆死 ⇒ 移交 P4-a（CDN/Group），本方案归档。
- 覆盖率挂（<78%）但 probe 召回达标 ⇒ 持有/出生联动断 ⇒ 先试 knob（阈值/核），再试 Phase-2 全层门控。
- 覆盖率过、分数挂 ⇒ 不是本场问题 ⇒ τ 调整/P4-d 轨迹重打分承接（CQTR 谱系）。
- AP_m/l 跌超 −0.3 ⇒ slot 重分配伤大目标 ⇒ 32 种子或 264 增补臂。
- hard-FP 恶化 ⇒ 种子背景峰出生的假阳性 ⇒ 提峰值阈值 + C2 的 SNR 过滤协同，仍败则回退。

## 6. (f) 与其它场叠加兼容性

| 场 | 关系 | 细节 |

## 9. 预算辩护：为什么是 64、为什么静态

- 需求侧（val，R3 D2）：COCO-small 每图 mean 2.91 / p99 21 / **max 26**；probe 训练人口（<1024px²）同分布。probe 召回 76.3% ⇒ 期望真峰 ~2.2/图（p99 ~16）。**64 = 观测 max 的 2.4×、p99 的 3×+**：覆盖密集尾与 C2 贴入增密（每图 +4~6 小 GT 后仍 ≪64）后仍富余。
- 为什么不给更多：可学习块 136 已贴近全 GT p90（99/图）；大中目标 AR 0.874/0.986 靠它们，挖 128 个槽的回归风险换不来覆盖（probe 召回封顶 76.3%，槽多不解决 probe 找不到的 23.7%）。
- 为什么静态：DQ-DETR 式变长 query 与固定 shape 批处理/DDP 静态图/CUDA graph 三者都冲突（调研 B §2.2 风险列）；容量维度已证不 binding（~0.9pt），动态预算解的是非约束问题。多余槽的语义就是"出生在背景峰 → eos"——零机制成本。HGSQ 的 AQDB 思想以"静态 slot + 峰值分数排序填充"的形态被吸收，而非变长形态。
