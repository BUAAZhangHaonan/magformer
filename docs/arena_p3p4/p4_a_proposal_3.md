# P4-a 提案 #3 ｜ CDN-S：小 GT 保供对比去噪组（正 ×3 + 判别负 ×1，块对角隔离，AIM 窗口损失，q 一致目标）

> 提案人 #3/5 ｜ 2026-09-20 ｜ 纸面轮，不跑实验。代码证据全部来自 `experiments_archive/v317_next_stage_2026-07/source/magformer/`（下称树内路径）。

## 0. 一句话方案与规格表

**机制**：对每个 AIM 资格线内（<4096px²@1024² 画布）的小 GT，训练期在 200 查询池之后拼接一组**固定的 96 行去噪查询**——每入选 GT 生成 3 个尺度相对噪声档的正样本重构查询（λ=0.05/0.15/0.30 × box 尺寸，含尺度抖动）+ 1 个同 GT 大扰动判别负样本（带全图 GT 重叠门），自注意力块对角隔离（正则 200 池 | 噪声组 g1 | g2 | g3 | 负组），掩码损失走 AIM 确定性窗口网格（复用 matcher 现成实现语义），正样本 cls 目标与 MAL-CP+ 同源同度量（q=重构 soft-Dice，QFL β=2.0，warmup 1000）。**推理期 DN 组不生成，0ms，字节级与基线一致**。主匹配（200 池 o2o + AIM）语义零改动——DN 行在进 matcher 前被剥除（criterion.py:209-216 现成逻辑）。

| 配置项 | 取值 | 说明 |
|---|---|---|
| dn_enabled | true（当前树内默认 False，arch.py:164） | 复活现有 DN 通路并修复缺陷 |
| 资格线 | area < 4096px²（与 AIM 同阈值） | 一个旋钮、一个语义 |
| 入选优先级 | <64px² 全取 → <1024px² → <4096px² 按面积升序 | n* = 24/图 上限 |
| K（正样本噪声组） | 3 组，λ = {0.05, 0.15, 0.30}（相对 box 边长） | 尺度相对噪声——小目标专用核心 |
| 尺度抖动 | log-normal ±{5%, 15%, 30%} 每组 | 与 λ 同档 |
| 负样本 | 每入选 GT 1 个：位移 1.5–2.5×box + 尺度 ×0.5–0.75 或 ×1.3–2.0 | 同 GT 大扰动（CDN 语义），非 rolled-box |
| 负样本有效性门 | soft-Dice vs 图内全部 GT < 0.02 且 box-IoU < 0.1（AIM 网格判定，重采样 ≤3 次，失败置 padding） | 单类标签矛盾消除 |
| N_dn | 96 行固定静态形状（24×3 正 + 24 负，批内 padding 行全掩） | CUDA graph / 静态形状兼容 |
| 隔离 | 块对角 attn mask：[200 正则池] ⊕ [g1] ⊕ [g2] ⊕ [g3] ⊕ [负组]，padding 行作 key 全掩 | 修复 tgt_mask=None 缺陷 |
| DN 掩码损失 | AIM 确定性窗口网格（R=clamp(win,8..64)），非均匀 12544 点 | 修复 criterion.py:680 的噪声主导 |
| DN 正样本 cls 目标 | q = 重构 soft-Dice（detach，QFL β=2.0，warmup 1000，与 MAL-CP+ 共用常数） | DEIM 打包铁律的 DN 侧落实 |
| DN 负样本目标 | no-object（仅 cls，无掩码损失），负样本逐位不动 | 与 P4-c C1 负样本纪律一致 |
| 损失权重 | 各项与主路 weight_dict 同权，整组 × λ_dn = 0.5 | 网格 {0.25, 0.5, 1.0} 从 0.5 起 |
| DN 参考点 | 保持初始噪声位置（树内 detach 逻辑 1011-1018 保留） | 不让 DN 掩码预测挪动 DN 出生点 |

**对 P4-b 移交件的继承与增量**：继承 tiny-CDN 的 K=3、N_dn≤96、小 GT 专用骨架与 SDN 的块对角隔离修复（均 P4-b VERDICT 移交条款）；本提案新增五项二者均未覆盖的承重件——(1) 尺度相对噪声日程（<64px 目标的绝对坐标噪声无意义）；(2) 判别负样本重设计（同 GT 大扰动 + 全图重叠门，修复 rolled-box 的单类标签矛盾）；(3) DN 掩码损失的 AIM 窗口化（否则把 AIM 修掉的噪声从损失侧重新引进来）；(4) q 一致 cls 目标（DEIM 铁律在 DN 通路的落实）；(5) 隔离从"补丁"升级为"单测不变量"（冻结 parity 测试，见 §e）。

## (a) 机制因果链

### a1. o2o 下小 GT 正样本稀缺如何限制学习（因果链四环）

1. **供给环**：o2o 二分匹配下每个 GT 每层深监督恰好 1 个正样本 query。<64px 桶可见期望 0.85 个/步（batch=4），即使 P4-c 分层贴入提到 ~3-10 个/步，每个 GT 仍只有 1 张"匹配彩票"——**且这张彩票要 query 先自己走到目标附近才中奖**。R3 实测：38.1% 的 COCO-small GT 全图任何分数下无 IoU≥0.5 检测、<64px 桶 87.8% never-hit（best-IoU 中位 0.006）——彩票根本没刮开。
2. **频率环**：focal 平衡被中大目标主导（小目标像素份额 0.124%、损失点份额 0.1-0.4%）。每步 <64px 正样本 cls 事件 ≈0.85→贴入后 3-10 次，相比全池每步 ~220 次匹配事件，小目标的"此处有物"正梯度近乎滴灌。
3. **质量环**：唯一中奖的 query 常常定位差（掩码内容糊，CF1 反事实 +27.1pt），MAL-CP+ 的 q 目标会进一步下调低质量匹配的 cls 权重——**这是 DEIM 自己声明的循环：增密不足时，质量感知损失反而放大稀缺**（DEIM 消融：Dense O2O 无 MAL 退化、有 MAL 才兑现；调研 C §3 候选 1/§4 教训 3）。打破循环的唯一方式就是补供给。
4. **成型环**：种子实验（P4-b R2b）证明覆盖可由出生位置解决（92.1%），但 cls 分数卡在 0.22-0.29——覆盖侧（SCB+）与分数侧（MAL-CP+）都已另场解决后，**残余瓶颈正是共享头（class_embed/mask_embed/解码器层）从未被足够多的小目标正样本事件训练过**。

### a2. CDN-S 为什么攻击根因且安全

- **保供而非彩票**：DN 正样本出生在 GT 噪声邻域（不掷匹配骰子），每入选小 GT 每步保证 3 个正样本 × 9 次 head 调用 = **27 次重构事件**，叠加主匹配的 9 次彩票，小 GT 正样本事件 ×4（9→36 次/GT/步）。与贴入相乘：贴入把可见小 GT ×3-10，CDN-S 把每个的利用率 ×4——这正是 DEIM"Dense O2O（数据侧增密）×MAL"结构在查询侧的同构补全。
- **训练的是共享头，语义与主路一致**：DN 行与正则行走同一 class_embed/mask_embed/解码器层（forward_prediction_heads 逐行线性），重构梯度直接提升 mask_embed 对小目标的画笔能力（供 P3 的 27.1pt 掩码内容池）与 cls 头对小目标的打分能力；λ=0.30 档（12px 目标位移 ~3.6px）专门训练"从近失位置锁定目标"——恰是 SCB+ 种子从 probe 峰值出生后要完成的动作（probe 峰对小 GT 定位 76.3%，峰偏几 px 是常态）。
- **判别负样本对症 hard-FP**：<64 det 池 80.5% hard-FP。CDN 负样本=同 GT 大扰动（"像但不对"），是 hard-FP 的可控训练态替身：教 cls 头在似是而非处输出低分。这补上单类场景负样本稀少导致的分数纪律缺口（调研 B 候选 1 风险条目反向利用）。
- **安全性由构造保证，不靠超参**：DN 行 (i) 进 matcher 前被剥除（criterion.py:209-216，aux 同剥 253-258）——AIM 代价矩阵、margin 2.43σ、num_masks 归一化全部不变；(ii) 自注意力块对角隔离下**正则 200 池的前向计算图与无 DN 时数学等价**（隔离使两子图无任何信息与数据流交叠，耦合仅剩共享权重梯度——而这正是供给通道本身）；(iii) 推理期不生成（arch.py:1373 `self.training` 门）。o2o 主匹配不被稀释、不去重压力不增（DDQ 教训规避）、正样本洪峰不进匹配池（Group DETR 表 7 教训规避）。

## (b) 与二分匹配 / AIM / 种子槽（SCB+）的兼容性与隔离设计

### b1. 主匹配零语义改动（逐点核对）

| 接触点 | 现状 | CDN-S 下 |
|---|---|---|
| matcher 输入 | 200 行 pred_logits/pred_masks | **不变**：criterion 在 matcher 前剥 DN（209-216 行现成），aux 输出同剥（253-258） |
| AIM 代价 | 全覆盖（去帽后）、margin 2.43σ | 不变；AIM 窗口计算与 DN 损失共用同一套网格语义（同阈值 4096px²、同 bbox+30% 窗、同 R clamp），"匹配选的就是它，DN 画的就是它"零度量漂移 |
| num_masks 归一化 | 全 GT 计数 | 不变；DN 损失按自身 valid 计数归一（现有 647/691 行 valid-mean 形式保留） |
| 深监督 ×9 | 每层独立匹配 | 不变：DN 行随 aux 输出一同产生、一同剥除 |
| DDP/EMA | — | DN 构造仅依赖本 rank targets+RNG（每图独立）；EMA teacher 为 eval 前向 → `self.training=False` → 无 DN，师生一致 |
| CUDA graph | 静态形状 | 固定 96 行恒定形状，无动态 batch 维变化 |

### b2. 隔离设计（块对角 + 逐组）

自注意力 bool mask（B·heads, 296, 296），五个对角块：`[正则 200（含 SCB+ 64 种子槽）] ⊕ [g1 24] ⊕ [g2 24] ⊕ [g3 24] ⊕ [负组 24]`，块间互掩；批内 padding DN 行作为 key 全掩（作为 query 不产生损失）。

- **为什么组间也要隔离**：不同 λ 档的组若互通，易组 query 可读难组 query 的答案，噪声课程失效（DINO 的组隔离语义）。
- **正则块的前向等价性**（本提案安全论证的核心）：块对角隔离下正则 200 行的自注意力 softmax 仅在自身块内归一——其计算图与无 DN 完全一致；cross-attention 逐行消费自己的语义掩码（DN 行有自己的掩码，正则行掩码由正则行预测产生，互不可见）；预测头逐行线性。因此**冻结权重 eval 模式下 DN on/off 的正则行输出应当逐位一致**——这条性质被固化为单测 T1（见 §e），把 P4-b 发现的隔离缺陷从"修一次"升级为"永久回归不变量"。
- 与 SCB+ 的两个具体交点已核对：(i) probe-fg 种子先验只作用于 `[num_learned, num_regular_queries)` 行，DN 行在本组掩码内自治（multiscale_decoder.py:847-852 注释即为此设计，无需改）；(ii) DN 参考点 detach 逻辑（1011-1018）保留——DN 的 deformable 采样锚定在噪声出生点，防止 DN 掩码预测自我强化。

### b3. 负样本有效性门（单类特有，承重）

每次负样本扰动后，在 AIM 网格上计算其落点框与图内**全部** GT（不限入选集）的 soft-Dice 与 box-IoU；超过门（Dice>0.02 或 IoU>0.1）则重采样（≤3 次），仍失败置 padding 行。杜绝"负样本压在真目标上"的标签矛盾（缺陷 D2 的根因）。工业图 GT 密度高时的兜底形态：改为同 GT 尺度失配（size ×2.5–4、中心不动）——中心在真目标上但框完全错配，仍教"这个提名不配得分"而不否认目标存在。P1 冻结探针（§e）预注册了这一分支的触发判据。

## (c) 理论收益上界与依据

### c1. 文献锚（全部注出处）

- Group DETR（ICCV 2023, arXiv 2207.13085）：**Mask2Former R50 12ep mask AP 38.5→39.7（+1.2）**——o2m 供给族在本架构家族的唯一公开数字；同文表 7：不分组 3300 query o2m 32.6→8.4（反面）。其开销 +5min/epoch（23→28，≈+18%）。
- DN-DETR（CVPR 2022, 2203.01305）：R50 12ep +1.9 AP；**同性能仅需 50% epoch**（收敛加速锚——对本场 16K 短门/32-48K 组合臂有直接意义）。
- DINO/CDN（ICLR 2023, 2203.03605）：DN-DETR 43.4→49.4（+6.0，含混合选点）；对比去噪正负捆绑的原始出处。
- Mask DINO（CVPR 2023, 2206.02777）：CDN-mask 在掩码架构可行（COCO IS 54.5），组件可单独摘取。
- DEIM（CVPR 2025, 2412.04234）：增密必须配 MAL 的消融证据（打包铁律）。

### c2. 本地证据锚

- 供给稀缺：0.85 可见 <64px GT/步；损失点份额 0.1-0.4%（SYNTHESIS P10/P4）。
- 受益人群：64-1024px² 桶 best-IoU 中位 0.399-0.680（已部分检出、内容与分数双差；R3 D1）——DN 重构直接训练这群；<64 桶已检出者的 TP 分中位 0.29（P4-c 证据）。
- 掩码内容池：CF1 +27.1pt（SYNTHESIS）；残差 ~10.1pt 属已检出者的 mask 质量/分数（R3 D6）。
- hard-FP：80.5% 池占比（P4-c 证据）——判别负样本的直接靶。
- seed 实验：覆盖 92.1% × 分数 0.22-0.29（P4-b R2b）——共享头训练不足的在位证明。

### c3. 上界算式（诚实口径：本场主张为 P4-b/c 之上的**边际**）

```
边际收益 = 事件放大(×4) × 受益桶可回收池 × 共享头迁移率 r
受益桶可回收池 ≈ 64-1024px² 桶的掩码/分数残差 + <64 已检出者分数残差
             ≈ 10.1pt（R3 D6 残差）中该桶份额 ~40-60% ≈ 4-6pt
r（重构梯度→匹配路径收益的共享权重迁移率）= 0.25-0.45（保守，
    依据：DN-DETR +1.9 与 DINO +6.0 的差值全来自配套件而非 DN 本体，
    且我们只训小 GT 子集）
上界 ≈ 4-6pt × (0.25~0.45) 的方向性区间，扣除与 SCB+/MAL-CP+ 的重叠
主张：边际 +1.0 ~ +2.5pt AP_s（中心 +1.5），主通道=掩码内容(小桶) +
收敛加速(DN-DETR 50% epoch 锚) + hard-FP 分离(负样本)
置信度：中（0.5）——DN-mask 在单类工业小目标上无直接公开数字，
所有数字均为跨域外推，靠 16K 门裁决
```

明确**不重复计入**：存在性缺口 37.5pt oracle 值归 P4-b（覆盖）；TP 分数 0.29→0.40 门归 P4-c（分数成型）。CDN-S 只主张把这两场投资的有效率抬高（每个贴入/种子 GT 的利用率 ×4）。

### c4. 为什么不选 Group/H-DETR 作主路（同场候选的对比，供裁决人）

| 维度 | CDN-S（本提案） | Group DETR | H-DETR |
|---|---|---|---|
| 供给保证 | 出生即 GT 邻域（无彩票） | 仍靠注意力发现（38.1% no-detection 正是发现失败） | 同左 |
| M2F 公开数字 | 无（Mask DINO 组件可行性） | **+1.2（唯一）** | 无（Deformable 系 ~+2） |
| 训练开销 | **+1.4~2.3%** | +18%（超本场剩余预算） | ~+7%（边缘） |
| matcher 额外成本 | **0**（DN 剥除） | K 组 ×9 层独立匹配（AIM 窗口 ×K） | 辅支路第二套匹配 ×9 |
| 推理 | **0ms（不生成）** | 0ms（弃组） | 0ms（弃支路） |
| 分数污染风险 | 无（不进匹配池） | 需组内 o2o 纪律 | 需 MS-DETR 式解耦 |

预注册升级卡（Phase-2，非 v1）：若 16K 门显示 DN 方向正确但供给不足，加 H-DETR 迷你辅支路（K=2 重复 GT 列、100 辅 query，预算 +4~5%）——单列于此供裁决人排期，不计入本提案开销。

## (d) 开销预算（给算式）

### d1. 训练 ms/it

基线 1.44–1.60 s/it（4 卡 DDP）。CDN-S 三项增量：

1. **解码器 query 轴 200→296**（线性项为主：mask head 与 cross-attn 逐行线性，self-attn 二次但占比小）。
   经验锚外推：Group DETR 实测 300→3300 query（R50-M2F-COCO）= +17.9% 步时 → 每 +300 query ≈ +1.63% → +96 ≈ +0.52%。
   结构修正 ×2–3（我们的 mask head 9 次调用含 2 次 stride-4 65K cell 大网格，且 1024² 输入下解码器份额高于 COCO 参考）→ **+1.0~1.6%**。
2. **DN 损失与构造**：AIM 窗口网格 R²≤4096 点/行 vs 均匀 12544 点（便宜 3-10×）；有效行 ≤96×4 批 → 点采样总量 ~0.4M 点 vs 主路 ~2.75M 点；构造为逐 GT 框运算 + 正弦 PE，微秒级 → **+0.2~0.3%**。
3. **masked-MHA 核心路径切换**（bool attn_mask 使 self-attn 无法走 fast path，296² 规模）→ **+0.2~0.4%**。

**合计 +1.4~2.3%，登记上界 +2.5%**。matcher 侧增量 = 0（DN 剥除；对比：任何 o2m 臂都要为辅 query 重跑 ×9 匹配）。

叠加账单：P4-c +3~6% + P4-b 核心 +~1% + 本提案 +2.5% = **全树 +6.5~9.5% ≤ 20% 红线（2 倍余量）**。

降档阶梯（若实测超档）：K=3→2 与 N_dn=96→64（约 −0.8%）；λ_max 0.30→0.20（不改开销，改难度）；负组减半（−0.2%）。注意固定 padding 意味着"少入选"不省算力——降档必须减 N_dn 本身。

### d2. 推理 ms

**0ms**。DN 组仅训练期生成（`self.training` 门，arch.py:1373）；不进 topk、不进 maskness 融合、不进导出。P4-d 的 CQTR 重打分等导出端方案看到的推理图与基线字节级一致（单测 T7 强制）。

### d3. 显存（≤24GB/卡）

```
Δ 掩码 logits 激活（9 次 head 调用存 aux）
  = B × N_dn × Σ_cells × 2B(bf16)
  Σ_cells ≈ 1K+4K+16K+1K+4K+16K+1K+65K+65K ≈ 173K cells（stride 32/16/8/4 网格 32²/64²/128²/256²，按层调度 (i+1)%3、末两层 level 3）
  = 4 × 96 × 173,000 × 2B ≈ +133MB
Δ self-attn bool mask = 4×8×296²×1B ≈ 2.8MB
Δ DN 损失瞬态（grid_sample/目标网格） ≈ +10~50MB
Δ 解码器层内激活（FFN/投影，占 decoder 层激活的 96/296=32%；若梯度 checkpoint 开启则近 0，关则 ~+0.3-0.6GB）
合计 ≈ +0.15GB（checkpoint 开）/ +0.8GB（最坏，关）
```

实测门确认峰值 ≤23.5GB（§e S0）。

## (e) 正确性验证方案

### e1. 单测（CPU/float64 优先，GPU 一致性各一）

- **T1 隔离 parity（防作弊核心不变量）**：冻结小配置 eval 模式，DN on/off 两次前向，正则 200 行输出 allclose（CPU float64 atol=1e-6；GPU bf16 atol=1e-3）。失败=隔离实现有洞。
- **T2 块对角正确性**：断言 attn mask 模式——正则行可见 key 恰为 [0,200)；g_k 行恰见本组 24 行；负组行恰见负组；padding 行作 key 全掩。
- **T3 负样本门**：合成多 GT 图上采 1000 次，全部负样本 soft-Dice(vs 任意 GT)≤0.02 且 box-IoU≤0.1；单 GT 图（无处安放）触发尺度失配兜底。
- **T4 噪声尺度相对性**：12px GT 在 λ=0.05/0.15/0.30 档的位移标准差分别为 ~0.6/1.8/3.6px（±20% 容差）；noised box clamp 在 [0,1]。
- **T5 DN 损失 AIM 窗口**：平预测（全 0 logits）下 DN pos 的 mask/dice 损失与解析值一致（窗口内点全部落在 GT bbox+30% 内）；梯度对 mask_embed 非零。
- **T6 dn_meta 一致性**：异质 GT 数（含 0 小 GT 图）下 valid 掩码、96 行静态形状、批内 padding 全掩正确。
- **T7 eval 端到端 parity**：同一 checkpoint、同一输入，dn config on/off 产出 dets 哈希一致。
- **T8 q 目标无泄漏**：DN q 目标 detach、无梯度回路；warmup 1000 步内目标=1、其后=q。
- **T9 DDP 采样一致性**：两 rank 同种子同 targets 产出相同 DN 组（确定性）。

### e2. 冻结探针（训练前否决门，CPU 重放 dataloader 1000 步）

- **P0**：T1 通过（不通过则方案源头否决——隔离不可证）。
- **P1 负样本有效率 ≥60%**（重采样后）；落点-最近 GT soft-Dice p90 ≤0.02。若 <40%：工业图 GT 密度使负样本无处安放 → 切换尺度失配兜底形态（§b3），不否决方案。
- **P2 供给核算**：含小 GT 图中 ≥95% 有 ≥1 组 DN 供给；每步有效 DN pos 行数分布落在我们申报区间（贴入开/关两态各测）。低于 80% → 检查 n* 优先级实现。

### e3. ≤16K 短训门（封存 128K 基座，双臂：对照=SCB++MAL-CP+，实验=+CDN-S；与 P4-b/c 门同协议同 seed）

**防毒化哨兵（contract 指定，全部预注册）**：

| 哨兵 | 指标 | 门 |
|---|---|---|
| S0 资源 | 步时增幅 ≤+2.5%；显存峰值 ≤23.5GB | 超档 → 降档阶梯 |
| S1 主匹配质量 | matched-IoU 中位（0.635）≥ 对照−0.005；AIM margin p10 ≥ 对照−2%；日志断言 matcher 输入恒 200 行 | 败 → 隔离/剥除实现 bug，回 T1/T2 |
| S2 重复率 | 每小 GT det 数 ≤1.45（基线 1.30）；dup 簇 ≥2 占比 ≤10%（基线 8.2%） | 败 → DN 行泄漏进导出（T7）或共享头重复吸引子 → λ_dn 减半 |
| S3 hard-FP | <64 det 池 hard-FP 分数中位 ≤ 对照（方向性目标 ≤0.08）且 >0.5 计数不增 | 败 → 负门过松或 dn_neg 权重过高 → 负权重减半/收紧门 |

**DN 通路健康**：DN pos 重构 soft-Dice 轨迹 0.30→≥0.65；λ 阶梯单调（λ=0.05 组 ≥ λ=0.30 组 +0.05）；DN neg 均值 cls 概率 ≤0.10。重构 dice 平坦 → λ_max 过大或 T5 窗口实现错。

**效应门**：小桶 TP 分数中位 ≥ 对照 +0.03；AR_s@100 不降；AP_s 净 ≥ +0.5pt@16K（收敛加速下保守）；38.1% 存在性缺口不恶化。过门 → 32-48K 组合臂（判据：净超 R4 退火对照线 ≥+1.0pt，与 P4-b/c 组合臂判据对齐）。

**2×2 归因臂（16K 内完成）**：DN on/off × DN-cls q/one-hot。one-hot 臂预期 hard-FP 搭车（S3 恶化）——DEIM 打包铁律在 DN 通路的在位证明；若 one-hot 臂不恶化，说明 q 打包在 DN 侧冗余，可简化（也值得知道）。

### e4. 失败判读树（预注册）

S1 败→实现 bug（非方案失败）；S2/S3 败→权重/门参数问题，一次降档重跑；效应门败但哨兵全过→供给通道迁移率低于预期，触发 §c4 升级卡评估或止损（保留隔离修复与缺陷修复为独立产出——它们是任何 DN 臂的公共前置）。

## 诚实备注

1. 本提案的全部收益数字是跨域外推（DN-mask 无单类工业小目标公开数字），置信度按 0.5 计；判分公式的开销分母是全场最低档之一（+1.4~2.3%），推理 0ms。

3. 固定 96 行 padding 在小 GT 稀少的步上存在算力空转（~0.5-1% 步时换静态形状与 CUDA graph 兼容）——已在开销账内如实计入。
