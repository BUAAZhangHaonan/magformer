## 三、裁决

**胜出（骨干）：#1 BAS-CL**——理论处理最完备（标签可达性是五家中唯一给出"为什么软标签消除 0/1 振荡"的机制论证，直指 ±1px 抖动），三段设计对大目标收敛最保守，开销近最低，验证门含 no-op 逐位回归。

**合并采纳的独有贡献**（构成本场最终设计 "BAS-CL+"）：
1. **#5 的 balanced_ce 豁免**（关键）：`_sigmoid_ce_loss` 的 fg_ratio clamp 0.01 使小目标边界外侧点被降权 ~100×——内侧强推、外侧不罚 = 损失形式直接许可软坡。**带内点必须豁免该降权**，否则任何边界监督的外缘钉定力被抵消。#3 的 fg_ratio-from-GT-area 修复作为替代方案保留在消融卡。
2. **#2 的跨层坐标复用**：点包每迭代构建一次、9 层共享（消除层间采样不一致这个额外抖动源）。
3. **#4 的地板配额算术**：带点数=max(地板32, 周长份额)，构造性保证 + 优于纯比例分配。
4. **#3 的杀线纪律**与冻结探针（带内/内部 BCE 比 ≥1.5 预注册，<1.1 即杀）并入验证协议。

**亚军：#4 BASS**（开销最低+地板保证；若 #1 的软标签在短训中触发 AP@0.5 护栏，回退到 #4 的纯采样形态）。
**落选组件**：#3 的窗口确定性 Dice（与 coverage 软标签功能重叠、实现最重）；#2 的 β 加权臂（默认关，共识正确）。

**BAS-CL+ 最终形态**：三段采样（50% 不确定性 + 30% GT边界带[地板32, 尺度自适应带宽 r=clamp(√A/8,1.5,6)@1024] + 20% 内部/近邻）→ 标签 = 512² coverage 软图（avg_pool 2×2，CF1 构造对齐）→ 带加权 BCE（带内豁免 balanced 降权，λ_b=3 ramp 2K）+ 带 Dice（权重走同一 ramp）→ 几何点包每迭代一次、9 层复用 → 全 GPU（逆 CDF 免 nonzero 同步）。

## 四、实验室验证（胜出设计，预注册）

1. 单测（CPU）：no-op 逐位回归；软标签与 R2 渲染协议一致（对软图施 bilinear×2+0.5 = CF1 掩码）；带内点密度 ≥200×；豁免路径只影响带内点。
2. 冻结探针（~15min GPU）：带内/内部 BCE 比 ≥1.5（<1.1 杀）；带内错分率基线（#5 的读数）。
3. 8K/16K 双臂短训（封存 128K 基座，对照臂=R4 退火线）：主门 matched IoU p50(<64) 0.635→≥0.70@8K / AP_s@0.75 0.247→≥0.30@8K、≥0.35@16K；净值 ≥+1.5pt vs 对照臂；护栏 AP@0.5≥0.59、空掩码率≤+1pt、hires 组梯度 ≤2×。
4. 消融卡：采样-only vs 全包（软标签必要性）；λ_b {1.5,3}; fg_ratio 修复 on/off。

## 五、诚实备注

- 五家的收益主张（+4~11pt）全部锚 CF1 上限 27.1pt 的 15-40% 回收率，属同类外推；裁决不采信号度最高的 #4（+7~11），取理论最完备的 #1（+6~10）作中心估计——**最终数字以短训门为准**。
- <64px² 桶的 CF1 上限只有 +2.7pt 且受 rec@0.5=12.2% 钳制——本场主要兑现在 64-1024px² 桶（它们全部计入 COCO-small）；<64 桶收益主要变现为 matched IoU 提升，为 P4 场的复利做铺垫。全场共识，如实声明。
- 高 IoU 段的部分缺口属渲染链表达力（<32px² 链 frac≥0.5 仅 0.443）——归 P3-b，本场不重复计费。
