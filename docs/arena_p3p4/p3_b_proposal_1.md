# P3-b 提案 #1：CARD —— 面积条件排序解码（L1，零训练）+ 亚 cell ROI 精修头（L2，第二阶段）

提案人：独立提案人 #1（P3-b 场，5 席之一）。日期 2026-09-21。
定位声明：**第二阶段**。本提案的全部兑现行以 P3-a BAS-CL+（coverage 软标签）收敛为前提条件设计，同时保证在当前 128K EMA 权重上可零训练先验、零风险退场。

---

## 0. 一句话主张

渲染链 4.0pt 缺口（CF2−CF1）里 **+1.0~3.5pt（链级，实测 oracle 上界）属于"逐实例阈值族"从未被开采的残差信号**——今天的解码是把这个（BAS-CL+ 之后将被校准的）coverage 场过一台**固定解码器**（bilinear×2 → 全局 0.5），而固定解码器只在总体均值上 Bayes 最优、从不逐实例最优。CARD 用**逐实例面积条件解码（L1）**回收这一段（零训练、≤+0.5ms、CUDA-graph 兼容），并用**亚 cell ROI 精修头（L2）**啃阈值族外的亚 cell 几何段（≤+1.0ms、训练 ≤+4%）。全程不改训练匹配、不改导出契约、不改 512 画布。

## (a) 机制因果链：4.0pt 的构成分解与回收段

### a1. 缺口构成（全部锚定 R2 实测，rescore 口径）

CF2（精确 GT 掩码）−CF1（GT 穿生产链：512 画布 INTER_AREA coverage → bilinear×2 → 0.5）= **0.6033−0.5636 = 4.0pt**。分桶：64-256 损失最大（0.3336→0.3817，+4.8pt），256-1k 次之（+4.0pt），<64 因检测召回瓶颈被压缩（+2.2pt）（R2 report §D5）。

按机制把 4.0pt 切成两段：

| 段 | 机制 | 链级实测界 | 证据 |
|---|---|---|---|
| **段 I：面积多数决偏差（阈值族可回收）** | 0.5 等值线对每实例不是最优操作点；2-3 cell 目标上 0.5 面积多数决系统性侵蚀（<32px² 链 frac≥0.5 仅 0.443，τ=0.4 即 0.600；32-64：0.866→0.955） | 分桶自适应 +1.0pt（链 AP 0.807→0.817）；**逐目标 oracle 阈值 +3.5pt（→0.842）** | R2 §D3 |
| **段 II：亚 cell 几何不可表达（阈值族外）** | bilinear×2 只产生邻 cell 中点插值，每 cell 的 2×2 子像素模式空间（16 pattern/cell）被坍缩成光滑场；残差 ≈ 4.0−3.5 ≈ 0.5pt 以内 + 链外结构损失（oracle 0.842 < stride-1 的 1.000） | 本链内不可全回收；stride-1 才到 1.000（远期、+23.2pt 在缺口定义之外） | R2 §D3/§D7 |

### a2. 为什么根因是"固定解码器"而不是"阈值没调好"

- **全局阈值已死**：F1@128K 实测 0.45 → +0.09pt（噪声内）、0.40 → −0.13pt（f1-128k-calibrated §二.3）。这不是"阈值机制无信号"，而是**全局杠杆把逐实例信号在总体里平均成了零**——链级证据同向：0.45≈0.5 并列（0.808/0.807）、统一 0.4 反而 −0.9pt（0.798），但分桶自适应 +1.0、逐目标 oracle +3.5。信号存在且**只在逐实例粒度**。
- **±1px 形态学探针的双向变差**（<64：0.652→0.476/0.256）排除"系统性偏大/偏小"——它排除的是形态学修边，不排除排序解码：阈值族是沿每实例概率排序单调移动操作点，与抖动正交（R2 §D4 的结论原文即"修复必须来自更好的内容（训练），不是后处理形态学"——阈值≠形态学，且更好的内容正是 P3-a 交付、本提案第二阶段消费的东西）。
- **maskness 随桶漂移**（score p50 0.613/0.723/0.821）证明当前软场未校准——固定 0.5 连"总体最优"都不是。BAS-CL+ 的 coverage 标签**按构造**使软场每 cell 值 = GT 覆盖率 → 0.5 等值线被校准、面积积分无偏。**届时固定解码器"总体最优"成立，逐实例残差（oracle−固定 = 3.5pt）成为唯一剩余的解码侧信号**——这就是本提案的窗口。

### a3. 回收映射

- **L1（面积条件排序解码）→ 段 I 全部**：两个变体，同一思想"让二值掩码的面积/操作点由该实例自己的软场统计决定，而不是全局常数"：
  - **L1a 面积匹配分位解码（top-Â）**：Â = 4·Σ sigmoid(512 画布 logits)（每 cell=4px²@1024；BAS-CL+ 下无偏，因为 E[Σc]=GT 面积/4）；二值掩码 = 1024 上采样软图的 top-Â 像素（等价于逐实例分位阈值 τ̂）。top-Â 本身是逐目标阈值族的成员（τ=第 Â 大概率值），上界 ≤ oracle 0.842，但**选择器是原理性的（面积一致）而非作弊的（不知道 GT）**。
  - **L1b 面积→阈值 LUT**：τ̂ = LUT[面积 bin(Â)]，LUT 离线在链模拟（或生产软场 dump）上按每 bin 期望 IoU 最大化拟合，推理只是一次 gather——比 L1a 更便宜（无 histogram），信息量低于 L1a（只用面积），上界 ∈ [0.817, 0.842]。
- **L2（亚 cell ROI 精修头）→ 段 II 的链内可表达部分**：对 Â<320px² 的实例，在 coarse 掩码 ROI（512 画布 16×16 cell）上，用 query 嵌入条件化的小头预测**每 cell 的 2×2 子像素残差 logit**，融合进上采样 logit 后再过 L1 解码。这是 DCT-Mask 的"query 条件化高频表示"思想的 ROI 化、并保留 512 画布不动（避开反面锚：Mask R-CNN 28²→112² 34.7→32.5 的"朴素加固定分辨率"陷阱——我们不放大画布，只在被门控的小 ROI 上增加解码粒度，且 DCT-Mask 自证推理近零开销 22 vs 23 FPS）。

## (b) 兼容性：渲染链 / CUDA graph / 导出契约 / TREX+ / 匹配

1. **渲染链与 CUDA graph**：改动点唯一且形状静态——`gpu_postprocess.postprocess_tensors`（198-217 行）。(i) 在 gather 后、interpolate 前对 512 画布做 `sigmoid+sum`（静态形状 26.2M 元素）；(ii) LUT 为 device 常驻 buffer，gather 出 (B,K) 阈值向量（或 top-Â 经 256-bin 直方图/下采样 CDF 求 τ̂，形状同样静态）；(iii) `mask_probs > mask_threshold` 的标量比较改为 `> τ[:,None,None]` 广播比较——**数据依赖只在值、不在形状，全部可被 CUDA graph 捕获**（现 mask_threshold 本就是 graph 常量，docstring 明示；改动等价于把常量换成常量形状的张量）。配置键 `inference_decode_mode ∈ {fixed, lut, quantile}`，切换需重建 graph（一次性）。
2. **导出契约不变**：输出仍是 uint8{0,1} (K,1024,1024) F-order 掩码 + RLE；bbox 提取 `compute_bbox_xyxy_gpu` 读同一二值掩码，语义逐位一致；maskness 公式不变（τ 变 → 掩码变 → maskness 随之变，这是机制的一部分而非违约）。软掩码导出（直接出概率图）**明确不做**：破坏 COCO RLE 契约，只对部署侧有意义，本轮放弃。
3. **TREX+（P4-d，已占 0.5-2ms）**：TREX+ 消费导出后的检测轨迹重打分；CARD 改变掩码 → maskness → final_scores 的输入分布。**结构无冲突（TREX+ 在 CARD 下游、且是重排序不依赖绝对分标定），但需联合重验证**：裁决书把"TREX+ 校准表在 CARD 开启下重拟合一次"列为并跑项（零训练）。
4. **二分匹配 / set-prediction**：L1 是纯推理侧、逐实例、无跨实例交互，训练匹配零触碰。L2 新头的辅助损失**不进匹配代价**（对 matched 实例的 ROI 监督，detach 于 matcher），o2o 主匹配不变——与 AIM/BAS-CL+ 的匹配结构正交。
5. **与 512 画布/最后一层接线的关系**：`multiscale_decoder.py:982-1000` 最终迭代消费 `mask_features_hi`（512²）的 einsum 掩码——L1/L2 都不动这条接线；L2 的输入恰是同一 `mask_features_hi` 的 ROI crop，复用 `pixel_decoder_msdeformattn.py:383-395` 已验证的零初始化 warm-start 纪律（新头零初始化 → step-0 与基线逐位等价，BAS-CL+ 权重零回归风险）。

## (c) 理论收益上界（链模拟数字锚定 + 诚实折损）

### c1. 链级上界（完美内容 = coverage 精确，即 BAS-CL+ 收敛态）

| 解码 | 链级 AP_s 估计 | Δ vs 现状 0.807 |
|---|---|---|
| 固定 0.5（现状） | 0.807 | — |
| 固定 0.45 / 0.4 | 0.808 / 0.798 | +0.1 / −0.9（已实测死） |
| 分桶自适应 | 0.817 | **+1.0**（上界：L1b 的下界情形） |
| **L1a top-Â（本提案主件）** | ∈ [0.817, **0.842**] | **+1.0~3.5**（离线可先验精确定位） |
| 逐目标 oracle 阈值 | 0.842 | +3.5（族上界） |
| stride-1（缺口外，远期） | 1.000 | +23.2（不在本轮定义内） |

关键附加数字：**<32px² 子桶**固定 0.5 frac≥0.5 仅 0.443，top-Â 预期 ≥0.62（τ=0.4 已到 0.600，面积匹配比固定 0.4 更贴每实例）；<64 桶内自适应链级 0.371→0.446（桶内 +7.5pt）；<128px² 合并 frac≥0.5 0.755→0.846。

### c2. 折损到实测 AP_s（诚实阶梯）

- **折损系数实测锚**：全局杠杆的链级→生产折损 ≈ 0.1-0.15（链级 ±1pt → 生产 ±0.1pt 量级，见 128K 校准的 0.4 全局实测 −0.13pt）。
- **当前权重（无 P3-a）**：软场未校准（maskness 漂移）+ 内容抖动（F 探针）→ L1 预期 **+0.1~0.5pt AP_s**。诚实声明：很可能接近 0——这正是全局阈值扫描的结局，也是本提案把绑定判读放在 P3-a 之后的唯一理由。
- **P3-a 收敛后（第二阶段兑现行）**：内容 → CF1（coverage 精确）→ 链级→生产转移系数 → 1（CF1 反事实的构造就是"内容=coverage 场"），L1 兑现 **+0.8~3.5pt AP_s**（上界：CF1 0.5636 → 最高逼近 CF2 0.6033，即把量化缺口整段抹掉的方向）。BAS-CL+ 若只部分收敛，按收敛比例内插。
- **L2**：文献锚 DCT-Mask AP@75 +2.1 / AP_S +0.5、RefineMask 小目标 +1.5（大目标 +6.0 的反面提醒收益偏小）、PatchDCT +0.7。第二阶段在 L1 之上预期 **+0.5~1.5pt AP_s，抬 AP@0.75/0.9 崩塌段**（当前 0.247/0.018），置信中低，用门控保底（见 e）。
- **定量归属**：本场（渲染链 4.0 + 阈值自适应 1.0-3.5）合计上界 5-7.5pt = 全缺口 47.6 的 11-16%（R2 堵点表 #3）——本提案不与 P3-a 的 27.1pt 争功，只承诺把"链与解码"这 11-16% 里可先验的部分吃干净。

## (d) 开销预算（算式）

### 推理（每图，B=1，top-100，A100 级带宽 ~1.5-2TB/s 计）

| 项 | 元素量/算式 | ms |
|---|---|---|
| L1：Â = sigmoid+sum(512²×100) | 26.2M×4B×2 pass ≈ 210MB | ≤0.2 |
| L1a：τ̂ 直方图 CDF（512 画布 256-bin scatter_add，可 stride-4 下采样到 6.5M） | 26.2M（或 6.5M）atomics | 0.3~0.6 |
| L1b：LUT gather | 100 次 | ~0 |
| 广播阈值比较（替换现标量比较） | 105M 比较（与现状同量） | +0~0.1 |
| **L1 合计** | L1b 路线 ≤0.3；L1a 路线 ≤0.9 | **≤0.3~0.9** |
| L2：门控实例（Â<320px²，cap 48/图）ROI crop 16²→3 层 conv→32² 残差 scatter | 48×~50k FLOPs + 2 次 gather/scatter | **≤1.0** |
| **CARD 合计** | | **典型 ≤1.3，最坏 ≤2.0** |

预算分摊：TREX+ 0.5-2 + CARD ≤2.0 = **≤4.0ms < 剩余 8ms**（余 ≥4ms 给 P4-d 后续/裕量）。

### 训练

- **L1：零训练**（纯推理解码 + 离线拟合 LUT/直方图参数）。
- **L2**：ROI 头前向/反向 + 辅助损失（仅门控实例，≤48/图，16² ROI 的点采样监督）：ms/it 1.44-1.60 基线上 **+2~4%**（场红线 +5% 内；叠加 P4 栈 6-11% 后总 ≤15%，低于全局 20% 红线）。

### 显存

L2 头参数 ~0.3M（<2MB）；激活 48×16²×C×B ≈ 数十 MB 级。**总额外 <100MB/卡**，24GB 红线无压力。

## (e) 正确性验证方案（预注册判读数字，先验可裁决）

三级门，**前两级在纸面轮之后、实验室轮之内即可全部执行，且第一级今天就可在 CPU 上跑**（材料已备：`analyze2.py` D 段管线 + `results_D.json` 逐掩码 sim_raw——R2 报告附录明示含 sim_raw）。

**G1 链级离线模拟（零训练、零 GPU、~3min CPU）**：在 R2 D 段协议（2000 小桶 GT 穿精确链）上加三个解码变体：
- L1a top-Â（面积 = coverage 和×4）；
- L1b 面积 bin LUT（bin={32,64,128,256,1024} 边界，bin 内期望 IoU 最大化）；
- 复用已有 oracle 行做上界对照。
判读（预注册）：
- **G1-过**：L1a 链级 AP ≥ **0.820**（+1.3pt vs 0.807）且 <32px² frac≥0.5 ≥ **0.58**；L1b ≥ 0.812。→ L1 进冻结探针。
- **G1-降级**：L1a ∈ [0.812, 0.820) → 只保留 L1b/L1a 中优者、收益预期改写为 +0.5~1.0pt。
- **G1-杀**：L1a < 0.812（即面积匹配选择器连分桶自适应都不如）→ 阈值族残差信号被证伪，L1 撤案，本提案退为 L2-only 并明说。

**G2 冻结权重探针（零训练，GPU eval，~30min×2）**：`arch.py:1584-1586` 已支持 `include_raw_tensors` dump `mask_probs`——在 F1@128K 封存 EMA 上离线施加 L1，全量 COCOeval。本轮为**信息性**（预期 +0~0.5pt，F 探针风险已声明）；**绑定判读**在 BAS-CL+ 16K 短训 checkpoint 上重跑：L1 开启 vs 关闭，**AP_s ≥ +0.5pt 且 AP@0.5 回退 ≤0.3pt** 方进 128K 续训臂。同时用该 dump 重拟合 L1b LUT（消除链级/生产分布漂移，模型侧自校准）。

**G3 L2 短训门（第二阶段，8-16K，自 BAS-CL+ ckpt 起训）**：
- matched IoU p50（<64）：0.635 → **≥0.70**；
- AP@0.75：0.247 → **≥0.27**（L2 主指标，攻高 IoU 崩塌段）；
- AP_s：≥ BAS-CL+ 单独臂 **+0.5pt**；
- AP@0.5 回退 ≤0.3pt；ms/it +≤5%；零初始化 step-0 逐位等价单测（复用 hires replicate-init 的测试模板）。
- 任一硬门失败：L2 撤案，L1 独立存活（互不拖累）。

**工程单测**：CUDA graph 捕获下 L1 逐位一致性（eager vs graph replay）；τ 向量广播与标量路径在 fixed 模式下逐位一致（回归保护）；导出 RLE/bbox 与参考路径逐位一致。

## (f) 叠加兼容性与第二阶段时序声明

| 场 | 关系 | 说明 |
|---|---|---|
| P3-a BAS-CL+（已裁决） | **前置+正交互补** | BAS-CL+ 校准软场（0.5 等值线+面积无偏）→ L1 的面积选择器从"有噪"变"原理性"；L1 反过来开采 BAS-CL+ 留下的逐实例解码残差（oracle−固定=3.5pt）。BAS-CL+ 训练用软标签、解码阈值仍是 0.5——无冲突；L1 只在推理改操作点。 |
| P4-d TREX+（已裁决） | 同侧叠放 | 预算 0.5-2 + ≤2.0 = ≤4.0ms < 8ms；分数输入分布变化需联合重拟合 TREX+ 校准（零训练，裁决书并跑项）。 |
| P3-c HDA+（已裁决） | 正交 | L2 新模块单设参数组，默认挂主组日程，HDA+ 分组退火时纳入其分组讨论，无结构耦合。 |
| P4-a/b/c（训练侧） | 正交 | 掩码解码不在其杠杆面；L2 辅助损失不进匹配代价，不毒化 o2o/o2m。 |

**时序声明**：(i) 纸面轮后 G1 立即可跑（CPU、零风险）；(ii) G2 冻结探针可与 P4-d 校准同批执行（同一次 raw dump）；(iii) **绑定兑现实测在 P3-a BAS-CL+ 16K 短训 verdict 之后**（L1 开关是 eval 级开关，搭车其 checkpoint 零额外训练）；(iv) L2 短训严格排在 P3-a verdict 后，从其 checkpoint 热启。全场最省：**L1 一分钟训练都不需要**。

## 附：反候选与本轮放弃理由

1. 全局阈值再扫（已死：0.45 +0.09 / 0.40 −0.13，f1-128k 校准）；
2. 统一形态学/膨缩（F 探针双向变差 0.652→0.476/0.256）；
3. stride-1 画布（+23.2pt 在缺口定义外，训练/显存重写，远期路线——若 G1+G3 后 oracle 残差仍大，这是本场唯一继任者，明示让位）；
4. 软掩码直接导出（破坏 RLE 契约；部署侧另议）；
5. DCT-Mask 全量头当主件（AP_S 仅 +0.5、逐 query 300 系数在 2-3 cell 目标上表达预算错配——其思想被 L2 的 ROI 亚 cell 版吸收）；
6. PointRend/Mask Transfiner 式迭代推理细分（推理迭代×N，Transfiner −35% FPS 锚，超 8ms 预算风险）；
7. DynaMask 式逐实例动态分辨率整头（改动面大、−33% FPS，思想已由 L2 的门控 ROI 借用）。
