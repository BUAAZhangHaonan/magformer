# AP_s 收敛训练协议 — 洞察结论、有效性指标体系与性能方案 (2026-09-15)

## 1. 核心洞察（整合全部两轮赛道 + 六路诊断的结论）

**提高小目标分割指标的 core method 是"三条件同时在场 + 训练长过分数成型点"：**

1. **可画**（表示容量）：mask 渲染网格必须细到小目标拥有 ≥5×5 个格子 — stride-2 画布（oracle 实测：stride-4 上限 0.455，stride-2 上限 0.768；0.47+ 目标在 stride-4 下数学不可达）。
2. **可归属**（空间所有权）：必须有小 SNR 的匹配代价（GT 锚定点集，实测把 64-256px² 分配差从 14.8pt 压到 4.0pt）+ 至少一层注意力能看到 stride-4（实测 query 容量 +14pt）。
3. **可得分**（分数成型）：focal 分类头必须学到给小目标 query 打高分 — **这是训练动力学中最晚成型的环节，是唯一的真瓶颈**。证据链：
   - 微调赛道：四臂 (A0/d1/d2/r2b) 全部 0.27±0.006 — 4K 步动不了 300K 步形成的分数均衡；
   - 机制取证：探针 76% 定位、种子 query 92% 认领，但分数 0.2-0.3 进不了输出；
   - 输出端不可绕过：分数提升扫描 ×1.5~×5 单调变差（低分小检测被 FP 主导）；
   - 从头赛道（16K 步）：设计增益落在已成型区域（AP_m +5.3pt）而未到未成型区域（AP_s +0.64pt）— **小目标分数成型晚于中目标**。

推论：**架构已经够了，再堆机制边际收益低；缺的是训练时长穿过分数成型点。** 本阶段 = 把小模型+设计包训到收敛，用指标面板判定。

## 2. 训练有效性指标面板（比单一 AP 更早反映"设计是否在场、训练是否充分"）

每次评估（每 8K 步 fullval + 离线面板）产出以下指标，全部有既定工具与阈值：

| # | 指标 | 工具 | 健康 = | 反映什么 |
|---|---|---|---|---|
| P1 | 小 GT 拥有率: best-query IoU≥0.5 率分桶 (<64 / 64-256 / 256-1024px²) | matcher_ownership | 持续上升, 256-1024 桶先到 0.8+ | 分数成型前的容量先行指标 (AP50_s 上界) |
| P2 | 分配差: best−matched 拥有率差 (64-256px²) | 同上 | <5pt (d1 已达 4.0) | GT 锚定匹配器在工作 |
| P3 | **分数成型度**: 小 GT 拥有 query 的 cls 分数中位 + 小 TP det 的分数/排名 | seed_slot_analysis / dets 分析 | 分数中位升穿 0.5, TP/FP 分数分离变宽 | **唯一真瓶颈的直接读数** — 它起飞时 AP_s 才会起飞 |
| P4 | AR_s@100 趋势 | rescore (COCOeval) | 单调上升 (AP_s ≤ AR_s) | 检测集合在扩容 |
| P5 | 分桶 AP_s (<64 / 64-256 / 256-1024) | dets 离线分析 | 256-1024 先起, 64-256 后起, <64 最后 | 成型次序应为 大→中→小 (与 16K 步观测一致) |
| P6 | 过拟合哨兵: train-val dice 差 + val AP 回撤 | 训练日志 + 评估 | val AP 平台>3 次评估且 train 仍降 → 早停判定 | subset-4000 上 256 epoch 的过拟合风险 |
| P7 | 探针峰值命中率 (若臂含探针) | seed_slot_analysis | >0.7 | 探针监督在学 |

**判读规则**: P1/P2 先动 → P4 起 → P3 起飞 → P5 跟上。若 P1/P2 已健康而 P3 长期不动, 则"分数均衡是瓶颈"结论被加强（此时下一干预是按尺寸的分数校准目标, 而非更多架构）。

## 3. 训练性能方案（长训前提）

- 单卡实测: 小模型 2.3s/步 (s1b), 全模型 3.0-3.2s/步
- 待测: 双卡 DDP (nccl, bs1×2×ga2 = 同有效 batch 4, 语义与现行配方一致) — 目标 ≥1.8× 单卡
- 微优化待测: depth_backbone 加入 torch.compile 列表; 匹配器 per-GT 循环向量化
- 决策规则: DDP 缩放比 ≥1.8 → 双卡 DDP 顺序跑 (设计臂优先, 基线臂随后); 否则双臂并行单卡

## 4. 第一阶段训练 (256K 目标, 趋势判延)

- 臂: s1c = s1b 配置 (小模型+R1设计包) + max_iter 256K + cosine 256K + warmup 2500 + eval_period 8000
- 基线臂: s0c 同协议随后 (或按 DDP 决策并行)
- 评估面板: 每次评估的 dets 自动快照至 eval_<step>/ 并跑离线面板 (P3-P6); P1/P2/P3 每 16K 步在 checkpoint 上跑 150 图快测
- 过拟合处置: subset-4000 上若 P6 触发且 P3 已平台 → 判定收敛读数, 提前转入全量阶段
