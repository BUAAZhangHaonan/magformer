## Decision

R86 fails the pass gates.

The target result is close to R80 on bbox but lower on segm AP and AP75. The original first50 source sanity collapses, which is consistent with R86 changing the source anchor to 32K_512 geometry. This run should be recorded as a source-scale 32K_512 diagnosis, not as a replacement for the original 32K_1024 source experiment.
