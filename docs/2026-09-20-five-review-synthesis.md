任务：用户决策 128K 停训封存 F1、转测新算法后，在等待窗口开 5 路独立子智能体审阅，找出当前训练已暴露、AIM 未解决的堵点，按严重度列表并指认根因，作为下一步优化方向。

数据基础：F1 @ 112K（segm mAP 0.8692 / trainer 口径 AP_s 0.2638 / rescore 口径 0.2925），天花板 E3 stride-2 = 0.768，缺口 47.6pt（rescore 口径）。五路：R1 得分与排序 / R2 掩码质量与 IoU 结构 / R3 召回与查询容量 / R4 训练动力学 / R5 数据密度与增广。报告与复现脚本在各 `r*/` 子目录。

主进程已亲自复核两个最重的代码级发现：`matcher.py:219/287` 的 `sel = sel[:16]` 截断属实（AIM 与旧 grounded 路径都有）；`gpu_postprocess.py:210` 的 `binary_masks = mask_probs > 0.5` 硬编码与 maskness 乘法打分属实。

已被证伪/排除的假设（防走错路，同样重要）：
- **"小目标 TP 分数仍在成熟"——否**。24K→112K 全历史斜率 -0.003/8K（持平 88K 步）；且 0.41 是前 1200 图子集读数，全 val 实为 0.29。任何把小目标分数整体抬高的后处理都让 FP 搭车（<64 det 池 hard-FP 80.5%、AUC 0.49-0.75）：分位重标定 −13.1pt、score=IoU "完美排序" −11.9pt。打分维度可兑现总量 ≤2pt。
- **"c0 112.5K→141K AP_s 停滞"——从未测过**。c0 eval_period=37500，该区间 0 个 val 点（R4 查证）。此前引用为"停滞"是错误外推，本文更正。
- **重复/摊薄不是堵点**。每小 GT 均值 1.30 个 det，oracle 去重 −0.25~+0.26pt（R1/R3 两口径一致，R1 的 14.05 计的是含低分全池）。
- **查询/检测槽容量不是堵点**。每图小 GT max=26 ≪ 200 queries；密集图加权差仅 ~0.9pt；稀疏图 AR_s 也仅 0.319。
- **多尺度增广近中性**。<64 可见数 −22% vs 相对份额 +17%，近似对消；压碎（<8px）仅 9.7% 曝光。
- **深度弱对比度是上限约束非 bug**。小目标内外深度差 p50 ≈1.5σ 噪声；clip 饱和仅 0.03%。这反而要求 P2 修复时必须连深度一起 paste。

## 三、根本问题（一段话）

AIM 修好的是"**分得对**"（assignment），但当前瓶颈变成了三件事：**看得少**——有效 batch=4 每步只有 0.85 个可见 <64 GT、0.1-0.4% 梯度份额，数据侧增密通道（copy-paste）又被 depth 缺字段整体堵死；**画不精**——512 画布上已检出小目标的掩码内容质量一项就有 27.1pt 反事实上限，点采样监督对边界无约束；**切得早**——AIM 数量帽砍掉一半覆盖、topk-100 在 mask 融合前砍掉存在性。训练信号在当前协议内已耗尽（ce/mask/dice 自 24K 统计平坦，仅 giou 慢降），继续原配方到 256K 只有 ~1pt 退化收益。**要重新激活增长，必须加信号、恢复设计意图、解锁人为上限——三件事都不贵；掩码内容 27pt 才是通往 2× 目标的下一场战役。**

## 四、下一步方向（分阶段，供决策）

- **Phase A｜廉价解锁（封存后 GPU 空闲即做，合计 ~2h）**：topk-200 重推理（预期 +0.5~1.5，c0 有 +0.55 实测锚）→ 二值化阈值 0.45/0.40 扫描（~0-1）→ raw 权重对照 eval（0.1-0.3）→ AP_s-best checkpoint 并存。产出：F1 的诚实终值。
- **Phase B｜收尾对照臂（15.4h×4 卡，R4 强烈建议）**：封存副本 128K→160K 快速余弦收尾（max_iter 改 160K）。建立"更多步数+退火"对照线（中心 +1.0~1.25）——新算法预期效应（+0.3~0.8）与退火收益同量级，**无此臂则不可分**。
- **Phase C｜代码修复（与 B 并行写码，不占卡）**：AIM 去帽（分块向量化，1 天，带 >16 GT 单测）；copy-paste 深度修复+参数（bank≥2000、max_paste 12-20、warmup，1 天）；顺带 P9 死键处理。
- **Phase D｜激活臂（从封存 128K 起步，B 之后上卡或排队）**：AIM-fix + copy-paste + topk200 组合 finetune 32-48K 步。判据：相对 B 对照线**净增 ≥+1.5pt** 才确认"新算法激活增长"成立并继续加码；未达线则回诊（首选怀疑掩码内容路径）。
- **中长期**：P3 掩码内容战役（边界敏感监督/掩码-分数解耦，27pt 上限）与 P6 门控全层（+1~3）作为下一轮斗兽场主题；通向 0.472（2×）必须动 P3——已识别杠杆的现实合计（+3~7）到不了 2×，这是诚实的差距。
