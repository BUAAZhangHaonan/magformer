## 1. 论文实际主张（全文精读）

- **病理**：模态失衡——各模态收敛速率不同 → 单模态预测失配 → 弱模态被抑制，
  多模态甚至不如单模态（其引证 [8,9] 即 Ogm-GE/G-Blend 一系）。
- **机制三级**：硬对齐（单模态辅助头 + 单模态损失，ŷa,ŷv ⇝ y）→ 软对齐
  （预测级：单模态预测与均值的 KL 一致性，无监督，式 7）→ 表示级
  （InfoNCE 对比拉近配对样本特征，式 8）→ 混合级。
- **动态调度**：对齐前期重（先降跨模态差异）→ 后期转任务融合；启发式与
  双层优化两种调度，后者带收敛性证明。
- **证据域：仅分类基准**（KSounds/CREMA-D/Sarcasm 双模态 +0.6~2.7%，
  NVGesture/IEMOCAP 三模态 +1.35/+0.65%）；JS 散度与模态性能差相关。
  **无任何密集预测（分割/检测）实验。**

## 2. MAGFormer 是否具备迁移前提——不具备（核心判断）

1. **失衡病理不成立**：项目实测 RGB-only 59.52 vs RGB-D 68.42（深度 +8.9pt，
   BASELINE_RESULTS.md），深度是主要增益源而非被抑制的弱模态；深度塔质量本身
   另值 +5.2pt（convnextlite 65.45 vs nodpth 59.52）。
2. **外部旁证**：密集预测域多模态普遍大幅优于单模态（CMNeXt 在 DeLiVER
   四模态 66.30% vs 单模态 +9.10pt，arXiv 2303.01480）——与 magformer 一致，
   无"多模态不如单模态"病理。对齐类机制在密集预测的成功案例集中在
   **模态缺失/退化**场景：DMAF-Net（2506.11691，不完整多模态医学分割）、
   SGMA（2603.02505，不完整多模态遥感）、SAMDA（2403.07951，域适应）、
   ScatterNet（2404.12861，弱监督）、MoBaNet（2603.17705）、AVSAC（2402.02327）。
   即：**对齐救的是退化的模态，不是干净的互补双模态**。
3. **MAGFormer 的真实堵点不同**：不是"弱模态没被激活"，是"融合机制不如
   concat"（concat 0.91 mAP / 0.354 APs > 全部学习式融合 0.87 / 0.27）——
   这是融合质量问题，对齐的靶点（激活弱模态）与之错位。

## 3. 与项目历史硬证据的三次正面冲突

1. 30+ 优化模块全败；学习式融合族整体 < 简单 concat。对齐的自然落点
   （让学习式融合更好用）建立在项目已证伪的地基上；8 月跨模态辅助训练家族
   （塔蒸馏/旁路蒸馏，0.8439-0.8459）全部落在 0.84-0.86 家族带内。
2. 噪声带体制：128K 冻结基座上 4K 步微调 ±0.006 内任何训练侧目标不可分辨
   （EVIDENCE §7 + 2026-09 两提案战役四臂独立复现）——验证对齐损失只能
   从头/长训，一次验证 = 全量训练成本。
3. 动态对齐-融合调度（尤其双层优化）是 bass 教训的形态：多机制耦合的训练侧
   设计，失败时无法归因（B1' 归因案花了三个单变量审判臂才闭合）。

## 4. 结论与唯一口子

**结论：不适合迁移。** 前提（失衡病理）在 magformer 实测中不成立；论文证据域
（分类）与 magformer 域（RGB-D 密集实例分割）差异大；密集预测域的对齐成功案例
集中在模态缺失/退化场景；且与项目自身全部硬证据方向相反。

**唯一值得留档的可迁移形态**（若未来重启）：表示级对齐 + 简单融合——
两塔特征加训练期 InfoNCE 空间对齐损失（正对 = 同空间位置特征），融合保持
concat。零推理开销、零融合结构改动，不重蹈"学习式融合"覆辙。其隐含假设
（塔间特征空间失配是融合损失来源）从未被项目实验直接检验——但按噪声带证据
与 DPE 仅 +0.9pt 的量级先验，期望收益低，验证成本 = 一次从头长训。
预测级软对齐需每模态独立预测头（架构改动），不推荐。
