## 结论摘要（≤10 行，直接回答三个最终问题）

1. **(a) 128K 停训放弃的期望收益: 中心 ≈ +1.0~1.25pt AP_s (区间 +0.1 ~ +1.9)**。三模型外推 (幂律 +1.25 / 对数 +1.88 / 老 128K 家族后半程锚 +0.83) 中位 +1.25; 128K 落点估计 0.268 (0.264~0.271), 256K 终点 0.278 (0.269~0.287)。**新算法对照线应取 0.268 并标注 ±0.8pt 不确定度, 或直接跑下面的收尾臂消除它。** 战略上无关: 距 2× 目标 0.472 还差 ~20pt, 尾部收益不改变任何路线决策。
2. **(b) 增量衰减的主导机理 = "lr 中段噪声平台上的信号耗尽", 不是容量饱和, 不是 EMA 假象**: AP_s 相关的 ce/mask/dice 分量自 24K 起 88K 步内**统计平坦** (无权重 OLS 斜率 t=-0.2~-0.7), 唯一仍显著下降的是 giou (定位, -0.0020±0.0006/8K, t=-3.2) — 与 bbox_APs 仍在 +0.06pt/8K 而 segm 侧停滞一致; train loss 平坦 (24K) 比 AP_s 增量衰减 (~96K) 早 ~70K 步, 是"噪声球内慢漂移"而非"loss 降完 metric 跟完"。
3. **(c) 值得跑 128K→160K 快速余弦收尾对照臂 (32K 步 ≈ 15.4h, 4 eval)**: 它把本报告最大的不确定度 (整个证据库**没有任何 256K/300K 日程的 50%~100% 段数据**) 变成数字; 新算法预期效应 +0.3~0.8pt 与退火收益 +0.5~1.3pt 同量级, 无此对照臂则二者不可分。144K (7.7h) 太短——EMA 半衰期 6.9K 步, 需 ≥2 个半衰期才能让 val 反映退火后权重。
4. 关键事实纠偏: **c0 "112.5K→141K AP_s 停在 0.2360" 是无测量断言** (eval_period=37.5K, 该段 0 个 val 点, train loss 同样平坦+噪声); s1c/s0c 实际死于 98.2K/105.5K (38%/41% 日程), 均未覆盖后半程; F1 的 lr 峰值 1e-5 只是主组, **hires 组 (stride-2 头+末层 cross-attn, 设计包核心) 20× = 2e-4 峰值, 112K 仍 1.21e-4**。

## 详细分析（每堵点: 方法→数据→数字→根因链）

### 堵点 1+2: F1 训练动力学全量解析与停训点核算

**方法**: 解析 F1 metrics_log.jsonl 全部 2270 条 train 行 (log_period=50, 覆盖 0-113.6K) 与 14 条 val 行; 按 8K 步分桶统计各 loss 分量均值/标准差; 用无权重 OLS (桶均值, 残差 stderr) 检验 24K 后各分量斜率; 核验 cosine_scheduler.py 逐点 lr 公式与 train.py 参数分组。

**数据→数字**:

(1) **loss 分量趋势** (8K 桶均值, 24K→112K 无权重 OLS):

| 分量 | 斜率 (/8K) | t | 判定 |
|---|---|---|---|
| train/loss (总) | -0.038 ± 0.224 | -0.2 | 平台 (桶间残差 std 2.4) |
| loss_ce (最终层) | -0.0008 ± 0.0046 | -0.2 | 平台 (桶均值 0.25-0.45 振荡) |
| loss_mask | -0.0004 ± 0.0005 | -0.7 | 平台 |
| loss_dice | -0.0001 ± 0.0005 | -0.2 | 平台 |
| loss_giou | **-0.0020 ± 0.0006** | **-3.2** | **仍显著下降** |

深监督 7 层同形态: 最终层 ce (L6) 64K-104K 稳定在 0.34-0.36, 各层同涨同跌 (相关噪声, 数据顺序效应)。**没有一个 segm/cls 分量还在降; 唯一存活的是定位分量 giou** — 与 val 侧 bbox_APs 仍 +0.06pt/8K (0.3268→0.3274) 而 segm_APs 停滞、segm_ARs 已停 (0.3091→0.3086) 完全一致。

(2) **grad norm / AMP**: preclip gradnorm 中位 ~1200-1400, clip_value=1.0 full-model → 100% 步被裁剪, 有效更新=lr×单位方向向量 (Deformable-DETR 式); AMP skip 累计 50/113.5K = **0.044%**, nonfinite_grad_count=0, amp_scale 0.0625-0.6 自适应正常。AMP 无罪。

(3) **lr 位置核算** (cosine mult=0.5(1+cos(π·(s-2500)/253500)), 逐点与 logged 值对账误差 <2%):

| **128K** | **49.5%** | **5.08e-6** | **1.02e-4** | — (停训点) |

(4) **两种对齐的增量表** (AP_s, pt/8K 等效):

| 对齐方式 | F1 (256K 日程) | c0c (300K 日程) | s1c/s0c (256K) | 老 128K 家族 (32K optimizer 步日程) |

| 日程% ~85-100% | **无数据 (决策风险核心)** | 无数据 | 无数据 | **+0.11~0.13/4K = +0.22~0.26/8K; 后半程合计 +0.71~0.83pt** |

关键读法: **F1 在 112K 步处的每窗增量 (+0.21±0.09) 已等于老家族在其 85-97% 日程段 (退火尾段) 的速率** — F1 用了 3.5× 于老家族全程的 optimizer 步数就到达了同样的"末段速率"。这说明增量衰减主要由**累计步数 (数据量) 驱动而非日程分数驱动**; 日程% 对齐会系统性高估 F1 的剩余空间 (同分数下 F1 已多喂 8× 数据), 绝对步数对齐则高估其 lr 位置可比性 (老家族终点 lr≈0, F1 当前 6e-6/1.2e-4)。**c0 在 37.5-47% 的"停滞"不能外推到 F1 的 50-100%**: 一是 c0c 该段根本无测量 (堵点 5), 二是即便信其 train loss 平坦, F1 的 train loss 从 24K 就平坦而 AP_s 之后又涨了 3.7pt — 平坦≠无收益。小模型臂同样给不出后半程证据 (死于 38%/41%)。唯一实证过"后半程+退火"的是老 128K 家族: **后半程 +0.71~0.83pt (占总增益 30%), 末 1/4 +0.24pt** — 即退火尾段有真实但有限的收敛收益, 从不为零。

(5) **外推** (128K→256K, 16 个 8K 窗):
- 幂律增量拟合 (≥20K): inc=1.39e5·s^-1.187 → **+1.25pt**
- 对数曲线 (≥56K): AP_s=-0.0511+0.0272·ln(s) → 128K→256K **+1.88pt** (对数拟合在减速曲线上系统性偏乐观)
- 老家族形状锚 (速率已匹配老家族末段): **+0.83pt**
- 悲观 (增量跌到噪声底 ±0.05/8K): **+0.10pt**
- **中心 = +1.0~1.25pt**; 128K 落点 0.2681 (0.2645~0.2709, 由最近 3 窗均值 +0.21/8K 外推两窗, 注意 120K/128K 两个 eval 会先落地, 届时用实测替换)。

根因链: 每步方向归一化更新 × 高 lr (尤其 hires 20×) → 权重常驻半径 ∝ lr 的噪声球 → segm/cls 损失面在当前协议下的可达集合于 24K 附近探索完毕 → 此后 AP_s 增量来自噪声球内慢漂移与 EMA 平均化 (+0.3~0.5/8K, 逐步衰减) → 日程后半的增量主要来自 lr 退火带来的噪声球收缩 (老家族实证该部分为 +0.2~0.85pt 量级) → 128K 停训冻结的是未退火的 EMA 均值, 放弃的中心估计 ~+1.0pt。

### 堵点 3: hires 20× 组的动力学含义

train.py:705-759: hires_dw/hires_proj/hires_shuffle + small_probe/seed_proj/seed_norm + **最后一层 cross_attention** 全部 20× = 2e-4 峰值。这恰是设计包小目标能力的主要载体 (stride-2 头、末层细注意力)。后果: (i) 这些模块的噪声球是主组的 20× lr 半径, 桶间 loss 均值振荡 (ce 0.25-0.45) 与 112K 桶的 ce 反弹 (0.326→0.429, ~2σ) 与此一致; (ii) AP_s 增量在 104-112K 塌到 +0.04 (噪声底) 可能部分是 hires 组噪声淹没信号, 而非信号真尽; (iii) 128K 冻结点时 hires lr 仍 1.02e-4 — 该组从未经历过低 lr 区。修复方向: 收尾臂里对 hires 组提前/加速退火。此堵点与堵点 2 是同一枚硬币的两面 (信号耗尽 vs 噪声淹没), 收尾臂可同时检验。

### 堵点 4: EMA 滞后量级

代码核验 (trainer.py:1660-1699, model_ema.py): **eval 100% 用 EMA shadow 权重**, best.pt 存 EMA 权重 + raw backup; EMA decay 0.9999 带 2500 步线性 warmup。半衰期 ln2/1e-4=6931 步; 指数核均值滞后 9999 步 ≈ 1.25 个 eval 窗口。量级估计: (i) 对线性趋势, EMA 水平滞后 = 速率×9999 ≈ 0.28pt/16K × (10/16) ≈ **0.18pt**, 但增量一阶抵消 (只时移); (ii) 对减速曲线, EMA 增量 [104,112]K 实际反映 ~[94,102]K 的真实速率 — **观测值偏乐观, EMA 不会制造虚假平台** (方向与"EMA 压制增量"的担忧相反); (iii) loss 噪声带 (桶内 std ±22-27, 单行 50 步粒度) 远宽于任何 EMA 口径差 — 增量衰减不是 EMA 伪影; (iv) 残余风险在停训点本身: 128K 的 EMA 整合的是 hires lr ~1.0e-4 高噪声期权重, 若退火, EMA 需 ~2 个半衰期 (14K 步) 重新 settle — 这是收尾臂必须 ≥16K 步的原因。免费动作: best.pt 内含 raw backup, 一次重评即可分离 EMA 效应 (~15min GPU, 由有 GPU 权限的人执行)。

### 堵点 5: 决策前提的两处事实纠偏

(i) c0_corrected_300k: metrics_log.jsonl 中 val 仅 3 点 (37.5K/75K/112.5K), eval_period=37500, 下一个 eval 本应在 150K — **112.5K→141.25K (被杀) 段不存在任何 AP_s 测量**; 其 train loss 112-136K 桶在 36.9-41.9 间振荡 (ce 0.43-0.59), 与 F1 同样是"平坦+噪声", 既不支持也不否定停滞。(ii) s1c/s0c 实际停止于 98.2K/105.5K (2026-09-18 13:51, 为 F1 让路), 日程 38%/41% — briefing 的 "~120K" 不准确; 两臂增量都在衰减 (s1c 88-96K +0.23, s0c 96-104K +0.20), 设计臂优势 (+3.37pt@96K) 是全程早期拉开的, 对"后半程还有没有"不构成证据。

### 续训对照臂设计 (问题 c 的落地)

从封存的 128K checkpoint 副本续跑, config 改 max_iter=160K (LambdaLR 按新 horizon 重算: 128K 处 mult≈0.099, 主组 lr 从 5.08e-6 跳到 ~1.0e-6、hires 组到 ~2.0e-5 再余弦到 0 — 即"快速收尾退火"), eval_period 保持 8K, 跑 32K 步 ≈ **15.4h** (当前实测 2.08K 步/h 含 eval)。产出: 4 个实测点直接回答"退火+更多步数值多少 pt", 把对照线不确定度从 ±0.8pt 压到 ~±0.15pt。判读规则: 新算法臂 (从 128K 副本同协议出发) 必须**显著超过收尾臂的 160K 终点**才算算法效应; 若收尾臂 +≥0.5pt, 则 128K 冻结基线系统性低估, 所有旧对照需重锚。不值得的情形: 若新算法实验本身需要 4 卡立即满载且不可排队, 可放弃, 但必须把 ±0.8pt 写进判读规则。144K 版 (7.7h) 不推荐: EMA 半衰期 6.9K 步, 16K 步仅够 EMA 刚开始反映退火权重, 读数会低估退火收益。

## AIM 覆盖度说明（动力学维度 AIM 解决了什么/残余什么）

**AIM 已解决的 (动力学侧)**: EVIDENCE §8 的裁决 — matcher 列由噪声决定 (dice 代价信噪比 0.3-2.4 vs 背景噪声 ±1.9) → AIM 用尺度无关 soft-Dice 统计量 + bbox+30% 窗口确定性精确计算, margin 2.43σ (19×), 多数小 GT 列退出掷硬币区。在训练动力学上, 这直接削减小 GT query 的**分配方差**, 进而削减其梯度噪声 — 是"query 稳定持有→分数成型"链条的使能器 (F1 config: matcher_small_gt_mode: aim, aim_w_bce: 0, 1.72ms/次, 推理 0ms)。

**AIM 未解决的 (本报告实证的残余)**: (i) **宏观收敛形状不变** — F1 (带 AIM) 的 loss 平坦 onset (24K)、增量衰减轨迹、末窗噪声底 (+0.21±0.09/8K) 与无 AIM 的家族基线 (c0c +0.14/8K@37.5%, 老家族 +0.22-0.26/8K@末段) 同形态, AIM 没有改变"何时进入噪声平台"; (ii) **lr 位置/噪声球动力学** — 20× hires 组与中段高 lr 平台是 AIM 之外的变量; (iii) **表征容量** — stride-4 oracle 上限 0.455, F1 当前 0.264 只用 58%, 缺口在表征/头侧不在分配; (iv) **分数校准流** — 分数起不来是微调赛道定位的卡点, AIM 不直接作用。结论与 EVIDENCE §8 一致且经 F1 动力学加固: **AIM 是稳定性使能器而非主引擎; 增量衰减的机理在本报告判定为"协议内信号耗尽+噪声平台", 属于 AIM 覆盖范围之外**。新算法若要超越 0.268±0.8 的对照线, 需要作用于可得分条件本身 (表征/分数/数据), 而非再降分配方差。
