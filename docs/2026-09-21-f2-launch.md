# F2：完整版 + 七胜出者 256K 从头训练 — 发射记录

日期：2026-09-21 ｜ 状态：配置就绪 + 冒烟进行中，等待 G1 判读后发射

## 1. 谱系与决策

- **F1**（`f1_full_design_256k`，2026-09-18 发射，09-20 用户决策 128K 停训封存为 `p5_runs/f1_seal_128k`）：完整架构 + 设计包（min_scale 0.5 / 4 特征层 / stride-4 / mask_stride2_head / topk 2.0+64+only_stride4 / scale_balanced / hires 20×）+ AIM 匹配器。终点 segm AP 0.8744 / AP_s 0.2698（校准口径，EMA）。
- **F2** = F1 配置 **+ 七场斗兽场胜出者（训练侧五件）**，其余逐字节一致；ImageNet 从头初始化（tower 权重 + `model_init.pth` 头），**不加载 128K seal**（用户决策：8K 即可达 80+ AP，起点更干净；`f1_seal_128k` 永久保留在盘）。
- 胜出者键值**逐字复制**自 G1 B1 合并臂（16K finetune 验证协议）：
  - BAS-CL+（P3-a）：`bass_enabled`（含三段采样/coverage 软标签/带加权 BCE/带 Dice，schema 默认参数）
  - MAL-CP+（P4-c）：`mal_enabled` + `mal_scale_in_ce` + copy_paste 块（bank 2000 / max 12 / prefill 800 / tiny 0.60 / small 0.25 / crop 192 / SNR 0）
  - mCDN+（P4-a）：`dn_enabled` + scalar 3 / noise 0.3 / `dn_max_gt_cap 8`（DN 槽位恒 32，DDP 安全）
  - SCB+（P4-b）：probe + seed 64 + prior-all-layers + `seed_ramp_iters 4500` + `seed_dropout 0.15`
  - HDA+（P3-c）：`hires_mult_anneal`（分数窗口 [0.1, 0.5]，256K 即 25.6K→128K 线性退火 20×→1×）
  - TREX+（P4-d）/ ACB（P3-b）：推理侧，非训练键；发射后对 F2 checkpoint 离线验证（Gate 0 位等 / Gate A AUC / Gate C ΔAP_s≥+0.30；ACB 链模拟 G1≥0.815）。
- ramp 取值原则：分数型调度自动缩放；绝对步数 ramp 保留 B1 验证值（均为早期稳定性目的：bass 2000 / mal warmup 9000 前向 ≈1000 优化步 / seed 4500 / probe warmup 300）。

## 2. 训练协议

256000 优化步；4-GPU DDP（GPUs 4,5,6,7，端口 29516）每卡 bs1 × accum 1 = 有效 batch 4（与 c0/F1 完全一致，LR 无需重调）；lr 1e-5 cosine，warmup 2500，backbone_multiplier 0.5；AMP + EMA 0.9999；eval/ckpt 每 8000 步全量 val 3276；compile [fusion, rgb, depth]（warmup 失败自动降级 eager，见 §4）；`find_unused_parameters: false` + `ddp_broadcast_buffers: false` + `gradient_as_bucket_view: true`（commit 98d327f6 的 DDP 修复）。
判读锚：F1 同期轨迹（8K: 0.7928 AP / ~0.21 AP_s 一带，来自 F1 metrics；首个 8K eval AP>0.1 为健康门）；c0 fullval 0.8603/0.2642、F1@128K 0.8744/0.2698 为收敛参照。

## 3. 发射前置门

1. **合并冒烟**（200 步 × {4-GPU DDP, 单卡 accum4}，GPUs 0-3）：正确性 = 两者 loss 轨迹对齐（<5% 窗口均差）+ 评估/存档链走通；吞吐门 = 4 卡 images/s ≥ 2.2× 单卡。
2. **G1 判读**（B1 vs A0，16K，预注册门 +1.5pt AP_s）：B1@4K − A0@4K 配对 + B1 轨迹单调性；灰区则推迟发射至 A0 补全后全配对（见 EVIDENCE.md §11 事故记录）。
3. 冒烟已捕获并修复一个集成 BUG：DN 行未从 `pred_boxes` 剥离 → 匹配器 200-vs-232 行崩溃（commit 44c7b7b8，含 3 个回归测试；此 BUG 若未发现将在 B1 第 1 步击杀整臂）。

## 4. 已知问题与对策

- **compile warmup OOM**（24GB 卡，winners 全开时 warmup 峰值超限；`expandable_segments` 本平台不支持）：trainer 逐模块重试后仍失败则**优雅降级 eager**（不阻塞训练）。后果 = 步时 ~+10-15%（eager ~1.5-1.7s/it vs 编译 ~1.38）。发射不为此等待；若 B1/F2 实测 eager 步时可接受即维持，否则在首个 ckpt 周期后评估 compile 子集（如仅 fusion）。
- **单 4-rank 束铁律**（251GB 主机）：任何时刻仅一个 4-rank 训练束（EVIDENCE.md §11）；F2 发射后 A0 补全用单卡 accum4（~50GB，可并存）。
